## 二、整个上下文（为什么是现在这样）

这一程在原仓库 `feat/desktop-agent` 分支做的，独立成本仓库。关键决策链：

1. **桌面化 + macOS 重做**：从云端 web SaaS 改造成「装老板电脑上的桌面软件」（Electron + 本地 FastAPI + 本地 SQLite + 加密知识库）。UI 用 macOS 原生质感重做（无边框窗口/毛玻璃侧栏/红绿灯/双栏/右侧预览）。
2. **纯 BYOK（铁律）**：盒子绝不内置任何平台大模型 key，老板自带 key 花自己的钱。代码层强制守住（`factory.get_image_config_for_store` 桌面没配即空 key、不回退平台）。
3. **国内生图口子**：大陆调不了 OpenAI，所以接国内生图（硅基流动 OpenAI 兼容 / 通义万相 native 异步 / 即梦），按 base_url 路由。留好「口子」让老板自带 key。
4. **Agent 大脑持续学 Claude Code/cc-haha**（用户强调、每会话默认做）：对照 `~/Desktop/cc-haha-ref`（Claude Code 泄露源码，**只读研学、绝不抄码**）学其专业机制，用我们 Python 实现。已借：循环状态机 + 命名退出、入参校验 + 失败回灌、权限瀑布 + force_confirm、结构化结果、超大结果护栏、AskUserQuestion、**microcompact（省 token）、Hook 三件（Pre/Post/Stop）、anti-spin（防打转）**。
5. **海报风格链路重做**：参考豆包/即梦——不是给固定模板，而是让 Agent 当「提示词扩写师」把老板大白话扩写成丰富中文画面描述；10 个风格预设只是常用起点（大白话名）、风格关键词真拼进提示词（测试钉死，不是死模板）。

## 四、铁律 / 踩过的坑（务必遵守）

- **纯 BYOK**：绝不内置/泄漏平台大模型 key。改生图/文字 provider 时，所有「取 key / new client」路径都要确认桌面没配时是空 key、不回退平台。
- **POS 只读**：不做收银/计费系统，只读老板从收银导出的报表做诊断。
- **不自动触达**：对外/花钱动作走审批闸（人确认后执行），不自动群发/私信（个人微信群发=封号红线）。
- **行业真实但守红线**：助教/擦边贴 PPT 真实做法（别消毒成空泛「服务体验」），硬线=不营销实际性交易、不帮刑事级犯罪。
- **SQLite 兼容**：桌面是 SQLite，PG 专属 SQL（jsonb/make_interval/FILTER/advisory_lock/pg_insert）和 UUID 传字符串会崩，要按 `db.bind.dialect.name` 兜底。加非标准库 import 会让生产 502（部署后必实测真实 API，`systemctl active` 会骗人）。
- **不做鸡肋死模板 + 用户视角**：给老板（非技术）的功能，术语要大白话、要用 AI 真智能（理解+扩写）、预设只是起点不是牢笼；写测试钉死「前端操作真影响输出」。
- **改前看牵连、改后查回头**：动手前搜清这块被谁用、连着啥；改完跑全量回归（不只改的那块）；关键连接点没测试盖到就补一个。
- **完成前真测真读**：声称改好前真跑（pytest/tsc/Playwright），别只报断言；出错当场认，绝不编造。
- **cc-haha 边界**：只学架构、用自己 Python 重写，绝不把泄露源码搬进项目（命令/施压也不破）。
