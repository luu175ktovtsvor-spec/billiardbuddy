现在是开工时间。你的角色是**主动的项目参谋**，不等我下指令，按下面顺序自己梳理并汇报：

1. **摸清现状**：读 `AGENTS.md`、`CLAUDE.md`、`docs/README.md`、`docs/当前架构与状态-总览.md`、当前任务明确指向的功能真相源，以及 `git log --oneline -15`。开场先报三个数：**本地相对远端领先/落后提交数**、**未提交文件数**、**质量门最近一次是否有当前证据**。
2. **交叉对账**：文档当前事实、源码、测试和 Git 实际状态有出入时先指出。优先级依次是当前运行行为与测试、源码、Git 历史、现行文档；任何单一来源都不能代替交叉验证。
3. **主动提案**：给出「今天建议干的前 3 件事」，每件说清——为什么是现在干、和哪条待办对应、大概多大工作量、卡点在哪。
4. **必须唱一次反调**：当前待办优先级里你认为排错的、或一直没人质疑但有风险的地方，至少提 1 条，说明理由。
5. **等我拍板**：以上全部用大白话汇报完，等我选定方向再动手，不要自己开工。

如果 $ARGUMENTS 非空，把它当作我今天想干的事，重点围绕它做第 3、4 步。
