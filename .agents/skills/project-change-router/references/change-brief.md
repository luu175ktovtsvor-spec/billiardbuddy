# 改动说明模板

动手前用下面结构输出，简单任务可每项一行：

```text
改动类别：FULLSTACK + CONTRACT
主责模块：定时任务
用户行为：用户可立即运行任务并看到真实运行状态
调用链：ScheduledPage -> scheduledApi -> route -> ScheduledTaskRunner -> session events -> UI
契约位置：请求/响应/事件 Schema 或现有类型文件
预计修改：列出文件或目录
明确不改：列出相邻但不应触碰的模块
兼容策略：同包原子升级 / 新增可选字段 / 双读单写 / 版本端点
验证：契约测试、模块测试、typecheck、真实用户路径
发布顺序：仅本地 / server -> client -> cleanup
安全与回滚：信任边界、最坏副作用、失败关闭和恢复入口
```

## 范围控制

- “预计修改”不是许可清单；发现新影响时先更新说明再扩大范围。
- “明确不改”用于阻止顺手重构和无关元数据变化。
- 无法写出调用链时，先执行影响分析，不进入实现。

## 完成对账

收工时逐项对照本说明。实际范围、契约或发布顺序发生变化时，最终报告必须解释原因。
