### ⚠️ 还要注意 / 没完全收尾

1. **M1-2 错误路径"代码合了但没被 E2E 跑到"**。S3 是成功路径,没触发到出错分支。
   出错时新逻辑(先落库已产成品 + 补发 done(stopped_reason=error) + 前端不加空气泡)才会走到。
   → **以后有机会真触发一次生成错误**(如断网/key 失效/模型报错)**,确认成品确实落库、前端 spinner 正常收**。

   前端是构建产物(standalone),**必须 rebuild + 重打 dmg** 才生效。下次发版务必带上。

3. **M1-4 未修(低优先级)**:无 `is_disconnected` 早退。客户端中途关页/切会话后,
   后端循环仍跑完整任务(白烧算力/token)。→ 用户中途取消时后端不会立刻停,留意成本。

4. **M1-5 未修(低优先级)**:出错那一轮学习器仍可能照跑,把失败内容当门店事实学进去(低频污染)。

5. **keepalive 间隔 ~5s(33 × 0.15s 轮询)**。当前 `:3100` Next 代理验证 OK;
   若以后换更激进的反代/网关、空闲超时 < 5s,需把这个阈值调小(`loop.py` 里 `_ka >= 33`)。

### ⚠️ SQLite 时区坑(记一笔,后人别再踩)
`Generation.created_at` 是 `DateTime(timezone=True)` 以 UTC 存,但 **SQLite 上 DateTime 丢 tzinfo**、比较退化成字符串比。凡按"北京月/日"聚合的查询,**起点必须先 `astimezone(utc)` 再比**,否则月初/日初东八区那几小时错分。PG 不犯(带 tz),桌面 SQLite 犯。`quota_service._period_start_now` 和新 `quota._month_window` 是正确范本。
