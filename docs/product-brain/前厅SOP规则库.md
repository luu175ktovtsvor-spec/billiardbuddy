# 前厅 SOP 规则库

---

## 1. 前厅业务定义

### 1.1 前厅是什么

前厅是台球房客户到店后的第一触点，负责从客户进店到离店的全流程接待服务。前厅的转化能力直接影响门店的团购客户转化率、客户留存率和好评率。

### 1.2 前厅负责什么

- **接待**：客户到店迎宾、引导选台、介绍服务
- **团购核销**：美团/抖音团购券核销与接待
- **加微信**：引导客户添加门店/前厅微信，为私域运营打基础
- **进群引导**：引导客户进入门店微信群
- **客户解释**：台费说明、会员卡介绍、助教服务介绍、排队说明
- **忙时排队**：满台时客户排队管理和安抚
- **投诉安抚**：客户不满或投诉的现场处理
- **离店跟进**：客户离店后的感谢和二次邀约
- **卫生执行**：店内环境、台面、器材、卫生间的日常清洁
- **开店闭店**：每日开店准备和闭店收尾工作
- **前厅日报**：每日前厅工作数据汇总

### 1.3 前厅岗位价值

- 团购客户到店后能否加微信、进群、二次到店，前厅说了算
- 前厅服务水平直接影响美团/抖音好评率
- 前厅是门店形象的第一个展示窗口

## 2. 前厅典型场景

### 2.1 团购核销话术

- **时机**：客户到店出示团购券时
- **目标**：核销顺畅 + 自然引导加微信 + 为后续转化铺垫
- **话术要点**：先确认订单→核销→简单介绍→引导选台→自然提加微信
- **示例方向**：“您好，团购券我帮您核销一下。这是您的台号，我们这边环境您可以先看看。方便加个微信吗？后面有活动或者优惠我第一时间通知您。”
- **转化衔接**：团购核销不是终点，是加微信和私域转化的起点

### 2.2 新客加微信

- **时机**：客户到店时/打球中/离店前
- **目标**：自然获取客户微信，不给客户压力
- **话术要点**：给出加微信的合理理由（活动通知/预约方便/福利群/赛事信息）
- **示例方向**：
  - 到店时：“加一下我们微信吧，以后想打球可以直接微信预约台位，不用等。”
  - 打球中：“加个微信，我们周末经常有比赛和活动，到时候通知您。”
  - 离店前：“加个微信吧，下次来之前跟我说一声，帮您留台。”
- **不要**：强制加微信、加微信后立即推销

### 2.3 进群引导

- **时机**：加微信后或客户表现出社交/打球需求时
- **目标**：引导客户进入微信群，增加客户粘性和触达渠道
- **话术要点**：说明群的价值（约球搭子/活动通知/福利信息）
- **示例方向**：“我们有一个会员群，里面都是喜欢打球的朋友，经常约局。拉你进去吧，想打球的时候群里喊一声就有人。”
- **不要**：不说明群价值就硬拉、拉进群后不管

### 2.4 客户接待

- **时机**：客户进店全过程
- **目标**：提供良好体验，为后续转化铺垫
- **流程**：迎宾→了解需求→引导选台→介绍服务→过程关注→送客
- **分客户类型**：
  - 团购客户：标准接待+重点加微信引导
  - 会员客户：称呼姓名+偏好问候+专属服务
  - 新客户：多介绍、多引导、建立好感
  - 助教客户：对接助教、确认预约、服务跟进
- **不要**：区别对待团购客户、冷落新客户

### 2.5 忙时排队说明

- **时机**：全台满时，新到客户需要等待
- **目标**：安抚客户情绪，降低流失率
- **话术要点**：先道歉→告知等待时间→提供等待期间可做的事→趁机推荐其他服务
- **示例方向**：“不好意思现在全满了，预计要等大概20分钟。您可以先坐这边喝杯水，我们这边也有助教可以了解一下。或者加个微信，下次来之前提前跟我说，帮您留台。”
- **不要**：让客户干等不招呼、不告知等待时间

### 2.6 投诉安抚

- **时机**：客户表达不满或投诉时
- **目标**：先安抚情绪，再解决问题，防止差评和流失
- **流程**：倾听→共情→道歉→解释→补偿方案→跟进
- **分投诉类型**：
  - 台费嫌贵：说明价值，不贬低竞对
  - 助教服务不满意：了解具体情况，承诺改进，提供补偿
  - 环境/卫生问题：立即处理，道歉+补偿
  - 排队太久：道歉+补偿+引导下次预约
- **核心原则**：不推卸责任、不激化矛盾、给台阶下
- **不要**：说“这是规定”、推给其他同事、态度冷漠

### 2.7 空台提醒

- **时机**：下午空台较多时
- **目标**：通过内容促活，吸引客户到店
- **内容类型**：朋友圈文案+群公告，发下午优惠/搭子局/小游戏活动
- **示例方向**：“下午台位有空的，想打球的朋友滴滴我，拼一局！”（朋友圈）“下午2点抢一大战，报名费10块，有空的速度群里报名！”（群公告）
- **不要**：编造虚假优惠、制造紧迫感假象

### 2.8 离店跟进

- **时机**：客户离店后（当天或次日）
- **目标**：感谢到店、了解体验、铺垫二次到店
- **分客户类型**：
  - 新客户：感谢第一次来+询问体验+下次到店邀约
  - 老客户：感谢再来+关注最近变化+下次活动预告
  - 助教客户：感谢预约助教+询问体验+下次预约引导
- **示例方向**：“今天打球感觉怎么样？环境还满意吗？下次来之前微信跟我说，帮您留台～”
- **不要**：离店当天连发多条、纯推销

### 2.9 开店 SOP

- **场景目标**：标准化每日开店流程
- **检查清单**：
  - [ ] 开门、开灯、开空调
  - [ ] 检查台面清洁、球具归位
  - [ ] 检查卫生间清洁和用品补充
  - [ ] 检查饮料/商品库存
  - [ ] 确认今日预约和赛事安排
  - [ ] 前厅员工到岗确认
  - [ ] 准备迎宾
- **系统可输出**：开店检查清单（可按门店定制）

### 2.10 闭店 SOP

- **场景目标**：标准化每日闭店流程
- **检查清单**：
  - [ ] 最后一台客户离开后开始闭店
  - [ ] 台面清洁、球具归位
  - [ ] 卫生间深度清洁
  - [ ] 电器关闭（灯/空调/音响/电视）
  - [ ] 门窗锁闭
  - [ ] 垃圾清理
  - [ ] 安全检查（消防/水电）
  - [ ] 填写闭店记录
- **系统可输出**：闭店检查清单（可按门店定制）

### 2.11 卫生检查

- **场景目标**：标准化卫生检查流程
- **检查维度**：台面/球具/地面/卫生间/休息区/前台/窗户/垃圾
- **检查频率**：开店时检查、营业中巡检、闭店前终检
- **系统可输出**：卫生检查清单和记录模板

### 2.11a 小推车促销

- **场景目标**：系统化执行小推车促销，提升商品费收入
- **执行频率**：下午场1小时推一次，晚场40分钟推一次，包厢1小时推一次
- **4品类话术方向**：饮料类 / 零食类 / 烟类 / 果盘类
- **话术原则**：不是推销，是"路过顺便问一下要不要"的服务式话术
- **记录要求**：每轮记录应促销金额 vs 实际销售金额，计算差额
- **目标**：商品费是球房仅次于台费和助教费的第三大收入来源
- **系统可输出**：小推车促销方案（品类+话术+时间安排+记录模板）

### 2.11b 电器管理

- **场景目标**：规范化电器管理，控制电费成本
- **执行频率**：一小时报备一次空调开启数量
- **记录维度**：大厅空调开启数 / 包厢空调开启数 / 恒温器状态
- **目标**：节能降成本，不是限制客户舒适度
- **原则**：人少关多余空调，人多区域确保温度舒适
- **系统可输出**：电器管理报备表模板 + 电器开关策略建议

### 2.12 前厅日报

- **场景目标**：每日前厅工作数据汇总
- **日报字段**：
  - 今日接待人数
  - 团购核销数
  - 加微信数
  - 进群引导数
  - 推卡/推助教数
  - 投诉处理数
  - 商品销售
  - 卫生检查结果
  - 今日问题记录
  - 明日注意事项
- **系统可输出**：前厅日报模板和数据填充

## 4. 话术规则

### 4.1 自然

话术不能有机械感、模板感。同样的意思提供2-3种不同风格的表达方式。禁用“您好欢迎光临请问有什么可以帮您”的机械迎宾语。

### 4.2 简短

单条话术控制在50字以内。前厅在现场说给客户听的，不是让客户读的。可以拆分为多步骤（第一步说什么→客户可能怎么回→第二步说什么），但不能一次性输出长篇大论。

### 4.3 不像推销

推卡、推助教的话术不能有“推销感”。用“推荐”“了解一下”“很多客户喜欢”代替“必须办”“一定要”“不办就亏了”。核心逻辑是“提供一个对你有价值的信息”，而不是“我要卖你东西”。

### 4.4 不骚扰

离店跟进频率适度，不过度频繁。同一天不发多条。给客户回复空间，不是单向消息轰炸。客户不回复时不连续追问。

### 4.5 能引导下一步动作

每条接待话术结束都要有明确的下一步引导：加微信→进群→预约→到店。话术不是终点，是下一个转化的起点。但引导要自然，不能强迫。

### 4.6 分渠道表达

- **当面说**：短（3-5秒能说完），自然，配合表情和肢体语言
- **微信私聊说**：像聊天，开头有称呼，结尾留回复空间
- **群里说**：规范，要照顾到群成员都在看，不涉及个人隐私
