## 0. 一句话总纲

**经营球房，营销是重中之重，没有之一。** 营销不是发优惠、投团购、买达人，而是：**清晰客户画像 → 了解真实需求 → 围绕需求做产品 → 对外传播吸引优质客户消费**。本质四步：**识别 → 创造 → 传播 → 交付**。

营销分两层：
- **营（战略层）**：行业分析、选赛道、市场调研、定位、定价、产品、客群分类、客户真需求、传播。
- **销（执行层）**：团队搭建、运营策略、销售策略、推广渠道。

## 1. 营 · 战略层

### 1.1 行业分析
- 台球行业处于爆发期，野蛮生长的另一面是乱象丛生。**专业化、精细化运营才是生存之道**，靠粗放打法的球房会被淘汰。
- 消费群体：以青年男性为主力，女性占比持续上升。**女性更看重环境与服务，男性更看重竞技性与情绪价值**——这决定了不同客群要用不同的产品和话术去打。

### 1.2 选赛道与定位（定位定江山）
- 四类球房定位（按城市层级和商圈灵活组合）：
  - **社区球房**：亲民、高频、社区粘性。
  - **商业球房**：品质、体验、商圈流量。
  - **竞技球房**：赛事、培训、专业设备、竞技氛围。
  - **竞技商业球房**：竞技 + 商业混合。
- **定位的目的 = 给客户一个选你的理由。** 定位是针对竞争对手，在客户心智里建立一个优势位置。
- 新店定位前必须做**市场调研**：位置、业态、租金、人流量；对周边 3km 竞对的经营数据做摸底，再决定自己的定位。
- **定位清晰之后才谈怎么干活**，定位不清就推进运营，必然事倍功半。

### 1.3 定价（定价定生死）
- 球房四大盈利点：**台费、商品费、器材费、助教（管理）费**。其中台费是核心。
- 常见定价错误：盲目定高（"装修档次高 / 体量大 / 要做高端"就抬价）、被竞争逼着大幅降价、长期促销。
- 定价铁律：
  1. **价格虚高要按真实台费均价回调**，定价过高会逼走客户、拉高获客难度；定价过低伤利润、伤定位。
  2. **取消大额充值赠送，全部改一卡通**：过大的充值赠送会让后续提价更难，且不再是有效锁客手段。一卡通逻辑——本金可全场消费，赠送金额仅限抵台费。
  3. **取消大额充值赠送的落地步骤**：先培训筛选管理层 → 下架旧充值价目表 → 对老客提示"最后一次" → 之后改为再充值送台费券。
  4. **引流产品低价爆款**：设引流区/引流台，用低价不限时段产品（如新人特价、阶梯时长套餐）把人先引进店感受氛围。
  5. **团购品类精简到 4–5 个**，做爆款单量积累；品类太多不利于跑出爆款。
  6. **价格尾数小技巧：8 → 9**。
- 价格是否写进对外文案，由门店自己决定（项目里通过"允许写价格"开关控制）；不公开时用"价格私我/详询前台"，不要写占位符或假数字。

### 1.4 促销
- 促销的本质：**"我想让谁、去干什么"**——先想清目的，再设计动作。
- 常用促销动作及作用：助教免费体验（培养消费习惯）、充值送器材券（培养兴趣）、入会礼包、赠送红牛/巧克/皮头/手套等小物（**提高沉没成本、增强粘性**）。

### 1.5 产品：球房卖的是什么
- **两大卖点：氛围 + 人情世故。**
- **氛围**靠五感营造：听觉（音乐）、触觉（温度）、视觉（人气）、嗅觉（香氛）。
  - **商业球房氛围的最主要因素 = 助教数量。**
  - **竞技球房氛围的最主要因素 = 竞技客户基数。**
  - 快速造氛围的手段：引流台、助教休息区、管理层接待位、音乐、开台次序、活动。
- **人情世故**是另一条命脉，贯穿接待、上钟、维客全流程。

### 1.6 客户识别：四大类客户（核心模型）
| 客户类型 | 核心需求 |
|---------|---------|
| **散客** | 线下社交 |
| **竞技客户** | 技术交流 |
| **助教客户** | 情绪价值 |
| **追分客户** | 输赢刺激（须控制金额、守合规底线） |
- 这是球房客户分类的根模型。**选了哪类客户，运营动作、活动设计、话术方向就往哪类靠。**

### 1.7 传播
- 两大阵地：
  - **本地生活**：本地点评/团购平台、本地推、达人。
  - **内容平台**：短视频矩阵、直播、交友软件、图文社区。
- 渠道范围：门店是线下交付，**必须做透线下 5 公里以内的流量导入**。小城市做本地网红，大城市做区域网红。
- 品牌传播三部曲：**差异化**（和竞对的区别）→ **重复性**（频繁占领心智）→ **高感知**（一句话让人记住你的卖点）。
- 内容两条线：流量型（吸睛）与获客型（讲产品卖点），分工使用，不要混为一谈。

## 2. 销 · 执行层

### 2.1 团队搭建
- 人员配置随球台规模匹配（台越多，助教/教练/前厅梯队越厚），稳定期按规模配齐管理层 + 助教组 + 教练 + 前厅。
- **开业筹备时间线（开业前 30–40 天店长到位）**：第一周市场调研、搭管理层；第二周助教管理招助教、教练拓客；第三周拓客；第四周拓客 + 邀约 + 招服务员 + 全员培训。
- **开业前 7 天最关键**：储备客户能否前 7 天邀约到店决定人气；前 7 天接待口碑决定门店口碑；前 7 天能否让客户养成到店习惯决定复购。

### 2.2 客户运营五步闭环
**引流 → 服务 → 转化 → 复购 → 裂变。** 服务和转化做好，复购自然产生，进而口碑裂变。

### 2.3 引流四路
1. **助教引流**：短视频 + 直播吸粉、交友平台加好友。核心链路：公域引流 → 私域导流 → 社群维护。
2. **管理层/教练引流**：进同行店消费、结交球友搭子。核心链路：客户身份 → 熟悉客户 → 引导到店。
3. **团购引流**：把平台评分和爆款产品做起来（评分是团购引流的地基）。
4. **线上曝光**：员工短视频矩阵 + 门店本地推。

### 2.4 转化
- 转化流程：**管理层接待 → 引导到台 → 二次邀约 → 客户反馈。** 管理层接待是转化的第一道关，极其重要。
- 转化抓手（按客户需求选用）：免费体验、人情世故、上钟沟通技巧、小游戏、球技指导、组局、会员赛/活动、私杆保养、帮谈门等。
- **客户打标签**：备注 = 名字 + 初次进店时间 + 客户类型 + 球技档位；描述 = 距离 + 消费频次 + 常去分区。散客再细分（娱乐型 / 仅限朋友 / 刚上瘾 / 竞技型），分类制定维护策略。

## 3. 人才管理

总框架：**选 → 育 → 用 → 留**（招聘看年龄/经历/能力匹配 → 培训带教 → 任务目标 → 绩效评估 → 晋升或淘汰）。
铁律：**没有合适的人才之前，企业不会良性增长**；选错人，劣币驱逐良币，招到不合适的人是管理最大的浪费。

### 关键岗位画像与职责
- **助教（商业球房核心岗位）**：核心工作是营销（不是单纯陪打）。岗位要求排序：**个人形象 > 沟通能力 > 台球技术**。优秀助教标准：端得住、懂人情世故、意志坚定、赚钱欲望强。新人 7 天内按实打计薪并筛掉无保底潜力者。
- **助教管理**：核心任务 = **提升助教赚钱的能力**。四个工作重点：招聘、面试、培训·筛选、带教。职责：搭团队、扛业绩指标、让助教赚到钱、持续招聘保稳定。带人核心：一对一、面对面、松弛有度、营销意识。终极目的：让客户对助教管理产生依赖。
- **教练**：价值 = **增加球房的竞技客户基数**。组织：实习/副/主教练。工作核心：营销、提升散客娱乐性、人情世故、竞技技术指导、竞技氛围打造。流程闭环：小游戏 → 加微信 → 要好评 → 分辨客户 → 基础教学 → 引导单人进店 → 深度教学 → 邀约 → 组局 → 比赛 → 活动 → 进圈子。终极能力：办内部会员赛，让会员互相成朋友、自发约球。
- **前厅主管**：核心 = 统筹管理、供应管理、设备管控。日常含小推车促销、电器（空调）能耗报备等成本管控动作。
- **店长**：核心工作 = **营销**。须具备营销/数据分析/团队搭建/组织活动/解决问题能力。组队靠**赛马机制**。盯四大数据：**助教数据、教练数据、前厅数据、总营业额数据**。要会控成本（人员、电费、器材/商品损耗、成材率），并常年不间断策划活动、保持新鲜感。

## 4. 数据分析

- 老板抓店长的指标：营业额与利润、人事指标、台费（含团购占比）、当日助教上班人数、平均陪打时长、商品费、器材费。
- 三类分析：**日经营趋势**（看营业额增减）、**营销数据分析**（促销前后对比、是否达成目标、差距多少）、**薪资架构与 PK 机制**。
- **PK 机制**导入三层：管理层 PK、助教 PK、助教奖励机制。配套以陪打时长/业绩排名为口径的阶梯奖励，能显著拉动日均台费。

## 5. 可直接喂 AI 的铁律清单

1. 营销第一；营销 = 识别→创造→传播→交付，不是堆优惠。
2. 先定位再干活；定位是给客户一个选你的理由。
3. 定价定生死：台费为核；取消大额充值赠送改一卡通；引流台低价爆款；尾数 8→9；团购精简做爆款。
4. 球房卖氛围 + 人情世故；商业球房氛围看助教数量，竞技球房氛围看竞技客户基数。
5. 四大类客户：散客求社交、竞技求交流、助教求情绪价值、追分求刺激（控金额守合规）。
6. 客户运营五步：引流→服务→转化→复购→裂变；服务转化做好，复购裂变自来。
7. 线下 5 公里做透；传播靠差异化 + 重复 + 高感知。
8. 助教是商业球房核心岗位，核心工作是营销，形象 > 沟通 > 技术。
9. 店长/助教管理/教练的核心都是营销与"让人赚到钱"，不是单纯陪打或管人。
10. 一切以数据复盘驱动；促销必须有前后对比和目标达成判断。
