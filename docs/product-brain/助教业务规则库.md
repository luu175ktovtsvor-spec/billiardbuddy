# 助教业务规则库

---

## 1. 助教业务定义

### 1.1 助教是什么

助教是商业球房的核心岗位，提供**单独付费的专业台球陪练与教学服务**。助教的核心工作是营销获客与客户维护（不是单纯陪打），助教管理的核心任务是提升助教赚钱的能力。

### 1.2 助教服务定位

- 助教服务是**单独付费的增值服务**，不是免费陪练
- 助教推广是**助教服务获客与预约转化**，不是展示“有陪打服务”
- 助教管理是门店**提升客单价和客户粘性的重要岗位**
- 助教客户是**高价值客户群体**（客单价翻倍以上）

### 1.3 助教业务对球房的价值

- 提升客单价：从纯台费消费升级为”台费+助教费”
- 增加客户粘性：助教客户复购率远高于纯散客
- 差异化竞争：专业助教服务是商业球房区别于社区球房的核心竞争力
- 氛围营造：商业球房的氛围靠助教数量和服务质量

### 1.4 助教服务双层分类

台球房助教必须区分两类，不能只理解为”专业教学陪练”：

#### A. 技术陪练型 / 高级助教

这类助教通常有一定球技水平，客户预约的原因包括：

- 想提升球技
- 想有人带着练
- 想纠正常见问题
- 想进行更专业的陪练
- 想找水平更高的人一起打
- 追求技术对抗和进步

**产品表达方向**：专业台球陪练、技术指导、一对一训练、纠正动作、提升水平

#### B. 服务体验型 / 普通助教

多数普通助教客户，并不是为了高水平训练，而是为了综合服务体验，包括：

- 形象吸引力（得体、干净、有亲和力）
- 沟通自然、会聊天
- 情绪价值（让人感到轻松、被关注、不尴尬）
- 服务意识好、会带氛围
- 打球过程轻松愉快
- 一个人来也不尴尬
- 有人陪打
- 摆球、记分、陪打等基础服务体验
- 到店可约、预约转化

**产品表达方向**：助教服务体验、轻松陪打、沟通自然、氛围轻松、一个人来也自在

**关键认知**：普通助教服务的商业价值，很多时候来自”服务体验 + 氛围 + 情绪价值 + 预约转化”，而不只是”教学”。产品底层必须理解这一点，但在对外表达时需要专业转译。

### 1.5 普通助教的真实业务价值

普通助教对门店的商业贡献，主要体现在以下维度：

| 价值维度 | 具体表现 | 产品理解要点 |
|---------|---------|------------|
| 形象吸引力 | 得体形象让客户愿意到店、愿意预约 | 理解为”服务吸引力”，不低俗化 |
| 沟通自然 | 能和不同类型客户自然交流 | 理解为”服务软技能” |
| 情绪价值 | 让客户感到轻松、被关注、不尴尬 | 理解为”服务体验的一部分” |
| 服务意识 | 主动摆球、记分、关注客户需求 | 理解为”基础服务质量” |
| 氛围体验 | 带动打球氛围、让球房不冷清 | 理解为”门店氛围营造” |
| 陪打体验 | 让一个人来的客户有人陪打 | 理解为”陪打服务”，不低俗化 |
| 预约转化 | 从首次体验转化为持续预约 | 理解为”客户生命周期价值” |
| 降低到店门槛 | 一个人来不尴尬、不用找搭子 | 理解为”降低客户决策成本” |

**产品必须做到的**：
- 理解这些真实需求，不做道德评判
- 对外表达时专业转译，不低俗、不擦边、不过度颜值营销
- 输出的内容可以让门店直接发布，不用担心平台审核或客户反感

## 2. 助教推广层级

助教推广不是单一动作，而是分层的体系。不同层级的推广目标、内容角度、使用渠道完全不同。

### 2.1 门店层助教推广

- **目标**：让市场知道本店提供专业助教陪练服务
- **内容角度**：品牌级别的服务介绍，强调专业性和品质感
- **渠道**：门店官方账号（抖音企业号/公众号/美团页面/朋友圈）
- **典型内容**：“XX球房配备专业助教团队，一对一陪练提升你的台球水平。预约咨询请私信。”
- **注意事项**：不提及具体助教个人信息，不涉及价格数字

### 2.2 助教管理账号推广

- **目标**：以助教管理身份进行行业招聘和团队展示
- **内容角度**：团队风采、培训场景、工作氛围、招聘信息
- **渠道**：助教管理个人号（抖音/朋友圈/行业社群）
- **典型内容**：团队合照、培训花絮、助教日常、招聘邀约
- **注意事项**：展示专业团队形象，不涉及个别助教过度曝光

### 2.3 助教本人个人号运营

- **目标**：建立个人品牌，获取客户，维护客户关系
- **内容角度**：台球技术展示、教学片段、客户互动（经同意）、个人日常、门店氛围
- **渠道**：助教个人抖音/朋友圈/小红书
- **典型内容**：台球技术视频、教学心得、客户学习进步记录、日常训练、赛事参与
- **注意事项**：内容方向为专业台球人设，禁止低俗擦边、性别暗示

### 2.4 助教短视频获客

- **目标**：通过短视频平台获取新客户
- **内容角度**：台球技术展示、教学干货、客户见证、趣味台球内容
- **渠道**：抖音/快手/视频号/小红书
- **典型内容**：技术教学短视频、精彩进球合集、客户案例（经同意）、台球知识科普
- **注意事项**：内容要有获客价值（让人想学、想约），不是纯娱乐

### 2.5 助教朋友圈获客

- **目标**：通过朋友圈维持客户关系和吸引新客户
- **内容角度**：多样化内容轮换（技术展示/客户互动/门店活动/个人生活/赛事参与）
- **渠道**：助教个人微信朋友圈
- **典型内容**：每日1-2条，不同类型轮换，避免全是广告
- **注意事项**：不要每天发同样的内容，不要只发广告，要有人味

### 2.6 助教客户私聊邀约

- **目标**：一对一邀约客户预约助教服务
- **内容角度**：个性化话术，分客户类型和新老程度
- **渠道**：微信私聊
- **典型内容**：初次邀约/复约邀约/长期未来唤醒/拒绝后挽回
- **注意事项**：话术自然不骚扰，体现专业度，不跪舔

### 2.7 现场助教服务推荐

- **目标**：在客户到店时推荐助教服务
- **内容角度**：现场观察客户水平→自然推荐→说明服务价值→引导体验
- **渠道**：前厅/教练/店长现场推荐
- **典型内容**：“看你打得不错，我们有一位助教专门练这个杆法的，要不要体验一下？”
- **注意事项**：不强制、不贬低客户水平、强调“提升”而不是“你不行”

### 2.8 助教招聘

- **目标**：持续招聘助教人才
- **内容角度**：岗位介绍、团队氛围、发展空间、收入预期
- **渠道**：招聘平台公开文案+社交平台私信+行业社群+微信朋友圈
- **注意事项**：
  - 平台公开文案使用合规的岗位描述（“台球陪练”“台球助教”），不规避平台审核
  - 私信邀约话术要真诚，不画大饼
  - 需告知用户招聘平台的使用规则风险

### 2.9 助教客户维护

- **目标**：维护助教客户关系，提升复购率和客户生命周期价值
- **内容角度**：课后回访、技术进步记录、节日问候、专属活动邀请
- **渠道**：微信私聊
- **典型内容**：课后跟进（体验反馈+下次预约引导）、进步记录分享、生日/节日祝福
- **注意事项**：体现“记得你”的专属感，不是群发模板

## 3. 助教管理日常工作

### 3.1 招聘

- 人才画像：个人形象 > 沟通能力 > 台球技术（有技术更好，但不是第一标准）
- 招聘渠道：BOSS直聘/抖音/朋友圈/行业推荐/店内招聘
- 关键动作：持续发布招聘信息、筛选简历、主动私信邀约
- 系统可生成：招聘文案（公开+私信）、简历筛选要点、面试邀约话术

#### 人才优先级（PPT 补充）

助教招聘时，按以下优先级筛选：

1. **个人形象** > **沟通能力** > **台球技术**
2. 有技术更好，但不是第一标准
3. 优秀助教标准：端的住、懂人情世故、意志坚定、赚钱欲望强烈

#### 薪资结构注意事项（PPT 补充）

- **开业前招聘**：只有补助，没有保底
- **开业后薪资**：按约定条件执行（满月后）
- 7天内筛选期薪资按实打计算，不设保底
- 系统生成薪资相关内容时，具体金额用占位符

### 3.2 面试

- 流程：平台沟通→加微信→了解基本情况→确认意向→约面试
- 面试原则：双向选择，不降低标准求人来
- 面试重点：形象、沟通能力、服务意识、对台球的兴趣
- 系统可生成：面试提问清单、面试评估表、录用通知模板

#### 面试4步流程（PPT 补充）

1. **BOSS直聘沟通**：目的→加微信。线上不提助教工作（其他岗位面试转化）。晚上11点-凌晨3点发送邀约消息，立马回复→加微信；不回复→次日10点后一键群发
2. **微信沟通**：主导聊天内容，直接要照片。查看朋友圈照片，朋友圈没有照片大概率不合格。形象合格→直接约面试
3. **约面试原则**："是我招你，不是你招我"——不要废话，主导聊天，花最少精力筛最多人
4. **线下面试**：看形象、沟通、服务意识，不做复杂笔试

#### BOSS招聘被封注意事项

- 禁止在其他岗位聊助教（BOSS、微信）
- 禁止在助教岗位和第三方谈业务
- 非助教岗位面试转化时，线上不可提及助教工作

#### 同业挖人注意事项

- 周边门店挖人，视情况辐射到全城范围
- 用私人微信添加，先交朋友，正常沟通
- 了解她在原球房不爽的地方，放大问题让她认同你
- 后续再联系直奔主题
- 提供转介绍费（推荐入职有奖励）

### 3.3 培训

- 新人培训周期：7天筛选期
- 培训内容：门店制度、台球基础知识、服务标准、客户沟通、安全须知
- 培训原则：前7天为双向筛选，不适合的及时止损
- 系统可生成：7天培训计划、每日培训内容、考核问题清单

#### 7天筛选制度（PPT 补充）

- **七天内必须筛选出不存在保底的助教**——不合适的及时止损，不浪费双方时间
- **七天内薪资按实打计算**——没有保底，按实际上钟时长计薪
- 培训内容7模块：球技丨形象丨服务丨拓客丨约客丨维客丨技巧
- 筛选标准：端的住、懂人情世故、意志坚定、赚钱欲望强烈

#### 助教管理带人核心

- 一对一丨面对面丨松弛有度丨营销意识
- 当亲人、手把手、给足安全感

#### 助教日常管理注意事项

- **禁止集体开管理会**——多开分享会、针对性PK
- **不建议排钟**——让助教自主经营客户
- 工作氛围：开心来、开心走

### 3.4 带教

- 带教方式：老助教带新助教、助教管理一对一辅导
- 带教重点：客户沟通技巧、服务标准执行、个人号运营、客户维护
- 带教周期：一般1-2个月可独立
- 系统可生成：带教计划、带教记录模板、阶段性评估

### 3.5 排任务

- 每日任务类型：朋友圈发布、短视频拍摄、客户邀约、客户跟进、技能练习
- 任务分配原则：根据助教个人能力和阶段分配具体任务
- 任务检查方式：次日检查完成情况，不做实时监控
- 系统可生成：助教日任务分配表、任务执行建议

### 3.6 朋友圈内容

- 发布频率：每人每天1-2条
- 内容类型轮换：技术展示/客户互动/门店活动/个人生活/赛事参与
- 内容原则：不全部是广告，有人味，体现专业度
- 系统可生成：助教朋友圈批量文案（多种风格轮换）

### 3.7 短视频内容

- 发布频率：每人每周2-5条
- 内容方向：台球技术教学/精彩进球/客户案例/门店氛围/台球知识
- 拍摄方式：手机拍摄为主，不需要专业设备
- 系统可生成：短视频选题建议、标题文案、配文、话题标签、封面文案

### 3.8 客户邀约

- 邀约对象：意向客户（问过价的/体验过的/朋友圈互动过的）
- 邀约方式：微信私聊，个性化话术
- 邀约节奏：不过度频繁，尊重客户，体现专业
- 系统可生成：分客户类型邀约话术、邀约时机建议、拒绝应对方案

### 3.9 业绩提升

- 业绩指标：上钟时长、预约客户数、客户复购率、客户满意度
- 提升手段：提高服务质量、增加客户触点、优化个人号运营、提升台球技术
- 系统可生成：业绩分析报告、提升建议、优秀案例参考

### 3.10 PK / 激励

- 激励层级：管理层PK / 助教PK / 助教个人奖励（三层）
- PK原则：公平分组、透明指标、及时公示、兑现承诺
- 激励方式：阶梯奖励（如月陪打170h/200h/230h三档不同奖励）
- 系统可生成：PK方案（分组/指标/奖励阶梯/公示模板）、激励方案

### 3.11 日报

- 日报内容：助教到岗人数/上钟人数/平均陪打时长/新客数/预约数/客服跟进数/本日招聘进展
- 日报格式：数据+文字总结+明日计划
- 日报用途：发给店长和老板、作为管理决策依据
- 系统可生成：助教管理日报模板和自动填充

## 5. 内部理解与对外表达分层

产品大脑必须明确区分内部理解层和对外表达层。这是本次校准的核心原则。

### 5.1 内部理解层

系统可以理解（作为行业认知和意图识别基础）：

- 客户可能因为助教形象、气质、沟通、服务体验而预约
- “美女助教”在行业语境里通常指助教服务推广或预约转化需求
- “点助教”在行业中可理解为预约助教服务
- “好看的助教””漂亮助教”在行业中可理解为对助教服务吸引力的自然表达
- 摆球、记分、陪打、氛围感、情绪价值是普通助教服务体验的一部分
- 助教客户的消费动机可能包含技术提升、服务体验、社交陪伴等多重因素
- 新助教到店是门店高频的推广素材节点
- 助教照片、助教短视频是行业常见的获客内容形式

### 5.2 对外表达层

生成内容不应低俗化、擦边化、过度颜值营销。默认应转译为：

### 5.3 “美女助教”等口语的定位

“美女助教”不是绝对禁词，但不是默认外显词：

- **允许**：出现在用户输入理解层，作为行业术语识别项
- **允许**：系统内部识别为”助教服务推广/助教预约转化/助教到店通知”意图
- **不建议**：作为前端默认卡片标题
- **不建议**：作为系统默认输出词
- **必须**：转译为更专业的助教服务推广表达

**示例**：

用户输入：
> 今天美女助教到了，帮我发朋友圈

系统应理解为：
> 用户想做助教到店通知 / 助教服务推广 / 助教客户预约转化

输出建议：

而不是：

## 6. 边界规则

### 6.1 内容边界

- **不低俗**：禁止任何低俗、擦边、性暗示内容。助教推广内容必须围绕”专业台球陪练服务”。
- **不擦边**：禁止使用”性感””火辣””颜值天花板”等物化表达。注意：”美女助教””好看的助教””漂亮助教”等口语可作为内部意图识别词，但输出时必须专业转译（如”助教到店””助教可约””助教服务体验”）。
- **不暗示免费**：禁止”免费体验助教服务””来店免费陪打”等表述。可使用”助教体验课（价格详询门店）”。
- **不乱编助教姓名**：所有助教个人信息必须基于门店录入资料。
- **不乱编服务价格**：价格数字全部用占位或由门店填写。

### 6.2 助教推广输出边界

**条件允许**：
- 用户提供新助教/助教到店信息时，可以生成对应的推广内容
- 可以写”助教可约 / 到店可约 / 想约提前说”
- 可以围绕助教服务体验、陪打体验进行专业推广
- 用户明确要求助教推广时，按场景区分服务体验型/技术陪练型生成不同风格内容

**绝对禁止**：
- 用户未提供新助教信息时，不得凭空编造”新助教到店”
- 不得编造助教姓名、年龄、身高、照片描述、价格、档期
- 不得默认写免费、赠送、体验券
- 不得输出擦边、低俗、过度颜值营销内容
- 不得将助教服务暗示为异性陪伴服务

### 6.3 获客渠道边界

- **合规渠道**：抖音企业号/个人号、微信生态（朋友圈/私聊/社群）、小红书、美团/大众点评官方功能、到店自然流量转化
- **需谨慎渠道**：招聘平台（需注意招聘文案合规）、交友软件（系统不主动建议使用）
- **禁止引导**：不提供“如何规避平台封号”的操作指导、不鼓励违规获客方式

### 6.4 表达转译

| 行业现实 | 产品安全表达 |
|---------|-------------|
| 助教用颜值/身材获客 | 助教专业形象展示、得体形象 |
| 助教提供”异性情绪价值” | 助教提供个性化陪练服务体验、沟通自然 |
| “美女助教到了” | 今日助教到店、助教可约 |
| “点助教” | 预约助教服务、想约助教提前说 |
| “好看的助教” | 助教服务吸引力、今日助教可约 |
| “陪玩” | 陪打体验、轻松打两把、服务体验 |
| 交友软件引流获客 | 本地客户获客内容建议 |
| “擦边”短视频引流 | 助教个人号专业内容运营 |
| “招助教”被平台封号 | 合规岗位描述+招聘风险提示 |
| “新来的妹妹” | 新助教到店、助教服务体验 |

### 6.5 核心原则

> **行业现实可以进入内部理解，但产品输出必须专业、合规、可公开使用。**
>
> 助教业务的行业运营方式（包括其中的灰色部分）可以作为内部行业认知和风险边界参考，但在产品中必须转译为“专业助教服务推广”“助教个人号运营”“助教预约转化”“助教客户维护”等合规、专业的运营场景。
