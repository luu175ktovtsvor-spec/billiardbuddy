# 行业术语白名单与风险词转译规则

> 生成日期：2026-05-12
> 来源：10F-0 产品大脑链路校准
> 用途：指导 Prompt 引擎识别行业口语并转译为专业表达，指导前端展示词选择

---

## 1. 文档目的

台球房行业存在大量口语化、非正式表达。系统需要理解这些口语背后的真实业务意图，但在对外输出和前端展示时，必须转译为专业、合规、可公开使用的表达。

本文档定义三个层级的词汇规则：

- **白名单（A 类）**：可前端展示、可直接输出的行业专业词
- **识别层（B 类）**：底层可识别但不建议前端展示的词
- **禁止输出层（C 类）**：高风险词，系统绝不能直接输出

## 3. B 类 — 底层可识别但不建议前端展示的词

以下词汇系统需要理解其业务含义，但**不建议**作为前端按钮文字、卡片标题或系统默认输出词。输出时应转译为 A 类对应词。

| 行业口语 | 业务含义 | 转译为（A类词） | 不建议前端展示原因 |
|---------|---------|----------------|------------------|
| 美女助教 | 助教服务推广/助教到店通知/预约转化 | 今日助教可约 / 新助教到店 / 助教服务推广 | 物化表达，有低俗风险 |
| 好看的助教 | 助教服务吸引力/助教到店 | 今日助教可约 / 助教服务体验 | 颜值导向，不够专业 |
| 漂亮助教 | 助教服务吸引力 | 助教服务体验 / 新助教到店 | 同上 |
| 点助教 | 预约助教服务 | 预约助教 / 想约助教提前说 | 口语化，不够正式 |
| 大哥客户 | 大客户/老客户/熟客 | 大客户 / 老客户 / 熟客 | 江湖气重 |
| 颜值 | 形象/气质/服务吸引力 | 形象得体 / 服务体验好 | 过度颜值导向 |
| 情绪价值 | 服务体验/沟通氛围 | 服务体验 / 沟通自然 / 氛围轻松 | 心理学词汇，在运营场景中可能被误读为擦边 |
| 陪玩 | 陪打/服务体验 | 陪打体验 / 轻松打两把 / 助教服务体验 | 易被理解为低俗/擦边 |

**使用原则**：
- Prompt 引擎可识别这些词并映射到对应业务意图
- 生成内容时不得直接输出这些词（必须转译为 A 类对应词）
- 前端 UI 不得将这些词作为场景入口标签
- 在行业认知文档和内部规则文档中保留作为参考

## 4. C 类 — 高风险词 / 禁止直接输出词

以下词汇系统**绝对不能**在生成内容中直接输出。即使用户输入中包含这些词，也必须强制转译或拦截。

### 4.1 低俗擦边类

| 禁止词 | 风险说明 | 建议转译方向 |
|--------|---------|------------|
| 快来点她 | 低俗、物化女性 | 今日助教可约，想约助教服务可以提前说 |
| 陪玩 | 易被理解为低俗服务 | 陪打体验 / 助教服务体验 / 轻松打两把 |
| 身材好 | 物化表达 | 形象得体 / 服务意识到位 |
| 擦边 | 主动提及违规行为 | 不转译，直接拦截 |
| 低俗引流 | 主动提及违规行为 | 不转译，直接拦截 |
| 性感 | 物化表达 | 不转译，直接拦截 |
| 火辣身材 | 物化表达 | 不转译，直接拦截 |
| 颜值天花板 | 夸张+物化 | 不转译，直接拦截 |
| 新来的妹妹 | 不当称呼 | 新助教到店 / 助教服务体验 |

### 4.2 虚假承诺类

| 禁止词 | 风险说明 | 建议转译方向 |
|--------|---------|------------|
| 包赢 | 虚假承诺 | 帮你提升胜率 / 纠正动作少走弯路 |
| 包教包会 | 虚假承诺 | 系统训练能有效提高水平 |
| 保证提升 | 虚假承诺 | 帮你纠正常见问题，提升练球效率 |
| 全城最低价 | 违反广告法 | 价格透明 / 性价比高 / 欢迎来试两杆比较 |
| 全网最低 | 违反广告法 | 同上 |
| 100%满意 | 不可验证的绝对承诺 | 绝大多数客户反馈不错 |

### 4.3 违规经营类

| 禁止词 | 风险说明 | 建议转译方向 |
|--------|---------|------------|
| 免费助教 | 破坏助教付费定位 | 助教服务按门店实际规则执行 |
| 免费陪练 | 同上 | 同上 |
| 送助教课 | 助教服务不能作为赠品 | 助教服务为付费增值服务 |
| 助教体验券 | 暗示免费/低价 | 助教服务预约，价格详询门店 |
| 追分局 | 涉及赌博 | 轻竞技 / 台费局 / 熟人切磋 |
| 赌博 | 违法 | 不转译，直接拦截 |
| 下注 | 涉及赌博 | 不转译，直接拦截 |
| 规避审核 | 违规操作引导 | 不转译，直接拦截 |
| 刷好评 | 违规操作 | 口碑维护 / 引导自然评价 |

## 6. 转译执行原则

### 6.1 不直接复述原则

即使用户输入包含 B 类或 C 类词汇，生成内容中也不得直接复述这些词汇。必须替换为 A 类对应表达。

### 6.2 意图保留原则

转译改变的是表达方式，不是业务需求。用户想推助教就要帮推助教，只是用专业的方式推。

### 6.3 降级不明说原则

当用户输入包含 C 类禁止词汇时，系统不回复"您的输入包含违规内容"，而是默认以 A 类表达完成生成，用行动示范专业做法。

### 6.4 前端静默转译原则

前端快捷场景和示例中，默认使用 A 类词汇。不在前端 UI 中展示"这个词不能说/那个词被替换了"的提示，用户无感知转译。

## 7. 与 Prompt 引擎的协作方式

### 7.1 输入侧

Prompt 引擎在组装用户输入时，对本表中的 B 类词汇不做过滤。保留原始输入以便准确识别用户意图。

### 7.2 输出侧

Prompt 规则（`Prompt规则库.md` 规则 36/38d）约束输出时必须使用 A 类表达。本文档的转译示例表作为 few-shot 参考注入 Prompt 上下文。

### 7.3 前端侧

前端场景卡片、快捷入口、示例文案均使用 A 类词汇。详见 `docs/product-brain/台球房岗位场景库.md`。
