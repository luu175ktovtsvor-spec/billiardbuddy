# 小程序接入 · Phase 0 清单（备案 / 认证 / 域名）—— 用户照此办

> 这是 `docs/plans/小程序接入-编排.md` 里 **Phase 0** 的细化步骤。Phase 0 只能你（用户）来办（实名/营业执照/阿里云账号/微信主体）。办完通知 AI → 进 Phase 1（配大陆网关 + web-view 壳）。
> ⚠️ 各步骤的具体页面/材料以**阿里云备案系统、微信公众平台的实际提示为准**；本清单给顺序和要点、避坑。

## 步骤
1. **续费大陆 ECS**（`39.106.214.21`，北京，包年包月，现到期 2026-08-22）。
   - 为什么：申请"**备案服务号**"通常要求 ECS **剩余时长 ≥ 3 个月**。现在剩约 2 个月，**不续费大概率办不了备案**。续到 ≥3 个月（建议直接续 1 年，反正长期要用它当网关）。
2. **申请备案服务号**：阿里云控制台 → ICP 代备案管理系统 → 用这台大陆 ECS 申请备案服务号（一个授权码，关联"服务器"与"备案申请"）。
3. **定子域名 + 解析**：用现有 `zzyppz.cn`，选一个子域名给小程序（如 `mp.zzyppz.cn`）。在阿里云 DNS 把这个子域名 **A 记录 → `39.106.214.21`**（大陆服务器）。不用新买域名。
4. **提交 ICP 备案**：阿里云 ICP 代备案系统 → 填主办者信息 + 网站信息 + 备案服务号 → 工信部短信核验 → 管局审核（**3–22 个工作日**）。
   - 备案成功后可能还需**公安联网备案**（一般备案通过后 30 日内办）。
   - 备案期间/之后：**该子域名必须一直解析到大陆服务器**（迁走会掉备案）。
5. **小程序企业认证**：微信公众平台 → 注册/已有小程序 → 完成**企业主体认证**（¥300/年）。web-view 必须企业认证。
6. **备案通过后，在小程序后台配域名**（开发管理 → 开发设置 → 服务器域名 + 业务域名）：
   - **request 合法域名** = `https://mp.zzyppz.cn`（小程序 wx.request 用）。
   - **业务域名（web-view）** = `https://mp.zzyppz.cn`；微信会让你**下载一个校验文件**（`xxx.txt`）放到网站根目录——这步把文件给 AI，**Phase 1 我用 Nginx 放上去**。
   - 都必须 HTTPS（大陆服务器要配 SSL 证书，Phase 1 我来）。
7. **完成后通知 AI** → 进 Phase 1：配大陆 Nginx 反代（serve 前端 + /api→美国后端）+ web-view 小程序壳 + 联调上线。

## 你需要准备的材料（备案常见）
- 主体：营业执照（企业）/ 法人身份证；负责人手机号、邮箱。
- 域名证书（阿里云域名一般自动带）、备案服务号、幕布拍照或核验（按阿里云提示，现多为 App 人脸核验）。
- 微信小程序：企业营业执照、对公账户或微信认证。

## 时间预期
- 续费：即时。备案：3–22 工作日（管局审核是大头）。企业认证：1–2 工作日。
- **备案是长杆**，建议**今天就启动续费 + 备案**，AI 同步做 Phase 1 代码（不等备案），备案一过即可联调上线。
