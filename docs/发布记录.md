> 📌 状态:✅现行 · 每次给人装包 / 发自动更新就记一行 · 最后核对 2026-07-02

**发版流程**：改 `desktop/package.json` 版本号 → commit → 打 tag `vX.Y.Z` → push（tag 自动触发 CI 出 Windows 包）→ 下载 artifact 解压 → `bash desktop/scripts/upload_update.sh <解压目录>` 传更新私服（zzyppz.cn/desktop/，服务器目录 `/var/www/desktop-updates/`）→ 所有已装客户端下次启动自动更新。

**版本号规则**：修 bug 尾数 +1（1.0.0→1.0.1）；完成一期改造中间 +1（1.1.0）；界面换代头位 +1（2.0.0）。**发更新的版本号必须大于用户手里的版本，否则不触发。**

**Mac 注意**：未签名，自动更新在 Mac 上静默跳过（代码已处理）——Mac 用户只能手动发装机包；要全自动需 Apple 开发者账号（99 美元/年）+ 签名公证。
