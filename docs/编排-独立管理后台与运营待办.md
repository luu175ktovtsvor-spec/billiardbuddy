### ③ 上线 runbook（说"上线"时按此做，需 SSH）

**第一步：在服务器建专用超管账号（不进 shell 历史）**
```bash
ssh root@47.77.237.250
cd /var/www/billiards-ai/server
ADMIN_PHONE='你定的超管手机号' ADMIN_PASSWORD='强密码（≥10位）' \
  PYTHONPATH=. .venv/bin/python scripts/manage_admin.py create --name 平台超管
PYTHONPATH=. .venv/bin/python scripts/manage_admin.py list   # 确认
```

**第二步：Nginx 加独立后台端口（复用证书 + 访问控制）**
在 zzyppz.cn 的 nginx 配置里新增一个 server 块：
```nginx
server {
    listen 8443 ssl;
    server_name zzyppz.cn;
    ssl_certificate     /etc/letsencrypt/live/zzyppz.cn/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/zzyppz.cn/privkey.pem;
    add_header X-Robots-Tag "noindex, nofollow" always;

    # 访问控制二选一（或都上）：
    #   A. 固定 IP（最严，IP 变了会被锁在外）：  allow 你的IP; deny all;
    #   B. Basic Auth（灵活，换网络也能进）：  auth_basic "admin"; auth_basic_user_file /etc/nginx/.admin_htpasswd;
    auth_basic "admin"; auth_basic_user_file /etc/nginx/.admin_htpasswd;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```
生成 Basic Auth 口令文件（方案 B）：`htpasswd -c /etc/nginx/.admin_htpasswd admin`

**第三步：公网 443 屏蔽后台（防被外人发现/访问）**——在现有 443 server 块加：
```nginx
location /admin            { return 404; }
location /api/v1/admin     { return 404; }
```

**第四步：放行 + 重载**
```bash
# 阿里云 ECS 安全组放行入站 8443（最好限制来源 IP）
nginx -t && systemctl reload nginx
```

**访问**：`https://zzyppz.cn:8443/admin`（登录专用超管账号）。

### 安全底线（必须）
- 专用强密码超管账号、与运营账号完全分离、不绑门店。
- 8443 必须有访问控制（IP 白名单 或 Basic Auth）+ noindex；公网 443 屏蔽 `/admin`。
- 安全组层面也尽量把 8443 限到你的来源 IP。

### "随时连接" vs "安全"的取舍
- **固定 IP 白名单**：最安全，但你换网络（手机/出差）会被锁在外。
- **Basic Auth + 独立端口 + noindex**（推荐默认）：换网络也能进，配合强超管密码已足够稳；办公室固定 IP 可再叠 IP 白名单。
