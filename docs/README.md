**台球运营知识只保留《PPT原件全文》里有据的运营逻辑/内容/知识**；PPT 没有的（借鉴别处/模型衍生/凭空杜撰）一律删，**唯一例外 = 安全红线**（助教自爱不越界·不实际性交易 / 门店不当庄不抽水不定盘口 / 未成年保护）。
