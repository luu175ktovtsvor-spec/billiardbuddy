## 维护规则

- 活文档只写当前事实、当前规则和当前待办。
- 同一主题只保留一个现行真相源，导航不复制正文。
- 任务完成后，只保留具有长期验收或参考价值的规格。
- 更新日期表示已按当前源码核对，不表示新增一份记录。
