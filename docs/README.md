## 文档维护规则

1. **完成工作后实时更新相关文档**，不做完不更新
2. **过时的一次性报告/草稿移入 `docs/archive/`**，不删除（保留溯源）
3. **新增文档按类别放入对应目录**，不堆在根目录
4. **product-brain 是活文档**，调整 Prompt 或业务规则时必须同步更新
5. **本文件是文档导航入口**，新增目录或文件时更新此索引
