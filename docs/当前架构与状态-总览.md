## 一、产品定位(这是什么)

- **装在用户自己电脑上的通用本机 AI Agent 桌面软件**,本质是一个**强 coding agent 桌面外壳**,对标 cc-haha(`~/Desktop/cc-haha-ref`,`NanmiCoder/cc-haha`,LICENSE 允许 copy/modify/distribute,可直接复制/抄/移植/改写)。
- 用户一句话 → AI 大脑(ReAct 循环)自主调工具把事做完:读写/改本机文件、跑命令、上网查抓、生图、列任务清单、把大任务派子代理。面向不懂技术的用户:说大白话、给能直接用的结果。
- **台球运营不是产品边界,是可 `@挂载` 的领域知识包**;默认不挂 = 通用电脑助手。生图、真实素材剪辑是**可挂载的延伸能力**,挂在同一个 Agent 的工具/审批/媒体任务框架上,不是独立产品。
- 免登录、单用户、全本地;模型 key 全内置(走网关藏 key),用户零配置开箱即用。

## 二、当前架构(截至 2026-07-09)

### 唯一代码栈 = `ts/`(Bun/TS 内核 + Electron 壳)

- **内核**:`ts/src/`,cc-haha 标准 coding-agent 循环。已具备:ReAct 主循环、Anthropic content-block 消息格式(内核只认 content-block,OpenAI 端点走 proxy 双向翻译)、工具 use/result 配对、权限五档(default/acceptEdits/plan/bypassPermissions/dontAsk)、hooks(PreTool/PostTool/Stop/UserPromptSubmit/SessionStart)、skills(SKILL.md 渐进披露)、slash commands、MCP(官方 SDK)、plugins 运行时挂载、子代理/后台任务/team-mailbox、EnterPlanMode/ExitPlanMode/VerifyPlan、分级压缩/轨迹落盘、steering(运行中插话)、EnterWorktree/ExitWorktree。
- **存储 = 文件式,无 SQL**(对齐 cc-haha):JSONL transcript(`transcripts/<id>.jsonl`)+ JSON 元信息(`sessions.json`/`tasks.json`/`*.meta.json`)。老 SQLite 是 Python 台球域数据,已随 `server/` 删。
- **桌面壳**:Electron(`ts/desktop/electron/main.ts` + preload)。生命周期:`whenReady → reserveServerPort → spawnSidecar → waitForServer → 建窗口 loadURL`;`before-quit` 杀 sidecar。原生菜单/系统托盘/集中 IPC 白名单(`registerIpc`,只暴露 `pickWorkspace`/`onMenu`,不给渲染进程裸 `ipcRenderer`)。
- **前端 renderer**:`ts/desktop/renderer/`(vanilla JS,`index.html` + `app.js`)。已有:聊天 UI + token 流式打字机、侧栏会话列表、完整审批卡(原因 what/why/impact + 破坏性警告 + 卡内 diff + 允许一次/本会话允许/拒绝)、彩色 diff 面板、工作区目录树 + 右侧预览、后台任务入口、失败重试、专家/领域包挂载入口。
- **打包**:electron-builder(mac dmg + win nsis),sidecar 二进制作 extraResources。
