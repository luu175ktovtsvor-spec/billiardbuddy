## 方法与诚实边界

- **竞品这半高置信**:每条挂证据(字节偏移/真符号名/主题文件 hex/真实 i18n 原文),CONFIRMED(直接读到)vs DEDUCED(推理)分清;分析过程当场纠正过自己 4 个判断(能自我打脸=真读进去了)。
- **推理的部分**:编译内核的函数体内部实现没反汇编,靠命名/日志/结构推断并已标注。
- **读不了的**:各家服务端逻辑、真实密钥、云端模型网关后台——机器上不存在。
- **"对我们项目"那半**:方向可信、已批判筛选;但"改哪个文件怎么改"必须先读我们真代码,见 `docs/plans/`。
