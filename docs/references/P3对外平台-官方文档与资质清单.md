## 🚧 剩下的"真发 / 真上架"——需资质或原生能力,我们只引导,后期按需

### 抖音 · 短视频真发
- **能做到真发吗**:可以,官方 `create_video` API 能代发到授权账号。
- **需要**:企业开发者认证 + 公函盖章 + 「代替用户发布内容」权限申请(能力实验室,可能被驳回)+ 用户扫码 OAuth。日 75 作品上限、发后审核。
- **官方文档**:
  - 内容发布接入方案 https://open.douyin.com/platform/resource/docs/ability/content-management/douyin-publish-solution 「官方」
  - 创建视频 create_video https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/video-management/douyin/create-video/video-create 「官方」
  - 上传视频 https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/video-management/douyin/create-video/upload-video 「官方」
  - 开发者类型与权限 https://developer.open-douyin.com/docs/resource/zh-CN/developer/introduction/type-and-permission 「官方」
- ❌ cookie/UI 自动化"野路" = 封号风险,不做。

### 抖音 · 团购/到店真上架与核销
- **能做到真上架吗**:商家自己在抖音来客后台可以(免费入驻、台球类目已开放、可能需 POI 报白);**我们经 API 替商家上架/核销**则需成为官方"生活服务服务商",门槛极高(注册资本 ≥100 万 + 保证金 + 城市限制 + 案例)——**对我们门槛过高,不做**。核销已有 POS/收银系统在接。
- **官方文档**:
  - 生活服务开放能力 OpenAPI 列表 https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/list 「官方」
  - 生活服务商家应用概述 https://developer.open-douyin.com/docs/resource/zh-CN/local-life/introduction/overview 「官方」
  - 代运营服务商接入指南 https://developer.open-douyin.com/docs/resource/zh-CN/local-life/guide/parterner-guide 「官方(导航壳)」
  - CPS(达人探店佣金)接入指南 https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/open-capacity/Industry/life/partner/CPS-guide 「官方」
  - 抖音来客(商家后台) https://life.douyin.com/p 「官方(JS 渲染)」

### 小红书 · 笔记真发
- **能做到真发吗**:**官方没有"发笔记到账号"的 API**(开放平台是电商、蒲公英是广告/商单)。唯一合规真发 = 官方「分享开放平台 / openSDK」唤起小红书 App、内容预填、用户手动点发——**需要原生 App 端能力**(我们当前是 H5 / 微信 WebView,接不了;上了原生 App 壳后可做)。
- **官方文档**:
  - 开放平台文档 https://open.xiaohongshu.com/document/api 「官方(JS 渲染,未逐字)」
  - 电商 API(apifox,已确认无笔记发布接口) https://xiaohongshu.apifox.cn/doc-2810951 「官方」
  - 蒲公英(品牌↔博主商单) https://pgy.xiaohongshu.com 「官方(JS 渲染)」
  - 分享 openSDK 机制(官方文档 JS 渲染未抓到逐字,集成参考见二手) https://www.cnblogs.com/zxxiaoxia/p/18373731 「二手」
  - 资质入驻要求(官方域名 PDF) https://picasso-static.xiaohongshu.com/test/8b3bc7324ca06fceea379177f9eed1fa/小红书资质入驻要求.pdf 「官方域名」
- ❌ 自动发笔记 / 矩阵号 = 封号红线(2024-11 起永久封号级严打),不做。

### 微信 · 群发 / 朋友圈 / 视频号

## 如果将来要把"替商家自动发/上架"集成进我们端口(注意点 · 2026-06-16 用户确认)

确认:**要集成 = 由我们(公司主体)去申请平台资质并集成**。四个注意点:
1. **资质 + 集成在我们这边**:我们申请平台开发者 / 服务商 / ISV 身份,并把 API/SDK 集成进产品。
2. **每个商家还要单独授权我们用他的号**:抖音/快手扫码 OAuth、企微管理员授权——两层,缺一不可。
3. **硬前提:原生 App**:小红书/快手的唤起 SDK、抖音的好体验都需要原生 App;现在是 H5 / 微信 WebView 接不了,与"小程序/App 接入"(feat/miniprogram)绑定。
4. **逐个评估值不值**:企微群发(ISV)、抖音代发(create_video,企业开发者+代发权限)→ 可行;抖音来客团购 API(生活服务服务商,注册资本 ≥100 万 + 保证金)→ 门槛极高、大概率不办;小红书自动发 → 官方无 API、不存在这条路(只有 openSDK 唤起,需原生 App)。

**商家侧**:无论我们办不办,商家用他**自己的基础资质**(营业执照/法人/平台商家号)就能在自己后台/App 发布上架——门槛低、是他的事。
**现状(只引导)零资质**:覆盖全平台、当天能上;等真有规模/需求,再照本文上面的链接逐个办那些重资质 + 上原生 App。

## 一句话原则
**内容我们全包到位,"最后那一下发布/上架"——能复制就复制、能唤起 App 就唤起、要资质要原生的就引导老板自己来。** 永不自动发、不碰封号红线、不替商家承担资质。
