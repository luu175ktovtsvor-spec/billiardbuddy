# 17-补：右侧详情/预览面板 各态（DetailPanelWrapper 内容态）

> **第二轮穷尽补齐**（2026-07-10）。归属：**App 外壳 = WorkBuddy** 侧（右侧产物/预览抽屉）。

## 0. 先纠一个 owner 认知偏差（照抄前必看）
owner 把顶部 tab 描述成「概览/任务进程/产物/文件」+「关注·审查按钮」，**对照真代码不准**：
- **`overview`/`taskProgress`/`artifacts` 不是三个并列顶部 tab**，是「概览视图」里 OverviewPanel 内部的三个可折叠 section（任务进程 + 产物 + 团队信息）。
- **真正的顶部 tab（切视图）** 是：`概览 / 工作空间文件 / 浏览器 / 变更 / MCP Apps / 专家`。
- `detailPanel.files`="文件"是死 key；文件 tab 实际用 `detailPanel.allFiles`=**「工作空间文件」**。
- `关注/审查`（detailPanel.follow/review）也是死 key，无任何 DetailPanel 组件渲染。owner 大概率在别页（发现/项目/自动化）看到"关注/审查"记错到这。
- **结论：这个面板没有「关注/审查」按钮，也没有「文件」tab。别做这两个。**

## 1. 两套壳并存 + 默认走哪套
`use-sidebar-mode.ts`：模式 `"legacy"|"next"`，优先级 URL query > localStorage(`agent-sidebar-mode`) > `window.PRODUCT_FEATURES.SidebarModeDefault` > `"next"`。→ **默认新壳 next**。切换广播 `agent-sidebar-mode-change`。
| | Legacy 壳 | Next 壳（默认） |
|---|---|---|
| 组件 | `DetailPanel` 自带 `.detail-header` | `SidebarNext` 包 `DetailPanel`(hideHeader) |
| 顶部切视图 | pills Tabs | ViewSelector 下拉胶囊 + 概览悬浮菜单 |
| 顶部还有 | 全屏还原按钮 | ArtifactTabsBar 产物标签条 + 钉住/收起/全屏 |
**注意分叉**：球房管家用的 `detail-panel-wrapper` 直接 import legacy 壳 DetailPanel；App 主工作区默认走 next 壳。两套内容区共用。**建议我们只做一套壳（next 壳更完整、是默认）。**

## 3. 「概览」内容 —— OverviewPanel（三 section）
DOM `.cb-overview-panel` 三 section：
**① 任务进程**（`tasks.length>0` 才显）：标题按钮 `detailPanel.taskProgress`="任务进程" + 折叠三角。展开 `.cb-task-progress` 每步：图标（completed 对勾/in-progress 空心圆环/error 红⊗/waiting 圆环）+ 竖连接线 + `task.title`。状态色 token：完成 `rgba(0,0,0,.3)`、进行中 `#00C29A`、等待 `rgba(0,0,0,.7)`。数据 `extractTasksFromArtifacts`（取 type==="task" 最新的 todolist）。
**② 产物**（始终显）：标题 `detailPanel.artifacts`="产物"。空态 `detailPanel.noContent`="暂无内容"。有内容列表每项 `.cb-overview-artifact-item`（h32，选中 `--selected` bg `#F2F2F2`）：`role=button`，`draggable`（拖到编辑器），图标按 type（ardot/canvas→ArdotFileIcon 绿角标/plan类→PlanFileIcon/task→TaskFileIcon/其余按扩展名）+ 标题。文件类型色：pdf#E57163、code#5A8AA4、word#528AE3、ppt#D24F31、sheet#51A776。**折叠阈值 5**（`ARTIFACT_COLLAPSE_THRESHOLD`）：超 5 显"展开更多（{count}）"，展开后"收起"。
**③ 团队信息**（`OverviewTeamSection`，`showTeamSection`；**legacy/next 都传 false，当前不显示，预留**）：标题"团队信息"，每项头像+名字+职业+状态（running 运行中/completedShort 已完成/failed 失败/pending 等待中）。

## 4. 各视图内容态 + 空态（照抄）
`SidebarNavContent`（左子栏）按 sidebarView 分支：mcpApps→SidebarNav；fileTree→header"工作空间"，有数据 FileTreeSidebarContent / 空="空目录" / 加载="正在加载文件树..."；changes→FileChangesSidebar（或文件版本 panel）；expert→SidebarNav"专家"；默认→OverviewPanel。
`.detail-main__body` 主区（优先级）：①browserUrl→BrowserPreview（webview）②compact+overview→OverviewContent ③expert→ExpertPreviewContent + 底部"立即测试"按钮 ④mcpApps→McpAppsHostTabContent ⑤fileTree 有数据 FileTreeMainContent/空"空目录"/加载"正在加载文件树..." ⑥选中 artifact→ArtifactContentRenderer ⑦**兜底空态**（artifacts/changes 没选产物）→ "请选择一个产物查看详情"。`.empty-content` flex 居中 font12 opacity.7。
**产物文件不存在**：点已删产物 → toast"该产物文件不存在，已从列表移除" + `onRemoveArtifact`。

## 5. Next 壳 · SidebarNext（默认壳，最需照抄的交互）
**A. ViewSelector 下拉胶囊**（切视图 tab）：
| value | 文案 | 中文 | 隐藏条件 |
|---|---|---|---|
| overview | detailPanel.overview | 概览 | 不隐 |
| fileTree | detailPanel.allFiles | 工作空间文件 | 不隐 |
| preview | detailPanel.preview | 浏览器 | 不隐 |
| changes | detailPanel.changes/fileVersionManagement | 变更/文件版本管理 | 无变更且非版本模式时隐 |
| mcpApps | detailPanel.mcpApps | MCP Apps | `!mcpAppsEntryEnabled` 隐 |
| expert | detailPanel.expert | 专家 | 无专家隐 |
DOM `.view-selector-pill`（`--open` bg `rgba(0,0,0,.03)`）内 icon+label+chevron（180ms cubic-bezier）。**内部 `currentView==="artifacts"` 在选择器显示为 `overview`**。
**B. 概览悬浮菜单**：`WbMenuIcon` IconButton，hover 打开 Popover（w320 radius16 maxH min(640,100vh-88)，portal 到 `.teams-container`）：header ViewSelector+钉住按钮，body 整个 SidebarNavContent。hover 关闭有 160ms 防抖 + MutationObserver 等 context-menu 消失。
**C. 产物标签条 ArtifactTabsBar**（`useUnifiedTabs` 跨视图统一 tab）：`.artifact-tab`（`--active/--draggable/--drag-clone/--drag-placeholder`）= icon+name+close（hover 才显，"关闭"）。可拖拽重排、可关，全关触发 `onAllTabsClosed`（钉住则收左栏，否则关整面板）。tab 色：idle 透明/hover #f2f2f2/active #f2f2f2。
**D. 右侧动作区**：全屏切换（PreviewMaximize/Restore，title `common.enterFullscreen/exitFullscreen`）+ 面板收起（PanelToggleIcon，`sidebar.next.collapseLeftColumn`="收起左栏"）。
**E. 钉住/收起左栏状态机**（owner 说的"隐藏/显示侧边栏"真实现，**不是** hideSidebar/showSidebar 死 key）：钉住按钮 title `sidebar.next.pinSidebar`="钉住产物栏"↔`unpinSidebar`="取消钉住"。`effectiveLeftCollapsed = sidebarPinned ? false : hasOpenedDetailContent`（选中产物/文件后左列表自动让位给预览）；窄态(<480)选中即收且取消钉住；钉住则左栏常驻。折叠动画 180ms。状态按 sessionId LRU 50 缓存。外层 class `.sidebar-next`（data-view + `--left-collapsed`/`--preview-fullscreen` 等）。

## 6. 关注/审查/隐藏侧边栏/文件 —— 死 key 实锤（照抄前必看）
两套 i18n 都有定义、grep 全部前端组件 bundle **零引用**：`detailPanel.follow`=关注、`review`=审查、`hideSidebar`=隐藏侧边栏、`showSidebar`=显示侧边栏、`files`=文件、`noDetails`=暂无详情。关注/审查活引用都在别的页面（项目/发现/自动化/灵感）。→ **详情面板不要做关注/审查按钮。**

## 7. Ardot「新画布」入口（合成产物机制，可务实简化）
**不是独立按钮，而是往产物列表插一个「合成产物」置顶项**：`isDesignSession` 且无正式 ardot 画布时插入 `id="design-new-canvas:{会话id}"`，`title`="新画布"、`subtitle`="打开 Ardot 设计画布"，`createdAt/updatedAt=Number.MAX_SAFE_INTEGER`（永远排最前）。点它进 Ardot 画布 webview（需授权，未授权显示 `DetailPanelAuthOverlay`）。
- **务实简化**：球房没 Ardot 画布，这块**整体砍掉**；机制可抄——往产物列表塞高 createdAt 合成项当入口，点开进专用 webview/工作台（对齐我们「生图工作台/剪视频工作台」）。

## 8. 外层容器：colleague-chat-artifact-drawer（球房管家实际用的壳）
源 `colleague-artifact-detail-panel.tsx`（非混淆带完整中文注释）。同事助理页右侧真正抽屉外壳，内层才是 DetailPanelWrapper→DetailPanel。
- `<aside class="colleague-chat-artifact-drawer{ is-wide}">`（aria"产物预览"），`position:absolute` 钉在 relative 的 `.colleague-chat-page`，**宽度 inline `width:{px}`**（非全屏=detailPanelWidth，全屏=父容器实测宽，都是 px 所以能 CSS `transition width 240ms` 做放大动画）。
- header（flex space-between padding 8×12 三边 1px 线）：标题"产物预览"(font14 w500) + 关闭按钮（**圆形 28×28**，aria"返回对话"，XCloseIcon16，`closeDetailPanel`）。
- body → DetailPanelWrapper。`box-shadow:-8px 0 24px rgba(0,0,0,.06)`。用 ResizeObserver 测自身宽回灌 DetailPanel。
- **传给 wrapper 的裁剪 props**：`canSaveArtifactToLibrary:false`、`disableArtifactToolbarActions:true`、`disableArtifactUploadActions:true`、`hideHeaderDebugTools:true`、`forceCloudEnvironment:true`、`disableDocumentSdkPreview:true`——同事页把保存到资料库/上传网盘/调试工具全关了。**球房管家可照此裁剪。**

## 10. 务实取舍标注（必做 / 可简化 / 暂不做）

**必做**：只做一套壳（next 壳）；ViewSelector 切视图（概览/工作空间文件/浏览器/变更）；OverviewPanel 三 section（任务进程/产物 + 折叠阈值5）；各视图空态文案；钉住/收起左栏状态机（选中产物后左列表让位给预览）；外层抽屉 `width:{px}` + CSS transition 放大动画 + 圆形关闭按钮 + 裁剪 props。

**可务实简化**：ArtifactTabsBar 拖拽重排可后置（先做可关闭 tab）；团队信息 section（当前 WorkBuddy 自己也传 false，不显示）；MCP Apps / 专家 tab 无对应能力就隐藏（利用 ViewSelector 天然隐藏机制）。

**暂不做/砍**：Ardot 新画布整块（换成我们自家工作台入口机制）；legacy 壳（只做 next）；关注/审查/文件死 key。
