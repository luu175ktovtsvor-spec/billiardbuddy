- **动作反馈套路**：`X成功`/`X失败，请重试`/`正在X...`。例：归档="任务已归档，可前往「系统设置-数据管理」中查看"、删除成功/删除失败，请重试、分享="已复制链接"、收藏="已添加到收藏"/"已从收藏中移除"
- 技能安装 toast："「{name}」技能已安装，"（用「」包名称）
- 消息中心确认可爱版："我知道啦"（对比其它地方"我知道了""知道了"）
- 更新 toast：正在检查更新... / 已检查到新版本，下载中 {percent}% / 新版本就绪 / 已是最新版本 / 检查更新失败，请稍后再试；架构不匹配"当前软件版本和系统架构不匹配，可能导致卡顿"

## 九、进度 / 工具执行动词（两阶段"正在准备X"→"正在X"，~185 条，特色）

每个工具都有**流式准备态**和**执行态**两句（`progress.phase.model_streaming.*` vs `tool_executing.*`）：
- 读文件：准备"正在准备读取文件" → 执行"正在读取文件"；写文件、编辑、执行命令(Bash)、搜索文件(Glob)、搜索内容(Grep)、获取网页(WebFetch)、搜索网页(WebSearch)、生成图片(ImageGen)、执行技能(Skill)、操作屏幕(ComputerUse)、创建/解散团队、发送消息、创建工作区、创建定时任务、发送微信/企业微信消息…全套都有对应中文
- 顶层态：准备中 / 等待模型响应 / 生成回复中 / 处理结果中 / 调用工具中 / 等待授权 / 等待回复 / 重试中 / 压缩上下文中
- 授权等待细分：等待执行命令授权 / 等待写入文件授权 / 等待编辑文件授权…
- 保护性提示："正在同步文件，请勿中断以免丢失数据"
- 对话工具卡状态：读取中/已读取、生成中/已生成、修改中/已修改、执行中/已执行/运行成功、检查中/已检查（lint）、搜索网页中.../已搜索网页

## 十、对话区专有文案（cb-chat-ui）

- 思考/加载："思考中"、"正在生成答案，请稍候"
- 新对话分隔："新对话开始" / "已自动开启新对话"
- 沙箱越权确认：标题"越权确认"；desc"CodeBuddy 想在沙箱外执行命令，需要你确认。"（**硬编码 CodeBuddy**）；拦截原因：检测到受保护文件修改 / 检测到用户配置黑名单目录 / 检测到敏感凭据路径访问 / 检测到批量删除操作

- 上下文压缩上限："上下文压缩已达上限，建议开始新对话或减少上下文（如禁用不必要的 MCP 工具/技能）。"

## 十一、WorkBuddy 语气 / 写法特点（照抄时要 get 的"味道"）

1. **第一人称帮手视角**：核心 slogan「**WorkBuddy，我帮你**」；通知/灵感用"我会通知你""帮你整理"——把产品当会说话的搭子。我们换"球房管家，我帮你"即可平移。
2. **"你的X超能力"框架**：职场/开发/设计超能力——把功能包装成能力增益。
3. **你/您混用但有规律**：UI 引导、鼓励语用亲昵的"**你**"（占绝大多数）；账号/积分/正式错误/隐私条款偏用"**您**"。规则：越正式/越涉钱和风险→"您"。
4. **口语软化词**：句尾爱加"**吧**"、偶尔用"**~**"、"**啦**"（"我知道啦"）。
5. **游戏化/拟人动词**：专家、助理用"**召唤**"；签到叫"Buddy 加油站""连登抽取 Buddy 周边"。
6. **emoji 克制点缀**：仅在营销/奖励/强调处——🎉 上线、🎁 礼包、⏳ 倒计时、↪ 转交上下文、📝 文件变更。正文基本不用。
7. **中点 · 串联卖点**："7 x 24小时云端待命 · 专属记忆 · 一句话分派任务"——短卖点并列。
8. **「」直角引号包 UI/名称**：「{name}」「系统设置」「+ 添加」——引用界面元素/文件名/按钮统一用「」，不用双引号。
9. **三套模板高度一致**：空态=暂无+引导、错误=一句诊断+"请…重试/请检查…"、结果=X成功/X失败，请重试——批量生成文案时照套。
10. **占位符规范**：`{name}`（品牌名，白标）、`{count}`/`{num}`、`{model}`、`{time}`、`{percent}`；人名/工具名走 `@{username}` / `{member}`。
11. **"智能体/Agent"混用**：中文界面多说"智能体""助理"，系统级说明里保留"Agent"。
