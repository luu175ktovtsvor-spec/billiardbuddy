## 0. 弹层技术底座（所有点击弹出的东西都走这套）

- **定位库 = floating-ui/react**。导出可见：`useFloating / FloatingPortal / FloatingFocusManager / FloatingOverlay / useHover / useClick / useDismiss / useRole / useInteractions / offset / flip / shift / size / arrow / autoUpdate / safePolygon`

- **Tooltip 默认参数**：`delay=300ms`、`portal=true`、`placement="top"`、`offset=6`、`interactive=false`、`showArrow=false`。`interactive:true` 时鼠标可移入 tooltip

## 1. 消息操作条（助手消息底部工具栏）= AssistantFeedback

**渲染顺序（从左到右）**：
1. **复制** — 永远显示。复制消息里所有 text block trim 后 `\n` 拼接
2. **点赞/点踩** RatingBar
3. MessageActions（外部注入的 icon-only 动作）
4. **分享** — 仅当 `config.onShareTask` 存在。点击=进入分享模式并选中当前对话组
5. **更多** MoreMenu
6. **积分** CreditUsageText（本轮 credit + 模型名，tooltip"本轮模型为：{modelName}"）
7. **时间** MessageTime

**显示时机（硬逻辑）**：只对 `messageType==="assistant"` 且不是同组中间消息显示；会话进行中且是最后一条时先不显示，等 `message.complete`；用户取消或会话已停时未完成也显示。`config.showFeedback===false` 则整条不显示。

### 1a. 点赞/点踩 RatingBar
- `thumbsState`：0=中性 / 1=已赞 / -1=已踩，**两者互斥**。图标空心/实心两版，选中=实心
- 点赞切到 1 时先关掉点踩反馈弹窗、调 onLike；点踩→**弹反馈弹窗**（不立刻置 -1，等提交才置）

### 1b. 点踩反馈弹窗 FeedbackDialog（floating popover）
- 锚定点踩按钮，Esc 关。标题"请选择不满意的原因"，右上角 `×`
- 选项一排可点 chip，**多选 toggle**；默认选项：**误解问题 / 上下文错误 / 答案不清晰 / 代码错误 / 回答不专业 / 代码格式错误 / 其他**
- 选"其他"→展开 textarea（占位"请描述具体的原因"，maxLength 200，右下计数 n/200，rows 3）
- 底部"提交反馈"，**未选任何项时 disabled**

### 1c. 更多菜单 MoreMenu（顺序：删除→自定义→反馈→复制请求ID）
触发"更多操作"。菜单项：`积分消耗: {credit}`（点击复制，toast"已复制积分"）→ separator → `删除`（弹 ConfirmDialog：标题"删除对话?"，正文"删除后无法恢复，请谨慎操作！"，确认/取消）→ 自定义 → `反馈` → `复制请求ID`（复制 requestId+traceId+conversationId，toast"请求ID已复制"）

### 1d. 用户消息内联编辑 UserMessageEditor
点用户消息"编辑"→ 变成内联 ChatInput（自带独立模型选择器）。**点外部空白取消**；有本地草稿缓存。提示"按 Enter 换行，Cmd/Ctrl + Enter 保存，Esc 取消"

### 1e. 朗读（TTS，agent-ui 层，不在这条工具栏里）
文案：朗读/停止朗读/加载语音中.../没有可朗读的文本内容/语音合成失败。三态图标（待朗读/加载中/播放中）。**注意**：主对话消息条（cb-chat-ui）里没有朗读按钮，也没用浏览器 speechSynthesis；朗读是 agent-ui/助理页那层的服务端合成。

## 2. 模型选择器 ModelSelect（输入框底部左侧胶囊）

触发按钮：图标+label+下箭头。自动模式时 label="自动"；否则=选中模型 label（剥掉 `(NNNk context)` 后缀）。
**弹出（Popover+PopoverList，自上而下）**：
1. **自动模式区**：一行"自动模式" + 开关滑块。开启后提示"自动模式已启用，将自动选择模型。"切换即关闭整个弹层
2. **Max 模式区**：Tooltip"最大化上下文窗口，关闭自动上下文压缩。\n\n该模式会消耗更多 Credit，建议仅在复杂或高质量任务中使用。"行=Max 模式+开关

5. **底部**：`配置模型`行，点击执行并关闭；Enter/Space 也触发
- 思考强度全文案：minimal/low"低"、medium"中"、high"高"、xhigh"超高"、max"极致"；思考模式开="已开启，可选择强度"，关="已关闭，将按普通模式发送"

## 3. 权限档选择器 PermissionModeSelector（两档）

**胶囊**：图标（默认档=盾牌；完全访问=三角警告）+ label + 箭头。类名 `pillDefault`/`pillDanger`。下拉（placement `top-start`，minWidth 160）两项：
1. **默认权限 - 安全沙箱**：点=直接切
2. **完全访问权限**：Tooltip（interactive，noPadding）显示"使用规则"四条：①减少确认步骤，允许 AI 直接执行更多操作 ②可能涉及敏感操作、文件修改或外部执行 ③仅建议在你信任当前任务时使用 ④你可随时切回默认权限。点（非 full）→ **弹确认对话框**

**开启完全访问确认弹窗**：
- 标题（带警告图标）"确认开启完全放开？"；正文两段"开启后，AI 将减少确认步骤…包括敏感操作、文件修改或外部执行。" / "仅建议在你信任当前任务时使用。"
- **必须勾选** checkbox"我已了解风险，并愿意继续"才能确认
- 确认按钮"确认开启"，**颜色 `#e74c3c`（红）**；取消"取消"
- 失败按错误码 toast（超时/5xx/网络）

**另一套并存**：`SandboxConfigBar`（沙盒/本地 × 默认/完全 四种组合）。规划模式开关 tooltip"先规划需求，再通过智能待办清单逐步实现。"

## 4. @提及 / 斜杠命令面板 Mentions（FloatingPortal 浮层）

`@`→PhraseTrigger.at、`/`→PhraseTrigger.slash；也可点"上下文按钮"（tooltip"添加上下文"）触发。
- **两层结构**：@ 或点按钮 → 先出**"选择提及类型"provider 列表**；选一个 provider（有子列表的右侧带箭头）→ 进入该 provider 搜索。**返回按钮**（当有>1 个 at-provider 时显示）
- **斜杠 `/`**：直接进命令搜索（占位"搜索命令..."，空态"未找到命令"）
- **搜索输入框**：自动聚焦（50ms 后），`onCompositionStart/End` **拼音输入保护**（输入法组合期间不触发选中）
- **键盘导航**：↑↓ 选、Enter 确认、Esc 关；**鼠标/键盘模式互斥**；选中项自动滚入视野
- **列表项**：图标+高亮名称+描述。分组带组标题（Skills/Commands）
- **无限滚动**（down，rootMargin 80px）。加载态骨架。空态随场景变
- **provider 类型**：file / image / command / skill / tencent-doc / tencent-lexiang / ima。命令 provider 描述"可用的快捷命令"。技能组底部"显示更多 Skills"（"还有 {count} 个 Skills"）
- 选中一项后默认关闭面板（除非 `keepPanelOpen` 或 `show-more-skills`）
- 输入框**空态按 Backspace** → 焦点跳到最后一个上下文标签

**上下文标签区 InputContext**：已加的上下文以 chip 展示，可点、可删。拖文件/图片进输入框有 DropZone + 提示。

## 5. 输入框底部工具栏其余控件

右侧从左到右：
- **剩余字数**：剩余<1000 才显示"剩余 {n} 个字符"；超限红字"已超出 {max} 字符限制"，**颜色 `#D7432E`**
- **上下文用量环**：16px SVG 环形进度（轨道 `rgba(128,128,128,0.2)`，进度 `#9CA3AF`）。hover tooltip"{percentage}% · {used} / {total} 上下文已使用"。**可点**→展开分类明细：系统提示词 / 工具及子智能体 / 对话消息 / 连接器及MCP / 技能
- **增强提示词**：默认 tooltip"增强提示词"；进行中转圈"增强中..."（点=取消）；已增强"恢复原文"（点=还原）
- **发送键**：空闲=IconSend，tooltip"发送"（`isSendDisabled` 时禁用，active 类高亮）；流式中=IconStop，tooltip"点击停止"（点=onCancel）；**二次确认停止**：pendingStopConfirm 时 tooltip 变"再次按下停止"，按钮内容显示快捷键标签（默认 Esc）

## 8. 命令/文件越权审批（两条不同交互）

### 8a. 工具审批菜单 ToolApprovalMenu（内联在工具卡片里）
简单菜单。命令确认文案：确认执行命令？/ 运行 / 允许 / 始终允许 / 跳过 / 拒绝 / 每次询问 / 自动运行；风险提示"高风险命令，可能影响系统稳定性"/"中风险命令，请谨慎执行"。文件写入：确认写入？/ 接受 / 拒绝

### 8b. 沙盒越权卡片 SandboxInterceptCard（替换输入框显示）
有 pending 越权时**顶掉输入框**显示这张卡：
- **头部**：标题（越权原因）+ 风险 chip（高危/中危，本地启发式判定）+ 命令原文（inline code）
- **选项列表**：带**序号(1/2/3)**的按钮。注释明确：**初始无任何选中态、无灰底、无箭头**；一点某项立刻该行灰底+箭头进入"提交中"，完成后父级移除卡片
- 普通命令三选项：允许(allow_once) / 本次会话内始终允许(allow_session) / 拒绝(deny)。批量删除类只两项：允许本次删除 / 取消删除
- 越权原因文案：检测到受保护文件修改 / 检测到用户配置黑名单目录 / 检测到敏感凭据路径访问 / 批量删除（"累计删除数量 {count} 项，阈值 {threshold}"）
- 顶部通用标题"越权确认" / "CodeBuddy 想在沙箱外执行命令，需要你确认。"

### 8c. 团队成员越权 TeamMemberInterceptCard
"@{member} 请求执行 {tool}。你的确认是必要的。" 三选项 本次允许/始终允许/拒绝

## 12. 键盘/快捷键汇总

- **发送**：输入框 Enter 发送；换行走 Shift+Enter
- **编辑消息**：Enter 换行，Cmd/Ctrl+Enter 保存，Esc 取消
- **停止**：流式态发送键二次确认，快捷键标签默认 Esc
- **Esc**：关各类浮层（mention/feedback/additions 统一 onEscapeKeyDown）
- **↑↓ + Enter**：mention/命令面板导航选中；鼠标移动与键盘导航互斥
- **Backspace（空输入框）**：焦点跳到最后一个上下文标签
- **Enter/Space**：侧栏项、模型"配置模型"底部项、上下文环等可聚焦元素激活
- **输入历史** useInputHistory（maxHistorySize 50，按 Option/Alt 键切换）
