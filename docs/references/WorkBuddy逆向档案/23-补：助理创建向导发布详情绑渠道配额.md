## 一、创建助理向导（CreateColleagueDialog，也复用作编辑）
**外壳** `.create-colleague-modal`：`width:min(700px,100vw-64px); height:min(608px,100vh-64px); radius16 bg --cb-panel-bg-primary border1px`。
**结构（单页竖排）**：
```
header: 标题(isEditMode?"编辑档案":"创建助理") + close(X)
nav.progress (进度条 单节点; grid 3列是历史残留) step-index(圆圈序号32px 2px边 active填充绿+光晕)
body:
  1. 助理昵称(必填*): input placeholder"例如：前端开发工程师"
  2. 职业快捷选项(grid 2列): 第一格"自定义"(虚线边 AddIcon,is-selected 当 templateId==="") + visibleRolePresets 前3个(INITIAL=3): 头像+标题+描述, onClick 自动填昵称+简介 + "查看更多"/"收起"(展开全部21个)
  3. 助理简介(必填*): textarea placeholder"描述 TA 的能力和职责..."
  4. 名称(必填*): input placeholder"给他起个好听的名字~"
  5. 头像: avatar-row 60×60圆; 初始9个(共20预制preset01~20) + 翻页 + 上传(PNG/JPG/WebP/GIF ≤5MB)
  ── 能力配置(高级) 手风琴(is-expanded) 4项:
    (a) 雇佣专家 → HireExpertModal
    (b) 连接仓库: github/cnb/gongfeng tabs; OAuth 轮询3s×100; CNB token弹窗

    (d) 内存记忆 + memory-switch
```

**21 职业预设**（各带职责描述 `rolePreset.*`）：前端/高级开发/小程序/移动端/AI/项目经理/UI设计/测试/后端架构/产品/小红书运营/内容创作/股票研究/行业研究/数据分析/体验架构/Web/软件架构/代码审查/游戏设计/文档生成。**白标改写**：换门店角色（前台/教练/营销/收银对账/会员运营/赛事组织…）。
