# 03 · 布局与外壳（Window Chrome / 三栏 Grid / 顶栏 / Composer / 页脚 / 右侧面板）

> **可信度**：CSS（类名/尺寸/颜色/中文注释含 Figma node_id）、布局常量、i18n 全明文可读。**读不到**的只有：顶层 React 布局 JSX 树（在压缩的 index-BneTCe4u.js / connector-CvFT3fv6.js，变量名 mangle）、左侧 rail 的精确 DOM 层级（宽度是 JS 内联 style，不落 CSS）、Composer 左右控件的确切 DOM 次序（按 module 名 + i18n 反推）、具体 lucide 图标选型。
>
> 标注：【CSS明文】直接读到；【JS常量】数值常量可直接读到；【JS压缩】变量 mangle 靠字符串/结构反推。

一句话定位：WorkBuddy 是一个 **Electron（frame:false + macOS hiddenInset + under-window 毛玻璃）桌面壳**，内部用 **VS Code 式可拖拽 Grid** 分成三条竖栏：**左侧主导航（展开264/收起48）| 中间聊天区（最小360）| 右侧制品预览面板（min318/默认500/max无限）**，栏间是 2px 可拖 sash；窗口过窄时按断点自动收右栏、再收左栏、最后把左栏降级成抽屉。

## 0. 关键尺寸常量总表（全部读到确切值）【JS常量】

```
SIDEBAR_SIZE      = { EXPANDED_WIDTH: 264, COLLAPSED_WIDTH: 48 }
CHAT_MIN_WIDTH    = 360           // 中间聊天区最小宽
CONTEXT_VIEW_SIZE = { MIN_WIDTH: 318, DEFAULT_WIDTH: 500, OVERVIEW_ONLY_WIDTH: 318, MAX_WIDTH: Infinity }  // 右侧制品/预览面板
RESIZE_HANDLE_SIZE = { WIDTH: 2 } // 栏间 sash 拖拽条 2px
// 响应式断点（窗口内宽 < 断点则收起对应栏）：
BREAKPOINT_HIDE_DETAIL  = 264 + 360 + 318 = 942
BREAKPOINT_HIDE_SIDEBAR = 264 + 360       = 624
// 侧栏收起判定：当该 grid 视图 box.width < 264 时切成 48px 图标条
```

布局引擎 = VS Code 式 Grid（`createComponentView("sidebar"|"main-content"|...)`, `gridRef.setViewVisible`, `getViewSize`, 拖拽 sash）。窗过窄时侧栏改**左侧抽屉**：`{ placement:"left", size:264, showBackdrop:true, animationDuration:300 }`。

Grid 里注册的可切换视图：`sidebar` / `main-content`（聊天）/ `detail-panel`（制品预览）/ `inspiration-panel` / `my-files-panel` / `tencent-docs-panel` / `tencent-lexiang-panel` / `ima-panel` / `iframe-menu-panel` / `login-view`。

## 1. Window Chrome / 窗口壳（无原生标题栏）【JS压缩，配置明文】

- `frame: false` + macOS `titleBarStyle: "hiddenInset"` + `vibrancy: "under-window"`（毛玻璃）；Windows 用 Mica/Acrylic + `titleBarOverlay`（主题变色）。
- 默认窗口 `{ width:1200, height:800 }`，记忆到 `userData/window-state.json`（带跨屏可见性校验，防开到屏幕外）。
- **红黄绿交通灯定位**：`MAC_TOPBAR_HEIGHT = 52`；`getTrafficLightPosition(h=52)` → 交通灯锚在 **x:21 / y:20**。可动态隐藏（`window:setTrafficLightsVisible`）。

**拖拽区（`-webkit-app-region`）**【CSS明文】：各顶部横条（detail-header 40px、detail-layout__top 54px、sidebar-next 各栏）整条 `drag`；里面所有 button/a/input/select/textarea/[role=button]/[role=tab]/.cb-button/nav 控件逐个 `no-drag`。
- Windows 壳：`.sidebar-next--windows-chrome { border-radius: 12px 12px 0 0 }`。
- macOS 避让交通灯：`--sidebar-next-window-control-inset: 68px`（常态）/ `96px`（预览全屏）；预览全屏顶栏 `padding-left: 87px`。

## 2. 左侧主导航栏（sidebar 视图，264/48px）

宽度是 JS 内联应用（不落 CSS），DOM 树在压缩包里【JS压缩】；导航项文案、埋点、时间格式从内嵌 i18n 读到确切值。

结构自上而下：**品牌区 → 新建任务按钮 → 图标导航 → 任务搜索框 → 任务列表（带相对时间）→ 底部用户区**。

- **新建任务按钮**埋点：`data-track-id="agent_new_task_button_clicked"`，`data-track-name="新建任务-侧边栏"`，`data-track-props='{"source":"sidebar","mode":"craft"}'`。默认进 craft 模式；新建中占位标题="新建任务中"。
- **底部用户区**：`SidebarFooter` / `SidebarFooterCollapsed` / `UserMenu` / `user-menu-avatar` → 用户头像 + 用户菜单（收起态有紧凑版）。侧栏还接 `merge-pinned-spaces-*`（置顶空间/项目合并进侧栏）。
- 相对时间格式：刚刚 / {hours}h 前 / 昨天 / {days}d 前。

**复用型侧栏导航组件 `.cb-sidebar-nav`**（也用于右侧文件树，BEM 明文）【CSS明文】：
```
__section-title  padding 8px 20px 4px; 11px/600; uppercase; letter-spacing .5px
__item           padding 8px 20px; 全宽; transition all .2s
__item:hover     bg var(--vscode-list-hoverBackground)
__item--selected bg list-inactiveSelectionBackground
__item-icon      14×14; margin-right 8px; 60% 主文本色
__item-title     13px/400; ellipsis
__item-badge     ≥16px 高16 圆角8 pill
__item-action    20×20; 默认 opacity 0，item:hover 才显现（悬浮操作按钮）
```

## 3. Composer / 聊天输入框（核心）

三层圆角盒（CSS-module 前缀 `pf4c4`）【CSS明文，结构可读】：
```
_content_    外壳: flex column; gap 4px; 圆角 18px; bg cb-content-background(暗 #252526)
  ├ _topArea_    顶行: 高 28px; space-between; 顶部圆角 7px  ← 上下文chips/上传
  ├ _mainArea_   真正打字区: 圆角 16px; padding 12px; gap 12px;
  │              bg 亮 #F5F5F5; 1px border; 底部两栏 space-between（左/右 item）
  └ _inputOverlay_  禁用遮罩: 圆角18px; bg rgba(255,255,255,.9); backdrop blur(3px)
```
输入框上方可浮 `.cb-input-banner`（warning `#FE9D2E`/error `#EF4444`/info `rgb(40,184,148)`，顶部圆角6px）。占位符="提问或输入"/"快捷命令"。

**左侧控件档**（DOM 次序按 module 名推断，非确证）：
- `+` 添加上下文（tooltip "添加上下文"）；上传/更多（"上传文件或更多操作"）
- `@` 提及（"提及文件/符号"，搜索占位"搜索文件、符号..."，分组 Skills/Commands）
- `/` 命令（"命令"/"可用的快捷命令"）
- **模式档**（module `1p5j7` = modeButton）【CSS明文】：高 24px、12px/500、圆角 3px、灰底、max-width 140px、icon 16px、带快捷键提示。可选：代码模式 / 问答模式 / 创建 Agent / 规划模式（tooltip "先规划需求，再通过智能待办清单逐步实现"）；含**专家子菜单**（带头像）。
- **沙盒模式**（真正的"权限档"）：tooltip "沙盒模式启用后，所有文件修改限制在工作空间内...操作工作空间之外的目录必须用户授权后单独在沙盒外执行"。inline 开关 `_inlineSandboxConfig_`。
- 增强提示词（含"增强中..."/"恢复原文"）。
- mention 按钮 `_mentionButtonLabeled_`：min-w 72px、h 32px、圆角 10px、14px/700。

**右侧控件档**（gapLarge 16px 分隔）：
1. **模型选择器**（module `xva83`）【CSS明文】：inline-flex、gap 6px、padding 4px 8px、12px/20、圆角 4px、透明底、hover 淡底。下拉带搜索/分组/submenu/勾选。文案：自动 / 自动模式（"自动模式已启用，将自动选择模型"）/ Max 模式（最大化上下文窗口、关自动压缩，消耗更多 Credit）/ 内置模型。
2. **麦克风/语音**：tooltip "语音输入 ({shortcut})"，start/stop/processing，错误档齐全。token `--cb-voice-confirm-color #00c29a`。
3. **发送按钮**（IconButton module `hg7y0`）【CSS明文】：`_large` 32px 圆形；`_active` bg `#6c4dff` 字白；`_loading` 反白。文案：发送 / 点击停止 / 再次按下停止。icon 按钮档：medium 24×24 / small 16×16 / large 32×32。

**上下文用量条**："{percentage}% · {used} / {total} 上下文已使用"，分类 = 系统提示词 / 工具及子智能体 / 对话消息 / 连接器及MCP / 技能。字数："剩余 {num} 个字符" / "已超出 {max} 字符限制"。

- 顶层 `<Sidebar|Chat|DetailPanel>` 组装、Grid 装配逻辑、各视图挂载顺序在压缩 JS，只能从字符串常量 + `createComponentView("...")` 反推。

- 旧版 vs 新版侧栏（sidebar-next）并存，当前默认走哪套在 feature flag（main/workbuddy-product-config.js）里，本切片未确证。
