## 八、创建助理向导（两步）

进度条（completed/active/upcoming）。标题"创建助理"，末步按钮"创建同事"（历史命名残留）。

**步骤1 基本信息**（必填校验：昵称+名称+简介都非空）
- **头像**：20 张预制候选（`avatar.preset01~20`）+ 上传自定义（PNG/JPG/WebP/GIF，≤5MB），"更多头像"翻页
- **助理昵称**（占位"例如：前端开发工程师"）+ **职业快捷选项**：一大排预设角色（前端/高级开发/微信小程序/移动端/AI工程师/项目经理/UI设计师/工程测试/后端架构师/产品管理员/小红书运营/内容创作/股票研究员/行业研究员/数据分析员/体验架构师/Web开发/软件架构师/代码审查员/游戏设计师/文档生成员），各带职责描述 + "自定义"
- **名称**（占位"给他起个好听的名字~"）
- **简介**（占位"描述 TA 的能力和职责..."）带 **"AI 写"** / **"语音"**
- **常用职责**多选：需求分析/方案拆解/报告生成/质量评审
- **协作风格**（占位"例如：主动追问背景，输出结构化结论，语气简洁专业。"）
- 有"填充示例"；实时**内容审核**（名称/职称/简介合规检测 + 查重）

**步骤2 能力配置（高级）**（"专家/仓库/资料库/模型"）
- **雇佣专家**（三 tab：专家 / 专家团 / 企业智能体 Beta，可搜索+分类，"从专家、专家团或企业智能体中选 1 个来源，带入能力、技能和方法论"）
- **连接仓库**（GitHub / CNB / 工蜂，选仓库+分支，OAuth）
- **腾讯文档**（授权只读后选文件）
- **知识库**（"连接后可检索文档内容辅助回答"）
- **选择模型**（推荐/Auto，标签 推理/多模态/默认，能力 图片输入/推理模型）

## 十、事件总线（colleague-navigation-bus，三个 RxJS Subject）

- `colleagueConversationsChanged$`：会话增删
- `colleagueConversationPatches$`：创建/删除/session 状态的本地短期补丁
- `colleagueAgentListChanged$`：助理本体增删（低频，Claw tab 订阅刷新，避免高频 session 事件刷爆）

## 十一、给「球房管家」照抄的要点（白标改写）

1. **两栏协作范式可借**：Dashboard（大卡+一句话派单+助理网格）→ 点卡进详情 → 点对话进"左 rail 竖排助理 + 右对话"大浮窗。核心是"一个总控 orchestrator 帮你拆解、@ 拉其他助理协作"的编排模型。球房场景换成：总控"店长助手" @ 拉"排班助手/营销助手/对账助手"。
2. **配色三分法**：结构照这套，颜色换我们的。品牌薄荷绿 `#00C29A`、悬浮球近黑 `#191919`、卡片中性灰阶换我们色板；状态点绿/蓝/橙语义可留、色值按我们体系。
3. **助理卡三态胶囊 + Pro 缎带 + 更多菜单（编辑/删除）** 是通用可复用的卡片语言。
4. **创建向导两步 + 20 预制头像 + 一排职业快捷预设**是很省事的建档 UX，球房换成"前台/教练/营销/财务"等门店角色预设。
