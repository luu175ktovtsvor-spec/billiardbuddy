# 01 · 设计系统（Design System）

> **可信度**：这一层几乎无盲区。所有 token 定义、组件类名、尺寸/色值/缓动都在明文 CSS 里，SVG 吉祥物渐变色也是明文，已逐一读到确切数值。唯一读不到的是"什么条件下加/切哪个 class"（在压缩 React JS 里），但 class 名可读、视觉规则由 CSS 决定，所以样式结论不受影响。
>
> 主要文件：`$R/renderer/assets/src-kZTgkaJN.css`（cb-* 两套主题）、`cb-bridge-BQMqrgRE.css`（wb-* 品牌 token 桥接）、`Progress-CMKBOJsA.css`（foundation 组件：按钮/tab/卡片）、`index.html`（body/滚动条基线）。

## 0. 架构：双 token 系统（先理清，这是照抄的骨架）

WorkBuddy 是**两层 token 叠加**：

1. **底层 `--cb-*`**（来自 packages/cb-chat-ui，IDE 出身）：主按钮是紫色 `#6c4dff`。定义在 `src-kZTgkaJN.css`。
2. **上层 `--wb-*`**（WorkBuddy 设计系统，`cb-bridge` 桥接）：**把主按钮改成黑/白单色**，并引入青绿品牌色。

分层顺序：**palette（原子色阶）→ semantic（语义层，如 --wb-color-text-primary）→ component（组件消费）**。这套分层法值得球房管家 1:1 照搬（只换色值）。

**主题切换选择器**：
- 浅色 = `body[data-vscode-theme-name="IDE Light"]` 或 `.light` / `:root.light`
- 深色 = `.dark` / `:root.dark` / `.cb-dark`
- 整个 app 还继承 VS Code 主题变量 `--vscode-*`（index.html 注入）。

**品牌双色要分清**：logo/吉祥物 = 青绿（`#0EC7A8`/`#00C885`/`#32E6B9`）；按钮/发送/选中等**交互主色** = 紫 `#6c4dff`（cb 残留）。但 wb 层把主按钮改成了黑白单色。→ 我们：品牌绿换我们自己的品牌色，紫色别用，主按钮保持黑白单色。

## 4. 组件级样式（确切数值，照着写）

### 4.1 主/次/幽灵按钮 —— wb foundation `.wb-button.cb-button`

基础：圆角 `lg` **8px**（circle 形态=50%）；苹方 SC；14px/22行高/字重 500；icon 槽 16×16，svg `currentColor`。
尺寸：small 高 32px padding 8×12 gap6；medium 高 32px padding 6×16 gap6；large 高 36px padding 12×16 gap4；icon-only large 36×36 / small 32×32。

变体（**主按钮是黑白单色，不是紫**——这是高级感关键）：
- **primary**：底 = 浅色 black-90（`rgba(0,0,0,.9)`）/ 深色 white-100（`#fff`）；字 = 浅白/深黑；hover black96%/white88%，active black80%/white72%，disabled black24%+字白60%。显式关掉 cb 的 brightness 滤镜。
- **secondary**：浅色 底白 + 字近黑 + 1px 描边 black12%；hover 叠 black4%，active 叠 black8%。
- **grey**：底 black4%（浅）/white6%（深）无描边；hover black8%，active black12%。
- **ghost**：全透明底，字继承；hover 才显淡叠加（标题栏 32×32 圆形热区常用）。
- **danger**：primary+danger=红底白字；其余变体+danger=底不变、字/边变红。

### 4.2 底层紫按钮 —— cb `.cb-button`（wb 层会覆盖它）

圆角 4px，`transition: all 0.2s ease`，字重 500，disabled opacity 0.5。primary 底紫 `#6c4dff` 字白，hover `filter: brightness(1.05)`；secondary 底 `#313248` 字 `#D2D3E0`；focus `outline: 2px solid focusBorder; offset 2px`。→ 我们不用这套紫。

### 4.3 输入框 Composer（主聊天输入区，CSS-module 前缀 `pf4c4`）

三层圆角盒：
- 外壳 `_content_`：flex 纵向，gap 4px，**圆角 18px**，底 `--cb-content-background`（深 `#252526`）。
- 打字区 `_mainArea_`：padding 12px，gap 12px，**圆角 16px**，底浅 `#F5F5F5`/深 vscode-input-bg，1px 描边浅 `#E6E6E6`/深 `rgba(255,255,255,.08)`，阴影浅 `0 6px 12px -8px black.02, 0 2px 4px -4px black.03`/深 none。
- 顶栏 `_topArea_`：高 28px，顶部圆角 7px。
- 遮罩 `_inputOverlay_`：圆角 18px，`backdrop-filter: blur(3px)`，底浅 `rgba(255,255,255,.9)`。
- @提及按钮 `_mentionButtonLabeled_`：高 32px，圆角 10px，min-width 72px，14px/700。
- 输入框激活边框走品牌青：`--cb-input-active-border: #00b96b`。

### 4.4 卡片 `.wb-card`

圆角 `xl` **12px**；底 `--wb-bg-primary`（浅白/深 gray-3）；`overflow:hidden`；过渡 120ms standard。
- 变体：`--elevated`（1px 透明边 + shadow-md）、`--outlined`（1px border-default 无影）、`--flat`。
- `--hoverable`：cursor pointer；hover 底→bg-tertiary；elevated→shadow-lg；outlined→边 border-strong；focus-visible `outline:2px solid border-focus; offset 2px`。
- padding：none=0 / small=8px / medium=16px / large=24px。

### 4.5 Tab `.wb-tabs`（底部滑动墨条 ink-bar）

- 容器：flex 纵向，gap 12px。
- 单 tab：透明底无边，**高 48px**，padding 0×8px，字 **12px/16px/400**，色 text-secondary，`transition: color 120ms`。
- 选中 `--active`：字 **600** + 色 primary（用不可见 bold 伪元素占位防抖）。
- **ink-bar**（底部墨条）：`position:absolute; bottom:0; height:3px; min-width:16px`，底 text-primary（**选中态用黑/白墨条，不是品牌色**），宽度/位移由 JS 注入 `--wb-tabs-ink-left/width` 驱动，`transition: transform/width 200ms`。left 形态改竖条贴右宽 3px。

### 4.6 焦点环（全局一致）

统一 **`outline: 2px solid var(--wb-border-focus); outline-offset: 2px`**（内嵌用 -2px）。`--wb-border-focus` = 浅 black-75（`rgba(0,0,0,.75)`）/ 深 white-70（`rgba(255,255,255,.7)`）——**焦点环是中性黑/白半透，不是彩色**。cb 侧焦点用 `#006ab1`/`#007fd4`。

### 4.7 开关 / Switch

轨道底 `--cb-switch-bg`：浅 `#ebebeb`/深 `#3a3a3a`；**激活底 `#00b96b`（青绿）**；滑块 `#ffffff`；off 轨 black6%/white8%。技能卡上的小开关激活态用 `#4cd964`。

### 4.8 选中态汇总

- 侧栏/列表选中：浅 `#f7f7f7`（或填充式 `#E5E5E5`）/ 深 `rgba(255,255,255,.06)`（填充式 `#343841`）。
- 标签选中：浅 底 `rgba(0,122,204,.2)` 字 `#005a9e` / 深 底 `rgba(100,150,255,.3)` 字 `#fff`。
- hover 底：列表浅 `#EFEFEF`/深 `#272C34`；icon 按钮 hover black5%/white10%。

## 5. 给「球房管家」的落地建议（白标改法）

- **直接照搬骨架不搬色**：token 三层分层（palette→semantic→component）、圆角/间距/字号阶梯、48px tab + 3px 墨条、8px 圆角黑白主按钮、18px/16px 双层圆角 composer、120/200/320ms + `cubic-bezier(0.4,0,0.2,1)` 动效——这些 1:1 可参考。
- **换掉的**：品牌青绿 `#00C29A` 与吉祥物青绿猫渐变 → 换成球房管家自己的品牌色和自绘笑脸；紫色 `#6c4dff`（CodeBuddy 残留）别用。
- **主按钮保持黑白单色**是它高级感的关键（不是彩色 CTA），值得抄；彩色只留给品牌强调点（勾选/激活药丸/链接）。
