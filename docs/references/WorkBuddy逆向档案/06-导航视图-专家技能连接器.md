## 0. 顶层结构：一个页 = 三 Tab

侧栏那项中文叫 **"专家·技能·连接器"**（窄栏简写"技能·连接器"）。它是**顶部 3 Tab 容器**，按 URL 路由切内容：
1. `experts` → "专家" → `ExpertCenterPage`（路由 `/experts`，默认）
2. `skills` → "技能" → `SkillsPanel`（`/skills`）
3. `connectors` → "连接器" → `ConnectorPanel`（`/connectors`）

- Tab 头 `UnifiedMarketHeader` 注入到各子面板的 `headerLeft`（三子页共用同一条 Tab 栏）。
- **Tab 可被产品配置隐藏**：`useVisibleMarketTabs()` + `useMenuVisibility()` 决定每 Tab 显不显示；当前 Tab 不可见会自动跳第一个可见 Tab。→ 我们领域包可按开关裁 Tab。
- MCP **不在**三 Tab 里，是独立的"MCP 服务器"面板（连接器 Tab 的"自定义连接器"是它入口）。

## 1. 技能 Tab（SkillsPanel）—— 对我们技能系统最直接

### 1.1 两级结构
- **一级 Tab**：market（技能市场）/ installed（我安装的）。默认 market。
- **市场页内二级分段**（segment bar，20px 粗体、下划线态）：
  - **推荐**（精选技能/换一换/安装）
  - **SkillHub**（社区市场，排序：下载量/安装量/评分/Stars）
  - **套件**（plugin 套装）
  - **Knot**（另一 skill 市场源，带分类/标签，分页"加载更多"）
  - **企业 Skill**（"当前企业暂无可见的自建 Skill"，卡片打"企业自建"标，有 NEW 红点 `#ff4d4f`）
  - 右侧 **"仅展示未安装" checkbox**
- **顶部标题**：Skills/技能，副"赋予 {name} 更强大的能力"。搜索框（宽 220，占位"搜索技能"），跨源聚合，失败降级提示。

### 1.2 右上角「+ 添加技能」下拉（3 项 + 点击行为）
- **查找技能** → `goHome()` + `createSkillMode$.next({prompt: 找技能示例})` —— **开一个新 AI 对话让 AI 帮你找技能**
- **上传技能** → 拖拽/点击导入弹窗（见 1.5）
- **创建技能** → `goHome()` + `createSkillMode$.next({prompt: "请帮我创建一个可以实现「……」的skill", skillName: "skill-creator"})` —— **开新对话、预填、挂上内置 skill-creator 技能**

### 1.3 技能卡片（SkillCard）
- 容器 `.skill-card`：圆角 **16px**、padding 16/20、min-h 84、min-w 262；hover 加阴影。网格 `repeat(auto-fill, minmax(max(262px,25%-9px),1fr))` gap 8
- 内容：28px 圆形图标 + 名（14.5px/650）+ 来源标签（灰底小胶囊）+ 描述（2 行截断）+ 统计（下载/星标）
- **风险徽标**（16px 圆）：low `#4f86ff`、medium `#f5a623`、high `#ff4d4f`（18% 透明底）
- **"精选"缎带**（左上角，亮 底 `#E3F7F2` 字 `#40806F`）
- **套件标**（紫 `#a78bfa`）+ **能力标签**（skills绿/commands蓝/mcp橙/agents粉/hooks紫/rules青）
- **已安装态右上三件套**（顺序 `[⋯][pin][switch]`）：
  - `⋯` 菜单：**置顶/取消置顶** / **去对话** / **编辑** / **启用/关闭** / **卸载技能**
  - `pin` 置顶（22×22）
  - `switch` 开关（26×16，选中绿 `#4cd964`）—— 永远可见=启用/禁用
- **市场态卡片** hover 从底部滑入"直接安装"浮层；已安装显"试一试"；绿色更新浮层
- **点击卡片主体** → 打开技能详情视图 `SkillDetailView`；详情态外壳 `.skills-view--detail`，从"我安装的"进走两级面包屑「全部技能 / 我安装的」
- 技能图标 **10 个配色**：樱粉/晴蓝/草绿/电紫/阳橙/湖青/珊红/靛蓝/柠黄/青柠

### 1.4 "我安装的" + 批量管理
- 子页标题"已安装 N" + "批量管理"
- 批量工具条：全选/已选 N/启用/关闭/卸载。卡片进批量态左侧出复选框（选中黑底白勾）
- 批量卸载确认："确认卸载已选技能?"、"卸载后从已安装列表及本地文件夹移除"
- 批量更新弹窗："技能更新"、"发现 {count} 个技能有可用更新"、"全部更新"
- **技能自动更新**开关（不更新你本地编辑过的技能）；本地编辑过的更新前弹"更新将覆盖你的更改"
- 空态："还没有安装任何技能" + "上传本地技能文件夹，或通过 AI 对话快速创建一个专属技能"

### 1.5 上传/导入技能弹窗
- 标题"导入技能"/"上传技能至个人技能库"/"上传技能至项目"；拖拽区"拖拽文件或点击上传"，拖拽中"松开以导入"
- **文件要求**（直接照抄价值高）：文件夹或 .zip 需含 `SKILL.md`；`.md` 需含 YAML 格式的技能名称和描述
- 类型：文件夹 / .zip。状态：上传中/导入中/**"安全检测中..."**
- 上传策略拦截：企业禁止上传个人 Skill / 你被禁止 / 不在白名单 / 超大小限制

### 1.6 技能安全检测（重点）
安装/上传技能都过一遍安全扫描（病毒/恶意意图）：
- 流程："Running security scan…"、"Uploading files for security scan…"、需深度分析时"Deep analysis required / 可等或先装后台继续扫"
- **开关**：非高风险自动安装（高风险始终手动确认）；扫描开关
- 风险等级：safe/low/medium/high（安全/低风险/中风险/高风险），色沿用卡片风险徽标色
- 高风险弹窗："Security risk warning"；异步结果通知 `SkillScanResultDialog`（列出：技能名/风险等级/总体裁定/描述/威胁标签/病毒名），按钮 **"卸载技能"(红 #e74c3c)/"保留"**
- 倒计时继续："Continue installation ({seconds}s)"

### 1.7 技能推荐条（新任务里）
一条 skill-recommend-bar，用 chip 展示为当前任务推荐的技能（带专用 loading 图）。由"技能推荐"设置控制（"每次启动新任务时推荐适合的技能"）。空态"暂无技能推荐"。

## 3. 连接器 Tab（ConnectorPanel）—— 对我们"外部集成/数据源"参考

i18n `connectorPanel.*` + `connectors.*`。

### 3.1 布局
- 标题"连接器管理"，副"连接外部服务，扩展 AI 能力"；搜索"搜索连接器..."；工具条含 **"自定义连接器"**（加 MCP，见 §4）
- 分区：**已安装 {count} 个应用 / 可用**
- 卡片：图标+名+描述+徽标+**状态点**（connected/connecting/error）+连接按钮（可 loading/取消）+开关。不兼容态需升级
- 空态"暂无连接器 / 可用连接器将在此显示"

### 3.2 内置连接器清单（确切原文）
- **GitHub** — "管理代码仓库和代码审查"（支持授权仓库子集）
- **工蜂 Git** — "腾讯内部代码仓库管理"
- **CNB** — "云原生开发平台"（token 令牌连接）
- **Figma** — "连接 Figma，访问设计文件与组件资源"（选画板/粘贴 Frame 链接）
- **MasterGo** — "读取设计稿，生成前端代码"
- **腾讯文档 / 乐享知识库 / IMA 知识库** — 自动连接 + 授权提示

### 3.3 连接/授权方式（3 种）
- **OAuth 跳转**："点击连接将引导您完成授权流程"、"将跳转页面授权连接..."
- **扫码授权**："扫码授权"、"扫码完成后页面将自动关闭"，可复制链接
- **设备码/浏览器授权**：在浏览器确认/输入授权码，"授权码 {time} 后失效"
- **Token 令牌弹窗**（CNB 用）：输入访问令牌 → 连接

### 3.4 连接器详情弹窗
名/描述/图标；**工具列表**；GitHub 类有**已授权仓库列表**；MCP 类有**自定义请求头**（header 键值）；版本提示条；底部动作 配置/详情/解绑/去试试；⋯ 管理菜单（管理/断开/解绑/重连，危险项）。断开确认"确定要断开连接器 {name} 吗?"；危险区"撤销授权"（"撤销授权将断开...你可以随时重新连接"）

## 4. MCP 服务器（独立面板）—— 对我们 MCP 接入参考

i18n `mcp.*`：
- 标题"MCP 服务器" / "MCP 服务管理"，副"安装 MCP 服务，为 AI 扩展更多工具能力"。分区"我的 MCP"。搜索"搜索服务器..."。空态"暂无 MCP 服务器 / 点击配置按钮添加 MCP 服务器"

## 6. 核心可直接照搬的信息架构（★对球房管家最有价值）

**侧栏一项 →（专家|技能|连接器）三 Tab 统一市场**；每 Tab = "市场浏览（多来源分段）+ 我安装/我的 + 详情弹层 + 一键安装/召唤/连接"；技能来源分层（推荐/官方 SkillHub/套件/社区 Knot/企业自建）；**创建技能 = 开新对话跑内置 skill-creator**；所有第三方产物（skill/expert 包、MCP）都过**安全检测 + 信任确认**闸；连接器分 OAuth/扫码/设备码/Token 四种授权。

→ 球房场景：技能=门店运营小工具（排班/对账脚本），专家=运营角色，连接器=收银/会员/门店系统集成；同样走"市场+我的+详情+安装"闭环 + 安全闸。
