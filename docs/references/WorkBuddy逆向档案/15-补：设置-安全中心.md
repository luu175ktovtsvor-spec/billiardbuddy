# 15-补：设置-安全中心（Security Center）

> **第二轮穷尽补齐**（2026-07-10）。归属：**App 外壳 = WorkBuddy** 侧（设置弹窗一屏）。
> **可信度**：几乎源码级可读（bundle 保留中文注释和源文件路径），下列全部按真代码写。
> **务实取舍**：见第 14 节。这套「铁律感」（沙箱开关 + 文件/命令/网络白黑名单 + 审计 + 红色危险二次确认）正是 owner 说很值得抄的。

## 0. 入口与总体架构
- 导航挂载：`case "securityCenter": return securityCenterEnabled ? <SecurityCenterPanel .../> : <GeneralSettingsPanel/>`。有 `securityCenterEnabled` 特性开关，关掉回退通用设置。侧栏 label="安全中心"。
- 组件树（源 `.../SecurityCenterPanel/`）：`index.tsx`（主页）；卡片 `AuditCenterCard/DataSecurityRow/RuntimeToolsCard/SecurityEntryRow/SystemAuthorizationCard/SystemToolsCard`；详情页 `NetworkDetail/CommandDetail/FileDetail/AuditDetail`；共享 `DetailHeader/RuleListSection`；hooks `useSecurityCenter/useExperimentalFeaturesConfig`。
- **详情页是整页替换**：`activeDetailPage="network"|"command"|"file"|"audit"` 时 `return <XxxDetail onBack=.../>`，不是弹层。每页顶部有 `DetailHeader`（带「‹ 返回」）。
- **状态与后端契约（`useSecurityCenter`，adapter=host RPC 总线）**：
  - 拉取 `emit("get-security-center-state")` → `on("security-center-state-result", {sandboxEnabled, systemToolPolicy, sandboxRules, commandSafetyRules, fileSafetyRules, auditLog, defaults:{...}})`
  - 保存 `emit("save-sandbox-rules-config", {...customRules, auditAction})`；`emit("save-sandbox-safety",{enabled})`
  - 审计 `emit("query-audit-log",{limit,cursor,category,decision,from,requestId})` → `on("audit-log-query-result",{requestId,entries,nextCursor,total})`；`emit("clear-audit-log")`；`emit("export-audit-log")`
  - 运行时 `get/save-bundled-runtime-config`；实验/删除保护 `get/save-experimental-features-config`
  - 沙箱总开关镜像 localStorage（`SANDBOX_SAFETY_STORAGE_KEY`，默认 true），派发 `window` 事件 `"sandbox-safety-change"`。
  - **默认名单不在前端**：`defaults.*` 由 host 按平台下发；前端只做「默认表+用户自定义」合并展示，落盘只存用户增量。内置项不可删（disabled，显示"内置"）。

## 14. 务实取舍标注（必做 / 可简化 / 暂不做）

**必抄且值得抄（铁律感）**：沙箱开关 + 左侧 3 入口行（文件/命令/网络）、三详情页「说明卡 + 增删名单 + 内置项不可删 + 重置默认」骨架、审计中心（预览5条 + 详情页搜索/三筛选/无限滚动/导出/清空）、关闭沙箱的红色危险二次确认。
- 数据契约照抄：一个 `save-sandbox-rules-config` 收 network/command/file/systemToolPolicy 增量 + `auditAction`，配 `security-center-state-result` 全量回推、`audit-log-query-result` 游标分页——前后端事件名可直接复用。命令/文件默认名单交给后端按平台下发这套机制保留（安全正确性）。

**可务实简化**：内置运行时表可简化成「一个总开关 + 一句说明」，不必做三行工具表；审计客户端 5000 条扫描搜索可退化为「后端带 keyword 查询」；命令名单如想更专业可捡回遗留的等宽+分级徽标样式（当前已简化成通用 RuleListSection）。

**暂不做/砍**：`SystemToolsCard`（纯 Windows WSL/wmic，球房几乎不碰）；`SystemAuthorizationCard`（macOS 专属，若只发 Win 可砍，见 16-补）；「实验功能」独立卡（当前构建已删，删除保护+批量删除阈值并入数据安全卡，版本管理撤下 UI）；遗留的 `__command-rule-*` 严重度分级 CSS（0 渲染）。
