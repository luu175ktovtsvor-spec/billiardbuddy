## 1. 弹窗外壳 SettingsModal（结构+交互，逐字可抄）
DOM 树（真实 className）：
```
.settings-modal-overlay            ← 全屏遮罩，点空白处关闭
  .settings-modal                  ← 弹窗盒子（flex 横向）
    .settings-modal__nav           ← 左栏容器
      <SettingsNavigation/>
    .settings-modal__content       ← 右侧内容区（flex 纵向）
      .settings-modal__close       ← 右上角 X 按钮
      .settings-modal__panel       ← 面板滚动容器
        renderPanel()              ← 按 activeTab 渲染对应面板
```
**尺寸/样式（照抄值）**：
- overlay：`position:fixed` 铺满，`background:rgba(0,0,0,0.56)`，`z-index:1000`，进场动画 `fadeIn 0.15s`。
- modal：`width:min(1040px, 100vw-64px)`；`height:min(720px, 100vh-64px)`；`min-height:min(480px,100vh-32px)`；`border-radius:12px`；`box-shadow:0 18px 48px rgba(0,0,0,0.28)`；进场 `slideUp 0.2s`（translateY(20px)+scale(0.98)→0/1）；`overflow:hidden`。
- 左栏 `.settings-modal__nav`：`width:236px`（≤600px高时 200px），右边 1px 分隔线。
- 右上 `.settings-modal__close`：绝对定位 `top:7px right:7px`，`34×34`，`border-radius:8px`，透明底，`:active` 才有底色；里面是 16×16 的 X（两条 stroke-width 1.5 的 path `M12 4L4 12 M4 4L12 12`）；`aria-label="Close settings"`；`-webkit-app-region:no-drag`。
- `.settings-modal__panel`：`padding:clamp(16px,4vh,34px) clamp(20px,4vw,38px) clamp(16px,4vh,36px)`；子面板（`[class$="-panel"]`）自身 `overflow-y:auto`，滚动条宽 10px、thumb 半透明圆角。
- **Logo 是死代码**：`SettingsModal({logo})` 收了 logo 参数但 render 里没用；左栏顶部实际靠 `.settings-navigation` 自己的 `padding-top:34px` 留白（**没有品牌 logo 区**）。白标时无需处理 logo。

**关闭/交互逻辑**：
- 点遮罩关闭：`onClick` 仅当 `e.target===e.currentTarget`（即点到空白遮罩）才 `closeSettings()`。
- **ESC 关闭**：全局 keydown 监听，`config.mode==="widget"` 时不装监听。
- `config.mode==="widget"` → 整个 `return null`（widget 模式不渲染内嵌弹窗，改调原生设置）。
- `!routeState.isOpen` → `return null`。
- **失效自动回落**：4 个 useEffect，当前 tab 的功能开关被关掉时（memory / helpFeedback / securityCenter / agentMail）自动 `switchTab("settings")`，避免停在空面板。

**响应式**：≤480px 时 modal 变全屏无圆角、纵向排列、左栏变横向可滚动。≤720px 时 section 的 title/desc 与 action 改上下堆叠。

## 4. 系统设置页 = GeneralSettingsPanel（本切片核心）
容器 `.general-settings-panel`（`max-width:780px`），标题 `<h2>` 用 `settings.title`="**设置**"（注意：系统设置页大标题写"设置"，不是"系统设置"；`font-size:20px; font-weight:650`），底部 1px 分隔线。下面 `.general-settings-panel__list`（`gap:8px`），每块用 `SettingSection` 卡片。

**⚠️ 本版系统设置页真实只有这些块（按渲染顺序）**：
1. **显示语言** → `CustomDropdown`，选项 `中文(简体)`/`English`。切换即时生效（`saveLocale`+emit）。**本版无重启确认**（i18n 里有 `restart.*` 文案但没接线，热切）。埋点 `settings_system_language`。
2. **字体大小** → `FontSizeSlider`（仅 `!cloud`）。
3. **技能自动更新** → `Switch` 默认 ON（cache `skills_auto_update_enabled`）。desc 硬写了 "WorkBuddy" 品牌名，**白标要改**。仅 `!cloud`。
4. **非高风险技能自动安装** → `Switch` 默认 OFF（cache `skills-security-auto-install-non-high-risk`）。仅 `!cloud`。
5. **技能推荐** → `Switch` 默认 ON。仅 `skillRecommendFeatureEnabled===true`。
6. **锁屏远程** → `Switch`。仅 `!cloud`。每 5s 轮询主进程 `getPowerSaveBlockerState`。
7. **默认工作空间存储路径** → 不是开关，是 `readonly input`（显示当前路径）+ `更改` 按钮。仅 `!cloud`。点"更改"→ `adapter.pickFolder({defaultPath})` 调**系统原生目录选择器**；选中新目录→`saveWorkspacePath`+emit+ 成功 toast "默认工作空间存储路径已更新"（2s）；无 pickFolder 能力→error toast "当前环境不支持选择目录"。**不支持手动键入**。
8. **界面主题** → `CustomDropdown` `深色/浅色`。**⚠️ 仅 `isCloudMode` 才渲染**！桌面模式下**系统设置页里没有主题选择**——桌面版深浅切换在 app 外壳（账号菜单"外观"）。任务把"主题深浅"放这里是错的。
9. **体验优化计划** → `Switch` + 行内链接 `了解更多`（跳隐私政策）。总是显示。
10. **通知** 分组（仅 `!cloud`）：
    - **桌面通知** → 绿色 `去授权` 按钮（仅 `isMac`），点它打开 macOS 系统设置通知面板。
    - **客户端通知** → `Switch`（`saveClientNotificationEnabled`）。

**任务列表里出现但本版没有的项（务必核对）**：
- **简洁模式**（`settings.compactMode.*`）→ i18n 有、任何组件都没引用，死文案。
- **禁用智能体团队** + **本地技能与记忆沉淀** → 真实渲染在 **智能体设置页（ExtensionsSettingsPanel）**，不在系统设置页（见 4b）。
- **发送消息快捷键** → i18n-only、无组件引用。

### 4b. 智能体设置页 ExtensionsSettingsPanel
复用同一套容器，大标题 `settings.extensions.title`="智能体设置"。三块：
1. **禁用全部插件** → `Switch` + 一行动态"当前状态"。
2. **禁用智能体团队** → `Switch`。
3. **本地技能与记忆沉淀** → `Switch`。

## 5. 状态/路由模型（照抄机制）
- Context：`SettingsProvider` 提供 `{routeState, openSettings, closeSettings, switchTab, config, agentMailEnabled}`。
- `routeState = { isOpen, activeTab, subRoute? }`。
- **默认 tab = `"settings"`** → 无参打开就落在系统设置页。
- **路由靠 URL hash**（即使桌面 app 也写 `window.location.hash`）：`#settings`/`#settings/<tab>`/`#settings/<tab>/<subRoute>`。**我们可换成本地 state，不必真写 URL hash。**
- `getValidTabs()` 按环境 + memory/securityCenter/agentMail 开关过滤 `ALL_TABS`。
- 入口点：账号下拉菜单 `openSettings("settings")` / `openSettings("account")`；独立齿轮"设置按钮"。

## 6. 可复用子组件（照抄规格）
- **SettingSection**：卡片式条目。有 `children`→`--stacked`（title/desc 在上、children 在下、上边框分隔）；无 children→`--inline`（title/desc 左、action 右）。背景卡片底色、`border-radius:4px`、inline `padding:10px 14px`、title `13px/650`、desc `12px/400 line-height:19px`、action 区 `min-width:128px` 右对齐。
- **CustomDropdown**：自绘下拉（非原生 select）。trigger `min-width:150px; height:30px; border-radius:6px; 1px border; font 13/500`，右侧 chevron `open` 时 `rotate(180deg)`。menu `top:calc(100%+4px)`、`box-shadow:0 10px 30px rgba(0,0,0,.28)`；option `height:30px`，选中项 `font-weight:600` + 右侧对勾（色 `#28b894`）。点外部关闭、支持键盘 Enter/Space。
- **FontSizeSlider**：7 档滑块。`min=1 max=7 step=1`，默认档=2（=16px）。7 个刻度点，当前档刻度隐藏让位给 thumb（16×16 圆、2px 边）。底部三标签 小/默认/大。markdown root px 表 `{1:14.857,2:16,3:17.143,4:18.286,5:20.571,6:22.857,7:26.286}`。拖动即时存 localStorage（`agent-ui-font-size-level`），应用字号 debounce 300ms。
- **Switch**：共享组件库 antd 风，统一 `size:"small"`。覆写：track `min-width:32px; height:18px`，handle `14×14 top:2px`。on 底色走全局 antd primary（本产品 `#6c4dff` 紫，我们换自己品牌色）。

## 8. 务实取舍标注（必做 / 可务实简化 / 暂不做）

**必做（机制照抄、值不变）**：
- 弹窗尺寸/圆角/动画、遮罩点空白关闭+ESC 关闭。
- 左栏 32px 行高 + 半透明选中态。
- SettingSection 卡片（inline/stacked）、CustomDropdown 自绘下拉、FontSizeSlider 7 档机制。
- 默认工作空间存储路径（input + 原生目录选择器 `adapter.pickFolder` + toast）——对齐我们"配置工作目录持久化"需求，很值得照搬。

**可务实简化**：
- hash 路由 → 换本地 state。
- cloud/local 双模、widget 原生设置、enterprise、overseas 环境分叉 → 全部拉直成纯桌面单模式，砍掉所有 `isCloudMode` 判断。
- 最小导航建议保留 6-8 项：账户 / 系统设置 / 快捷键 / 数据管理 / 系统授权(仅 macOS) / 帮助与反馈 /（可选）记忆、个性化。
- 主题深浅切换按 owner 边界放到 WorkBuddy 外壳（账号菜单"外观"），不进设置弹窗。

**暂不做**：
- 智能体邮箱(agentMail)、模型(models)、{name}设置(claw 人格)、安全中心/软件配置整套本地运行时沙箱、体验优化计划(数据回流)、企业/cloud 相关分支、技能推荐/非高风险技能自动安装（取决于我们有没有技能市场）。

**白标**：技能自动更新那条 desc 硬写了 "WorkBuddy" 品牌名，必须替换；品牌色别用紫 `#6c4dff`。
