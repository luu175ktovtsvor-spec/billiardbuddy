## 3. 创建/编辑页 = 全面板编辑视图（★重点）

点"+ 添加自动化"或点任务行 → 渲染 `AutomationEditModeView`（**整页替换，不是小弹窗**；头部 56 + 内容）。头部：面包屑"自动化" + "取消"/"保存"（周期选择为空时 disabled）。字段顺序：

1. **名称** → Input
2. **工作空间**（"（可选）"）→ 已选可关闭 Tag；未选"+"下拉（可搜索，占位"搜索工作区..."，空"无可用目录"）。CWD 标签格式"自动化任务-{suffix}"
3. **提示词** → 内嵌**完整 ChatInput**（和主对话同款，`interactionMode:"editor"`），带模型选择器 + 底部槽位：**SkillSelector**（技能）+ **ExpertSelector**（专家：召唤专家/最近召唤/召唤其它专家/不使用专家）+ **ConnectorSelector**（连接器）
4. **执行频率** → 调度编辑器（见 §4）
5. **推送到微信小程序**（Switch）："推送到 WorkBuddy 微信小程序" + hint"开启后，推送会通过安全链路把文件同步到云端…"（白标：换我们自己的渠道）
6. **连接器**（"连接器({count})"）：hint"勾选即授权该连接器在任务中免确认使用"，空"暂无已连接的连接器"+"管理连接器"入口（跳走时弹"跳转到连接器管理?当前编辑将暂存，回来后自动恢复"）
7. **执行权限**（两项）：
   - **免确认执行**（fullAccess，带"（推荐）"）：desc"允许 AI 在无人值守任务中自动执行操作，可能涉及敏感数据或文件修改，仅在信任任务时使用，用户可随时恢复默认权限。"
   - **需逐次确认**（default）：desc"敏感操作需用户确认。如果你离开屏幕，任务会停在等待状态。仅推荐在本地调试/手动监管时使用。"

### 权限风险确认弹层（选"免确认执行"时弹）

- 底部"改为「默认权限」运行 →"链接 + 主按钮"确认创建"

## 4. 调度编辑器（核心，数据模型 = 标准 RRULE）

顶部 Segmented 三选一（scheduleMode）：**周期 / 按间隔 / 单次**。

**数据模型**：`scheduleType = "once" | "recurring"`；`schedule = { freq, byday[], bymonthday[], bymonth[], byhour, byminute, interval, intervalHours }`；`validFromDate`/`validUntilDate`；once 用 `scheduledDate`/`scheduledTime`。

**① 周期模式**：CustomSelect（5 选项）+ 对应子选择器 + 时分：
- 每天（DAILY, interval:1, byday:全周）
- 每周（WEEKLY, interval:1）+ WeekdayMultiPicker（周一…周日）
- 双周（WEEKLY, interval:2）+ WeekdayMultiPicker
- 每月（MONTHLY）+ MonthdayMultiPicker（选 1–31 号，多选 tag）
- 每年（YEARLY）+ 选月份 + 选日期
- 末尾 **TimePicker**（时:分）
- 校验：未选任何周几/月号/月份→保存 disabled（"请至少选择一个星期/日期/月份"）

**② 按间隔模式**："每 [Input] 小时"（intervalHours，最小 1，freq:HOURLY）+ 一排周几胶囊（可限定只在某些天跑）。校验"按间隔执行需至少每 1 小时"。快捷预设"每 30 分钟/1/2/4/8 小时"

**③ 单次模式**：TimePicker + 日期。校验"请选择单次执行日期"、"单次执行时间必须晚于当前时间"

**TimePicker 弹层**：宽 220，**向上弹**，圆角 10，两列 grid（时/分），选项 30px，选中态背景 active 字重 500。

**生效日期区间**：触发器整宽 36；弹层宽 340 向上弹，内是 7 列月历，底部有"今天"按钮。

## 12. 给「球房管家」的落地要点

- **调度模型直接照搬**：三档（周期/按间隔/单次）+ RRULE 数据结构（freq/byday/bymonthday/byhour/byminute/interval）+ 生效日期区间——这套很成熟，可 1:1。
- **权限档 + 风险确认弹层**（免确认执行 vs 逐次确认）对无人值守 Agent 是标配，照抄。
- **12 内置模板结构**换成球房场景（营业额播报/排班提醒/对账/巡检）。
- **主按钮黑白反转**（浅 #111 / 深 #fff）是它高级感来源，配色其余换我们的。
- 推送渠道文案里的"WorkBuddy 微信小程序"换成我们自己的渠道。
