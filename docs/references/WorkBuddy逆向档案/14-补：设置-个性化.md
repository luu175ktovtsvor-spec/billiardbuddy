## 3. 语气风格 —— 【是下拉，不是卡片】
**结构**（`.__setting-row`：左右两列 flex，gap18，顶对齐）
- 左 `.__setting-text`：name="基本风格和语调"(15/500) + desc="设置 AI 助手回复你的风格和语调。这不会影响 AI 助手的功能。"(13 次要色 行高1.6)
- 右 `.__dropdown`（relative）：
  - **触发按钮** `.__dropdown-trigger`：当前选中项名 + 14×14 V 箭头。`padding:6px 12px; 1px 边; radius8; min-width100; 13px`。hover 边框变亮；`--open` 边框变主色紫 + `box-shadow:0 0 0 2px rgba(124,58,237,.15)`，箭头 rotate(180)。
  - **展开菜单** `.__dropdown-menu`（`dropdownOpen` 时）：`top:calc(100%+4px); right:0; min-width240; radius10; box-shadow:0 8px 28px rgba(0,0,0,.25); padding4; z10`，进场 `personalization-dd-fade 0.12s`。
  - **每个选项** `.__dropdown-option`（`<button>` padding 9×12 radius7 flex gap10）：左 name(13)+hint(11 muted)；右对勾"✓"（默认 opacity0，选中 opacity1）。选中态 `--selected` 背景 `rgba(124,58,237,.12)` 文字紫 500；hover `rgba(255,255,255,.05)`。

**8 个选项**（数组 `TONE_STYLE_OPTIONS`，顺序固定）：
| # | key | 中文名 | hint |
|---|-----|--------|-----------|
| 1 | `""`(空) | 默认 | 不设定特定风格 |
| 2 | `professional` | 专业严谨 | 清晰、准确、值得信赖 |
| 3 | `friendly` | 亲和友善 | 温暖、平易近人、鼓励支持 |
| 4 | `straightforward` | 直言不讳 | 简明扼要、不废话、直击要点 |
| 5 | `creative` | 天马行空 | 富有想象力、善用比喻类比 |
| 6 | `efficient` | 高效务实 | 最少文字、最大信息量 |
| 7 | `sarcastic` | 毒舌吐槽 | 犀利吐槽、但绝不伤人 |
| 8 | `socratic` | 启发引导 | 用提问引导思考、授人以渔 |
- 默认选"默认"（空字符串）。点选项 → `setToneStyle(key)` + 关下拉；**不会立即保存**，要点底部"确认"才落盘。点外部/失焦收起。

## 4. 加载过程欢迎语开关
- 同 `.__setting-row`。name="加载过程欢迎语" / desc="在 AI 生成等待过程中展示辅助提示。关闭后可在这里重新打开。"
- 右 `Switch size="small"`（轨 34×18，滑块 14，开时 translateX(16)，开态色=品牌色）。
- **企业账号特判**：有 `enterpriseId` → 开关 disabled，desc 换"企业版账号不展示加载过程欢迎语。" 未登录也 disabled。
- **存法与另两项不同**：**不走确认按钮、即时生效**，存 localStorage（键 `workbuddy.loadingTips.dismissed:<uid>`，开=删标记、关=写"1"）。切换后立即 `saveLoadingTipsEnabled`，失败 toast"保存加载过程欢迎语设置失败"并回滚。
- 还做跨窗口同步（`storage` 事件 + 自定义事件）——单窗口桌面版可省。

## 5. 自定义指令（textarea，竖排无左右分栏）
- name="自定义指令" / desc="告诉 AI 助手你希望它始终遵循的规则和偏好,这会直接影响所有对话。"
- `<textarea .__textarea>`：`min-height120; max-height200; padding12×14; radius10; 14px; resize:vertical; margin-top12`。focus 边框紫 + `box-shadow:0 0 0 2px rgba(124,58,237,.1)`。placeholder=`例如: "每次回答我之前都说 ok, 再接后续内容"`。`maxLength=1500`（`MAX_CUSTOM_PROMPT_LENGTH`）。
- 底部 `.__input-footer`（两端对齐）：左 hint="这些指令会应用于你的所有对话"(12 muted)；右 `.__char-count` 格式 `{已输入} / 1500`。颜色：>1200 警告黄(#f59e0b)、>1500 错误红(#f14c4c)、正常 muted。

## 6. 底部确认按钮 & 脏检查
- `.__footer`（右对齐 margin-top24 padding-top20）一个 `.__confirm-btn`="确认"（padding 7×24 radius8 13/500，**绿底** `#28b894`/白字，hover opacity.9）。
- **脏检查** `isDirty = 语气 或 自定义指令 ≠ 初始值`。不脏时 `--disabled`（opacity.4 not-allowed）。**只有语气/指令参与脏检查，欢迎语开关不参与**。
- 点确认 → `adapter.savePersonalization({toneStyle, customPrompt})`，成功把 initial 更新为当前值 + toast"设置已保存"；失败 toast"保存设置失败"。

## 7. 状态流转 & 持久化
- 进面板 `adapter.getPersonalization()` 灌 state + `initialRef`（脏检查快照）。开关状态另从 localStorage 读。
- 存（语气+指令）：`daemonClient.configSet("personalization", {toneStyle, customPrompt})` → 主进程 AppConfig。读 `configGet("personalization")`。
- **后端消费**（值得抄的设计）：`PersonalizationCollector` 读 `appConfig.get("personalization")`（兜底旧路径 `~/.workbuddy/settings.json` `.personalization`）；`toneStyle` 在白名单 7 个里（后端白名单**不含空字符串**，"默认"=不注入）→ 读 **`style-<key>.md`** 文件内容，注入 prompt 变量 **`ToneStyleContent`**；`customPrompt` trim 后注入 **`UserCustomPrompt`**。两者都是系统提示词变量，失败只 warn 不阻断。

## 11. 务实取舍标注（必做 / 可简化 / 暂不做）

**必做**：整屏本来就轻，语气下拉（8 项 name+hint+key）+ 欢迎语开关 + 自定义指令 textarea（字数分档变色）+ 确认脏检查，基本 1:1 复制即可。

**可务实简化**：
- 加载欢迎语开关的跨窗口同步（storage/custom event）可删——桌面单窗口直接读写。
- 语气这层如嫌下拉朴素，**可升级成卡片网格**（数据结构完全一样，只换渲染；但 WorkBuddy 原版是下拉）。
- 8 种语气对应 8 个后端 md 模板——如逻辑简单，可不做 md 文件，直接系统提示按 key 拼一句风格指令（务实版）。

**暂不做**：
- 企业账号特判（enterpriseId + 企业版专用 desc）——面向球房老板单机版无意义，去掉，开关永远可用。
- legacy `settings.json` 兜底读取（无历史包袱）。
