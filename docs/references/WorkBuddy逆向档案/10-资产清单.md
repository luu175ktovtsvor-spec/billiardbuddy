## 1. 品牌吉祥物 A：平面几何"笑脸猫" logo（★核心）

这是 app 图标/侧栏 header 上那个笑脸——一套**可变色的矢量系统**（同一套 path 数据在多文件换配色复用）。

**造型（几何拆解，来自 `$R/renderer/assets/logo-workbuddy-BUNGQxi-.svg` 64×64 与 `resources/icon.png`）**：
- 外框：圆角方（`rx=13.8106`，约 21.6% 圆角），**竖向线性渐变**填充
- 猫脸=两部分：①左上角一对**尖猫耳 + 脸颊轮廓**（半透明白剪影）；②右下一个**圆角矩形"屏幕脸"**，里面**两只白色胶囊眼**（圆角 rect，细长竖条，略 -30° 倾斜 → "眯眼微笑/满足"表情）
- 一枚**柔光高光圆斑**（app 图标里是黄色 `#FFE255` @49% 透明）
- 整体读作：一只从右下探头、眯眼笑的猫。极简、扁平、几何

**三套配色变体（同一造型，不同品牌线，SVG stop-color 精确读出）**：

| 变体 | 背景渐变 | 光晕斑 | 前景 | 文件 |
|---|---|---|---|---|
| **绿色（WorkBuddy 主）** | `#0EC7A8` → `#00C885` | `#FFE255` 黄 @49% | 白 | `logo-workbuddy-BUNGQxi-.svg`、`resources/icon.png` |
| **紫色（CodeBuddy header）** | `#6C4DFF` → `#583ED3` | `#32E6B9` 薄荷绿 | 白脸 + `#32E6B9` wordmark | `header-cat-icon-*.svg`、`header-icon-*.svg`、`small-icon-*.svg` |
| **橙色（LearnBuddy）** | `#FF8F54` → `#FFB700` | `#F2FF00` 亮黄 | 白 | `header-learnbuddy-B8SEJIKS.svg` |
| **黑白（CLI/终端）** | 白底黑猫 / 黑底白猫 | 无 | — | `$R/cli/dist/web-ui/logo.svg` |

> **关键**：主 app 图标是绿的（#00C885/#00C29A 族），但产品名 header 锁定紫底+薄荷绿字。眼睛=两枚倾斜圆角胶囊，是这个 IP 最省事又最识别的记忆点。→ 我们做绿色笑脸对标绿色变体渐变即可。

## 5. 图标集（★线性图标风格/来源，已确认）

- **主 UI 图标库 = `lucide-react`**（`lucide-react-BwkA_fXk.js`，约 **198 个** `createLucideIcon`）。lucide = 开源 MIT 线性描边图标集，统一 **24×24 viewBox、2px 描边、圆角线帽、`currentColor` 描边**，类名前缀 `lucide-`。→ **我们直接也用 lucide 即可零成本对齐这种"细线、圆头、克制"观感。**
- **编辑器/文件区图标字体**：`codicon`（VS Code 官方，ttf）、`seti`（Seti-UI 文件类型，woff）；CLI web-ui 另带 file-icons/devopicons/octicons/fontawesome/mfixx woff2
- **集成/连接器品牌图标**（第三方 logo 位图）：QQ、钉钉、飞书、企业微信、微信、乐享、腾讯文档、腾讯会议；腾讯文档全类型 `tdoc-{doc,sheet,slide,mind,flowchart,board,form,pdf,folder,...}.png`。→ 这些是**别人的商标**，我们换成台球行业自己的连接器图标
- 小图标特例：`kb-*.svg`（知识库）其实是把 80×80 PNG 用 `<pattern>` 塞进圆角方（位图不是矢量）

## 7. 品牌色板（★完整绿阶，light/dark 两套，从 cb-bridge 精确读出）

Token 体系：`--wb-palette-{brand,green,...}-N` 原子色阶 → `--wb-color-text-*` 语义层 → 组件消费。（详见 [01-设计系统.md](./01-设计系统.md)，这里给一句话选型结论。）

**Brand（主强调·teal 偏绿，"笑脸绿"那族）**：
- LIGHT：`brand-8 #00C29A`（= --wb-brand-primary / --wb-color-text-brand-default）；`brand-9 #009273`、`brand-10 #00614D`
- DARK：`brand-7 #22cba8`（暗色主品牌绿）、`brand-8 #4cf0ce`

**Green（成功/正向，更"草绿"）**：LIGHT `green-8 #0CBF5B`；DARK `green-6 #24c46c`

**高频绿色字面量**：`#10b981`（×22，emerald，成功/图表绿）· `#00b96b`（×21，主 CTA 绿）· `#07C160`（微信品牌绿，×3）· `#32E6B9`（吉祥物眼睛/光晕）

> **一句话给我们**：主品牌绿取 `#00C29A`（亮）/`#22cba8`（暗）这条 teal-green（app 图标渐变 `#0EC7A8→#00C885` 就是它两端），成功态用 `#0CBF5B`/`#10b981`，吉祥物眼睛点睛用 `#32E6B9`。整套是"偏青的春绿"，不是微信那种纯绿。**——这是 WorkBuddy 的色，我们要换成球房管家自己的品牌色。**

## 8. 字体文件（哪些是壳自带、哪些靠系统）

- **app 壳正文字体 = 系统栈，不内嵌**：中文 `"PingFang SC"` 打头，回退 `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", sans-serif`；字号继承 VS Code `--vscode-font-size`（默认 13px）。UI 里点名过 `Inter`、`Poppins`（但**没有对应 woff2**，靠系统/缺失回退）
- **等宽（代码/终端）**：`Menlo, Consolas, "JetBrains Mono", "SF Mono"` 等——**全系统栈，不内嵌**
- **真正内嵌的字体**：
  - `Assistant`（4 个 woff2）：唯一内嵌的品牌/UI 无衬线，**但只被 excalidraw 白板组件用**，不是全局正文
  - `KaTeX_*`（~60 个）：数学公式渲染
  - `codicon`、`seti`：图标字体（非文本）
- → **壳本身别背字体包**，跟它一样用 PingFang SC + 系统栈最省；只有真需要（公式/白板）才内嵌

## 9. favicon / 托盘 / dock 图标

- **无 favicon**：`index.html` 的 `<head>` 里**完全没有 `<link rel="icon">`**（Electron app 不需要网页 favicon）
- **app/dock 图标**：`$R/resources/icon.png`（286K，绿色笑脸猫，1024²）
- **macOS 菜单栏托盘**：`$R/resources/trayTemplate.png` + `@2x.png`——**纯黑猫剪影 template 图**（`~Template` 命名 → macOS 自动按明暗菜单栏反色，只用 alpha 通道）
- → 我们：准备 ①1024² 彩色 app 图标（绿色笑脸）②`*Template.png`/`@2x` 黑色单色剪影给 mac 托盘（命名必须带 `Template` 才自动反色）

## 10. 一句话选型建议（给球房管家）

- 图标直接上 **lucide-react**（观感即对齐）
- 品牌色取我们自己的绿（参考它 teal-green 的做法，但换成球房管家的色），成功 `#10b981` 级别
- 吉祥物做**我们自己的**绿色笑脸（参考"圆角方+白脸+两枚倾斜胶囊眼+柔光斑"几何配方，以及"换眼睛符号=换情绪"机制），再配一套**黑白线稿门店场景插画 + 唯一绿点睛**
- 字体 PingFang SC + 系统栈不背包
- mac 托盘用 `Template` 黑剪影
