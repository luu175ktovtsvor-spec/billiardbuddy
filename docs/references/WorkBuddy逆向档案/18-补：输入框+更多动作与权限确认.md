# 18-补：输入框「+更多动作」菜单 与 权限确认

> **第二轮穷尽补齐**（2026-07-10）。归属：**App 外壳/输入区 = WorkBuddy** 侧。
> **可信度**：本版解包**没压缩、带中文注释和设计稿节点号**（大金矿），下列每条=真代码 + 设计师注释像素规格。
> **最重要纠偏**：档案说的「权限子菜单（默认权限 vs 允许完全访问）」**不在「+」菜单里**。「+」菜单只有 6 项（添加文件/引用文件/模式/专家/技能/连接器）。**权限是输入框页脚一个独立按钮**（盾牌+「默认权限/允许完全访问」+下箭头），点它弹 popover 才是权限面板 + 二次确认弹窗。i18n 里 `input.wbAdd.permission`="权限" 是当年在"+"菜单里的残留，现在没人用。
> **务实取舍**：见第 17 节。权限那套（默认/完全访问 + 二次确认）建议 1:1 保留。

物理文件（`wb-deep/renderer/assets/`）：组件 `connector-CvFT3fv6.js`；ConfirmDialog `src-CMgU1OQk.js`；样式 `connector-C7gGcGMD.css` + `src-kZTgkaJN.css`；文案 `zh-cn/en`。源码路径 `packages/agent-ui/src/components/main-content-core/wb-input-add/` 和 `wb-input-footer/permission-setting/`。

## 1. 「+」触发按钮（WbInputAddMenu）
- 24×24 圆形透明按钮，居中 `WbAddPlusIcon`(16×16 加号)。hover/打开态 `.active` 背景 `--cb-hover-bg`。
- **加号旋转动画**：打开时 `svg{transform:rotate(45deg)}`，过渡 `0.42s cubic-bezier(0.25,0.8,0.3,1)`——加号平滑转成"×"。标志性交互，务必抄。
- `aria-label`/`title`=`input.wbAdd.title`="更多操作"。定位 `useFloatingRef` placement `top-start` offset8 `matchWidth:false`（面板固定 200 宽）。**不用 Portal**（`position:absolute` 渲染在选择器子树内，让 useDismiss 不误判二级面板为外部点击）。
- 一级面板 `_menu_`：`width:200 padding:8 radius:16 border:0.5px --cb-popover-border box-shadow:--cb-shadow-popover`，进场 `0.18s ease-out` opacity 淡入。
- 点击 trigger toggle；ESC/点外 dismiss，关闭时清二级菜单 activeId。

## 2. 一级菜单结构（两组，中间分隔线）
**组 1（文件类）**：add-files `input.wbAdd.addFiles`="添加文件"（回形针）；reference-files `input.wbAdd.referenceFiles`="引用对话中的文件"（@）。
**组 2（能力类）**：mode "模式"（魔法棒）；experts "专家"（眼镜）；skills "技能"（魔法棒）；connectors "连接器"（链环）。
- 每项行 `_item_`：`height:32 padding:0 8 radius:8 gap:8 font14/22 PingFang SC`。左 16×16 图标 + 标签 + 右 14×14 chevron。hover/激活 bg `--cb-dropdown-item-hover-bg-color`(#f2f2f2)。disabled `--cb-text-muted` not-allowed。
- **各项隐藏逻辑**（host 没注入对应能力就整项隐藏，空组不渲染分隔线）：add-files 无任何 onPick* 隐；reference-files 无 onInsert 或拉不到文件隐；mode 无 setMode 隐；experts onSelect+onSummonMore 都无隐；skills onInsert+onManage 都无隐；connectors 无 onSummonMore 隐。**利用这套"无注入即隐藏"机制删起来干净。**

## 3. 二级面板展开/悬停/关闭机制（核心交互）
- **hover 展开**：`onMouseEnter`+`onMouseMove` 双绑，进入一级项立即设 activeId 弹二级。
- **二级定位**：以 active 项为 reference，`right-start` offset4，flip fallback `[left-start,right,left]` + shift，`strategy:"fixed"`，autoUpdate。
- **不抖动关闭**：离开整块才关，**120ms 关闭延迟**（`SUBMENU_CLOSE_DELAY_MS`）兜边界回弹；进入 menu/submenu 任一立刻清计时。激活项右侧隐形**安全三角/桥接区**（`.itemActive::after` `left:100% width:20 height:max(140px,100%+96px)`）让鼠标斜切不掉。
- 点二级项后 `closeMenu()` 关整个弹层。未接通模块返回占位面板 `input.wbAdd.submenu.placeholder`="功能开发中…"。

## 6. mode 子菜单 —— Craft / Plan / Ask
结构 = 顶部**描述区**（随当前模式换文案）+ 分隔线 + 两个开关行（Plan、Ask）。**Craft 没有独立开关行**：默认态，两开关都关=craft。
- 描述区（12/20 tertiary pre-line）：craft"当前为默认模式，可高效执行并完成任务。"/plan"当前为计划模式，将先规划任务，等你确认后再执行。"/ask"当前为问答模式，适合问问题，找思路，无法做执行。"
- 两开关行 `ModeToggleRow`（184×32 hover #F2F2F2）：左主文案+英文小字(12px rgba(0,0,0,0.3))+右 toggle：
  - Plan：`label.plan`="计划"（"Plan"）；tooltip"开启后，WorkBuddy 会先规划任务，等你确认后再执行"。
  - Ask：`label.ask`="仅问答"（"Ask"）；tooltip"适合问问题、找思路，无法做执行"。
- **tooltip 延迟 1000ms**（默认 300ms 太灵敏、选模式误触，2s 才是想看说明），黑主题，placement bottom，带箭头。
- **互斥切换**：点某行=已是该模式则切回 craft，否则切到该模式（关掉另一排他模式）。切换后**立即关整个"+"弹层**。
- **ModeToggle 开关**：26×16 track，off `--cb-toggle-track-off-bg`(rgba(0,0,0,0.06))，**on `--cb-switch-active-bg`(#00b96b，设计稿注释 #00C29A)**，thumb 12×12 白，off left2/on translateX(10)，0.15s。
- **mode-chip**：currentMode≠craft 时输入框上显示 chip（图标+标签+hover×），点×`setMode("craft")` 退出，`aria-label`=`input.modeChip.clear`="退出{mode}模式"。craft 态不显示。

## 10. ★权限设置按钮（wb-input-footer/permission-setting.tsx）—— 独立于「+」菜单

- 按钮 `PermissionSetting`（`height:32 padding:0 8 radius:8 gap:4`），有 `variant:"footer"|"toolbar"` + `compact` 三形态：
  - **默认权限态**：盾牌+勾 `ShieldSecuredIcon`(17×17) + 文字 `inputFooter.permission.default`="默认权限" + 下箭头(opacity0.5)。文字色 tertiary，hover 变 primary 且 label 加粗 500。
  - **完全访问态**：盾牌+感叹号 `ShieldDangerIcon`(16×16) + 文字 `input.wbAdd.permission.fullAccess`="允许完全访问" + chevron(opacity1)。整按钮 `.buttonDanger` 文字变**红 `--wb-palette-red-9`(#B42C3F)**。
  - **打开态** chevron rotate(180)（0.42s 同"+"曲线）。**disabled 态**：opacity0.5 not-allowed，Tooltip `disabledTip`="当前模式仅可使用默认权限"。

## 11. ★权限面板（permission-submenu.tsx）
面板 `_panel_`（`width:200 padding:8 radius:16 border:0.5px shadow flex-col gap:8`）：
- 顶部描述区（12/20 tertiary pre-line）：默认态"当前为默认权限，所有操作都会在安全沙箱约束内进行，超出范围会请求你的允许。"；完全访问态"当前权限为允许完全访问，\n请注意数据安全，建议执行可信任的任务。"
- 分隔线 + **单个切换行**（184×32 hover #F2F2F2）：左标签"允许完全访问" + 右**红色 `PermissionToggle`**（26×16，off track-off，**on `--wb-palette-red-7`(#E85C5C，设计稿 #E54747)**；thumb 12×12 白，故意用红区分高风险）。
- **整行是 tooltip 触发区**（无独立 info 图标），黑 tooltip，placement right，maxWidth224，内容"开启后将减少确认步骤，允许 AI 直接执行更多操作。可能涉及敏感操作、文件修改或外部执行"。
- **切换语义（关键）**：当前 `default-sandbox`(off→on) → **必须弹二次确认弹窗**，不直接切；当前 `full-access`(on→off) → **直接** `onModeChange("default-sandbox")`，无需确认。

## 12. ★★确认允许完全访问弹窗（ConfirmDialog appearance="workbuddy"）
**档案缺的核心件。** 文案全部 `input.wbAdd.permission.confirm.*`：
- **标题**"确认允许完全访问？"，左带**红色危险盾牌** `WbErrorIcon`(20×20，色 `--cb-error-color` 设计稿 #F64041)，16/24/600。
- **正文**（padding-left:28px 对齐标题文字 / 14/22 secondary / pre-line）："开启允许完全访问后，AI 将减少确认步骤，并可直接执行更多操作，包括敏感操作、文件修改或外部执行。\n仅建议在您信任当前任务时使用。"
- **勾选框**（padding-left:28 gap4）："我已了解风险，并愿意继续"。自定义 14×14 方框（**无圆角**）：未选边框 `--wb-palette-gray-5`(#E6E6E6/暗#3a3a3a)，选中填充黑90%+白勾。
- **按钮**（workbuddy 外观 gap12，height32 padding0 12 radius8 14/600）：取消（secondary）+ 确认"允许完全访问"。**确认按钮受勾选门控**：`confirmDisabled = !confirmChecked || confirming`；`confirmButtonColor = 勾选且不loading ? "#F64041"(红) : "#F5B9B9"(浅红禁用)`；confirmLoading 时显"..."。
- **确认流程** `handleConfirm` → `setConfirming(true)` → `await onModeChange("full-access")` → 成功关弹窗、重置勾选。
- **ConfirmDialog 通用**：Portal 到 body；点遮罩空白/Esc 关闭；`buttonOrder` 默认 cancel-confirm。**workbuddy 外观容器**：max-width480 padding24 radius24 border0.5px 底 `--cb-dropdown-bg-color` shadow；遮罩 `rgba(0,0,0,0.6)`。

## 14. 外部模型数据安全提示（读不到确切挂载点）
i18n 有 `input.externalModelWarning`="使用外部模型，注意数据安全"、`model.group.external`="外部模型"、`mcp.trustThirdParty`="第三方服务，WorkBuddy 未审核"。**但 `externalModelWarning` 在本包所有 JS 搜不到任何 `t()` 引用**——死 key 或 lazy chunk 挂载，读不到渲染点。若要做"选外部模型→输入框附近黄字提示"，文案可用这句，挂载点自定。

## 17. 务实取舍标注（必做 / 可简化 / 暂不做）

**必做**：
- 「+」按钮加号旋转动画 + 悬停展开二级 + 120ms 关闭延迟 + 安全三角 + 0.18s 淡入——全抄。
- 「+」菜单**只留 4 项**：添加文件（本地）、引用对话中的文件、模式、技能。
- **模式**（Craft/Plan/Ask）保留——对上 cc 的 permission/plan mode，描述区+双开关+互斥+mode-chip 照抄。
- **权限（默认权限 vs 允许完全访问 + 二次确认弹窗）1:1 保留**——这是安全护栏，红色开关 + "我已了解风险"勾选门 + 勾选前确认按钮禁用（浅红 #F5B9B9）这套是后端沙箱/信任门的前端体现，别简化。文案照抄（WorkBuddy 换我们品牌）。

**可务实简化**：add-files 只留本地文件；skills 搜索/pin 可保留（对上我们技能库）。

**暂不做/砍**：专家、连接器、腾讯生态（网盘/腾讯文档/ima/乐享）——利用"无注入即隐藏"删干净；连接器 chip / 已连接应用 popover（无 MCP 生态）；外部模型提示（读不到挂载点）。

**白标**：所有 "WorkBuddy" 字样换我们品牌（mode tooltip.plan、mcp.trustThirdParty 等）；埋点 id 前缀 `agent_` 换我们命名；类名 hash（`_1qhrc_`/`_1h7yd_`）是 CSS-module 编译产物，自己写不会撞。

## 盲区
1. `input.externalModelWarning` 死 key，确切渲染点读不到。
2. 「+」菜单和权限按钮/连接器 chip 在工具条精确左右排布顺序读不到完整拼装源（组合在别的 chunk）：WbInputAddMenu 内联渲染在 selector 子树、权限按钮在 wb-input-footer、chip 属 wb-status-chips，三者分属不同容器。
3. 部分颜色"设计稿注释值"与"实测 token 值"有细微差（已双列标注，以实测为准）。
4. add-files netdrive hasArrow 意味有下一级（网盘目录树），未深挖。
5. 深色具体 hex 部分从注释推断，非每个都在 CSS 直接命中。
