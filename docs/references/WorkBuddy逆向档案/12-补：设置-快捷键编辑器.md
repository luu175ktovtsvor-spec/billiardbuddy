## 四、录制交互状态机（核心，`use-shortcut-recorder.ts`）
设计模型：①点绑定区→进入录制；②按键实时跟随显示；③**所有键松开→自动提交(保存)**；④只按了修饰键没普通键→行内报错并留录制态；⑤Escape 任意时刻取消。**没有中间"确认"态，松手即存。**

- **进入录制** `startRecording(id)`：清态、`state='recording'`、`setShortcutRecording(true)`（全局标志让 app 其它快捷键让路）。
- **keydown**（捕获阶段）：`preventDefault+stopPropagation+stopImmediatePropagation`；裸 Escape→取消；每次先清 error；`event.key` 变形时用 `event.code` 经 `resolveKeyFromCode()` 还原；修饰键进 set，普通键先删旧普通键（只留一个）、大写、空格转 Space；`buildBindingFromPressed()` 拼实时串（**修饰键顺序固定 Ctrl→Shift→Alt→Meta**）；有普通键则立即查 `findNonEditableConflict`（撞固定键立刻报错）。
- **keyup**：删松开的键（Meta 松开且已有完整绑定→直接清空 set，规避 macOS ⌘ keyup 丢失）。set 空（全松开）时提交判定：有冲突→报错留态；无修饰且不在 `ALLOWED_STANDALONE_KEYS`（Escape/Enter/F1..F12）→报 errorNoModifier；只按修饰键→errorModifierOnly；都过→ `setCommittedBinding`。
- **取消三途径**：裸 Escape / 窗口 blur / 点击组件外（mousedown 监听**延迟 100ms 才挂**，避免刚点进来就取消）。
- **提交后**（Panel watch `committedBinding`）：`validateBinding` 有错→留录制态不保存；`findConflictingShortcutId` 撞其它命令→显示红色冲突键 + "已被使用"、留态；都过→ `saveShortcutOverride(id,committed,platform)`+ toast"快捷键设置成功"。

## 五、三层拦截逻辑（`shortcut-registry.ts`）
**A. validateBinding** 顺序：无普通键→errorMissingKey；无修饰且不在 ALLOWED_STANDALONE→errorNoModifier；`findSystemReservedConflict` 命中→返回 `reservedReason.*`；`findNonEditableConflict` 命中→errorNonEditableConflict。
**B. 系统保留键 `SYSTEM_RESERVED_SHORTCUTS`**（按平台，锁死）：mac `Meta+Q/C/V/X/W/A/Z/Tab/M/R`；win `Ctrl+C/V/X/A/Z`、`Alt+F4`。只比对当前平台。
**C. findNonEditableConflict**：遍历 `editable:false` 定义比当前平台默认绑定。
**D. findConflictingShortcutId**：遍历全部当前绑定，`areBindingsEquivalent` 命中且非自己→返回其 id。
**等价判定 `areBindingsEquivalent`**：四修饰位全等 + 普通键 lowercase 比；`=`↔`+`、`-`↔`_` 视为同物理键（`EQUIVALENT_KEY_GROUPS`）。
**resolveKeyFromCode**：`KeyX`→X，`DigitN`→N，`CODE_TO_KEY_MAP`（Minus→`-` Equal→`=` Slash→`/` 等），`F\d`→原样。

## 六、重置 / 清除 / 删除
- **清除单条**（行内 delete 图标，仅 editable 且已绑定）→ `clearShortcutBinding`：当前平台 override 存**空串 ""**（=显式"未指定"，两平台都置空），**不是恢复默认**。删除图标自定义 `DeleteIcon`(14×14)。
- **重置单条**（reset 图标，仅 `isCustomized`）→ `removeShortcutOverride`：删 override（两平台一起删）。图标内联 SVG 逆时针箭头。
- **未指定行**：delete 位用不可见占位 `.__action-btn-placeholder`(28×28) 顶住对齐。
- **全部恢复默认**：只对 `isCustomized` 的 id 调 `resetAllShortcutOverrides`（**单次写入**避免 race）+ toast。
- `isCustomized` = 当前平台 override 值 ≠ 该平台默认值。

## 七、搜索（含拼音，`pinyin-match.ts`）
`filteredShortcuts`：先按环境/语音过滤，再按 query。query trim+lower + 中文标点归一。每条命中即保留：label includes；`matchesPinyinInitials`（仅 query 全小写 ASCII：`dk`匹"打开"、`dakai`匹"打开设置"）；单字符 query 比主键显示；多字符比 `formatShortcut`/原始绑定串/id includes。

## 八、存储 / 持久化 / 跨平台
- localStorage key `agent-ui-keyboard-shortcuts`，结构 `{version:1, overrides:{[id]:{mac?,win?}}}`。空串=未指定，undefined=用默认。
- `saveShortcutOverride`：`isBindingComplete` 校验；写当前平台 + **自动映射另一平台**（`mapBindingToPlatform`：win↔mac 只换 `Ctrl`↔`Meta`）；dispatch `agent-ui-keyboard-shortcuts-change`；`scheduleUploadToCloud`。
- 副作用桥接：`send-message` → 同步旧 `agent-ui-submit-message-shortcut`；`toggle-window` → 调 `window.workbuddyDesktop.globalShortcut.updateToggleWindow` 让主进程重注册全局键。
- 云同步 `applyOverridesToLocal / scheduleUploadToCloud / syncBridgesAfterCloudPull`——**我们本机 app 可整块砍掉**。
- legacy 迁移 `migrateLegacySendMessageShortcut`——我们无历史包袱可砍。

## 十二、务实取舍标注（必做 / 可简化 / 暂不做）

**必做（能用且不坑的关键）**：录制状态机（keydown/keyup/blur/click-outside + release-to-commit）、三层拦截（validate/保留键/命令冲突 + `=/+`、`-/_` 等价）、`resolveKeyFromCode` 兜底、reset 单条/全部、未指定占位对齐。扁平列表直接照做。

**可务实简化**：
- 拼音搜索降级——中文命令少，先只做 label 子串 + 绑定串子串匹配，拼音首字母作二期。
- `mac↔win` 双写映射可保留（成本低），若一期只出一个平台可只存当前平台。

**暂不做/砍**：
- 云同步整块（`applyOverridesToLocal / scheduleUploadToCloud / syncBridgesAfterCloudPull / markLocallyModified`）——本机只需 localStorage。
- legacy 迁移（`migrateLegacySendMessageShortcut` 及旧桥）。
- 二次确认弹窗按需（源码扁平版没有，i18n 里有备用字符串，要更稳可自行加 Popconfirm，非必须）。

**白标**：本块文案无品牌名，可直接用；`--cb-*` 换我们派生 token、`--cb-button-primary` 换品牌主色。
