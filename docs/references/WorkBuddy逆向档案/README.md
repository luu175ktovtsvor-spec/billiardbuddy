# WorkBuddy 逆向档案（供「球房管家」开发参考借鉴）

> 本目录是对本机 WorkBuddy（腾讯 CodeBuddy 家族的桌面办公 Agent 产品）真实前端代码的**逆向综合档案**，用来给我们自己的桌面产品「**球房管家**」在开发时参考设计系统、页面结构、交互逻辑、文案写法。

## 这是什么 / 不是什么（白标铁律）

- **是**：参考它的**设计系统 / 页面结构 / 交互模式 / 文案语气**——这些是通用的产品工程经验，值得学。
- **不是**：不抄它的商标资产。我们品牌名 = **球房管家**（绝不叫 WorkBuddy/CodeBuddy），笑脸吉祥物做我们自己的，品牌色换我们自己的。
- **三分法口径**：
  1. **Agent 对话循环级交互**（消息渲染、流式回复、对话内部机制）→ 我们另对标 **cc-haha**，本档案对这块只扒到"外壳/契约"，不深挖。
  2. **App 层的样子**（布局、导航、各视图、点击弹层、文案）→ 全参考 WorkBuddy，本档案是这块的主力。
  3. **颜色/品牌**→ 换成球房管家自己的（WorkBuddy 的青绿 `#00C29A` 与紫 `#6c4dff` 都不要）。

## 关键认知

WorkBuddy 侧栏那些项（新建任务 / 助理 / 项目 / 专家·技能·连接器 / 自动化 / 更多·资料库·灵感）**不是光图标**——点开每一个都是一整套内容和交互。本档案的重点就是把"每个入口点开后展示什么、怎么交互、点了弹什么"扒清楚。

## 每篇的"可信度"标注约定

各篇都标了**哪些是从真代码直接读到的**、**哪些因混淆读不到只能推断**：

- **【读到】/ 明文**：从可读 JSON（i18n 语言包）、CSS（token/类名/尺寸/色值）、SVG（造型/渐变）、未混淆源码块直接读出，确切。
- **【结构推断】**：从压缩 JS 的 JSX 结构 / className 字符串 / i18n key / 常量逆推——变量名被 mangle，但结构与文案在，可信度高。
- **【读不到/盲区】**：顶层 React 布局 JSX 树、hooks 内部状态机、后端下发的清单数据、主进程逻辑、对话循环本体——这些在压缩 JS/后端/别的 chunk 里，只能反推或标为待补。

## 源码根路径

逆向时的解包根：`$R = /private/tmp/.../wb-archive-src`（会话临时目录，各篇引用文件时用 `$R` 前缀）。这是一次性解包产物，档案本身已把关键结论固化，无需再回源码。
