## 第二轮 · P1 内容工具（2026-06-17）

> 这几个工具走项目**原有 curated 模板**（当初基于行业资料建的，底子不差），本轮是**补缺口**，不是推倒重来。三路子代理(约客/诊断/玩法)各自先读我们模板、再对照真实做法给分优先级改进。

### 助教约客（`operation/assistant_outreach.yaml` + `knowledge/assistant_promotion.yaml`）
真实做法核心缺口 = **缺"按客户生命周期分层"**（行业主线：RFM、美业沉睡客7步法）。已补：
- **客户阶段分层策略**：新客(关怀混脸熟先建信任不急约) / 活跃老客(熟人语气直接约) / 沉睡客(给台阶不质问、越久越不施压) / VIP(专属尊贵、单独问候不混群发) / 团购引流客(真实关怀不硬推办卡)。作为文本引导，由 AI 结合关系亲疏+补充说明判断阶段，**未加必填变量**。
- **阶段↔风格联动**：沉睡客用"关心/回忆"不用"激励挑战"；VIP用"关心/新物"；新客用"好奇请教/轻松调侃"。
- **沉睡客唤醒递进话术**(assistant_promotion)：30天/60天/90天+ 三档，递进式非一次发完、隔几天一条、绝不群发。
- **发送规律**：同一客户两次约客间隔≥2-3天、别天天发、决策时点发、带名字带专属钩子不群发。
- **新增2条红线**：① 不得暗示/邀约"私下·店外见面"(吃饭/送回家/出去玩)；② 不得用愧疚感·情感绑架话术(抱怨"很久没理你")。
- 依据：致远RFM分层、群应用SCRM美业沉睡客7步(分层+5条隔日话术+不群发)、人人都是产品经理"不打扰是最大惊喜"。台球助教1v1约客逐字话术公开网未找到，分层/节奏/禁忌主要为**同类借鉴+经验**，已适配台球。

### 经营诊断（`operation/diagnosis_tool.yaml`）
真实做法核心缺口 = **爱说空话("提升服务/加强营销")** + **没有"淡季/时段空台"诊断轴**。已补：
- **内行铁律**(写法要求)：① 每条原因落到「责任部门+具体动作」禁止空话；② 根因按"先查结构性病根(选址/收入单一)→再查运营动作"排序，别一上来归因价格/动不动降价；③ "留住老客>拉新引流"(羊毛党打一次就走)；④ "活动≠比赛"(真有效=买赠/秒杀/拼台局/小赛+当场拉群锁复购)；⑤ 助教问题根因=约客能力/客流/情绪价值非排班；⑥【数据分析】对齐老板每天真看的5维(现金vs卡余额占比/新老充卡比/商品消费占比/时段分布/球台开台时长)。
- **新增"淡季/时段空台诊断"维度**：空台时段分布、错峰人群开发(午休/学生/夜班/退休)、错峰分时定价、填谷抓手(约局/拼台/周赛月赛/包场/主题夜)、救场铁律(错峰定价+性价比填谷不全店降价)。
- 依据：新浪财经/澎湃台球行业冰火报道(选址>收入结构>氛围>营销根因序、商场店1/3亏损)、知乎台球操盘手(每日5维数据/满台率/死群病灶)、腾讯新闻台球助教实地采访(约不到客=没收入)、健身房留存(拉新成本5倍、沉睡客优先救近1月)。

### 玩法推荐（`knowledge/mini_games.yaml`）
真实做法核心缺口 = **现有12个全是"单人对台子技巧挑战"，缺"人与人社交局"**。已补 **4 个双人/多人社交玩法**：
- 苏格兰双打(你一杆我一杆，适合情侣/男女/老带新) / 环打·车轮战(3-6人轮流，升级版抢一大战) / 拼台搭子局(前台撮合水平相近散客组局) / 新手vs老手让球友谊赛(拉平水平差让新手敢上桌)。一律娱乐社交导向、输赢只挂"请瓶饮料/小奖品"不涉赌。
- 依据：APA苏格兰双打/Ring Game/让分体系、Society Billiards新手友好联赛、分润宝台球拼台/单身夜真实例、密室桌游社交业态借鉴。

## 结构性待办（需动代码/前端/新文件，本轮未做——价值高但超出"纯文本校准")

> 这些是三路子代理给的更大改进，本轮为控制风险(纯 YAML 文本、不破渲染)未实施，列此跟踪。

1. **诊断·新增 `off_season`(淡季/时段) problem_area 选项**：当前只在模板补了诊断维度(AI 靠 current_situation 触发)；要成为前端可选项需改 `diagnosis_service.py` 的 `PROBLEM_AREA_LABELS` + 前端诊断页选项。顺带把 `customer_loss` 标签"服务"→"老客流失"、`activity_effect`"综合"→"活动效果"。
2. **诊断·决策树系统注入**：`diagnosis_service.py` 目前只 render `operation.diagnosis_tool` 单模板，未注入 `diagnostic_logic.yaml` 决策树。可参考其他 `run_generation` 注入 knowledge 的做法，把决策树/core_metrics 拼进 prompt(比纯文本铁律更系统)。
3. **玩法·新建 `knowledge/growth_playbook.yaml`(拉新裂变/留存套路库)**：梯度集赞、邀请阶梯、连续打卡挑战、低价限时限桌引流、拼台/男女搭配局、异业互赠券；留存=低价月卡(不打价格战)、同城群高频内容、积分翻倍+排行榜、每日幸运抽奖、会员闲时特权。**所有金额/赞数/折扣一律 `[请填写]` 占位**(不编数字)。建好后接入玩法/活动工具。
4. **赛事·补"赛季制新手友好联赛"格式**(`tournament_rules.yaml`)：3场单打+1场双打、赛季积分、高手当导师、每周轮换、明确"无试训压力新手友好"——补"让客户每周有理由来"的留存抓手。
5. **主题之夜模板**：单身夜/女生姐妹场/情侣场/团建包场/台球+桌游双业态/看球之夜，每个给适合人群+氛围设计+配套话术方向。
