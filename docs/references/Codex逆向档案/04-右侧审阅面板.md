## 4. diff 视图

- 行号列 + 代码;**新增行绿底、删除行红底**(删除行左侧红竖条)。
- 高亮 = **shiki / VS Code(Monaco)**,和对话内代码块的 hljs 不是一套(见 `03 §6`)。
- diff 太大时提示:`此差异较大,每次仅显示一个文件`。
- 真实色(token):
 ```css

 --color-decoration-added: var(--green-500); /* 行内标记 */
 --color-token-diff-surface: color-mix(in srgb, var(--color-token-main-surface-primary) 94%, var(--color-token-foreground));
 --diffs-font-family: var(--font-mono);
 --diffs-font-size: calc(var(--codex-chat-code-font-size) - 1px); /* 比对话代码小 1px */
 /* 删除行/文件徽标转发 VS Code:--vscode-diffEditor-removedLineBackground / gitDecoration-*ResourceForeground */
 ```
- 面板正文其实是个功能很全的 markdown/代码渲染器(CSS Modules 类名实锤):`_markdownRoot / _paragraph / _heading / _codeBlock / _table* / _mermaidBlock(mermaid 图) / _blockquote / _tableCellFileLink(表格内文件链接)`。→ 说明右面板不止 diff,还能渲染富文本报告 / 表格 / mermaid。

## 5. 文件树(截图 05)

> ⭐ **本质 = 工作目录(cwd)文件浏览器**(owner 2026-07-11 校正):这棵树**不是"只列改过的文件"**,而是**展示 agent 当前工作目录整个文件夹的树**——等同于 WorkBuddy 右侧的「工作空间文件」、也等同于 VS Code 左边的 Explorer。`+/−/•` git 改动徽标只是**叠加**在这棵工作目录树上的状态标记。点任意文件 → 在右面板打开(tab + 面包屑 + 内容/diff)。这对我们产品尤其贴题:用户是"本机 AI 执行助手"的使用者,能直接看到工作目录里有哪些文件、agent 动过哪些。

- 顶 `筛选文件…` 搜索框 + 缩进树。
- **当前打开文件高亮**(浅色选中条)。
- 文件按扩展名给**不同小色块图标**:TS 蓝方块 / JSON 花括号 / MD 图标 / py 图标…
- **每个文件右侧一个改动徽标**:`+`(绿·新增)/ `−`(红·删除)/ `•`(黄橙·修改)。徽标色转发 VS Code `gitDecoration-*ResourceForeground`。
- 文件夹可折叠(`dataeye / receiver / tests / desktop / build / e2e-pw …`)。
