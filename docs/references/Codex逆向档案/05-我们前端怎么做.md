## 1. 配色最终口径(三来源合一)

| 维度 | 取谁 | 值 |
|---|---|---|
| 外壳结构色(表面/文字/边框分级) | **Codex 的"前景锚定"法** | 边框/次文字/图标都用 `color-mix(前景 N%)`,别写死灰 |
| 正文色 | Codex | `#1a1c1f`(带蓝近黑) |
| 主按钮 | Codex(=走法 B) | 前景色近黑 + hover/active 透明度分级 |
| 焦点环 | Codex | `#339cff`(唯一允许的蓝) |
| **强调/品牌绿** | **我们自己(走法 B)** | `#10a37f`,只点缀——**不换成 Codex 蓝、也不换成 WorkBuddy 的 `#00b96b`** |
| 文件名链接蓝 | 行业默认(两家同源 VS Code textLink) | `#006ab1`/`#3794ff`,已在 `--color-link` ✅ |
| 状态色(成功/警告/错误) | Codex 原子色阶 | 见 `01 §2` |

> 一句话:**结构和克制照 Codex,唯一的品牌绿留我们自己的**。

## 4. 右侧审阅面板落地顺序(P0,拆小步)

全部在 `workspace/FilePreviewPanel.tsx` + `stores/filePreviewStore.ts`(`openFile(path)` 契约名**别改**)上**扩展**,不推倒:

1. **面板头**:tab 条(接 `tabStore`)+ 面包屑 `项目 > … > 文件` + 分支/改动统计 `+N −M`。
2. **diff 体**:`DiffViewer` 补红绿行底(`--color-editor-added` 绿 15%、删除行红底左红条)+ shiki 高亮 + 「此差异较大,每次仅显示一个文件」。
3. **文件树**:`筛选文件…` 搜索 + 缩进树 + 扩展名色块图标 + 每文件 `+/−/•` 徽标(VS Code gitDecoration 色)。
4. **环境信息卡**:没开文件时的默认态(变更统计 / 分支 / 提交或推送)。
