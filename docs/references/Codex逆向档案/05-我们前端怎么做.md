## 1. 配色口径(最终)

| 维度 | 取谁 | 值 |
|---|---|---|
| 外壳结构色(表面/文字/边框分级) | Codex「前景锚定」法 | 边框/次文字/图标用 `color-mix(前景 N%)`,别写死灰 |
| 正文色 | Codex | `#1a1c1f`(带蓝近黑) |
| 主按钮/发送/选中/焦点/链接 | **我们的浅蓝** | `#0a84ff`(暗 `#409cff`),token 在 `theme/workbuddy-tokens.css`(现 = Codex 主题层) |
| 状态色(成功/警告/错误) | Codex 原子色阶 | 见 `01 §2` |
| diff 红绿 | Codex/VS Code 同源 | `--color-editor-added` 系,见 `01 §7` |
