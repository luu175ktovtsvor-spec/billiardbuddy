## 1. 双层配色模型(最重要的认知)

Codex 的颜色分**两套、各管一摊**,别混:

- **A 层 · Codex 自己的原子调色板**(蓝/绿/橙/红/紫/黄 + 灰阶)——管**状态与强调**(成功/警告/错误/焦点/角标)。写死 hex,见 §2。
- **B 层 · VS Code 主题变量 `--vscode-*`**——管**外壳与代码面**(表面 surface、侧栏、输入框、边框、代码/diff 高亮、文件链接色)。取自当前 VS Code 主题(Light+/Dark+),所以随明暗主题自动翻。

关键转发(真实):
```css
--color-token-foreground: var(--vscode-foreground); /* 正文/图标锚点 */
--color-token-main-surface-primary: var(--color-background-surface); /* 主表面 */
--color-token-input-background: var(--vscode-input-background); /* 输入框底 */
--color-token-bg-primary: var(--color-token-side-bar-background); /* 侧栏底 */
--font-sans: var(--vscode-font-family, var(--font-sans-default));
--font-mono: var(--vscode-editor-font-family, var(--font-mono-default));
--color-token-diff-editor-inserted-line-background: var(--vscode-diffEditor-insertedLineBackground);
```
> 含义:**Codex 的"暖中性外壳"其实是 VS Code Light+ 主题的表面色**;它没自己定义品牌背景色。我们抄的时候,外壳中性色可以自定(见 §11 映射),但要理解 Codex 的克制正来自"外壳交给编辑器主题、自己只出状态色"。

## 3. 语义色规则:一切锚定「文字前景色」(Codex 克制感的来源)

**正文/图标/边框/按钮的每一档,都不是写死的灰,而是从同一个 `--color-text-foreground` 用 `color-mix` 调透明度得来**。这是抄 Codex 最该学的一招:

```css
--color-text-foreground: #1a1c1f; /* 浅色:带蓝调的近黑,不是纯黑 */
--color-text-foreground-secondary: color-mix(in oklab, var(--color-text-foreground) 70%, transparent);
--color-text-foreground-tertiary: color-mix(in oklab, var(--color-text-foreground) 50%, transparent);

--color-icon-primary: var(--color-text-foreground);
--color-icon-secondary: color-mix(in oklab, var(--color-text-foreground) 70%, transparent);
--color-icon-tertiary: color-mix(in oklab, var(--color-text-foreground) 50%, transparent);

--color-border-light: color-mix(in oklab, var(--color-text-foreground) 5%, transparent);
--color-border: color-mix(in oklab, var(--color-text-foreground) 8%, transparent);
--color-border-heavy: color-mix(in oklab, var(--color-text-foreground) 12%, transparent);
```

**按钮**——主按钮底色 = 文字前景色本身(近黑),hover/active 靠透明度分级:
```css
--color-background-button-primary: var(--color-text-foreground); /* 近黑主按钮 */
--color-background-button-primary-hover: color-mix(in oklab, var(--color-text-foreground) 8%, transparent);
--color-background-button-primary-active: color-mix(in oklab, var(--color-text-foreground) 16%, transparent);
--color-text-on-accent: var(--gray-1000);
/* 次按钮 secondary/tertiary 同理,只是百分比更低(2%/4%/5%…),即更淡的中性填充 */
```
> 这跟我们「走法 B:主按钮中性近黑、不引品牌色」**完全一致**——等于 Codex 给我们的走法 B 做了官方背书。

**焦点/状态**——蓝只在这里出现:
```css
--color-border-focus: var(--blue-300); /* #339cff 键盘焦点环 —— 全站几乎唯一的蓝 */
--color-icon-accent: var(--blue-300); /* 图标强调,极窄用法 */
--color-text-error: var(--red-500)/var(--red-300);
--color-text-success: var(--green-500)/var(--green-300);
--color-text-warning: var(--orange-500)/var(--orange-300);
--color-border-error: color-mix(in oklab, var(--red-500) 15%, transparent);
--color-border-warning: color-mix(in oklab, var(--orange-500) 15%, transparent);
```

## 4. 圆角(带一个全局缩放开关,值得抄)

```css
--corner-radius-scale: 1; /* 来自 --codex-corner-radius-scale,可整体缩放所有圆角 */
--radius-2xs: .125rem; /* 2px */ --radius-xs: .25rem; /* 4px */
--radius-sm: .375rem; /* 6px */ --radius-md: .5rem; /* 8px */
--radius-lg: .625rem; /* 10px */ --radius-xl: .75rem; /* 12px */
--radius-2xl: 1rem; /* 16px */ --radius-3xl: 1.25rem; /* 20px */
--radius-4xl: 1.5rem; /* 24px */ --radius-full: 9999px;
/* 每个 = base × --corner-radius-scale;行/卡默认 --radius-lg(10px);输入单行圆角 = spacing×5.5 = 22px */
```
> **抄这招**:所有圆角走 `calc(base × 一个 scale 变量)`,以后要做「圆角风格」设置项,改一个变量全站生效,不用挨个组件改。

## 9. Codex token → 我们 token 映射(落地用)

我们现有 token 在 `ts/desktop/renderer-react/src/theme/globals.css`(`--app-*`)+ `workbuddy-tokens.css`。对照:

| 用途 | Codex 真实 | 我们现有 / 建议 |
|---|---|---|
| 正文色 | `#1a1c1f`(带蓝近黑) | `--app-text-primary` 建议对齐到 `#1a1c1f`(现 `#1d1d1f` 也接近,可保留) |
| 次要文字 | 前景 70% mix | `--app-text-secondary` 用 `color-mix(前景 70%)`,别写死 `#86868b` |
| 边框发丝 | 前景 5%/8%/12% mix | 三档 hairline 都用 `color-mix(前景 N%)`,替换写死的 `rgba(0,0,0,.06)` |
| 主按钮 | 前景色近黑 + 透明度 hover | `--app-primary-action` 已是中性近黑 ✅,hover/active 改走透明度分级 |
| 强调/成功 | green-500 `#00a240` | 我们 accent 绿 `#10a37f`(走法 B)**保留自己的**,不用改成 Codex 绿 |
| 焦点环 | blue-300 `#339cff` | `--app-focus-ring` 用 `#339cff`(唯一允许的蓝) |
| 文件链接色 | VS Code textLink `#006ab1`/`#3794ff` | 已在 `workbuddy-tokens.css` 的 `--color-link`,来源对(见旧笔记),**保留** |
| 圆角 | base×scale,行 10px | 引入 `--corner-radius-scale`;行/卡走 10–12px |
| 间距 | 4px 基 | 已同(Tailwind) |
| 阴影 | §6 五档 + hairline | 直接搬 §6 数值 |
| 图标 | lucide | 换 `lucide-react` |

> **配色总口径**:外壳中性 + 近黑主按钮 + 前景锚定分级 → **照 Codex**;唯一强调色**保留我们走法 B 的绿 `#10a37f`(不换成 Codex 蓝/绿)**;文件链接蓝 `#006ab1` 保留(VS Code 行业默认,两家同源)。焦点环用 Codex 的 `#339cff`。
