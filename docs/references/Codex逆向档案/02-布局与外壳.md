## 3. 真实动效(直接抄数值)

```css
/* 内容/卡片入场:上浮 8px + 轻微放大,26ms 慢出曲线 */
@keyframes content-in { 0%{opacity:0; translate:0 8px; scale:.98} to{opacity:1; translate:0 0; scale:1} }
.enter { animation:.26s cubic-bezier(.16,1,.3,1) both content-in; }
/* 退场更快:.18s cubic-bezier(.4,0,1,1) */

/* 通用 enter(列表项等):translateY(-4px)+scale(.98) → 正常,时长 var(--transition-duration-basic) */
@keyframes enter { 0%{opacity:0;transform:translateY(-4px) scale(.98)} to{opacity:1;transform:none} }

/* Toast:上方滑入 + 阴影 */
._alert{ box-shadow:0 4px 12px #0000001a; font-size:var(--text-base); line-height:1.5; }
/* toast-open:translateY(-4px)→0,.25s cubic-bezier(.175,.885,.32,1) */

/* 弹窗/抽屉遮罩「幕布」:毛玻璃 + 半透主色底,极快 .11s */
._curtain{ backdrop-filter:blur(12px); background:color-mix(in srgb, var(--color-token-bg-primary) 74%, transparent); }
```
> 全部尊重 `@media (prefers-reduced-motion:reduce)`(关动画)。**抄这套**:入场统一「上浮几 px + 轻微 scale + 慢出 cubic-bezier」,别做花哨滑入/弹跳——和我们设计规范 §5「轻动效」一致。

## 4. 侧栏滚动淡出遮罩(细节质感)

侧栏用一个 `mask-image` 线性渐变,让列表滚动时**头尾淡出**(不是硬切):
```css
--sidebar-scroll-header-mask-distance: calc(var(--spacing) * 2); /* 头部淡入 8px */
--sidebar-scroll-footer-fade-distance: calc(var(--spacing) * 10); /* 底部淡出 40px */
/* mask-image: linear-gradient(to bottom, transparent→black→…→transparent) */
```
> 小而高级的质感:长会话列表滚动时上下边缘柔化。我们侧栏可选做。

## 5. Electron 特调

- CSS 里有 `.electron-dark` 类(深色下把某些底色改 `#2d2d2d`)和 `[data-codex-window-type=electron]` 选择器(Electron 窗口下收起部分 label,见 `03` 输入区响应式)。
- 说明 Codex 前端**同一套代码跑 web 和 Electron**,靠 `data-*` / class 分叉少量差异。我们是纯 Electron,可直接取它 Electron 分支的取值。
