# 03 · 对话流与组件

> 📌 状态:✅现行 · 最后核对 2026-07-11 · 数据源 = 截图 `01/02/04/08` + `真实CSS摘录/{composer-utility-bar,page-layout,model-picker-power-slider}.css`

## 1. 消息两态:助手无气泡 / 用户浅灰气泡

- **助手消息不套气泡、不放头像**,整块左对齐、正文排版直接铺开(markdown)。靠留白和分隔分块,不靠卡片。
- **用户消息右对齐 + 中性浅灰圆角气泡**(截图里 `阅读一下我项目的代码…` 那种),无头像。
- **处理时长**:助手回答上方一行小灰字 `已处理 36s / 已处理 1m 15s`(`--text-secondary`)。

> 与我们走法 B 完全一致:用户气泡中性浅灰、助手无气泡。对应 `components/chat/MessageList.tsx` + `AssistantMessageHeader.tsx`。

## 2. 工具行(低噪工具流的核心)

一行一个动作,**过去式动词 + 目标**,行首一枚 **lucide 图标**:

| 图标(lucide) | 文案范式 | 目标渲染 |
|---|---|---|
| `search` | `已在 ts 中搜索"…"` | 关键词 |
| `terminal`(方块) | `已运行 git log --oneline --decorate -12` ▸ | 命令走**等宽**,可展开看输出 |
| `folder` | `已列出 permissions 中的文件` | 目录名 |
| `book-open` / `file` | `已读取 resolve.ts` | **文件名 = 可点链接** |

- **多个读文件折叠成组**:`已读取文件 ▾` 一个折叠头,展开是一列文件名(截图 04)。→ 对应我们新建的 `components/chat/ToolCallGroup.tsx`。
- **文件名链接**:近黑色(**不是蓝**)、hover 才加下划线、hover 弹**完整路径气泡**(截图 08:`/Users/swl/Desktop/…/ts/src/permissions/resolve.ts`)。→ 对应 `shared/Tooltip.tsx` + 全局 `.qf-tool-link`。
- 每行可带展开 `▸/▾` chevron 看细节(命令输出、diff)。
- 颜色:图标/文字走 `--color-icon-secondary`(前景 70%)、`--color-text-secondary`;hover 提亮到 100%。

> 关键口径(旧笔记已校准):**Codex 工具行文件名本身不用蓝**,只有"代码编辑器语境下的文件链接"(diff 面/树)才用 VS Code textLink 蓝。我们工具行图标要换成 lucide;文案统一"已 X 了"过去式。对应 `ToolCallCard.tsx` + `toolMeta.ts`(图标/文案映射表)。

## 3. 思考块(collapsed thinking)

- 一条**灰色可折叠预览行** + chevron,预览首句思考(截图 02:`I need to gather information about…` 灰italic + ▾)。
- 展开看完整思考;默认折叠、不喧宾夺主。→ 对应 `components/chat/ThinkingBlock.tsx`。

## 4. 多步进度胶囊「第 N/M 步」

- 浮在对话内容中间的**独立圆角小胶囊**(不在气泡里),左侧一个小 spinner:`◌ 第 1/5 步`(截图 02)。
- 随任务推进更新 current/total。→ 我们 `StreamingIndicator.tsx` 里的 `StepProgressPill` 已吸收(复用 todos 数据算 current/total),做法一致;`SessionTaskBar.tsx` 也相关。

## 5. 消息动作条(助手消息底部)

- 一排图标:`复制 / 👍 / 👎 / 🔊朗读 / ↗分享 / ···`,右侧接 `共消耗 ◇ 3.93`(用量,截图见 WorkBuddy 也有同款,Codex 是 `···` 收更多)。
- 图标走 `--color-icon-tertiary`(前景 50%),hover 提亮。→ 对应 `components/chat/MessageActions.tsx`。

## 6. 代码/文本块(对话内)

- 块头一行:`text` 语言标签 + 右侧 `复制` / `分支(diff)` 图标;浅灰圆角容器,底部有横向滚动条(长行)。
- **高亮 = highlight.js(hljs)**,不是右面板那套。真实 hljs 配色(直接可用):
 ```css
 /* 浅色(One Light 风) */
 .light code{color:#383a42}
 .light .hljs-keyword,.hljs-doctag,.hljs-formula{color:#a626a4}
 .light .hljs-string,.hljs-addition,.hljs-attribute{color:#50a14f}
 .light .hljs-literal{color:#0184bb}
 .light .hljs-built_in,.hljs-class .hljs-title{color:#c18401}
 .light .hljs-symbol,.hljs-bullet,.hljs-link,.hljs-meta,.hljs-title{color:#4078f2}
 .light .hljs-comment,.hljs-quote{color:#a0a1a7;font-style:italic}
 /* 深色(ChatGPT 风):keyword #2e95d3 / string #00a67d / number #df3079 / built_in #e9950c */
 code,pre{font-family:var(--font-mono)!important}
 ```
 → 对应 `components/markdown/MarkdownRenderer.tsx`,代码块用 hljs + 上面配色。

## 7. 输入区(Composer)

截图里底部整块常驻输入框,自上而下:

- 占位符 `要求后续变更`(后续轮)/ 新会话时是引导句。
- **底工具条**(`composer-utility-bar` 真实 CSS):左 `+` 附件;项目/环境选择器(`_dropdownLabel*`,值文字 `--color-token-text-tertiary`,hover/open 提亮到 foreground)。
- **权限胶囊**:橙色 `⚠️ 完全访问`(**橙,不是绿/红**)+ chevron;点开是访问级别菜单。
- **模型强度**:`5.5` + `极高` 双段(数字档 + 文字强度),即 `model-picker-power-slider`——一个带**刻度 tick + thumb + 填充 mask** 的强度滑杆,动效 `cubic-bezier(.23,1,.32,1)`、档位切换 `.2–.4s ease-in-out`。
- **发送键**:圆形上箭头;**运行中变黑色方块(停止态)**。
- **响应式**:用 CSS **容器查询**按输入框宽度逐级收起 label(`@container composer-footer (width<=440px){隐藏 labelSm}`…),Electron 窗口有专属断点 `[data-codex-window-type=electron]`。

真实片段(`composer-utility-bar.css`):
```css
._footer{ container: composer-footer / inline-size; }
._dropdownLabelValue{ color: var(--color-token-text-tertiary); }
._utilityBarLabel:hover ._dropdownLabelValue{ color: var(--color-token-foreground); }
@container composer-footer (width<=440px){ ._labelSm{display:none} }
@container composer-footer (width<=300px){ ._labelXs{display:none} }
```
→ 对应我们 `components/chat/Composer.tsx` + `ChatInput.tsx`。权限用词照 CC:`默认/接受修改/计划模式/跳过确认`(但 Codex 这颗是「完全访问」橙胶囊,可融合)。
