# 06 · 斜杠命令浮层(slash command autocomplete)

> 📌 状态:✅现行 · 最后核对 2026-07-12 · 来源:解包 `/Applications/ChatGPT.app` app.asar,`webview/assets/app-initial~app-main~new-thread-panel-page~…js` 内 `RPa/v2r/g2r/m2r/O2r/w7` 等组件反混淆读出;我们的落地在 `ts/desktop/renderer-react/src/components/chat/Composer.tsx`(TokenPanel)。

## 数据模型(命令注册,S7 hook)

```ts
{
  id: string                    // 'review-mode' / 'skill:<path>' / 'custom-prompt:<id>'
  title: string                 // 本地化标题「初始化」;技能 = 原名不翻译
  description?: string          // 本地化描述
  Icon?: Component              // 左图标(内置命令各有专属;技能有默认图标)
  RightIcon?: Component         // 右侧内容 —— 技能行 = scope 灰字(个人/系统)
  group?: string                // 分组;技能 = t('composer.slashCommands.skillsGroup')「技能」,主命令无组
  enabled?: boolean
  requiresEmptyComposer?: bool  // true = 只在输入框仅有"/"时出现(压缩/反馈这类)
  searchAliases?: string[]; triggers?: string[]   // 默认 ['/']
  onSelect / onSelectFromInlineSlash
}
```

技能 scope 标签(`skills.scope.*`):builtIn→**System/系统**、personal→**Personal/个人**、team→Team/团队、adminInstalled→管理员安装。我们映射:`skillLayer` bundled→系统 / user→个人 / workspace→项目;`source:'pack'`→专家(产品项)。

## 排序 / 过滤管道

1. 注册序 `sortBy(entries, [group ?? '', title])` —— **无组排最前**,技能组殿后。
2. composer 有草稿文本 → 过滤掉 `requiresEmptyComposer` 项。
3. 查询打分 = max(fuzzy(title), fuzzy(id), fuzzy(aliases));**先整段 indexOf,否则子序列**。
4. 结果排序 `[组首现顺序, -score, title]` —— 组优先于分数,**组不打散**;不截断条数,靠滚动。
5. 相邻同组聚 section;组标题只在「多 section」时显示。

## 交互

- 触发:输入以 `/` 开头;`/^\s*\/[^/\r\n]*\s*$/` 语义 = 无第二个斜杠、无换行(路径 `/usr/bin` 不误触发)。
- 键盘:↑↓ 选、Enter 选中填入、**Esc 收浮层不动文本**(输入变化后自动重弹)。
- Codex 另有 dialog 版命令面板(cmdk,带搜索框,按钮打开);inline 浮层是输入 `/` 的这条,两者共用注册表。

## 我们的落地差异(有意保留)

- 图标:builtin→斜杠、skill→拼图、pack→靶心(Codex 每内置命令有专属图标,我们无图标元数据,统一按 source;后续要贴可给 bundled 命令补图标字段)。
- 选中行背景用我们的中性 `--color-surface-hover`(Codex 也是中性灰,非强调蓝)。
- `requiresEmptyComposer` / dialog 版面板未引入(我们命令无此语义)。
- 中英文:框架文案(「技能」「系统/个人/项目」「没有匹配的命令」)中文;命令/技能名保持原名——与 Codex 中文环境行为一致。
