# 台球运营管家 · 桌面版（初始版本）— 怎么在你电脑打开 + 试什么

> 这是初始版本(MVP)。装在你自己电脑上、全本地跑;门店数据在你本机、知识库加密。
> 安装包:`desktop/dist/台球运营管家-0.1.0-arm64.dmg`（Apple 芯片 Mac）。Windows 版需在 Windows 机上出(代码已适配)。

## 一、怎么装、怎么打开
1. 双击 `.dmg` → 把「台球运营管家」拖进「应用程序」。
2. 第一次打开:因为没买苹果签名(内测省钱),系统会拦一下。**右键点图标 → 打开 → 再点"打开"**;或「系统设置 → 隐私与安全性 → 仍要打开」。装好后正常双击即可。
3. 打开后:注册/登录 → 填一下门店资料(店名/城市/定位等,AI 越懂你的店越好用)→ 进「AI 管家」对话页。

> 首次用**发布功能**前,装一次浏览器内核(只需一次):终端跑
> `cd "<项目>/desktop/publisher" && pip install -r requirements.txt && patchright install chromium`

## 二、试什么（三个能力）

### 1. 一键发布（抖音/快手/视频号/小红书）
菜单 →「一键发布」→ 选平台 → **扫码登录你自己的号** → 选一个视频 + 填标题话题 → **点确认才发**(用你的号真实发出)。

### 2. 视频剪辑
菜单 →「视频剪辑」→ 选视频 → 转竖屏 / 裁剪 / 烧字幕 / 加 Logo 水印 / 变速 → 本机处理 → 剪好「去发布」。

### 3. ⭐ AI 直接操作你电脑上的文件（这版新加、最能体现"真 Agent"）
在「AI 管家」对话里直接说,它会**真的去你电脑上读/写/改文件**(不是只在对话里复述):
- 「帮我写一份周末情侣活动文案,**存成文件**」→ 它写好 + 存到内容库。
- 「把刚才那份文案里的价格**改成 双人 99 元**」→ 它**直接改那个文件**、给你看改了哪儿、你点确认才落盘。
- 「把这个 Excel 报表的**今日营业额改成 8600、加一列各助教提成**」→ 它直接改 Excel。
- 改任何文件**都会先自动备份原件**(可回滚)、**只动它的内容库 + 你选的文件**(不碰你电脑别的东西)、**写/改都先弹给你确认**。

## 三、心里有数的几点
- **全本地**:内容生成、AI、报表、文件操作全在你电脑上跑,不依赖我们服务器、断网也能用大半(发布/调大模型那刻要联网)。
- **你的数据是你的**:门店资料、店脑记忆、生成内容都存你本机。
- **知识库抄不走**:打进包里是加密块,同行解开也读不到。
- **这是初始版**:先跑通骨架,后续补 AI 主动备料、回评论/私信、读 POS 导出做诊断等(见 `docs/plans/桌面Agent-完整能力地图-路线图.md`)。
