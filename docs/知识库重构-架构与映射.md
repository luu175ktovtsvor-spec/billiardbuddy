# 知识库模块化重构 · 架构与映射（施工图）

> 目的：把 124 个平铺 YAML（knowledge 52 + operation 72）按"台球运营逻辑的种类"重新模块化，对齐"骨架+典范、模型延伸"（Anthropic/OpenAI 官方背书），并接回 Agent。本文是唯一施工依据。

## 0. 已验证的真实机制（动文件前的安全底）
- **prompt_engine** 用 `rglob("*.yaml")` 递归扫 + 按 `key:` 登记（不认路径）→ 文件进子文件夹**不破坏渲染**，加 `domain/freedom/tags` 额外字段也无害（宽松登记）。
- **护栏测试** `test_knowledge_guardrails.py` 用 `glob(** , recursive=True)` → 认子文件夹。
- **bge-zh 语义 RAG**（`rag/recall.py`）只服务"老板运行数据"（生成历史/报表/店脑），**不索引知识模板**。
- **知识模板选取** = `scenario_catalog` 清单法（按 category/key 匹配）+ `look_up_knowledge`。
- 结论：**进文件夹 + 加元字段，对四个消费方都安全**。

## 1. 判定（研究已证实）
精简知识库（核心逻辑 + 少量典范 + 清晰结构，剩下交模型延伸）**优于**穷举死规则——有 Anthropic context-engineering「curate canonical examples，别穷举 edge cases，smallest high-signal token set」、Agent Skills「only add what model doesn't know，set degrees of freedom」直接背书。**唯一边界**：安全红线 / 硬数字 / 品牌白名单必须钉死、检索保真，不交模型发挥。

## 2. 目标架构：5 业务域 × 4 层 + facet 标签
**4 层渐进披露**：
- **L0 核心层（常驻系统提示，越薄越好）**：运营总则 + 安全红线(单一源) + 模块地图(5 域各一句 description)
- **L1 域目录页**（每域一张 `_index.yaml`，<500 行）：该域骨架 + 子知识索引 + 典范指针
- **L3 细则层**（现有 YAML 正文，按需读/清单召回）
- **检索路由**：scenario_catalog 升级为"先按 domain/facet 预过滤、再清单匹配"

**每个 YAML 加 3 元字段**（机器可判，直接对接护栏测试）：
```yaml
domain: customer-ops        # strategy|marketing|customer-ops|talent-mgmt|data-analysis
freedom: skeleton           # skeleton🟢 | hard_number🔴 | red_line🛡️
tags: [scene:约客, role:助教, channel:私域]   # facet 正交标签,RAG/清单预过滤
```

## 5. B 揪出的 7 个现状病 + 修法
1. **K/O 双轨重复**（同主题两文件，口径易打架）→ K=可召回的行业逻辑，O=run_generation 成品模板**只引用 K、不重复内容**。
2. **巨型文件吞多节点**（core_operations 横跨营销+客户+六岗+定价；business_cases 塞定位+卖点+客户+开业）→ 拆细或降级为"总纲/索引"。
3. **跨类文件无归属** → 单一主域 + tags。
4. **命名拼音/英文混用、同义散落**（game_rules/billiards_game_rules/mini_games/tournament_rules 四个玩法）→ 按域归拢。
5. **缺漏节点**（PPT 有库里弱）：行业分析/赛道、老板选人之道、客户转化五步、市场调研→补。
6. **自由度标注缺失** → 加 `freedom:` 字段（本次重构核心动作）。
7. **红线分散各自复述** → 集中到 strategy 的安全底线**单一源，其余只引用不复述**（硬数字同理）。

## 6. 执行编排顺序（非破坏性优先，每步跑护栏测试）
1. **元数据层**（非破坏，先做）：给 124 文件打 `domain/freedom/tags`
2. **L0 核心层**：建运营总则 + 红线/硬数字单一源 + 模块地图
3. **L1 域目录页**：5 个 `_index.yaml`（骨架+典范指针）
4. **细则瘦身**：穷举死规则(扣分表/分级/逐字)→骨架+典范；红线/硬数字钉死保留
5. **衔接 Agent**：scenario_catalog 加域路由 + L0 注入系统提示
6. **验通畅 + 三维测试**：路由准 / Context Recall 防断档 / Faithfulness 防跑偏（确定输入·模糊输入·模型发挥三类场景）
