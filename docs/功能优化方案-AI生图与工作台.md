## 一、AI 生图优化

### 1.1 当前状态

用户在AI生图页面输入文字+上传参考图 → 生成图片 → 可以点"基于此调整"再次生成。

**已确认要改的：**

| 问题 | 现状 | 改法 |
|------|------|------|
| Logo/二维码叠加有Bug | 后端 `add_overlay` 门控导致叠加永远不生效 | **去掉叠加功能**，不再做Pillow硬P Logo |
| 去掉叠加相关功能 | 前端有"叠加Logo"、"叠加二维码"、"叠加门店信息"三个勾选项 | 前端删除这三个选项，后端删除对应逻辑 |
| 保留参考图上传 | 用户上传的图片作为reference image传给AI | 保持不变，这就是正确的做法 |
| 保留门店资料中的Logo/二维码上传 | 作为品牌资产存储 | 保持不变，以后可能用在别的地方 |

### 1.2 生图交互重构：对话式迭代

**借鉴：** ChatGPT+DALL-E的对话式生图（纯对话驱动，上下文全保留）

**核心思路：** 用户不满意 → 用文字说哪里不满意 → AI基于原图+对话历史重新生成 → 直到满意

**新的交互流程：**

```
┌─ AI 生图 ─────────────────────────────────────┐
│                                                │
│  ┌─ 入口区 ──────────────────────────────────┐ │
│  │  文字描述：[做一张周赛海报，费用10元]        │ │
│  │  参考图：[上传按钮]（最多5张）              │ │
│  │  比例：3:4  质量：标准                      │ │
│  │  [生成]                                    │ │
│  └───────────────────────────────────────────┘ │
│                                                │
│  ┌─ 对话区 ──────────────────────────────────┐ │
│  │  你：做一张周赛海报，费用10元               │ │
│  │                                            │ │
│  │  AI：[图片]                                │ │
│  │      [基于此调整] [下载]                    │ │
│  │                                            │ │
│  │  你：背景太单调了，加点台球元素             │ │
│  │                                            │ │
│  │  AI：[新图片]（基于原图+对话历史）          │ │
│  │      [基于此调整] [下载]                    │ │
│  │                                            │ │
│  │  你：颜色太暗，亮一点                       │ │
│  │                                            │ │
│  │  AI：[新图片]                              │ │
│  │      [基于此调整] [下载]                    │ │
│  └───────────────────────────────────────────┘ │
│                                                │
│  ┌─ 输入区 ──────────────────────────────────┐ │
│  │  [输入调整描述...]              [发送]      │ │
│  └───────────────────────────────────────────┘ │
└────────────────────────────────────────────────┘
```

**关键机制：**

1. **"基于此调整"按钮** — 点击后自动把上一张图作为reference image传给AI，用户只需输入文字描述
2. **对话历史保留5轮** — AI能看到之前生成了什么、用户调整了什么，不会重复犯错
3. **参考图只在当前对话有效** — 生成后自动清空references，不会跨轮次残留
4. **新对话自动创建** — 第一次生成时创建conversation_id，后续调整都挂在同一个对话下

### 1.3 灵感标签重新设计

**当前：** 15个标签平铺，视觉效果和交互都不对

**改为分类卡片网格：**

```
灵感标签
├── 🏆 赛事类
│   ├── 周赛报名 → 点击后自动填充prompt + 跳转对话区
│   ├── 月赛海报
│   └── 赛后战报
├── 📱 社交媒体
│   ├── 朋友圈配图
│   ├── 短视频封面
│   └── 门店品牌图
├── 🎯 营销推广
│   ├── 充值活动
│   ├── 团购引流
│   └── 开业活动
└── 👥 助教相关
    ├── 助教形象图
    ├── 助教推广
    └── 教练推广
```

点击标签 → 自动填入prompt + 自动开始生成（不再需要用户手动点生成）

### 1.4 生图高级选项精简

**当前高级选项（全部去掉）：**
- ~~叠加门店信息~~ → 由AI根据prompt自动决定
- ~~叠加Logo~~ → 去掉
- ~~叠加二维码~~ → 去掉
- ~~无文字模式~~ → 保留（这个有意义，用户可能只要图不要字）

**最终保留的选项：**
- 比例选择（3:4, 1:1, 9:16, 16:9）
- 质量选择（标准/高清）
- 无文字模式（开关）

### 1.5 修复清单

| # | 问题 | 改动 | 文件 |
|---|------|------|------|
| 1 | Logo/二维码叠加Bug | 去掉叠加逻辑 | `server/api/v1/posters.py` + `server/services/poster_service.py` |
| 2 | 参考图跨轮次残留 | 生成后清空references | `web/src/app/dashboard/posters/page.tsx` |
| 3 | refineFrom只生效一次 | 对话中保持refineFrom有效 | `web/src/app/dashboard/posters/page.tsx` |
| 4 | 对话历史assistant消息为空 | 保存assistant的描述文本 | `server/services/poster_service.py` |
| 5 | 历史列表Markdown语法未渲染 | 预览用纯文本，详情用Markdown | `web/src/app/dashboard/history/page.tsx` |
| 6 | 高级选项不持久化 | 用localStorage保存 | `web/src/app/dashboard/posters/page.tsx` |

## 二、AI 工作台优化

### 2.1 当前状态

用户选角色 → 选任务卡片 → 选客户类型 → 选输出包 → 生成 → 复制

**核心问题：** 每次生成都是独立的，没有对话历史，无法连续追问。

### 2.2 对话式工作台

**新交互流程：**

```
┌─ 工作台 ──────────────────────────────────────┐
│                                                │
│  ┌─ 任务卡片（可折叠）─┐  ┌─ 对话区 ─────────┐ │
│  │  [店长] 老客维护     │  │                  │ │
│  │  [店长] 周赛通知     │  │  你：帮我写一条    │ │
│  │  [店长] 空台朋友圈   │  │  老客户邀约文案    │ │
│  │  [助教] 助教推广     │  │                  │ │
│  │  ...                │  │  AI：[流式输出]    │ │
│  │                     │  │  [复制] [编辑]    │ │
│  │  最近使用：          │  │  [基于此优化]     │ │
│  │  • 老客维护(2h前)   │  │                  │ │
│  └─────────────────────┘  │  你：语气改亲切些  │ │
│                           │                  │ │
│                           │  AI：[基于上一轮   │ │
│                           │  完整上下文优化]   │ │
│                           └──────────────────┘ │
│                                                │
│  ┌─ 输入区 ──────────────────────────────────┐ │
│  │  [我想做什么...]               [生成]      │ │
│  └───────────────────────────────────────────┘ │
└────────────────────────────────────────────────┘
```

**关键机制：**

1. **任务卡片作为快捷入口** — 点击卡片 = 发送一条预设prompt，直接进入对话
2. **对话历史保留5轮** — 用户可以连续追问："把语气改亲切些"、"加上周末活动信息"
3. **"基于此优化"改为真正的对话追问** — 不再截断500字，传完整上下文
4. **流式输出保持Markdown渲染** — 用react-markdown的streaming渲染器，消除布局跳动

### 2.3 修复清单

| # | 问题 | 改动 | 文件 |
|---|------|------|------|
| 1 | 没有对话历史 | 后端支持conversation_id + 前端对话式改造 | `server/api/v1/stream.py` + 前端 |
| 2 | "基于此优化"截断500字 | 去掉截断，传完整content | `web/src/app/dashboard/workbench/page.tsx` |
| 3 | 角色Tab和下拉框不同步 | 统一为一个state | `web/src/app/dashboard/workbench/page.tsx` |
| 4 | 流式输出布局跳动 | 用Markdown streaming渲染器 | `web/src/app/dashboard/workbench/page.tsx` |

## 三、门店资料简化

### 3.1 当前状态

11组98个字段一次性展示，用户填不完就离开。

### 3.2 简化为3层

```
门店资料
├── 必填信息（6个字段，首次使用必填）
│   ├── 门店名称
│   ├── 城市/区域
│   ├── 球台数量
│   ├── 定位类型（社区/商业/竞技/竞技商业）
│   ├── 当前经营重点（拉新/留存/活动/品牌）
│   └── 内容语气（接地气/品质感/活泼专业）
│
├── 补充信息（按需填写，影响生成质量）
│   ├── 助教相关
│   ├── 赛事相关
│   ├── 团购相关
│   └── 会员相关
│
└── 高级设置（折叠，默认值已合理，极少需要改）
    ├── AI安全规则（12个开关）
    ├── AI偏好设置（8个开关）
    └── 内容风格细节（6个字段）
```

**关键：** 首次注册只填6个字段就能开始使用，AI根据定位类型自动推断其他字段的默认值。
