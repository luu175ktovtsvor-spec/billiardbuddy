# 管理后台使用指南

## 访问方式

访问地址：`https://zzyppz.cn/admin`（生产域名，HTTPS）

前提条件：账号的 `is_admin` 字段必须为 `true`。默认注册用户不是管理员，需要手动设置。

## 功能模块

### 1. 总览（/admin）

显示核心数据：
- 总用户数
- 总门店数
- 总生成次数
- 本月收入
- 即将到期/已过期订阅提醒

### 2. 用户管理（/admin/users）

- **用户列表**：手机号、名称、状态、角色、注册时间
- **搜索**：按手机号或名称搜索
- **用户详情**：点击查看门店信息、订阅状态、使用量、最近生成记录
- **开通订阅**：选择套餐+月数+收款备注+金额
- **调整配额**：不动套餐，直接给该用户门店设本月生成次数/Token 上限（"先试用、好用再提额"的入口；无配额行时自动创建，立即生效）
- **禁用/启用**：控制用户账号状态

### 3. 订阅管理（/admin/subscriptions）

- **订阅列表**：门店、用户手机、套餐、状态、到期时间、收款金额
- **状态筛选**：全部/活跃
- **续费**：选择续费月数+收款备注+金额
- **到期提醒**：即将到期（7天内）显示黄色标签，已过期显示红色标签

### 4. 套餐管理（/admin/plans）

- **套餐列表**：名称、价格、生成次数、Token限额、海报限额、最大成员数（列表含已停用套餐，停用项灰显——停用后仍可在此重新启用，不会消失）
- **编辑**：修改套餐名称、价格、限额、启用/停用

### 5. 收入统计（/admin/revenue）

- 本月收入（元+笔数）、累计收入、即将到期/已过期订阅数
- **统计口径**：基于收款流水（`subscription_payments`），开通和续费各计一笔、计入实际收款月份；订阅表上的金额字段仅作"最近一笔"展示，不参与累计（避免续费覆盖导致历史收款丢失）

## 工作流程

### 用户开通权限流程

1. 用户注册账号
2. 管理员在 `/admin/users` 搜索用户
3. 点击"开通订阅" → 选择套餐 → 填写收款信息 → 确认开通
4. 用户登录后即可使用对应套餐的功能

### 续费流程

1. 管理员在 `/admin/subscriptions` 查看到期订阅
2. 点击"续费" → 填写续费月数和收款信息 → 确认续费
3. 到期时间自动延长

## 安全说明

- 管理后台只有 `is_admin=true` 的用户可以访问
- 非管理员访问会被重定向到 Dashboard
- 所有管理操作需要管理员权限验证
