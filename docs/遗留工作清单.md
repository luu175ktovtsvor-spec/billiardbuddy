## 三、给接手者的建议

1. **先跑测试建立基线**：`cd server && uv run pytest`
2. **优先级**：账号安全（P1）→ 数据正确性（P1）→ 统一管道（P2，根治性）→ 前端/内容（P2/P3）
3. **改 Prompt/知识只改 YAML**，新增 knowledge 必须含 `key` 和 `template` 字段，否则 PromptEngine 加载报错
4. **每条新增生成路径**务必带齐：配额检查 + 注入检查（有自由文本时）+ 输出过滤 + 生成记录落库 + 用量递增
5. 知识注入已做意图筛选，**不要再往知识库无脑堆内容**，避免重新引入"知识过载"稀释质量
