**部署踩坑教训（重要）**：
- **SSH host key**：服务器变配重启后 host key 变，本地旧 known_hosts 致 SSH 应用层被拒（症状迷惑：nc 22 通、网站 200，但 SSH 全程无回显/盲写文件 404）。修复：`ssh -o UserKnownHostsFile=/dev/null -o StrictHostKeyChecking=no`
- **部署后必须 `git rev-parse --short HEAD` 实锤确认**，别只看 curl 200——曾因此误判两次部署成功（实际 SSH 静默失败没上线）
- expect 抓短命令输出:命令末 `echo M_DONE` + `expect "M_DONE"`，纯 eof 会丢 buffer
