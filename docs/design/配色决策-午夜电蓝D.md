# 配色决策 · 对话窗口"果冻"设计 → 午夜电蓝 D(2026-06-26)

> 📌 状态:✅现行 · 最后核对 2026-06-26

owner 拍板:对话窗口果冻设计的**配色**采用 **D · 午夜电蓝**(海军蓝底 + 电光蓝),从原品牌绿 `#10a37f` 换过来。理由:这版是几版蓝里唯一"像专门设计过的"(Linear/Vercel 那种高级科技感),沉稳又不端着。

> ⚠️ **暂时只定颜色**。hero 文案/字("球房的活,一句话交给它。"等)**后续还要改**,现在先保留占位,别动文案。

## 选中的色值(绿 → 蓝映射 · 真落地只改这些 CSS 变量)
原绿 demo `docs/design/对话窗口动效-demo.html` 的 `:root`;D 版只改下面几个,结构/动效不动:

| 变量 | 原(绿) | **D 午夜电蓝** | 用途 |
|---|---|---|---|
| `--bg0` | #07080c | **#070b14** | 窗口最深底(偏海军蓝) |
| `--bg1` | #0b0d14 | **#0c1322** | 窗口次底 |
| `--a1` | #10a37f | **#2f6bff** | 主 accent(电光蓝·按钮/气泡/状态) |
| `--a2` | #0bb39a | **#4d8bff** | accent 2(极光) |
| `--a3` | #3fe0b8 | **#7db4ff** | accent 浅(极光/状态点/就绪点) |
| `--a-weak` | rgba(16,163,127,.12) | **rgba(47,107,255,.12)** | 弱底色 |
| `--bubble-u` | linear-gradient(135deg,#13a884,#0e9f93) | **linear-gradient(135deg,#2f6bff,#1e5bff)** | 用户气泡 |
| 品牌名渐变末 | #b9efdf | **#bcd4ff** | `.brand` 文字渐变 |
| hero 标题渐变末 | #c4e9de | **#c9dbff** | `.hero h1` 文字渐变 |

aurora 三团(b1/b2/b3)、`.pill .d` 就绪点都吃 `--a1/2/3`,自动跟着变。

## 看色用的 demo(已保留)
`docs/design/对话窗口-午夜电蓝D-demo.html` —— 双击用浏览器打开即看(纯静态)。

## 真落地到产品时
把前端品牌主色从绿 `#10a37f` 改成这套蓝即可(纯换色、不动结构/动效)。注意:产品里 `#10a37f` 用在 settings/composer/spinner/确认弹层等**多处**,换主色要全局一致替换(可顺手抽成一个 CSS 变量,以后换色只改一处)。
