# 生成工作室 · 设计(出图 ⇄ 图生视频 一条龙)

> 📌 状态:✅现行 · 最后核对 2026-06-27

> **看图**:① 界面 demo `docs/design/生成工作室-UI-demo.html` ② 架构图 `docs/design/生成工作室-架构图.html` —— **双击用浏览器打开可圈可点地看**(配色=午夜电蓝 D)。本文是配套设计说明。

## 为什么要它
现在生图/生视频**全靠对话大模型在聊天里调 API**:看不见参数、没法对比、不能迭代、更没把"图→视频"串起来。做一个**独立的「生成工作室」**——**直接调效果、不经过对话大模型**,治这个痛点;并把台球房最需要的"海报 → 一键变引流短视频"打通。

## 给谁用 · 两档
- **简单档**(给不懂技术的老板):说一句话 + 点台球风格卡 + 传物料 → 直接出图/出视频。
- **调试档**(你/进阶):**看 AI 扩写后的完整 prompt 还能改、换生图模型、调尺寸/质量/风格/视频时长运镜、并排出几版对比**——这才是你要的"可调试效果",不像现在全靠跟模型聊、看不见也调不动。
- 不学 ComfyUI 那种节点图(对中专生太复杂),学 Runway/Pika/Kling 那种"一句话 + 卡片 + 一键转视频"的简单工作流。

## 界面(见 UI demo)
- **左·控制台**:做什么(海报/朋友圈图/引流视频/招聘)→ 说一句话 → 台球风格卡(喜庆/潮酷/高档/温馨/运动/清新…)→ 门店物料(logo/收款码/门店照)→ 比例+质量 →【调试档露出:扩写后 prompt 可改 + 换模型 + 出几版】→ 生成。
- **中·画布**:大图预览 + 动作条「再来一版 / 基于这张调(快捷词:字更大、背景更简洁、换配色)/ 裁切水印 / 下载 / ⭐**做成视频**」。
- **右·版本对比**:同一句话出的几版并排比、留版本时间线(含"由第3版动出来的视频 v1"),挑最好的。
- **⭐图→视频浮层**:点"做成视频"→ 弹面板「首帧=当前这张海报 + 时长 + 运镜 + 配文案」→ 出引流短视频。

## 🔑 图 ⇄ 视频连接(技术已就绪,不是从零)
出一张海报 → 把图 url 当 `first_frame` → 火山 Seedance `role:first_frame` → 引流短视频。**后端 `video_service._resolve_first_frame` + `ark_video.py` 已打通并用真 key 验过**,工作室只需把"某张生成图"的 url 递给生视频。

## 架构(见架构图 · 绿=现成 橙=要搭)
```
① 前端「生成工作室」壳子 🆕(独立Tab·搬老web posters 交互 + 简单/调试双档)
        ↓ 直接调(非聊天)HTTP
② 后端 API 🆕(把现成服务暴露成"直接调":/studio/expand 扩写 · /generate 出图 · /i2v 图生视频)
        ↓                      ↳ 老web有现成 /posters/{generate,expand,reference} 路由可搬
③ 服务层 ✅全现成:扩写引擎(poster_prompt_engine 豆包式·台球专用) · 出图组装(poster_service 物料/风格/文字) · 本地改图(image_tools) · 图生视频(video_service/ark_video)
        ↓ 按 base_url 路由
④ 模型出口 ✅全现成·走网关藏key:gateway/app.py → 生图(GPT Image-2 美国relay / 硅基 Qwen-Edit / 通义万相) · 生视频(Seedance /v1/video/generations)
```
**真正要新搭的只有橙色两块:前端工作室壳子 + 后端"直接调"API。** 绿色全是现成积木(生图后端满分 + 图生视频已通 + 台球风格/扩写/物料齐)。

## 台球味(全现成可接)
- **风格**:`poster_styles.py` 10 个台球场景预设(label+desc+视觉片段三件套),前端卡片直接渲染。
- **物料**:logo/二维码/门店照三类上传 + 角色判定(现原图喂 GPT 融合),门店名/城市自动注入。
- **扩写**:台球专用扩写师(中文文字保真、不编造价格、反"美女助教"擦边)。
- **用途预设**:开业/活动/引流/招聘/节日,出的就是台球房引流物料(海报→短视频→配抖音文案一条龙)。

## 老实说的缺口
1. 视频只支持"**首帧 animate**"一种(没有中间帧/尾帧/参考视频)——对引流够用。
2. 视频**暂不支持 BYOK**(只内置 ARK 一家,`get_video_config_for_store` 写死)。
3. **通义万相不支持图生图**(叠 logo/二维码/底图改图要走硅基 Qwen-Edit / 火山 Seedream / GPT)——选模型时把能力差异(`image_catalog` 的 `supports_edit`)暴露给用户。

## 建议落地分期(一次性想清、可分步做)
- **P1 出图工作室**:搬老 web posters 交互 + 暴露 `/studio/{expand,generate}` + 台球风格卡/物料 + 简单/调试双档 + 版本对比。
- **P2 接图→视频**:每张图加"做成视频"→ 暴露 `/studio/i2v`(把图当 first_frame 调现成 video_service)+ 时长/运镜/配文案。
- **P3 锦上添花**:并排多模型对比、本地裁切水印(edit_image)接进动作条、出图+视频+平台文案一键打包。
