# 桌面 AI Agent · macOS 设计规范（2026-06-19）

> 适用范围：**桌面端 Electron App 的 Agent 对话体验**（本仓库 `main` = 桌面产品；先聚焦 `/dashboard/chat` 及其周边）。
> 这与 web 端"微信手机优先、iOS 蓝"的设计是**两个语境**：桌面端走 **macOS 原生质感**。
> 技术底座不变：Next.js + React + TailwindCSS + shadcn/ui。**不换组件库，用 macOS 设计语言重做皮。**
> 设计图（mockup）见同目录 `mockups/agent-chat.html` —— 写码以设计图为最高优先级参考。

## 1. 设计原则（macOS 味的来源）

1. **原生窗口质感**：无边框窗口 + 原生红绿灯（`titleBarStyle: 'hiddenInset'`）+ 毛玻璃侧栏（Electron `vibrancy: 'sidebar'`）。这是 macOS 味的灵魂，Electron 自带，不自己画。
2. **克制、留白、层级靠分层不靠边框**：浅灰底 + 白卡，hairline 细线分隔，柔和阴影。
3. **内容第一**：弱化 chrome，强调老板的内容（文案/海报/数据）。
4. **轻动效**：悬停微亮、按压微缩（`active:scale-[0.98]`）、卡片入场淡入上浮，不做花哨过场。
5. **触控/点击目标舒适**：可点元素 ≥28px 高（桌面比手机可略小，但不拥挤）。

## 2. 设计 Token

### 配色（浅色为主，后续可加深色）
| 用途 | 值 | 说明 |
|---|---|---|
| 强调色 accent | `#007AFF` | 沿用品牌 iOS/macOS 系统蓝（与现有一致，省迁移） |
| accent-hover | `#0a84ff` | |
| 窗口内容底 | `#ffffff` | 主对话区 |
| 侧栏底（毛玻璃） | `rgba(245,245,247,0.8)` + `backdrop-blur-2xl` | 真机由 Electron vibrancy 接管，web 用半透明模拟 |
| 页面浅灰底 | `#f5f5f7` | macOS 标准浅灰 |
| 文字主 | `#1d1d1f` | Apple near-black |
| 文字次 | `#86868b` | Apple gray |
| 细线/分隔 | `rgba(0,0,0,0.06)` | hairline |
| 成功/确认 | `#28c840` | 绿 |
| 危险/取消 | `#ff3b30` | 红 |
| 红绿灯 | `#ff5f57` / `#febc2e` / `#28c840` | 仅 web mockup 画；真机用原生 |

### 字体
```
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display", system-ui, "PingFang SC", sans-serif;
```
- 正文 `13–14px`，标题 `15–17px`，次要信息 `12px`。比 web 手机端略小（桌面信息密度高）。
- 字重：常规 400，强调 500/600，不滥用粗体。

### 圆角 / 阴影 / 间距
| Token | 值 |
|---|---|
| 卡片圆角 | `rounded-xl`（12px） |
| 按钮/输入圆角 | `rounded-lg`（8px） |
| 小元素（pill/chip） | `rounded-full` / `rounded-md` |
| 窗口外圆角（mockup） | `rounded-2xl`（16px） |
| 卡片阴影 | `shadow-[0_1px_3px_rgba(0,0,0,0.06),0_1px_2px_rgba(0,0,0,0.04)]` |
| 浮层阴影 | `shadow-[0_8px_30px_rgba(0,0,0,0.12)]` |
| 内容内边距 | 卡片 `p-4`，列表项 `px-3 py-2`，区段间距 `gap-3/4` |

## 3. 布局

```
┌───────────────────────────────────────────────────────────┐
│ ● ● ●                                                       │  ← 红绿灯（原生，hiddenInset）
├──────────────┬────────────────────────────────────────────┤
│  侧栏(毛玻璃)  │  主对话区(白底)                              │
│  260px       │                                             │
│  · App 名     │  · 顶栏：对话标题 + 用量/模型               │
│  · + 新对话   │  · 对话流（滚动）：                          │
│  · 会话列表   │     用户气泡 / 管家回复 / 工具步骤chip       │
│  · ……         │     成品卡片 / 审批卡片 / 提问卡片(新)       │
│  ──分隔──     │                                             │
│  · 知识库主题  │  · 底部输入区：输入框 + 附件 + 发送          │
│  · 权限模式    │     + 权限模式分段控件                       │
│  · 设置/用量   │                                             │
└──────────────┴────────────────────────────────────────────┘
```
- 侧栏固定 260px，主区 `flex-1`。
- 深层不用顶部返回（桌面多窗格，靠侧栏切换）。

## 4. 关键组件样式

- **会话列表项**：`rounded-lg px-3 py-2`，选中 `bg-black/5`（或 accent 浅染），hover 微亮。
- **用户气泡**：右对齐，accent 浅底 `bg-[#007AFF]/10` 或浅灰，`rounded-2xl`。
- **管家回复**：左对齐，无气泡或极浅卡，正文排版（react-markdown）。
- **工具步骤 chip**：一行小药丸 `bg-black/[0.04] rounded-full px-3 py-1 text-[12px] text-[#86868b]`，带小图标 + "正在挑选文案模板…/已查今日推荐"。
- **成品卡片（deliverable）**：白卡 + hairline 边 + 标题行（图标 + "朋友圈文案"）+ 正文 + 右上"复制"按钮。这是老板直接拿走的东西，视觉要"可信、像成品"。
- **审批卡片（approval）**：浅黄/中性卡，标题"做海报需要确认" + 预览行（"竖版 9:16 · 暖色调 · 突出双人优惠"）+ `确认`(accent) / `取消`(次要) 按钮。花钱/对外动作的闸。
- **提问卡片（AskUserQuestion，新增）**：标题（管家的问题）+ 2–4 个选项（每项：标签 + 一句说明 + 可选预览块）+ "其它"自填 + 单/多选。让管家给老板"几个方案挑一个"，命中非技术老板的使用习惯。
- **输入区**：`rounded-xl` 输入框 + 左侧附件图标 + 右侧 accent 发送圆钮；下方一排**权限分段控件**（`都先问我 / 日常自己做 / 全部自己做`）+ 一句提示"群发、对外发布始终先问你"。

## 4.5 右侧预览/画布面板（artifact，可开关的第三栏）

参考 Claude Artifacts / ChatGPT Canvas / Cursor（三者都收敛到"左对话 + 右 artifact 预览"）。**统一的预览/画布 surface**，把已有的 Canvas（圈选定向改）+ 报表可视化 + 生图预览收进一个家。

- **触发**：生成了"可看/可改的成品"（海报/文案/报表）时，右侧滑出（~440px）；可 `✕` 收起 → 退回双栏。
- **面板头**：标签切换 `📝 文案 / 🎨 海报 / 📊 报表`（多 artifact 可切换）+ 关闭。
- **预览体**：
  - 海报 → 大图预览（实际比例，如 9:16）；
  - 文案 → 可编辑文档（Canvas）；**杀手锏=选中任意一段 → "定向改这段"**（对应 `canvas_service` `POST /canvas/edit`，只改选中、不动别处，正是 ChatGPT Canvas 的 inline-edit）；
  - 报表 → 表格视图，点格内联改（对应 `canvas.py` `POST /canvas/sheet` `/canvas/excel-edit`）。
- **底部工具条**：`⤓ 保存到本机` / `✎ 基于此调整`（以图/文生图、refine_from）/ `↻ 重新生成`；海报附尺寸标（`9:16 · 1152×2048 · medium`）。
- **布局**：开启后窗口变三栏（侧栏 240 + 对话 flex + 预览 440），中间对话流仍 ≤720 舒适宽。

## 5. 动效
- 卡片入场：`opacity 0→1 + translateY 4px→0`，~180ms ease-out。
- 按压：`active:scale-[0.98]`。
- 流式文本：逐字/逐块追加（已有 SSE），光标态可选。
- 不做：大幅滑入、弹跳、视差。

## 6. 真机 macOS 接入（P1 落地用）
```js
new BrowserWindow({
  titleBarStyle: 'hiddenInset',   // 保留原生红绿灯、内容延伸到顶
  vibrancy: 'sidebar',            // 侧栏毛玻璃
  visualEffectState: 'active',
  trafficLightPosition: { x: 16, y: 18 },
})
```
- 侧栏区域 CSS 设 `background: transparent` 让 vibrancy 透出；可拖拽区 `-webkit-app-region: drag`，按钮 `no-drag`。

## 7. 文案/用词规范（说人话，去黑话）

第一读者是**非技术的台球房老板**，界面上不出现任何技术黑话：

| 不要这样写 | 改成 |
|---|---|
| `BYOK` / `自带 Key` | 不出现这个词。需要时说人话：成本显示 **"本月 AI 花费 ≈ ¥X"**；模型配置页叫 **"我的 AI 模型"** |
| 顶栏 `DeepSeek V4 · 自带 Key` | 只显示**当前模型名 + ⌄**（如 `DeepSeek V4 ⌄`），可点切换；换了别家就显示别家，不附任何 key 说明 |
| 权限 `谨慎 / 自动改文件 / 全自动` | **`都先问我 / 日常自己做 / 全部自己做`** + 提示"群发、对外发布始终先问你" |
| 输入框占位符啰嗦（"问问管家，或帮你写点啥…"） | 短句：**"问问球房管家…" / "回复球房管家…"**（学 Claude Code 的 "Ask/Reply to Claude…"） |

原则：能力靠"欢迎页起手卡片"展示，不靠占位符解释；模型 key 已全内置、开箱即用，技术细节（key/BYOK/provider）作为可选高级档藏进设置，主界面只给老板看得懂的"模型名 + 花了多少钱"。
