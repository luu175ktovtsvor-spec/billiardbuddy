## 三、最高价值发现（按优先级）

### 🥇 P0｜经营诊断决策树（补项目最大短板）
数据分析板块含完整的 **6 条「指标阈值 → 诊断结论 → 责任部门 → 改进动作」闭环**，正是现有「经营诊断」功能缺的（现在只会输出泛泛建议）：

1. 助教费涨但总台费平 → 竞技客户没打出来 → 教练部加强下午约客
2. 开台数够（150+）但台费低 → 到店量足质差 → 强化大客户维护、提客单价
3. 充值-扣卡差距大 + 团购占比高 → 客户质量低、会员粘性弱 → 升级充值激励、提扣卡率
4. 团购占比 >70% → 教练获客弱 → 启动约客专项（日均邀约 20 人）
5. 商品费 < 助教费 → 推品能力不足 → 教练上钟加推品、前厅小推车日 3 次
6. 某区域开台率 <30% 或均时长 <1.5h → 配置不匹配 → 重配台桌用途、派高效教练驻守

附带：**收入分解公式**（总营业额 = 助教费+商品费+总台费；总台费 = 助教客户台费+竞技客户台费 = 直接开台+团购台费），让诊断从模糊变精准。

→ **新建 `knowledge.diagnostic_logic`** + 增强 `core_metrics`

## 四、⚠️ 必须处理的方向性偏差与冲突

### 冲突 1（最重要）：陪打导向 vs 获客导向
助教教练部、绩效薪酬两个板块**独立**指出：原料的绩效/提成高度挂钩「陪打时长/超休时长」（日均陪打第一名奖励、超休阶梯提成），而北极星明确「**助教核心工作是营销获客，不是陪打**」。

**处理**：陪打提成保留为「保底基础」，但**绩效与薪酬的增长部分挂到获客/转化/复购维度**（新客加微数、邀约进店数、复购率），降低「陪打小时数」权重。落地这些知识时按此校正，**不照搬原料的激励导向**。

### 冲突 2：合规是「内核转变」而非「换词」
原料强调招聘绝对不能出现「陪」字、不能问外貌、不能提高薪。这说明真正的合规不是把「陪练」改成「专业指导」这么简单，而是**把「情绪陪伴」的内核转成「技能提升+竞技体验」的内核**——岗位描述应强调「指导基础动作/执裁比赛/组织活动」，而非「聊天/喝酒/情绪价值」。

**处理**：增强 `compliance_rules`/`term_whitelist` 时按「内核转变」组织，而非只给替换词表。

### 冲突 3：定价铁律的落地路径缺失
PPT 用实际案例展示了「充 500 送 500 → 取消大额赠送 → 改一卡通/台费券」的三步递进（日均充值 2528→5973 元）。现有 `recharge_strategy` 有原则、缺这条决策路径。

**处理**：增强 `recharge_strategy`，补一卡通体系 + 大额充值整改路径。
