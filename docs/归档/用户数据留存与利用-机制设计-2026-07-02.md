# PART 1 · 架构与数据分区(设计定稿)

## 1.1 三层(原始 / 整理 / 报表,绝不混)
1. **原始落地层(收件箱)**:客户端传上来的原始批包,原样存、只增不改,能回溯、能重解析。
2. **归类整理层**:把原始包拆成六个"文件夹"(干净表)。
3. **看板报表层**:按天/门店预算好的汇总,喂看板直接读,不折腾原始数据。
> 好处:某层改了/坏了不连累另外两层。

## 1.2 六个"文件夹"(服务器模块)→ 喂哪个目标
| 模块(PG schema/表) | 装什么 | 存法 | 喂目标 |
|---|---|---|---|
| 📥 `raw_inbox` | 每批原始上传包(带 machine_id/store_id/批次) | PG,append-only | 源头/可回溯 |
| 📊 `events` | 动作流水:做了啥/成没成/耗时/报错 | PG 表 | ①② |
| 🖼️ `generations` | 提示词/结果/模型/token/好评差评 | PG 表 | ①③ + 成本 |
| 📁 `transcripts` | 整段会话长文本 | **大盘文件/对象存储**,PG 存索引卡片 | ①③ |
| 🏬 `stores` | 门店画像/身份/机器 | PG 表 | ④ |
| 📈 `marts_*` | 预算好的汇总(活跃/花费/好评率/留存) | PG 汇总表/物化视图 | 看板展示(四目标) |

## 1.3 三条铁则
- **大文件走大盘**:`transcripts` 长文本落大盘目录(或 OSS/COS),PG 只存"目录卡片"(指向+摘要),库不被撑肿。
- **每条贴两标签**:`machine_id`(哪台机)+ `store_id`(哪家店),四目标全靠它串。
- **每个文件夹只干一件事**,不混。

## 1.4 传输链路(端到端)
```
用户本机(Mac/Win 桌面 app · 后端 FastAPI 在跑)
  usage_events / generations / transcripts/*.jsonl / stores
     │ 采集器:增量取(游标 sync_state)→ 去重入队(sync_outbox)   [全量,不裁剪]
     ▼
  sync_outbox(本机 SQLite,append-only 队列)
     │ 上行器:批量 + gzip,httpx POST,带可吊销 app 令牌
     ▼  (失败→留队列/指数退避/下次续传;按 id 幂等)
  ── HTTPS 443 ──► owner 国内 app 机
     │ 接收端(独立服务):校验令牌 → 落 raw_inbox(幂等) → 整理入 events/generations/transcripts/stores
     ▼
  Postgres 18(数据在新挂大盘) + 看板(nginx + 登录口)
     ▲
  owner 本地:SSH 隧道连库看数 / 浏览器开看板
```

## 1.5 machine_id / 门店标识
- `machine_id`:**首启生成 UUID 存 `UPLOAD_DIR/machine_id`**(跨平台一套);可选增强=硬件级(Win 注册表 MachineGuid / Mac IOPlatformUUID)。
- 门店身份:`store_id` + 门店画像,随每批上行,把数据绑到"哪家付费门店"(目标 ④)。

## 1.6 访问 / 安全 / 留存
- PG 只绑 `127.0.0.1`,**不对公网开**;owner 本地看库经 SSH 隧道:`ssh -N -L 15432:127.0.0.1:5432 root@<app机>` → 本地工具连 `localhost:15432`。
- 看板挂 nginx + 登录口(80/443,证书按域名或裸 IP)。
- 留存:轨迹原文默认永久;若磁盘吃紧再定 N 个月滚动(PART 6 决策)。

# server/services/data_sync/machine_id.py
import os, uuid, platform
from pathlib import Path

def _upload_dir() -> Path:
    d = Path(os.environ.get("UPLOAD_DIR") or (Path.home() / ".billiards_data"))
    d.mkdir(parents=True, exist_ok=True)
    return d

def _hardware_id() -> str | None:
    try:
        sysname = platform.system()
        if sysname == "Windows":
            import winreg  # 仅 Win
            k = winreg.OpenKey(winreg.HKEY_LOCAL_MACHINE, r"SOFTWARE\Microsoft\Cryptography")
            return str(winreg.QueryValueEx(k, "MachineGuid")[0])
        if sysname == "Darwin":
            import subprocess
            out = subprocess.check_output(["ioreg", "-rd1", "-c", "IOPlatformExpertDevice"], text=True, timeout=5)
            for line in out.splitlines():
                if "IOPlatformUUID" in line:
                    return line.split('"')[-2]
    except Exception:
        return None
    return None

def get_machine_id() -> str:
    f = _upload_dir() / "machine_id"
    try:
        if f.exists():
            v = f.read_text(encoding="utf-8").strip()
            if v:
                return v
    except Exception:
        pass
    v = _hardware_id() or uuid.uuid4().hex
    try:
        f.write_text(v, encoding="utf-8")
    except Exception:
        pass
    return v
```

# server/services/data_sync/collector.py
from datetime import datetime, timezone
from sqlalchemy import select
from sqlalchemy.dialects.sqlite import insert as sqlite_insert
from models.sync_outbox import SyncOutbox
from models.sync_state import SyncState
from models.usage_event import UsageEvent
from models.generation import Generation
from models.store import Store

async def _cursor(db, source: str) -> datetime | None:
    st = await db.get(SyncState, source)
    return st.last_ts if st else None

async def _advance(db, source: str, ts: datetime):
    st = await db.get(SyncState, source)
    if st is None:
        db.add(SyncState(source=source, last_ts=ts))
    else:
        st.last_ts = ts

async def _enqueue(db, kind: str, ref_id: str, payload: dict | None) -> int:
    # 幂等:唯一冲突则忽略(SQLite on_conflict_do_nothing;PG 同名 API)
    stmt = sqlite_insert(SyncOutbox).values(kind=kind, ref_id=ref_id, payload=payload)
    stmt = stmt.on_conflict_do_nothing(index_elements=["kind", "ref_id"])
    res = await db.execute(stmt)
    return res.rowcount or 0

async def collect_once(db) -> int:
    n = 0
    # —— 使用事件 ——
    cur = await _cursor(db, "usage_events")
    q = select(UsageEvent).order_by(UsageEvent.created_at)
    if cur: q = q.where(UsageEvent.created_at > cur)
    rows = (await db.execute(q)).scalars().all()
    for r in rows:
        n += await _enqueue(db, "event", str(r.id), {
            "id": str(r.id), "event": r.event, "store_id": str(r.store_id) if r.store_id else None,
            "user_id": str(r.user_id) if r.user_id else None, "props": r.props,
            "created_at": r.created_at.astimezone(timezone.utc).isoformat() if r.created_at else None,
        })
    if rows: await _advance(db, "usage_events", rows[-1].created_at)
    # —— 生成记录(is_deleted==False)——
    cur = await _cursor(db, "generations")
    q = select(Generation).where(Generation.is_deleted == False).order_by(Generation.created_at)  # noqa: E712
    if cur: q = q.where(Generation.created_at > cur)
    rows = (await db.execute(q)).scalars().all()
    for r in rows:
        n += await _enqueue(db, "gen", str(r.id), {
            "id": str(r.id), "store_id": str(r.store_id), "type": r.type, "sub_type": r.sub_type,
            "prompt_used": r.prompt_used, "result": r.result, "model_used": r.model_used,
            "tokens_used": r.tokens_used, "effect_rating": r.effect_rating, "effect_note": r.effect_note,
            "is_favorite": r.is_favorite, "source_rec_id": r.source_rec_id,
            "conversation_id": str(r.conversation_id) if r.conversation_id else None,
            "created_at": r.created_at.astimezone(timezone.utc).isoformat() if r.created_at else None,
        })
    if rows: await _advance(db, "generations", rows[-1].created_at)
    # —— 门店档案(全量 upsert 语义:每次入队最新快照)——
    stores = (await db.execute(select(Store))).scalars().all()
    for s in stores:
        # store 用 "store:<id>:<updated_at>" 当 ref_id,画像变了就是新一条
        upd = getattr(s, "updated_at", None)
        ref = f"{s.id}:{upd.isoformat() if upd else ''}"
        n += await _enqueue(db, "store", ref, {"id": str(s.id), "snapshot": _store_snapshot(s)})
    # —— 对话轨迹(已完成的 conversation 落盘文件)——
    from services.agent.transcript import _transcript_dir
    tdir = _transcript_dir()
    if tdir.exists():
        for p in tdir.glob("*.jsonl"):
            cid = p.stem
            n += await _enqueue(db, "trace", cid, {"conversation_id": cid, "path": str(p)})
    await db.commit()
    return n

def _store_snapshot(s) -> dict:
    # 全量:把门店对象的普通列都塞进去(不裁剪)
    from sqlalchemy import inspect as _inspect
    return {c.key: _json_safe(getattr(s, c.key)) for c in _inspect(s).mapper.column_attrs}

def _json_safe(v):
    from datetime import datetime as _dt
    import uuid as _uuid
    if isinstance(v, _dt): return v.astimezone(timezone.utc).isoformat()
    if isinstance(v, _uuid.UUID): return str(v)
    return v
```
> ⚠️ 轨迹随对话滚动会变大:trace 已入队(synced_at 为空)且文件更新时,允许重新入队一次(把已同步的同 cid 置空 synced_at)——P1 简化为"文件 mtime 晚于该行 created_at 就重入队";实现见 uploader 侧对 trace 的处理或此处加 mtime 比较。P1 起步可接受"轨迹只在对话结束时上行一次",精细增量留 P2。

```python
# server/services/data_sync/uploader.py
import asyncio, gzip, json, logging
from datetime import datetime, timezone
from pathlib import Path
from sqlalchemy import select
from config import settings
from models.sync_outbox import SyncOutbox
from services.data_sync.machine_id import get_machine_id

logger = logging.getLogger(__name__)

def _pack(rows) -> bytes:
    batch = []
    for r in rows:
        item = {"kind": r.kind, "ref_id": r.ref_id, "payload": r.payload}
        if r.kind == "trace" and r.payload and r.payload.get("path"):
            try:
                item["payload"] = {**r.payload, "content": Path(r.payload["path"]).read_text(encoding="utf-8")}
            except Exception as e:
                item["payload"] = {**r.payload, "content": None, "read_error": str(e)}
        batch.append(item)
    body = {"machine_id": get_machine_id(), "batch": batch}
    return gzip.compress(json.dumps(body, ensure_ascii=False).encode("utf-8"))

async def flush_once(db, client=None) -> tuple[int, int]:
    if not settings.data_sync_endpoint or not settings.data_sync_token:
        return (0, 0)
    rows = (await db.execute(
        select(SyncOutbox).where(SyncOutbox.synced_at.is_(None))
        .order_by(SyncOutbox.created_at).limit(settings.data_sync_batch)
    )).scalars().all()
    if not rows:
        return (0, 0)
    content = _pack(rows)
    headers = {"Authorization": f"Bearer {settings.data_sync_token}", "Content-Encoding": "gzip",
               "Content-Type": "application/json"}
    own = client is None
    if own:
        import httpx
        client = httpx.AsyncClient(timeout=30)
    try:
        resp = await client.post(settings.data_sync_endpoint, content=content, headers=headers)
        resp.raise_for_status()
        now = datetime.now(timezone.utc)
        for r in rows:
            r.synced_at = now
        await db.commit()
        return (len(rows), 0)
    except Exception as e:
        for r in rows:
            r.attempts = (r.attempts or 0) + 1
            r.last_error = str(e)[:500]
        await db.commit()
        logger.warning("data_sync 上行失败(留队列续传): %s", e)
        return (0, len(rows))
    finally:
        if own:
            await client.aclose()

async def uploader_loop(stop_event):
    if not settings.data_sync_enabled:
        return
    from db.session import get_sessionmaker  # 按本仓库实际 sessionmaker 获取方式调整
    from services.data_sync.collector import collect_once
    backoff = 1
    while not stop_event.is_set():
        try:
            async with get_sessionmaker()() as db:
                await collect_once(db)
                ok, fail = await flush_once(db)
            backoff = 1 if fail == 0 else min(backoff * 2, 60)
        except Exception:
            logger.warning("data_sync loop 异常(不影响主流程)", exc_info=True)
            backoff = min(backoff * 2, 60)
        try:
            await asyncio.wait_for(stop_event.wait(), timeout=settings.data_sync_interval_s * backoff)
        except asyncio.TimeoutError:
            pass
```
> ⚠️ `get_sessionmaker` 用本仓库真实的 async session 工厂(找 `db/session.py` 或 `db/base.py` 里现成的 `async_sessionmaker`/`AsyncSessionLocal`,照 `daily_scheduler` 等现有后台任务怎么拿 session 抄)。

### Task P1.S1:服务器接收端 `POST /ingest`

**Files:** Create `dataeye/receiver/app.py`、`dataeye/receiver/db.py`、`dataeye/sql/schema.sql`

**接口契约(客户端↔服务器,锁定):**
- `POST /ingest`,Header `Authorization: Bearer <app令牌>`、`Content-Encoding: gzip`。
- Body(gzip 前 JSON):`{"machine_id": str, "batch": [{"kind": "event|gen|trace|store", "ref_id": str, "payload": {...}}]}`。
- 鉴权:令牌在服务器 env 的允许清单里(可吊销=从清单删)。
- 幂等:按 `(machine_id, kind, ref_id)` 唯一,冲突忽略。
- 响应:`200 {"accepted": n, "duplicated": m}`;令牌无效 `401`。

- [ ] **Step 1: 六模块 DDL**(`dataeye/sql/schema.sql`,PART 3 建库时执行)
```sql
CREATE TABLE IF NOT EXISTS raw_inbox (
  id BIGSERIAL PRIMARY KEY,
  machine_id TEXT NOT NULL,
  kind TEXT NOT NULL,
  ref_id TEXT NOT NULL,
  payload JSONB,
  received_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (machine_id, kind, ref_id)
);
CREATE TABLE IF NOT EXISTS events (
  id BIGSERIAL PRIMARY KEY, machine_id TEXT, event_id TEXT, store_id TEXT, user_id TEXT,
  event TEXT, props JSONB, created_at TIMESTAMPTZ,
  UNIQUE (machine_id, event_id)               -- event_id = 客户端 usage_events.id(去重)
);
CREATE TABLE IF NOT EXISTS generations (
  id BIGSERIAL PRIMARY KEY, machine_id TEXT, gen_id TEXT, store_id TEXT,
  type TEXT, sub_type TEXT, prompt_used TEXT, result TEXT, model_used TEXT,
  tokens_used INT, effect_rating TEXT, effect_note TEXT, is_favorite BOOL,
  source_rec_id TEXT, conversation_id TEXT, created_at TIMESTAMPTZ,
  UNIQUE (machine_id, gen_id)
);
CREATE TABLE IF NOT EXISTS transcripts (       -- 索引卡片;长文本落大盘文件
  id BIGSERIAL PRIMARY KEY, machine_id TEXT, conversation_id TEXT,
  file_path TEXT, summary TEXT, turns INT, created_at TIMESTAMPTZ,
  UNIQUE (machine_id, conversation_id)
);
CREATE TABLE IF NOT EXISTS stores (
  id BIGSERIAL PRIMARY KEY, machine_id TEXT, store_id TEXT,
  snapshot JSONB, received_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE (machine_id, store_id)               -- upsert 最新快照
);
```
> 注:去重两道保险——`raw_inbox` 按 `(machine_id,kind,ref_id)` 唯一挡重复上传;`events` 再按 `(machine_id,event_id)` 唯一(`event_id` = 客户端 `usage_events.id`)。整理入表时用 `INSERT ... ON CONFLICT DO NOTHING`。

- [ ] **Step 2: 接收端**(`dataeye/receiver/app.py`)
```python
import gzip, json, os
from fastapi import FastAPI, Request, HTTPException
from db import insert_batch   # dataeye/receiver/db.py

ALLOWED = set(filter(None, os.environ.get("INGEST_TOKENS", "").split(",")))  # 可吊销令牌清单
app = FastAPI()

@app.post("/ingest")
async def ingest(request: Request):
    auth = request.headers.get("authorization", "")
    token = auth[7:] if auth.lower().startswith("bearer ") else ""
    if token not in ALLOWED:
        raise HTTPException(401, "invalid token")
    raw = await request.body()
    if request.headers.get("content-encoding") == "gzip":
        raw = gzip.decompress(raw)
    body = json.loads(raw)
    accepted, dup = await insert_batch(body["machine_id"], body["batch"])
    return {"accepted": accepted, "duplicated": dup}
```
`dataeye/receiver/db.py`:用 `asyncpg`/`psycopg` 连本机 PG,先 upsert `raw_inbox`(冲突计 dup),再按 kind 整理进 `events/generations/transcripts/stores`;trace 的 `content` 写大盘文件 `TRANSCRIPT_STORE_DIR/<machine_id>/<cid>.jsonl`,表里只存 `file_path`+`turns`+`summary`(summary 取前若干字)。

# PART 5 · 测试与验收 / 耦合 / 回滚 / 安全

### 5.1 P1 验收标准(全绿才算完)
- 两台真机(**一台 Mac、一台 Win**)装正式包 → 用几天 → owner 后台能:翻到真实会话(含提示词/结果/工具轨迹)+ 成本(按 machine/门店/天)+ 崩溃 + 认出是哪家门店。
- 断网/关机/重启:队列不丢、不重复(幂等)。
- 上行失败/接收端挂:**用户主流程完全不受影响**(出文案/出图照常)。
- 后端 `cd server && uv run pytest tests/ -q` 全绿;前端(若动)`cd web && npx tsc --noEmit` 过;两平台各出一次正式包并真机验收。
- `python3 scripts/build_coupling_map.py --write` 后 `test_coupling_map_fresh.py` 绿。

### 5.2 耦合注意
- 采集只读现有表 + 只写自己的 `sync_outbox`/`sync_state`,不改现有业务表结构 → 对现有功能零侵入。
- 唯一挂载点是 `main.py` lifespan 加一个后台任务(照现有先例)+ config 加字段 + `init_local` 加 import。
- 动到 `api.ts`/`api/v1` 才需刷耦合地图;本 P1 基本不动前端接口(P2 动前端反馈入口时再刷)。

### 5.3 回滚
- 客户端:`DATA_SYNC_ENABLED=0` 即整条上行停摆(loop 直接 return),不影响任何主流程 → **一个开关即回滚**。
- 服务器:接收端/看板是独立服务,`systemctl stop dataeye-receiver` 即停,不碰 app/网关。

### 5.4 安全
- 客户端只带**可吊销 app 令牌**(服务器 `INGEST_TOKENS` 清单删一个即失效);真令牌/真 IP 只在 `gw.env`/systemd env,不进 git。
- PG 不开公网;owner 看库走 SSH 隧道。
- 上行走 443 HTTPS + 自有域名。全私有,不经任何第三方。
