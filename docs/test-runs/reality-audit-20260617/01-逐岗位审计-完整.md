- 控成本系统化:补店长'成本控制'卡/知识,把电费(空调每小时报备)、器材商品损耗、成材率(台呢/皮头/巧粉真实耗用口径)、人员人效拆清楚,别只剩'房租≤25%'一句空话

**最值得延伸**:
