（输入：{'problem_area': '竞争', 'current_situation': '隔壁新开一家，台费比我便宜10块，我不少老客被吸走了，要不要也降价'}）

【问题诊断】
核心问题：低价竞争导致老客流失，而非客源不足。

问题表现：隔壁新店台费低10块，你不少老客被吸走。这说明你的老客对价格有一定敏感度，或者隔壁除了价格，还提供了某种“新鲜感”或“人情味”替代了你的原有优势。

可能原因：
1. 老客维护体系薄弱（责任部门：店长+前厅）。老客流失前没有高频互动、没有记住他们的偏好（如固定台号、饮品习惯），导致隔壁一降价，他们觉得“去哪打都一样”，没有非留不可的理由。
2. 客户忠诚度锚点缺失（责任部门：店长+教练）。除了价格，你店里没有建立起让老客舍不得走的“软性连接”，比如固定的球友圈子、熟悉的助教、专属的赛事活动。隔壁的“便宜10块”直接击穿了价格敏感带。
3. 价格带未做防护（责任部门：店长）。你的定价体系可能缺乏弹性，没有分时段、分台型的差异化定价，导致隔壁打价格战时，你只能被动应对，而没有自己的“防御型低价产品”（如工作日白天场、特定时段特惠台）。

【数据分析建议】
需要收集的数据：
- 老客流失清单：过去1个月，到店次数≥4次但最近2周没来的老客，具体是谁？他们平时消费习惯（台费/是否点饮品/是否充值）？
- 现有会员的余额和充值时间：会员卡里还有钱的客户，最近是否也减少了到店？这是判断“纯粹价格敏感”还是“老客整体忠诚度下滑”的关键。
- 各时段台费收入占比：隔壁便宜10块，主要冲击的是哪个时段（晚上黄金档还是下午场）？如果是黄金档，说明核心客群流失严重；如果是下午场，可能是闲散客被吸走。
- 商品（饮品）销售占比：老客如果只是台费消费，说明他们只是来打球的“工具人”，忠诚度低；如果商品消费高，说明他们愿意为“氛围+服务”买单，价格敏感度其实没那么高。

数据分析方法：
- 对比流失老客与留存老客的“商品消费占比”和“充值记录”。如果流失老客几乎没有商品消费且未充值，那他们就是纯价格驱动型客户，降不降价都会走。
- 看隔壁降价后，你店里“高峰期开台率”是否下降。如果下降了但非高峰期没变，说明隔壁抢的是你最赚钱的时段，需要针对性防御。

【改进建议】
短期措施（1-2周）：
- 不要主动降价。降价会坐实“你只值这个价”，而且隔壁可以再降。
- 立刻启动老客回访。店长亲自私聊最近2周没来的老客，话术像朋友：“王哥，最近好久没见你来了，是不是隔壁便宜点把你勾走了？哈哈，开玩笑。这两天有空回来打两把，我帮你留好台，给你补两瓶水。” 重点是人情召回，不是价格让步。
- 前厅对所有到店老客做“软性锁定”：记住老客喜欢的台号、饮品，主动说：“哥，老位置给你留着呢，饮品老规矩？” 强化被记住的感觉。

中期措施（1-3月）：
- 每周一次“搭子局”或“台费局”（小奖品挑战）。把老客变成“局主”，让他们带朋友来，增强社交黏性。局主免费打，朋友半价，锁住他们。
- 推出“老客专属卡”：限老客购买，充1000送100台费（赠送仅限台位费），且赠送部分可在任何时段使用。这比直接降价更聪明，既给了实惠，又锁定了未来消费。
- 提升商品（饮品）的毛利率和多样性，让“顺带消费”成为习惯。老客到店，主动问“来杯奶茶/咖啡？” 哪怕只赚几块钱，也能增加单客价值，让台费不是唯一收入来源。

长期措施（3月以上）：
- 建立“人情世故”服务体系：店长+前厅需要记住前50名老客的姓名、偏好、甚至生日。每周至少主动联系一次老客，不是发广告，而是真心问“最近手感怎么样”“要不要约个局”。
- 打造“赛事+圈子”护城河：每月一场会员赛，让老客觉得“这里是我们球友的俱乐部”，而不是单纯的打球场所。赛事明确“让条件”（按档位让球），让低水平客户也有赢的可能。

【执行步骤】
第一步：今晚开始，店长私聊5个流失最明显的老客，用朋友口吻召回。不说降价，只谈人情。
第二步：本周内，梳理出前30名高价值老客（消费频次+商品消费高），建立“老客专属群”，店内氛围优先维护他们（保留台、优质服务）。
第三步：下周一，设计“老客专属卡”规则，限老客购买，赠送部分限台费，且告知“这是老会员福利，新客没有”。执行层面由前厅接待时自然推荐。

【预期效果】
改进后预期：老客流失速度放缓，1-2周内能召回部分流失的老客，且到店后客单价（商品消费）可能不降反升。3个月后，老客的消费黏性和社交归属感增强，对价格敏感度降低。

【风险提示】
可能遇到的困难：
- 老客回访时直接问“你们能不能也便宜10块/小时”，店长该如何回应？
- 增加商品消费后，如果客户觉得“你们这是变相涨价”，产生反感。

应对方案：
- 遇到直接要求降价的老客，店长话术：“王哥，咱们这儿的环境和服务跟隔壁不一样，你在这儿打顺手了也不想换地方。要不这样，你下次带朋友来，我送你两瓶饮料，台费咱就不动了。”
- 商品消费要自然推荐，不强制。可以设置“消费满一定台费送饮品”的机制，引导客户尝试，而不是生硬推销。
