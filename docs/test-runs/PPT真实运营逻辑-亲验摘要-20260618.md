## 一、营销·定位（P24-31）
- 三类球房：**社区球房 / 竞技商业球房 / 竞技球房**（与项目 positioning 选项对得上）。
- 定位逻辑 = Jack Trout 差异化："给客户一个买我们的理由，针对竞争对手在客户头脑里建立优势位置"。
- 真实竞争形态："1 栋楼 3 家球房"贴身竞争；定位打法可让"4 个月营收成倍增长"。

## 二、营销·定价（P39-45）—"定价定生死"
- **四大盈利点 = 台费 / 商品费 / 器材费 / 助教管理费**（"哪个定价最重要？"）。
- 真实案例数据（剥名）：某店两周营业额 44 万，其中**助教费 23.3 万 > 台费 18.3 万** > 商品费 8.4 万 → **PPT 用硬数据证实"球房主要靠助教挣钱"**。
- 定价常见病：定价过高/过低、竞争压力大幅降价、**长期促销**（伤价格体系）。
- 台费定价过高的诊断因素：装修档次高的错觉等。

## 三、营销·产品/促销（P64-66）
- 促销目的 = "我想让谁干什么"（目标导向，不是无脑打折）。
- 促销操作：**助教免费体验**（首次体验养消费习惯）/ 培养顾客消费习惯 / **充值送器材券**（小比例赠品，非大额返现）。
  - ⚠️ 注意"助教免费体验"是**拉新促销手段**（首单体验），与"把助教服务写成免费/赠品"是两回事，别混。

## 四、营销·传播（P79-80+）—线上曝光体系

  - **PPT 明确把"交友软件"列进内容/获客平台** → 助教刷交友软件获客 = PPT 真实打法。
- **内容两型（PPT 原话分类）：`流量型 = 擦边` + `获客型 = 产品卖点`** → **擦边引流是 PPT 正经分类的真实流量打法**，不是灰产臆测。
- 线上曝光四目的：品牌曝光 / 流量拉新 / 用户互动 / 直接转化；本地同城靠"员工抖音矩阵 + 门店本地推"。

## 六、人才管理·助教体系（P154-196）
