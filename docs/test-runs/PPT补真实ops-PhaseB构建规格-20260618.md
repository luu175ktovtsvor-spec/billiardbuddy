## 新文件（draft→我写+接线）
1. **operation/positioning_design.yaml**（定位方法论，HIGH，PPT P24-37/P85-87）
   - 输入：门店类型(社区/商业/竞技/竞技商业)+周边竞品摸底+自身优势
   - 输出：①该在客户心智占哪个词(性价比/氛围/竞技/助教)②一句高感知差异化口号(句式"找[核心需求]来XX"，如"找搭子抢台费来XX""找贴心助教来XX")③与竞品差异化切入④口号怎么在抖音/美团/门头/朋友圈重复传播抢心智
   - 依据：P25"给客户一个买我们的理由;定位=针对竞争对手在客户头脑建立优势位置";P85-87品牌传播三部曲(差异化→重复性"重复传播频繁抢占顾客心智"→高感知slogan)
   - 接线：role-config.ts 加卡(老板/店长岗)；promptKey
2. **operation/price_raise.yaml**（分区涨价playbook，HIGH，PPT P46-53）
   - 输入：门店当前各区价/上座/团购占比
   - 输出：接管/经营做起来后→各区域(团购区/包厢/竞技区/贵宾区/助教费)上调因素分析→哪些区可涨/涨多少/先涨哪个→分步
   - 依据：P47"接管后24年2月25日…各区域价格上调因素分析";接手后日均充值2528→5973、营业额6615→15182(把经营做起来后逐步提价的真实路径)
   - 接线：role-config 加卡(老板/店长)；diagnosis 命中"价格虚低/经营改善"可挂接
3. **knowledge/assistant_persona_building.yaml**（美女人设打造SOP，HIGH，PPT P186/188/157）
   - 内容：四风格定位(性感/可爱/飒爽/潮酷)+穿搭妆容到镜头/现场标准+短视频/直播/朋友圈人设内容方向+助教管理协助沟通统一往"引导加微信"收口
   - 依据：P157"个人形象>沟通能力>台球技术";P186"打造精致美女人设";P188四风格
   - 接线：content_service KNOWLEDGE_KEYWORDS(人设/形象/风格/穿搭) + rules.role.assistant_manager required_knowledge
4. **knowledge/store_manager_competency.yaml**（店长能力模型，MEDIUM-HIGH，PPT P241/244/249/254/245-248）
   - 内容：店长五大能力(营销/数据分析/团队搭建/组织活动/解决问题)+核心工作=营销(P244原文);用赛马机制搭团队、筛助教管理/教练;老板抓店长的硬指标(营业额利润/人事/台费团购占比/当日助教上班数/平均陪打时长/商品费/器材费 P254)
   - 接线：rules.role.manager required_knowledge + KNOWLEDGE_KEYWORDS
