## 二、真实诊断(看决策树「根因→责任部门→动作」+ 指标是否用上)


### 营收上不去
（输入：这两个月营业额一直上不去，台费收入还行但就是不涨，也不知道问题出在哪）

【问题诊断】
核心问题：台费收入平稳但总营业额停滞，说明收入结构单一、增值转化（商品/会员/助教）没有跟上客流增长，老客复购和客单价提升存在瓶颈。
问题表现：台费没跌、但也不涨，商品费和助教费占比偏低，会员充值转化弱，新客来了留不住。
可能原因：
1. 前厅推品能力弱，商品销售占比低，丢掉了客单价提升的机会 → 责任：前厅主管 → 动作：建立小推车巡场制度（下午1次/h、晚场40min/次），设商品销售日目标，员工每单必须主动推荐一次饮品/零食。
2. 客户到店后缺少"留下来继续消费"的钩子，老客复购依赖自然到店，无主动维护 → 责任：教练部 + 前厅 → 动作：教练每天加客户微信≥5人，当晚发一条"今天打得怎么样"回访；前厅对团购新客必须引导加微信进群，到店≥2次的客户标记为"待转化会员"。
3. 会员充值转化低，散客变会员路径不清晰 → 责任：店长统筹、前厅执行 → 动作：制定"到店3次或累计消费满200元"作为推送会员的门槛，前厅主动提"要不要充个卡，以后打台费更划算"（比例控制在充1000送99级别，不搞大额）。

【数据分析建议】
需要收集的数据（从真实经营台账里看，而不是凭空统计）：
- 现金消费与卡余额消费占比（判断会员消费是否在动）
- 新老客充值比例（新客转化率、老客续充率）
- 商品（饮品）消费占比，以及人均商品消费额
- 各时段消费分布（尤其下午场和晚场的台时数对比）
- 各球台开台时长，识别"冷台"（开台<2h的台位）
数据分析方法：
- 对比这两个月的数据趋势：每周的台费、商品费、充值金额曲线，看是整体平稳还是某项在下滑
- 算一下"单客消费 = 总营业额 / 到店人次"，如果人次没少但单客消费走低，说明客单价在下降，问题出在商品和会员转化
- 看团购核销占比，如果团购客户占台费比例>40%，说明新客质量偏弱、直接散客转化不足

【改进建议】
短期措施（1-2周，本周六6月20日、周日6月21日起执行）：
1. 【本周六/周日起，连做3天 "空台提醒 + 老客回访"】店长亲自私聊最近1个月到店≥2次的客户："周末台子有点空，过来打两把？给你留台。"（不优惠、纯邀约，卖人情）
2. 【前厅立规矩】每位团购新客核销时，主动问一句"要不要加个微信，下次来提前帮你留好台" → 加微信后拉入门店群，次日群内发一条"今天有人约球吗？我帮你们搭搭子"
3. 【商品小推车】每天下午14:00-16:00、晚上19:30-21:00，前厅推小车巡场一圈，问"哥喝点什么？"，每人每天目标至少推出去10单饮品

中期措施（1-3月）：
1. 【会员卡优化】一卡通模式（充值赠送仅限台费，比例控制在10-15%），取消大额充送；每月设一个"会员日"（如每月15号），当天会员台费9折（只针对会员，不对外公开降价）
2. 【建立"到店3次转化制"】客户到店满3次后，前厅/教练主动推一次会员："哥你来了好几次了，充值比较划算，要不要看看？"配上简单的利益对比（如"充1000送99，每次台费能省不少"）
3. 【固定周赛/月赛】每月至少1场台费局小赛（报名费可设在10元级别，奖金200-500元），目的不是赢钱，是让老客有理由带朋友来、拉群锁人

长期措施（3月以上）：
1. 【前厅+教练 双岗位PK机制】每月考核：前厅的商品销售额+加微信量，教练的组局数+竞技客户转化数，排名靠前的给奖励（如当日提成上浮或实物奖励）
2. 【私域社群运营常态化】群里每周固定"搭子局接龙"（周中1次、周末1次），店长/教练在群里主动撮合拼台，让到店的散客有"来了有人一起打"的感觉
3. 【优化客户结构】目标：3个月内助教费+商品费占比从当前水平提升至总营业额的35-40%（目前可能偏低），台费占比从70%+降到60%左右，降低对单一收入的依赖

【执行步骤】
第一步（本周内）：数据摸底，把这两个月的现金消费/卡消费/商品费/充值比例拉出来看，明确"哪一块钱没赚到"。同时把"空台提醒+老客回访"从本周六开始执行。
第二步（下周起）：前厅开始执行"每单推一次饮品"和"团购新客加微信进群"制度，教练每天加微信5人+回访前一天客户。店长每周一复盘商品销售额和微信群新增人数。
第三步（一个月内）：会员卡方案改成"充1000送99"模式并正式上线，配合"会员日"和第一场搭子周赛，观察会员转化率和充值数据是否有变化。

【预期效果】
改进后预期：
- 商品销售额逐步提升至总营业额的15-20%（不再是纯台费依赖）
- 会员充值人数和充值频次稳步增长，会员消费占比达到30-40%
- 老客复购率提升，工作日空台率下降（通过搭子局和回访激活）
- 客户结构优化：不再是"团购进来打一次就走"，而是"有人留微信、有人充会员、有人带朋友来"

【风险提示】
可能遇到的困难：
1. 员工（前厅/教练）不愿意主动推商品和加微信，觉得"太麻烦""怕客户烦"
应对方案：设基础奖励，每推成一单饮品/零食给小额提成（如0.5-1元/单），加微信也计入当日考核；先试一周，用数据说话（"加微信的客户复购率更高"）。
2. 老客户回访收到"烦"的反馈
应对方案：回访话术用自然的熟人语气，不群发、不推销，只问"最近忙不忙，有空回来打两把"，客户不回复就不再追问。
3. 会员卡改小比例赠送后，老会员觉得"缩水了"
应对方案：对存量老会员保持原政策至卡内余额用完；新会员自动执行新政策，同时强调"赠送金额虽然少了，但更灵活、全部能打台费"。


### 工作日白天空台
（输入：工作日白天和下午基本没人，12张台经常只开2-3张）

【问题诊断】
核心问题：工作日白天下午时段客流严重不足，12张台长期闲置9-10张，该时段营收贡献几乎为零。
问题表现：周三下午，店内空台率超过75%，到店客户以零星散客为主，无固定老客、无追分局、无团购客到店。整体氛围冷清，员工状态松散。
可能原因：
1. 错峰人群未开发：周边有午休上班族、夜班工人、自由职业者、退休人群，但门店从未针对这些群体做过任何触达和引导。
2. 该时段客户体验缺失：空台多、没人气、没氛围，客户进店后感受冷清，很难产生“下次还来”的念头。
3. 管理动作缺失：未设置该时段的专用运营动作（分时定价、拼台局、主题局），员工在该时段也无明确获客指标。

【数据分析建议】
需要收集的数据：
- 各时段（9-12点、12-14点、14-17点）的开台数、客户类型（散客/老客/团购）、商品消费情况。
- 周边3公里内写字楼数量、园区类型、居民区年龄结构（是否有大量退休/自由职业人群）。
- 近15天该时段的新老客充卡比例、朋友圈/社群到店转化率。
数据分析方法：
- 对比该时段与其他时段的商品消费占比——如果商品消费极低，说明客户连“待一会儿”的意愿都没有，问题出在“不值得来”而非“不知道能来”。
- 统计该时段团购核销占比——如果团购占比很低，说明不是引流问题，而是客户到了也不愿意在白天来。
- 拉出近一个月该时段做过哪些营销动作，按天对应开台数，看哪个动作有正向效果。

【改进建议】
短期措施（1-2周）：
1. 打造“工作日白天专属群”——用“空台+搭子+划算”组合拳，锁定周边白天有空的人群。今晚拉群，明天开始发群公告：
   “工作日白天店里空台多，想打球的提前说，给你留个好台位。一个人来也不尴尬，群里接龙约搭子。”
2. 设置“午休场”锚点：在朋友圈和群里发“中午12点到2点，来打两把再回去上班，时间刚好”，并放一张店内空台+阳光洒进来的图。
3. 员工动作：下班前（今晚）让前厅主管确认已加了哪些工作日白天到过店里的客户微信，挨个简单问一句：“今天白天打得怎么样？明天还来不？我帮你留台。”

中期措施（1-3月）：
1. 锁定“固定客户”——每月第一周定一个“白天老客下午茶局”，提前一周在群里接龙，到场送一杯饮品。目的不是活动本身，是让白天来的人有“圈子感”。
2. 每两周做一次“周二/周四白天小赛”，报名费低（20-30元），奖品设饮品券/台费券，让长期客户带动新客户。
3. 在大群里定期宣导白天时段的价值感：“白天过来，台子随便挑，想练球、想安静打局都在状态。”而不是只说“白天便宜”。

长期措施（3月以上）：
1. 结合周边人群画像，把白天时段从“成本负担”变成“第二主场”——比如与周边健身/咖啡店联动，白天来打球可兑换饮品券。
2. 设计老客裂变动作：白天到店打卡+朋友圈发空台氛围照，每带一个新朋友白天到店，奖励老客一次“免费一小时台费”（用赠券形式，不是直接降价）。
3. 将白天时段从“空台时段”升级为“社群专属时段”，定期做“白天会员日”，用氛围和人情味锁住该时段老客。

【执行步骤】
第一步（今晚/明早）：
- 建“星河台球·工作日白天专属群”，群公告写完，群内发第一条信息。
- 前厅主管整理白天到店过客户的微信，今晚发1-2条私聊。
第二步（明天上午）：
- 朋友圈发“今天白天空台多，来打两把，私我留台”。
- 群内发起“明天（周四）白天约球接龙”，看能凑到几人。
第三步（周六-周日）：
- 利用本周末两天客流多的时候，在店里、在群里提前告知“下周一开始有白天局了，想约的群里说”。周末当面给常来的客户口头提一句：“下周工作日白天有空的话过来，那个点清静，好打。”

【预期效果】
- 2周内：工作日白天时段开台数从2-3张提升至4-5张，氛围明显改善，员工在该时段的主动性提高。
- 1个月内：该时段出现2-3个固定老客，能带动其他人跟风来打。
- 3个月内：白天时段形成稳定的社群氛围，周边人群知道“星河台球白天也能去、有人玩、不冷清”。

【风险提示】
可能遇到的困难：
- 老板或员工认为“白天没必要投入精力，反正也赚不了多少钱”——这是最大的障碍。
- 客户觉得“白天来是捡便宜”，而不是“白天来是因为氛围好”。
应对方案：
- 让老板看到数据：2-3张台一天不过一两百块钱，但空台对晚上黄金时段的氛围拖累更大。白天的人气是晚上氛围的“底子”。
- 内容上不过度强调价格便宜，而是强调“白天店里台子随便挑、不用排队、能专注练球/安静打局”，让客户觉得自己会选时间、很懂。
- 员工激励：白天每成交一台，给前厅/助教5-10元即时奖励，不用大额承诺，小数目的即时反馈更能带动行动。
