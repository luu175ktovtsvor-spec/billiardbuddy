## 4. 优质样例库修正

### 4.1 是否移除 C11
**是。** C11（前厅投诉安抚）已从优质样例库移除。

### 4.2 移除原因

在 10D-2 原始测试结果中，C11 的 AI 输出包含以下经济承诺：

- "今天这局算我请的"
- "送您一瓶饮料"
- "今晚的单我帮您抹个零"
- "今晚送您一局台费减免"

这些属于 10D-3 要修复的"投诉安抚擅自经济承诺"问题（baseline_rules 第20条），不应出现在优质样例库中。

### 4.3 替换成了哪个 Case
**替换为 C15：赛后战报。**

### 4.4 为什么 C15 更适合作为优质样例

| 维度 | C11 (旧) | C15 (新) |
|------|---------|---------|
| 场景 | 投诉安抚 | 赛后战报（赛事/周赛） |
| 经济承诺 | **有**（送饮料、免单、抹零、台费减免） | **无** |
| 乱编信息 | 无 | 无（冠军名字和比分用占位符） |
| 电话地址 | 无 | 无 |
| output_package | 全部响应 | 全部响应（3项） |
| 微信真实感 | 中（话术有客服感） | **高**（像教练赛后真实发言） |
| 可直接使用 | 否（含经济承诺不可直接使用） | 是 |
| 场景覆盖 | 已有其他场景覆盖 | **新增赛事战报场景**，补充了优质样例库的赛事维度 |

C15 额外优势：
- 巧妙将战报转化为下次赛事预约引导（一石二鸟）
- 提供了 2 种朋友圈风格选择（赛果通报型 + 邀约引导型）
- 所有未知信息用占位符占位，格式规范

### 5.2 旧统计 vs 新统计对比

| 问题类型 | 旧统计（终端摘要） | 新统计（10D-2 MD 正文） | 变化 |

### 5.3 差异原因说明

旧统计来自 10D-2 测试过程中的终端自动违规检测脚本（`scripts/tmp_analyze_results.py`），该脚本使用正则匹配，存在以下局限：
- "未知信息未占位"检测不够全面（只检测了 `【请补充` 的有无，未检测反向情况）
- "output_package 未响应"关键词匹配过于宽松
- "输出太长"阈值不同（脚本用 2000 字，报告用其他标准）
- 一些统计维度（未知信息已占位、用户意图误判等）只在完整 MD 报告正文中记录

**本次修正后，10D-3 报告中的统计数据以 10D-2 完整 Markdown 报告正文为准。**
