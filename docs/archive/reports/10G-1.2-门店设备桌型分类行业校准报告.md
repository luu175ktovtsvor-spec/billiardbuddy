- TypeScript ProfileFormData 类型
- `profile_context` 门店画像设备摘要
- 产品大脑文档 + 字段字典同步

不做：10G-2、岗位工作台、新 migration、DeepSeek 调用。

## 3. 标准桌型枚举

| Key | 中文名 | 说明 |
|-----|--------|------|
| `normal_pool_table` | 普通台球桌 | 除独牙、乔氏以外的中式八球台球桌均归此类 |
| `duya_pool_table` | 独牙台球桌 | 独牙品牌台球桌 |
| `joy_billiards_table` | 乔氏台球桌 | 乔氏（JOY）品牌台球桌 |
| `snooker_table` | 斯诺克 | 斯诺克台球桌 |

**核心规则**：除独牙、乔氏以外的中式八球台球桌，统一归为普通台球桌。不要把"中式八球台""美式台""英式台""比赛台""娱乐台"等作为标准枚举。

## 4. operation_profile 结构

在 `operation_profile` 中新增 `equipment` 字段：

```json
{
  "equipment": {
    "table_count": null,
    "table_types": ["normal_pool_table", "joy_billiards_table"],
    "table_type_note": "12张普通台，2张乔氏"
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `equipment.table_count` | number/null | 设备总数（预留，MVP 未做前端展示） |
| `equipment.table_types` | string[] | 桌型多选，仅允许 4 个标准枚举值 |
| `equipment.table_type_note` | string | 补充说明（选填），不参与标准枚举 |

**不需要新增数据库 migration**，使用现有的 `stores.operation_profile` JSONB 字段。
