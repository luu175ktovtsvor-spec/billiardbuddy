## 1. 核心发现：Few-shot 示例与基线规则严重冲突

### 问题描述

`server/prompts/fewshots/` 中的多个示例文件包含违反 `baseline_rules.yaml` 的内容：

| 文件 | 行号 | 违规内容 | 违反规则 |
|------|------|----------|----------|
| `old_customer_recall.yaml` | 18-19 | "7号台最近换了新台呢" | 规则 17b：严禁编造门店新变化 |
| `old_customer_recall.yaml` | 32-33 | "新到一批球杆，环球的新款" | 规则 17b：严禁编造门店新变化 |
| `old_customer_recall.yaml` | 41 | "续费的话现在有优惠，多送2小时" | 规则 12：严禁编造优惠/赠送 |
| `old_customer_recall.yaml` | 48 | "老会员续费9折" | 规则 12：严禁编造折扣 |
| `old_customer_recall.yaml` | 57 | "2小时免费送你" | 规则 12：严禁编造赠送 |
| `old_customer_recall.yaml` | 66 | "台费8折+免费果盘" | 规则 12：严禁编造折扣/赠送 |
| `old_customer_recall.yaml` | 81 | "台费7折+免费饮品" | 规则 12：严禁编造折扣/赠送 |

| `vip_maintenance.yaml` | 59 | "老会员续费9折" | 规则 12：严禁编造折扣 |
| `vip_maintenance.yaml` | 66 | "台费8折+专属助教预约" | 规则 12+19：严禁编造折扣/VIP特权 |
| `frontdesk_greeting.yaml` | 19 | "我们有乔氏专业台" | 规则 17c：严禁编造桌型（除非门店画像有） |

### 影响分析

1. **AI 会学习错误模式**：Few-shot 示例是 AI 生成内容的参考模板，如果示例本身违规，AI 会模仿这些违规内容
2. **规则形同虚设**：baseline_rules 中的严格禁令会被 few-shot 中的实际示例覆盖
3. **生产风险**：用户可能复制使用包含虚构优惠/折扣的内容，导致经营纠纷

### 修复建议

**立即修复**：重写所有违规的 few-shot 示例，使其符合 baseline_rules：

```yaml
# 错误示例（当前）
- type: 久未到店
  channel: 私聊
  content: |
    哥，好久没见了，最近忙啥呢？
    你之前常打的7号台，最近换了新台呢  # ❌ 编造门店变化
    啥时候有空来试试，手感提升了一大截

# 正确示例（修复后）
- type: 久未到店
  channel: 私聊
  content: |
    哥，好久没见了，最近忙啥呢？
    店里最近人气挺旺的，晚上经常满台
    啥时候有空来打两把？我帮你留台
```

## 3. 规则库质量评估

### 3.1 baseline_rules.yaml 评估

**优点**：
- 覆盖全面：53条规则涵盖价格、优惠、助教、赛事、表达边界、合规红线
- PPT校准：规则与行业知识高度一致
- 可执行性强：规则具体、有示例、有转译表

**问题**：
- 规则数量过多（53条），AI 可能无法全部遵守
- 部分规则重复（如规则12、35、36都在说"不乱编价格"）
- 建议精简为20-30条核心规则
