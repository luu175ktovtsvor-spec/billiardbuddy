## 8. 是否明确哪些资料要回传 ChatGPT 审

**是。** 在文档 3（录音转写整理与回传模板）中明确了三级分类：

### 必须回传审查

1. 每天的真实球房每日观察记录（含新行业事实/新岗位任务的部分）
2. 每天的录音转写整理文档（含新信息的转写）
3. 任何包含新行业事实 / 新岗位任务 / 新业务规则的整理文档
4. 真实用户使用岗位工作台后的问题记录
5. 出现高风险表达或明显不准的 AI 输出
6. 安全边界突破案例

### 可回传

1. 普通截图（生成结果、页面）
2. 普通生成结果样例（用户认为可用的）
3. 用户口头反馈摘要

### 只需存档

1. 原始长录音文件（脱敏后删除）
2. 已脱敏但暂时没有新信息的转写全文
3. 普通环境启动日志
4. 无异常的 tsc/lint/build 日志

此外，文档 3 还包含可直接复制的 ChatGPT 审查指令模板。
