# 10G-3：门店资料完整度评分与场景触发补充提示任务

## 任务定位

你现在只负责【10G-3：门店资料完整度评分与场景触发补充提示】。

本任务基于 10G-1 / 10G-1.1 / 10G-1.2 / 10G-2 已完成的门店运营画像能力，继续完善“门店画像可用性”。

目标不是新增大功能，而是让系统知道：

1. 门店资料填得是否完整
2. 哪些模块缺资料
3. 用户生成某类内容时，是否应该提示补充对应资料
4. 补充提示不能阻塞生成，只做辅助提醒
5. 为后续岗位工作台打基础

本任务允许小范围编码，但不做岗位工作台、不做新 AI 模块、不做 120 条大测试。

## 四、核心功能目标

### 目标 1：门店画像完整度评分

基于 `operation_profile` 计算：

```text
总体完整度：0-100
模块完整度：
- 基础信息
- 经营目标
- 客户结构
- 私域群矩阵
- 助教体系
- 赛事活动
- 会员/团购/价格规则
- 桌型设备
- 内容风格
- 禁用规则
```

MVP 可以先做 8 个模块，不必全部 10 个都精细。

### 目标 2：门店资料页展示完整度

在门店资料页 AI 运营画像区域顶部显示：

```text
AI 运营画像完整度：72%
已完成：基础信息、私域群、内容风格
建议补充：助教体系、桌型设备、赛事活动
```

不需要复杂动画，简单清楚即可。

### 目标 3：场景触发补充提示

当用户在 AI 工作台输入内容时，根据 `user_intent / role / customer_type / output_package` 判断是否缺少对应门店画像资料。

例如：

#### 助教场景

用户输入：

```text
今天助教到了，帮我发朋友圈
```

如果 `assistant_system.has_assistant` 未填写或为 false，但用户明显要生成助教内容：

提示：

```text
建议补充门店资料里的“助教体系”，这样助教到店、助教可约、助教服务内容会更准。
```

#### 会员群场景

用户输入：

```text
会员群发个空台提醒
```

如果 `private_domain_groups.member_group.enabled` 不为 true：

提示：

```text
建议在门店资料里勾选“会员群”，AI 会更准确地区分会员群通知和普通客户群通知。
```

#### 竞技群场景

用户输入：

```text
竞技群发个约局通知
```

如果 `competition_group.enabled` 不为 true：

提示：

```text
建议在门店资料里勾选“竞技群”，AI 会更准确处理约局、周赛、轻竞技等内容。
```

#### 桌型场景

用户输入：

```text
帮我写个乔氏台球桌约局朋友圈
```

如果 `equipment.table_types` 为空：

提示：

```text
建议补充门店资料里的“台球桌类型”，避免 AI 不确定门店是否有乔氏/独牙/斯诺克。
```

### 目标 4：提示不阻塞生成

资料缺失时：

- 继续正常生成
- 不要强制用户补资料
- 不要弹出阻断式弹窗
- 只在结果区域或生成前区域显示轻提示

- positioning

- current_goals

- main_customer_types

#### assistant_system 助教体系

参考字段：

- has_assistant
- assistant_types
- assistant_booking_rule

#### events 赛事活动

参考字段：

#### commerce_rules 会员 / 团购 / 价格规则

- has_groupbuy

#### equipment 桌型设备

- table_types

#### content_style 内容风格

- moments_tone

## 九、Prompt 注入边界

`profile_suggestions` 不一定要注入给模型。

更推荐：

```text
profile_context → 给 AI 看，用于生成
profile_suggestions → 给用户看，用于提醒补资料
```

不要让模型把“建议补充资料”写进朋友圈文案正文。

如果要传给 Prompt，只能作为缺失信息处理，不应混入输出内容。

MVP 推荐：

- profile_context 继续注入 Prompt
- profile_suggestions 返回给前端展示
- 不注入 Prompt
