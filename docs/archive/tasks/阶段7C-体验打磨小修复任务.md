## 五、具体任务

### 任务 1：清理图片 alt warning

在不改变功能的前提下，为现有 `<img>` 增加合适的 `alt` 属性。

要求：

1. Logo 图片：
   ```text
   alt="门店 Logo"
   ```

2. 二维码图片：
   ```text
   alt="门店二维码"
   ```

3. 海报图片：
   ```text
   alt="生成的海报"
   ```

4. 历史页海报图片：
   ```text
   alt="历史海报"
   ```

5. 如果是纯装饰图片，可以使用：
   ```text
   alt=""
   ```

注意：

- 不要为了清理 warning 改成 Next.js `Image` 组件。
- 当前阶段继续保留普通 `<img>`，因为很多图片来自后端 `/uploads` 动态路径。
- `no-img-element` warning 本阶段可以接受，不强行处理。
- 本阶段重点只清理缺少 `alt` 的 warning。

### 任务 3：历史页海报记录展示文案微调

当前历史页已经支持 `type="poster"`。

请检查并优化：

1. 列表标签：
   - `daily_invite` 显示为：日常约球海报
   - `activity_promo` 显示为：活动促销海报
   - `tournament_notice` 显示为：比赛/周赛海报

2. 列表摘要：
   - 不显示原始 URL
   - 显示：
     ```text
     海报图片，点击查看预览
     ```

3. 详情区：
   - 标题可以显示模板名称
   - 图片上方可以显示：
     ```text
     海报预览
     ```
   - 操作按钮：
     - 打开原图
     - 复制链接
     - 下载图片

4. `model_used = pillow` 时，前端可以显示：
   ```text
   本地合成
   ```
   而不是直接显示 `pillow`

要求：

- 不改变后端数据
- 只改前端展示
- 不影响文案/活动历史
