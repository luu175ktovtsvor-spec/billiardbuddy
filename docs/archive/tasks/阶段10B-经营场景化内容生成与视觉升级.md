## 一、阶段背景

当前 MVP 已经实现：

- 注册 / 登录
- 门店资料
- Logo / 二维码上传
- AI 朋友圈文案
- AI 群公告
- AI 活动方案
- 海报生成
- 5 个海报模板
- 生成历史
- Dashboard 今日工作台
- 首次填写引导

但当前问题是：

- 产品仍然像“AI 文案 / 海报生成器”
- 还不够像“台球房私域运营工作台”
- 文案口吻偏通用，和豆包/通用 AI 差异不够明显
- 海报视觉偏工程 Demo，不够像可发布运营素材
- Dashboard 还不够像“今日该做什么运营”的工作台

阶段 10A 已经确定长期方向：

```text
产品定位：
台球房私域运营与助教管理工作台

不是收银系统
不是通用 AI 工具
而是帮助台球房做日常运营、客户转化、助教推广、搭子局/竞技局、赛事、大客户维护、前厅 SOP 的 AI 工作台
```

本阶段 10B 的目标是：

```text
把当前产品从“按内容类型生成”
升级为“按经营场景生成一套可用运营内容”
```

## 二、本阶段核心目标

本阶段要做 3 件事：

### 目标 1：新增经营场景化内容生成能力

新增一组经营场景入口：

```text
1. 团购转私域
2. 助教推广
3. 搭子局 / 竞技局
4. 周赛 / 月赛
5. 老客维护
```

每个场景生成一套运营内容：

```text
朋友圈文案
微信群公告
私聊话术
海报文案
执行建议
```

注意：本阶段不做复杂 CRM、不做客户数据库、不做助教资料库。  
这些内容先基于门店资料 + 用户填写的补充说明生成。

---

### 目标 2：优化现有文案 Prompt 口吻

现有：

```text
朋友圈文案
群公告
活动方案
```

要从普通 AI 文案升级为更像台球房真实运营的口吻：

```text
更短
更自然
更像微信口吻
更像店长/老板/助教会发的话
更贴近团购转化、助教推广、搭子局、周赛、老客维护
少一点官方腔
少一点套话
少一点“欢迎广大顾客”
多一点真实门店运营感
```

---

### 目标 3：优化现有海报视觉

当前 5 个海报模板功能已通过，但视觉较弱。

本阶段要优化现有 5 个模板视觉：

```text
daily_invite：日常约球海报
activity_promo：活动促销海报
tournament_notice：比赛/周赛海报
recharge_promo：充值活动海报
afternoon_special：下午场畅打海报
```

优化方向：

```text
减少随机圆点/噪点
增强版式层次
正文区域加半透明卡片
二维码区域做成白色卡片
Logo 放大并优化边距
底部门店信息更清晰
背景更高级
整体更像能发朋友圈的商业海报
```

## 六、后端设计建议

### 1. 新增经营场景生成接口

建议新增接口：

```text
POST /api/v1/generate/operation
```

请求体示例：

```json
{
  "scenario": "groupbuy_to_private",
  "tone": "friendly",
  "extra_note": "最近团购来的新客比较多，希望引导他们加微信进群，下次直接到店。",
  "target": "new_customers"
}
```

返回：

```json
{
  "generation_id": "xxx",
  "scenario": "groupbuy_to_private",
  "content": "...完整运营内容..."
}
```

生成结果应写入 `generations` 表：

```text
type = "operation"
sub_type = scenario
content = 生成结果
model_used = deepseek-chat
tokens_used = 实际或 0
```

如果当前 `Generation.type` 已有约束，请先检查，不要破坏历史。  
如果数据库没有枚举约束，可以直接使用 `operation`。  
如果有约束，不要乱改数据库，先报告。

---

### 2. 经营场景枚举

建议场景 key：

```text
groupbuy_to_private：团购转私域
assistant_promo：助教推广
partner_match：搭子局 / 竞技局
tournament：周赛 / 月赛
old_customer_recall：老客维护
```

前端中文显示：

```text
团购转私域
助教推广
搭子局 / 竞技局
周赛 / 月赛
老客维护
```

---

### 3. 输出结构建议

每个场景生成的内容建议统一结构：

```text
【场景目标】
说明这个运营动作解决什么问题。

【朋友圈文案】
给 2-3 条，可直接复制。

【微信群公告】
给 1-2 条，适合会员群/搭子群。

【私聊话术】
给 3 条，适合店长/助教/前厅私聊客户。

【海报文案】
标题：
副标题：
正文：
补充说明：

【执行建议】
今天怎么发、谁来发、发到哪里、什么时候发。
```

注意口吻：

```text
不要太官方
不要太长
不要像大公司公告
要像真实台球房店长/老板会说的话
```

---

### 4. 各场景生成重点

#### groupbuy_to_private：团购转私域

目标：

```text
把团购来的新客沉淀到微信/社群，下次直接到店消费。
```

内容重点：

```text
加微信
进群
下次直接到店
轻福利
不强推
自然转化
```

避免：

```text
不要让客户感觉被强行推销
不要说团购客户低价值
```

---

#### assistant_promo：助教推广

目标：

```text
帮助门店推广助教/陪练服务，提高客单价和预约率。
```

内容重点：

```text
今晚助教在店
新手友好
陪练预约
练球不尴尬
适合一个人来的客户
```

注意：

```text
表达要专业，不要低俗
不要把助教写成擦边内容
可以写“助教风采”“陪练预约”“新手友好”“氛围陪练”
```

---

#### partner_match：搭子局 / 竞技局

目标：

```text
把单人练球客户撮合成搭子局/轻竞技局，提高开台率和复购。
```

内容重点：

```text
一个人来也能凑局
轻松局
台费局
新手友好
老手切磋
群里扣 1 报名
```

注意：

```text
不要写赌博
不要写大额追分
可以写输一局请一局台费、饮料局、小奖品挑战
```

---

#### tournament：周赛 / 月赛

目标：

```text
组织赛事，提高门店氛围、老客活跃和私域内容。
```

内容重点：

```text
周赛报名
月赛报名
赛制说明
名额有限
赛前提醒
赛后战报
```

---

#### old_customer_recall：老客维护

目标：

```text
唤醒老客户，提高复购、充值和活动参与。
```

内容重点：

```text
好久没来了
今晚有空台
老朋友福利
周赛邀请
助教预约
充值提醒
```

注意：

```text
不要太像骚扰
要自然、熟人感、轻提醒
```
