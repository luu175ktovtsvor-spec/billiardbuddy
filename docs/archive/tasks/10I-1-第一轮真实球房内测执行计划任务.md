# 10I-1：第一轮真实球房内测执行计划任务

## 任务定位

你现在只负责【10I-1：第一轮真实球房内测执行计划】。

本任务是在 10I-0 真实球房内测启动包与观察记录模板完成后，制定第一轮真实球房内测的具体执行计划。

本轮不写代码、不改数据库、不改 Prompt、不调用 DeepSeek。

核心目标：

> 把“什么时候去球房、去了以后先做什么、测哪些功能、记录哪些内容、回来给 ChatGPT 审哪些资料”全部规划清楚。

10I-1 完成后，就建议正式去球房做第一轮真实观察和内测。

## 五、建议内测策略

### 第一轮不要做一周

建议第一轮先做：

```text
1 天真实球房观察 + 内测
```

目标不是完整覆盖，而是验证方向：

1. 门店资料是否能真实填写
2. 岗位工作台是否一眼能懂
3. 哪些任务卡真实有用
4. 哪些任务卡看起来不符合球房工作
5. AI 输出能不能直接发
6. 用户是否愿意补充信息
7. 是否出现新的行业规则和真实场景
8. 是否出现合规 / 风险 / 低俗 / 误导表达

第一天回来后，由 ChatGPT 审查记录，再决定是否做 3 天连续观察或一周观察。

## 六、第一天内测建议流程

请设计一个可执行的一天流程，建议包含：

### 到店前准备

1. 确认前端 / 后端能启动
2. 确认 DeepSeek API 可用
3. 确认登录账号可用
4. 准备每日观察记录模板
5. 准备录音设备 / 转写工具
6. 准备截图保存目录
7. 准备内测任务清单

### 到店后第一阶段：门店资料填写

建议先填写：

1. 门店名称 / 定位
2. 客户结构
3. 私域群矩阵：
   - 客户群
   - 会员群
   - 竞技群
   - 搭子群
   - 助教客户群
   - 赛事群
   - 员工群
4. 助教体系
5. 桌型设备：
   - 普通台球桌
   - 独牙台球桌
   - 乔氏台球桌
   - 斯诺克
6. 赛事活动
7. 内容风格
8. 不想写的内容 / 禁用表达

### 到店后第二阶段：岗位工作台试用

第一轮建议优先测试 12 张卡：

#### 店长

1. 今日朋友圈
2. 老客户回访
3. 会员群空台提醒
4. 竞技群约局通知

#### 助教管理

5. 今日助教可约通知
6. 助教短视频配文

#### 前厅

7. 团购核销后加微信
8. 客户问助教怎么回

#### 老板

9. 今日经营简报

#### 运营

10. 本周内容规划

#### 教练 / 赛事

11. 周赛公告
12. 赛后战报

### 到店后第三阶段：真实工作观察

观察真实岗位工作：

1. 老板 / 店长一天最操心什么
2. 前厅被客户问得最多的问题
3. 助教管理今天具体做了什么
4. 运营今天有没有素材和发布压力
5. 竞技群 / 会员群有没有真实消息
6. 周赛 / 约局 / 助教业务有没有真实流程

### 到店后第四阶段：收集反馈

向门店人员确认：

1. 哪个功能一看就有用？
2. 哪个功能看不懂？
3. 哪个功能生成结果最像人话？
4. 哪个功能生成结果太假？
5. 你会不会真的发出去？
6. 你想增加什么功能？
7. 哪些词在你们行业里常用但系统没理解？
8. 哪些表达不应该写？
