## 二、用户提供的业务背景

请在设计中吸收以下业务逻辑。

### 1. 台球房基础盈利逻辑

台球房基础收入主要靠：

```text
台费
```

但团购客户利润低。团购能带来新客，但如果客户一直走团购，门店不赚钱。

所以真正的运营重点不是“团购卖得多”，而是：

```text
把团购 / 散客转化为更高客单和更高复购的客户
```

主要转化方向：

```text
团购客户 → 私域客户
团购客户 → 助教客户
团购客户 → 竞技 / 搭子客户
新客户 → 老客户
老客户 → 复购 / 充值 / 周赛 / 助教预约
```

---

### 2. 客户分类

请至少按以下客户类型设计：

```text
1. 散客 / 团购客户
2. 新客户
3. 老客户
4. 助教客户
5. 竞技客户 / 搭子客户
6. 轻度台费局 / 小局客户
7. 大客户 / 高频客户 / 充值客户
```

注意：

- 不要把“赌局”作为产品模块。
- 可以用更安全、专业的表达：

  - 搭子局
  - 台费局
  - 轻松局
  - 友谊赛
  - 小奖品挑战

---

### 3. 团购客户转化逻辑

团购客户是入口，但不是终点。

系统应该帮助门店做：

```text
团购客户到店接待
团购客户加微信
团购客户进群
团购客户二次到店
团购客户转助教陪练
团购客户转竞技 / 搭子局
团购客户转会员 / 充值
```

可产品化为：

```text
团购客户转化助手
```

输出内容包括：

```text
接待话术
加微信话术
进群话术
二次到店邀约
老客回访
会员转化话术
助教陪练推荐话术
竞技 / 搭子局引导话术
```

---

### 4. 助教经营逻辑

助教是提高客单价的重要手段。

助教价值包括：

```text
提升客单价
提供情绪价值
提升客户停留时长
增加客户复购
促进客户主动预约
丰富门店内容素材
```

台球助教不好招，是球房痛点。

系统应该考虑：

```text
助教招聘
助教资料管理
助教照片 / 视频素材
助教人设包装
助教朋友圈内容
助教群内推荐
助教预约海报
助教客户邀约
助教业绩提升
助教每日任务
店长管理助教
```

重要定位：

```text
不是做收银系统里的助教上钟/计费/提成
而是做助教日常运营、推广、内容、客户跟进、管理辅助
```

---

### 5. 助教招聘痛点

台球助教不好招，所以可以设计：

```text
助教招聘内容助手
```

输出：

```text
招聘朋友圈文案
招聘海报文案
小红书招聘笔记
抖音招聘口播脚本
面试邀约话术
入职欢迎文案
新助教 7 天成长任务
```

---

### 6. 助教管理痛点

目标：

```text
让新入职助教拿到软件后，每天知道该干什么，觉得上班更轻松。
```

可设计：

```text
助教工作台
```

每日任务示例：

```text
1. 发一条个人朋友圈
2. 发一条门店活动朋友圈
3. 给 3 个老客户发邀约
4. 在会员群里发一次今晚在店提醒
5. 上传 1 张今日工作照片
6. 完成一次客户跟进记录
```

店长端可查看：

```text
谁今天在店
谁今天还没发朋友圈
谁今天还没跟进客户
谁有可预约时段
谁需要主推
谁素材不够
谁近期活跃度低
```

---

### 7. 竞技 / 搭子客户逻辑

单人练球客户可以转化为竞技 / 搭子客户。

逻辑：

```text
单人练球 / 低价引流
→ 店长 / 教练撮合
→ 两个客户凑局
→ 正常开台
→ 提高台费收入
→ 形成复购和社交关系
```

可设计：

```text
单人练球转搭子助手
```

输出：

```text
单人练球招募文案
搭子群公告
竞技局规则说明
轻松局说明
新手友好局说明
老手切磋局说明
店长撮合话术
客户私聊邀约话术
```

### 10. 前厅服务 SOP

前厅和店长日常有很多琐碎工作：

```text
开店检查
闭店检查
卫生巡检
前台接待
团购核销
新客加微信
客户投诉处理
忙时排台
空台巡场
设备异常记录
```

可设计：

```text

```

目标不是替代收银系统，而是：

```text
帮管理层把标准动作和每日待办做清楚
```
