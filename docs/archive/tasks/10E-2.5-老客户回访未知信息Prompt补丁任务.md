# 10E-2.5 / 10D-4.6：老客户回访未知信息 Prompt 补丁任务

## 任务定位

你现在只负责【老客户回访未知信息 Prompt 补丁】。

本任务是 10E-2 人工验收后发现的内容质量补丁，不是新功能开发。

问题来源：

在 AI 工作台测试“好久没联系老客户了，帮我发几句话约他们来打球”时，生成内容出现了不应该自动编造的信息：

- 编造客户上次到店时间
- 编造客户上次打了几局 / 打了什么玩法
- 编造门店新到台球桌 / 新设备

这些属于“未知信息未占位 / 老客户回访乱编细节”。

本任务只修 Prompt / rules YAML，不改代码，不改数据库。

## 二、必须修复的问题

### 问题 1：老客户回访不能编造客户历史行为

当用户只是说：

- 好久没联系老客户了
- 帮我发几句话约他们来打球
- 老客户最近没来了
- 想把老客户喊回来
- 老朋友回来打两把

系统不能自动编造：

- 上次到店时间
- 上次打了几局
- 上次消费记录
- 上次打什么玩法
- 客户水平
- 客户偏好
- 客户关系细节
- 客户曾经说过的话
- 客户参加过什么活动
- 客户输赢情况
- 客户办卡 / 充值情况

错误示例：

> 你上次来还是上个月打的几局中式八球。

正确表达：

> 好久没见你来打球了，最近有空回来打两把。

---

### 问题 2：老客户回访不能编造门店新变化

系统不能自动编造：

- 新到台球桌
- 换了球桌
- 新装修
- 新设备
- 新灯光
- 新球杆
- 新茶水
- 新活动
- 新教练
- 新助教
- 新店升级
- 环境大升级

除非用户明确提供。

错误示例：

> 店里新到了几张乔氏台球桌。

正确表达：

> 店里最近氛围还不错，有空回来找找手感。

如果确实需要提门店变化，必须占位：

> 如果门店近期有换台泥 / 灯光升级 / 设备维护，可以在这里补充一句真实变化。

---

### 问题 3：允许的老客户回访表达

老客户回访应该更像熟人自然招呼，不像销售。

推荐表达：

- 好久没见你来打球了
- 最近忙啥呢
- 有空回来打两把
- 回来找找手感
- 一个人来也没事，我帮你看看有没有合适的搭子
- 来之前跟我说一声，我帮你看一下有没有空台
- 最近店里氛围还不错，老朋友回来刚好热闹
- 不用特意安排，有空顺路来坐坐也行

默认禁止：

- 充值
- 优惠
- 折扣
- 会员价
- 新设备
- 新台球桌
- 具体客户历史记录
- 过度亲密
- 装作很熟但没有依据的细节

## 四、建议新增 / 强化规则

### 1. 老客户历史信息禁止编造

用户没有提供客户历史行为时，不得写：

- 上次什么时候来
- 上次打了几局
- 上次打得怎么样
- 上次消费了什么
- 上次参加了什么活动
- 上次和谁一起打
- 上次说过什么话

必须改为泛化表达：

- 好久没见
- 最近有空
- 回来打两把
- 找找手感

---

### 2. 门店变化禁止编造

用户没有提供门店变化时，不得写：

- 新到台球桌
- 换新台
- 装修升级
- 灯光升级
- 新设备
- 新球杆
- 新助教到店

如果用户想突出门店变化，使用占位：

- 【如门店近期有真实升级，可补充】
- 【如近期换台泥 / 灯光维护，可补充】

---

### 3. 老客户回访默认策略

老客户回访默认优先：

- 熟人招呼
- 找手感
- 约球搭子
- 空台提醒
- 来之前说一声
- 不带优惠
- 不带硬销售
- 不编细节
