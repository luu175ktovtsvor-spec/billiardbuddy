## 四、修复目标

### 目标 1：强化桌型枚举边界

必须明确：

- 标准桌型只允许：
  - 普通台球桌
  - 独牙台球桌
  - 乔氏台球桌
  - 斯诺克
- 不得把“美式台 / 中式八球台 / 英式台 / 比赛台 / 娱乐台”等写成标准桌型分类
- 如果用户说“美式台”或其他非标准表达，默认转译为“普通台球桌”或使用“店里台子”这类通用表达
- 门店画像未提供的桌型不得编造
- 桌型未知时使用通用表达，不强行展开设备优势

### 目标 2：强化新设备 / 门店变化边界

必须明确：

- 用户未提供“新设备 / 新换台 / 设备升级 / 换台泥 / 新到球桌”等信息时，不得写：
  - 新到台球桌
  - 刚换新台
  - 新换设备
  - 设备升级
  - 新换台泥
  - 新桌到店
  - 打感升级
- 如需要表达门店日常状态，可写：
  - 台子状态不错
  - 今天适合来打两把
  - 想打球可以提前说
  - 有空台我帮你看
- 不要用“刚换 / 新到 / 升级”制造吸引力，除非用户明确提供。
