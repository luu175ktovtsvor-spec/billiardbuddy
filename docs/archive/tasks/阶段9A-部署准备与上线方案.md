## 四、部署架构建议

请至少给出 2 套方案：

### 方案 A：低成本单服务器试用版

适合：

- 1-2 家熟悉门店试用
- 成本低
- 快速上线
- 用户量小

建议结构：

```text
一台云服务器
├── Nginx
├── Next.js 前端
├── FastAPI 后端
├── PostgreSQL
└── 本地 uploads 持久化目录
```

优点：

- 成本低
- 部署简单
- 适合早期验证

缺点：

- 扩展性一般
- 图片存在服务器本地
- 需要自己做备份
- 服务器故障会影响全部服务

---

### 方案 B：更接近生产的云服务版

适合：

- 多家门店试用
- 后续商业化
- 更稳定

建议结构：

```text
前端：Vercel / Cloudflare Pages / 其他前端托管
后端：云服务器 / Render / Railway / Fly.io / 国内云服务器
数据库：云 PostgreSQL
文件：OSS / S3 / R2
域名：前端主域名 + API 子域名
```

优点：

- 更稳定
- 图片文件更安全
- 扩展性更好
- 前后端分离清楚

缺点：

- 配置复杂
- 成本更高
- 需要处理跨域和环境变量

