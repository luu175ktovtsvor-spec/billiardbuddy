## 一、必须吸收的行业规则

台球行业当前设备分类先按以下 4 类处理：

1. 普通台球桌
2. 独牙台球桌
3. 乔氏台球桌
4. 斯诺克

重要规则：

> 除独牙、乔氏以外的中式八球台球桌，都归为普通台球桌。

不要新增其他桌型分类。  
不要把“中式八球台”“美式台”“英式台”“比赛台”“娱乐台”等作为标准枚举。  
如果需要补充说明，可以放在备注字段里，但标准分类只保留以上 4 类。

## 五、operation_profile 推荐结构

请在 `operation_profile` 中新增或规范设备字段。

建议结构：

```json
{
  "equipment": {
    "table_count": null,
    "table_types": [],
    "table_type_note": ""
  }
}
```

### table_types 枚举

只允许：

```text
normal_pool_table
duya_pool_table
joy_billiards_table
snooker_table
```

中文展示：

```text
normal_pool_table = 普通台球桌
duya_pool_table = 独牙台球桌
joy_billiards_table = 乔氏台球桌
snooker_table = 斯诺克
```

说明：

- `table_types` 多选
- `table_count` 可选数字
- `table_type_note` 作为补充说明，不参与标准枚举
- 不需要新增数据库字段，继续使用 `operation_profile` JSONB
