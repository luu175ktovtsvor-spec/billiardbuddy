## 七、接口调用要求

所有请求必须统一走：

`web/src/lib/api.ts`

不要在页面里散落 `fetch`。

### 朋友圈文案

调用：

`POST /api/v1/generate/copywriting`

入参：

```ts
{
  sub_type: "moments",
  tone: string,
  scenario: string,
  extra_note?: string
}
```

### 群公告

调用：

`POST /api/v1/generate/copywriting`

入参：

```ts
{
  sub_type: "group_notice",
  tone: string,
  scenario: string,
  extra_note?: string
}
```

### 活动方案

调用：

`POST /api/v1/generate/activity`

入参：

```ts
{
  activity_goal: string,
  target_customer?: string,
  budget_level?: string,
  duration?: string,
  extra_note?: string
}
```

注意：

- 活动字段统一使用 `target_customer`
- 不要使用 `target_audience`
- 不要传 `store_id`
- 前端只调用后端 generate 接口
- 前端不得直接调用 DeepSeek
