## 五、服务启动检查

请先确认以下服务状态。

### 1. Docker PostgreSQL

确认 Docker PostgreSQL 正在运行。

可执行：

```bash
docker ps
```

如果 PostgreSQL 未运行，可在项目根目录执行：

```bash
docker compose up -d postgres
```

### 2. 后端 FastAPI

确认后端运行在：

```text
http://localhost:8000
```

可以访问：

```text
http://localhost:8000/api/v1/health
```

如果后端未运行，请在项目根目录或后端目录启动：

```bash
cd server
uv run fastapi dev main.py
```

### 3. 前端 Next.js

确认前端运行在：

```text
http://localhost:3000
```

或：

```text
http://localhost:3001
```

如果前端未运行，请启动：

```bash
cd web
pnpm dev
```

### 4. 前端环境变量

确认：

```text
web/.env.local
```

中存在：

```env
NEXT_PUBLIC_API_URL=http://localhost:8000
```

注意：

- `web/.env.local` 只能放 `NEXT_PUBLIC_API_URL`
- 不允许出现 `DEEPSEEK_API_KEY`
- 不允许出现任何 AI 服务 Key

## 六、真实联调测试流程

请按顺序测试。

### 1. 登录测试

使用已有账号登录前端。

要求：

- 登录成功
- token 正常保存
- 能进入 dashboard

### 2. 门店资料检查

确认当前账号已有门店资料。

如果没有门店资料：

- 页面应提示“请先完善门店资料，AI 才能根据你的门店生成内容。”
- 提供跳转到 `/dashboard/store-settings` 的按钮
- 不允许调用生成接口

如果已有门店资料：

- 可以进入 `/dashboard/generate`
- 可以点击生成按钮

### 3. 页面访问测试

访问：

```text
/dashboard/generate
```

要求：

- 页面正常显示
- 三个 Tab 正常显示：
  - 朋友圈文案
  - 群公告
  - 活动方案
- Tab 切换正常
- 页面没有白屏
- 控制台没有明显报错

### 4. 朋友圈文案生成测试

在“朋友圈文案”Tab 中填写或使用默认值：

```json
{
  "sub_type": "moments",
  "tone": "friendly",
  "scenario": "daily",
  "extra_note": "今天下午空台比较多，想拉一波附近客户"
}
```

点击生成。

要求：

- 请求走 `api.generateCopywriting()`
- 实际调用 `POST /api/v1/generate/copywriting`
- loading 时按钮禁用
- 返回后显示 `content`
- 显示 `generation_id`
- 显示 `created_at`
- 内容不是空
- 内容不是 Mock 文案
- 一键复制可用

### 5. 群公告生成测试

切换到“群公告”Tab。

使用当前统一后端 enum 值，不要使用后端不支持的枚举。

示例：

```json
{
  "sub_type": "group_notice",
  "tone": "friendly",
  "scenario": "daily",
  "extra_note": "今晚 8 点想组织一波约球接龙"
}
```

点击生成。

要求：

- 请求走 `api.generateCopywriting()`
- 实际调用 `POST /api/v1/generate/copywriting`
- 返回后显示 `content`
- 显示 `generation_id`
- 显示 `created_at`
- 内容不是空
- 内容不是 Mock 文案
- 一键复制可用

### 6. 活动方案生成测试

切换到“活动方案”Tab。

示例：

```json
{
  "activity_goal": "traffic",
  "target_customer": "附近上班族",
  "budget_level": "medium",
  "duration": "3天",
  "extra_note": "希望提升下午场客流，不想做太大优惠"
}
```

点击生成。

要求：

- 请求走 `api.generateActivity()`
- 实际调用 `POST /api/v1/generate/activity`
- 返回后显示 `content`
- 显示 `generation_id`
- 显示 `created_at`
- 内容不是空
- 内容不是 Mock 文案
- 一键复制可用
