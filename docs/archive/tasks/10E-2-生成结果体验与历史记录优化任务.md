# 10E-2：生成结果体验与历史记录 Workbench 展示优化任务

## 任务定位

你现在只负责【10E-2：生成结果体验与历史记录 Workbench 展示优化】。

本任务基于 10E-1 / 10E-1.5 已完成的 AI 工作台前端产品化改造继续推进。

10E-1 已完成：

- 「我想做什么」Tab 改名为「AI 工作台」
- 新增 `web/src/lib/workbench-config.ts`
- 24 条示例按岗位分组
- 30 张快捷场景卡片
- output_package 三组展示
- 推荐输出组合按钮
- 默认输出类型优化
- AI 工作台布局微调

10E-2 的目标是：

把 AI 工作台生成后的结果和历史记录做得更容易看懂、复制、复用。

一句话：

> 用户生成完内容后，要能更快复制、看懂这次生成了什么、在历史记录里找回来。

## 四、本轮 P0 必做内容

### P0-1：生成结果区增加输出类型标签

在 AI 工作台生成结果展示区域，展示本次用户选择的输出类型标签。

例如用户选择：

- 朋友圈
- 私聊话术
- 执行建议

结果区顶部展示：

`朋友圈` `私聊话术` `执行建议`

要求：

1. 标签使用 `workbench-config.ts` 中的中文标签
2. 只在 workbench 结果中展示，不影响旧 4 个 Tab
3. 标签不要太花哨，保持现有风格
4. 如果没有 output_package，则不展示或展示“AI 工作台”

---

### P0-2：生成结果区显示用户输入摘要

在 workbench 结果区顶部展示一行本次输入摘要。

建议格式：

```text
本次需求：好久没联系老客户了，帮我发几句话约他们来打球
```

如果太长，最多显示 60 字，超出用省略号。

要求：

1. 只在 workbench 结果中展示
2. 不影响旧 4 个 Tab
3. 不要占太多空间
4. 摘要来自本次表单输入或 result input_params

---

### P0-3：生成结果增加“复制全文”按钮优化

如果当前已有复制按钮，请确认它对 workbench 仍然可用。

如果没有，请新增或优化：

- 复制全文
- 复制成功提示

要求：

1. 不要引入新的 UI 库
2. 使用浏览器 `navigator.clipboard.writeText`
3. 复制失败时有基本 fallback 或提示
4. 不影响旧 4 个 Tab

---

### P0-4：生成结果分段复制

给 workbench 生成结果增加“按段复制”的能力。

思路：

根据文本中的标题分段，例如：

- `【朋友圈文案】`
- `【私聊话术】`
- `【群公告】`
- `【执行建议】`
- `【活动方案】`
- `【SOP / 检查表】`
- `【PK方案】`

把生成内容切分为多个段落，每段旁边提供“复制本段”。

要求：

1. 只对 workbench 类型启用
2. 如果无法可靠分段，则保留全文复制，不要报错
3. 分段规则要简单、可维护
4. 不要破坏原始内容展示
5. 不要影响旧 4 个 Tab

建议新增工具函数：

```ts
parseWorkbenchSections(content: string): Array<{
  title: string;
  content: string;
}>
```

可以放在 `generate/page.tsx` 内部，也可以新建轻量工具文件，视现有结构而定。

### P0-5：历史记录 workbench 显示用户输入摘要

在历史记录页面中，workbench 类型记录应更容易识别。

列表中建议显示：

- 类型：AI 工作台
- 用户输入摘要：例如“好久没联系老客户了，帮我发几句话约他们来打球”
- 岗位：店长
- 目标客户：老客户
- 输出类型标签：朋友圈 / 私聊话术 / 执行建议

要求：

1. 读取 `input_params` 中已有字段，不改数据库
2. 如果字段不存在，安全降级，不报错
3. 不影响旧类型历史记录
4. 支持 workbench 筛选保持正常

### P0-7：校准示例 / 快捷卡片 outputPackage 配置

根据人工截图发现：

“今天下雨人少，发朋友圈拉人”已经正确勾选了：

- 朋友圈
- 执行建议

请继续静态检查 `workbench-config.ts` 中 24 条示例和 30 张快捷场景卡片：

如发现不一致，请修正 `web/src/lib/workbench-config.ts`。

## 七、实现建议

### 1. 中文标签统一从配置读取

不要在多个页面重复硬编码标签。

尽量复用：

- `OUTPUT_PACKAGE_LABELS`
- `ROLE_OPTIONS`
- `CUSTOMER_TYPE_OPTIONS`

如当前配置不方便查找，可增加 helper：

```ts
getRoleLabel(role: WorkbenchRole): string
getCustomerTypeLabel(type: TargetCustomerType): string
getOutputPackageLabel(item: OutputPackageItem): string
```

---

### 2. 文本摘要函数

建议实现：

```ts
function truncateText(text: string, max = 60): string
```

用于：

- 生成结果区摘要
- 历史记录摘要

---

### 3. workbench 分段函数

建议识别以下标题格式：

```text
【xxx】
### xxx
## xxx
```

但不要过度复杂。

如果解析不到 2 段以上，就不展示分段复制，只展示全文复制。

---

### 4. 历史记录安全降级

历史记录里可能有旧数据。

如果 `input_params` 缺少字段：

- user_intent 不存在：展示“AI 工作台生成”
- role 不存在：不展示岗位标签
- target_customer_type 不存在：不展示客户标签
- output_package 不存在：不展示输出标签

不要因为旧数据字段缺失导致页面报错。
