## 一、已可用后端接口

阶段 6A 已经提供以下接口：

### 海报生成

`POST /api/v1/posters/generate`

入参示例：

```json
{
  "template": "daily_invite",
  "title": "今晚约一局？",
  "subtitle": "约上搭子，来店里打几杆",
  "content": "适合朋友局、下班放松、新手练球。",
  "extra_note": "可选补充说明"
}
```

`template` 可选：

- `daily_invite`：日常约球海报
- `activity_promo`：活动促销海报
- `tournament_notice`：比赛/周赛海报

响应示例：

```json
{
  "poster_url": "/uploads/posters/poster_xxx.png",
  "template": "daily_invite",
  "created_at": "2026-05-10T21:27:09Z"
}
```

注意：

- 接口需要登录 token
- 用户必须已经创建门店
- 后端自动使用当前门店资料
- 前端不要传 `store_id`
- 前端不要传 Logo / 二维码路径
- 后端会自动从门店资料中读取 Logo / 二维码

## 七、模板选择设计

模板选项：

### 1. 日常约球海报

```text
template = daily_invite
```

展示文案：

- 标题：日常约球海报
- 描述：适合日常营业、下班约球、朋友局、新手练球
- 推荐默认内容：
  - title：今晚约一局？
  - subtitle：约上搭子，来店里打几杆
  - content：适合朋友局、下班放松、新手练球。

### 2. 活动促销海报

```text
template = activity_promo
```

展示文案：

- 标题：活动促销海报
- 描述：适合会员活动、节日促销、下午场引流
- 推荐默认内容：
  - title：本周活动来了
  - subtitle：约球更划算，来店咨询详情
  - content：适合会员回馈、下午场促活、老客回归。

### 3. 比赛/周赛海报

```text
template = tournament_notice
```

展示文案：

- 标题：比赛/周赛海报
- 描述：适合周赛报名、比赛通知、高手约战
- 推荐默认内容：
  - title：本周台球赛开打
  - subtitle：欢迎报名，一起切磋
  - content：适合周赛、月赛、门店交流赛宣传。

选择模板时：

- 可以自动填充推荐默认内容
- 如果用户已经手动输入过内容，切换模板时不要强制覆盖，除非用户点击“使用模板示例文案”
- 第一版可以简单实现：切换模板只更新模板，不强制覆盖表单

## 八、表单设计

字段：

### 1. 标题 `title`

- input
- 必填
- 1-30 字
- 示例：今晚约一局？

### 2. 副标题 `subtitle`

- input
- 可选
- 0-50 字
- 示例：约上搭子，来店里打几杆

### 3. 正文内容 `content`

- textarea
- 必填
- 1-200 字
- 示例：适合朋友局、下班放松、新手练球。

### 4. 补充说明 `extra_note`

- textarea
- 可选
- 0-200 字
- 示例：可以写活动时间、适合人群、发布场景等

前端需要做基础校验：

- title 不能为空
- content 不能为空
- title 超过 30 字要提示
- subtitle 超过 50 字要提示
- content 超过 200 字要提示
- extra_note 超过 200 字要提示

不要引入新的表单库，用 `useState` 即可。

## 十、API Client 要求

所有请求必须统一走：

```text
web/src/lib/api.ts
```

不要在页面中散落 `fetch`。

请新增类型，可以放在：

```text
web/src/types/poster.ts
```

建议类型：

```ts
export type PosterTemplate = "daily_invite" | "activity_promo" | "tournament_notice"

export interface PosterGenerateRequest {
  template: PosterTemplate
  title: string
  subtitle?: string
  content: string
  extra_note?: string
}

export interface PosterGenerateResponse {
  poster_url: string
  template: PosterTemplate
  created_at: string
}
```

API client 新增：

```ts
generatePoster(data: PosterGenerateRequest): Promise<PosterGenerateResponse>
```

注意：

- 不要传 `store_id`
- 不要传 Logo / 二维码路径
- 不要在前端直接使用 Pillow
- 不要在前端接 AI 图片模型
- 前端只调用后端 `/api/v1/posters/generate`

## 十四、错误提示要求

错误提示要用户能看懂：

不要把后端长错误堆栈直接展示给用户。
