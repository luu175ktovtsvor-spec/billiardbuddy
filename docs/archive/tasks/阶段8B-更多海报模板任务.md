## 一、本阶段新增模板

### 1. 充值活动海报

模板 key：

```text
recharge_promo
```

中文名称：

```text
充值活动海报
```

适用场景：

- 会员充值活动
- 储值优惠
- 老客回流
- 节假日促销
- 新店开业充值福利

推荐默认文案：

```text
title: 会员充值福利
subtitle: 充得多，打得更划算
content: 适合老客回流、会员储值、活动促销宣传。
```

视觉方向：

- 主色调：深紫 / 金色 / 暖黄色
- 风格：高级会员感、储值福利感
- 标题色：金色或白色
- 适合突出“会员”“充值”“福利”“限时”

---

### 2. 下午场畅打海报

模板 key：

```text
afternoon_special
```

中文名称：

```text
下午场畅打海报
```

适用场景：

- 下午场引流
- 工作日低峰时段
- 学生 / 附近居民
- 闲时促活
- 门店空台转化

推荐默认文案：

```text
title: 下午场畅打
subtitle: 趁空台，来打几杆
content: 适合工作日下午、附近居民、学生党和新手练球。
```

视觉方向：

- 主色调：浅蓝 / 青绿 / 明亮渐变
- 风格：轻松、清爽、低峰引流
- 标题色：白色或浅黄色
- 适合突出“下午场”“空台”“放松”“练球”

### 4. 海报生成接口兼容

`POST /api/v1/posters/generate` 应支持新增两个 template。

生成后仍然：

- 保存到 `server/uploads/posters/`
- 返回 `generation_id`
- 返回 `poster_url`
- 返回 `template`
- 返回 `created_at`
- 写入 `generations` 表

新增模板写入 generations 时：

```text
type = "poster"
sub_type = "recharge_promo" 或 "afternoon_special"
result = poster_url
model_used = "pillow"
tokens_used = 0
```
