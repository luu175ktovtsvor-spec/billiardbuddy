## 四、本阶段允许实现

请实现以下后端接口：

### 1. 生成历史列表

`GET /api/v1/generations`

功能：

查询当前用户所属门店的生成历史。

必须依赖：

- `get_current_user`
- `get_current_store`

要求：

- 只能查询当前用户所属门店的记录
- 不允许通过前端传入 `store_id`
- 默认按 `created_at DESC` 排序
- 支持分页
- 支持按类型筛选
- 支持按子类型筛选

建议查询参数：

```text
page: int = 1
page_size: int = 20
type: copywriting | activity | 可选
sub_type: moments | group_notice | planning | 可选
```

响应建议：

```json
{
  "items": [
    {
      "id": "uuid",
      "type": "copywriting",
      "sub_type": "moments",
      "input_params": {},
      "content": "生成内容",
      "model_used": "deepseek-chat",
      "tokens_used": 718,
      "created_at": "2026-05-10T19:37:25.452343Z"
    }
  ],
  "total": 100,
  "page": 1,
  "page_size": 20
}
```

注意：

- 数据库字段里叫 `result`
- API 响应给前端时统一叫 `content`
- 不要把 `prompt_used` 默认返回给前端列表接口
- 不要返回其他门店数据

---

### 2. 生成历史详情

`GET /api/v1/generations/{generation_id}`

功能：

查看某一条生成记录详情。

必须依赖：

- `get_current_user`
- `get_current_store`

要求：

- 只能查看当前门店下的生成记录
- 如果记录不存在，返回 404
- 如果记录不属于当前门店，也返回 404 或 403，建议返回 404，避免暴露数据存在性

响应建议：

```json
{
  "id": "uuid",
  "type": "copywriting",
  "sub_type": "moments",
  "input_params": {},
  "content": "生成内容",
  "model_used": "deepseek-chat",
  "tokens_used": 718,
  "created_at": "2026-05-10T19:37:25.452343Z"
}
```

注意：

- 默认不要返回 `prompt_used`
- 除非明确用于调试，否则前端不需要看到完整 Prompt

## 六、Schema 设计要求

可以新增：

`server/schemas/generation.py`

建议包含：

```python
class GenerationListItem(BaseModel):
    id: UUID
    type: str
    sub_type: str | None
    input_params: dict | None
    content: str
    model_used: str | None
    tokens_used: int | None
    created_at: datetime

class GenerationDetailResponse(BaseModel):
    id: UUID
    type: str
    sub_type: str | None
    input_params: dict | None
    content: str
    model_used: str | None
    tokens_used: int | None
    created_at: datetime

class GenerationListResponse(BaseModel):
    items: list[GenerationListItem]
    total: int
    page: int
    page_size: int
```

注意：

- 数据库字段 `result` 映射为响应字段 `content`
- 不要把 `prompt_used` 暴露给普通历史接口
- 不要返回 `store_id`
- 不要返回其他门店信息

这是本阶段最重要的要求。
