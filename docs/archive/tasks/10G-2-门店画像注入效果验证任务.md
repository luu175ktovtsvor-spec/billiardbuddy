## 任务定位

你现在只负责【10G-2：门店画像注入效果验证与小样本测试】。

本任务重点是测试和评估，不做新功能开发。

## 四、测试目标

验证以下问题：

1. 门店画像是否被正确注入 Workbench
2. 会员群是否影响会员群内容
3. 竞技群是否影响约局 / 周赛 / 轻竞技内容
4. 助教体系是否影响助教内容
5. 桌型分类是否影响赛事 / 竞技 / 客户邀约内容
6. 禁用优惠是否生效
7. 禁止电话 / 地址是否生效
8. few-shot 与 profile_context 是否能同时稳定工作
9. 未填写画像时是否安全降级
10. 旧 4 个 Tab 是否不受影响

---

## 五、测试规模

执行 **30 条真实 Workbench 调用**。

分 6 组，每组 5 条：

1. A 组：无画像降级测试
2. B 组：会员群测试
3. C 组：竞技群测试
4. D 组：助教体系测试
5. E 组：桌型分类测试
6. F 组：混合画像真实大白话测试

如果前 5 条中出现系统性错误，例如：

- Prompt 渲染失败
- profile_context 导致主流程报错
- API 全部失败
- Store 画像读取失败

则停止测试并报告。

## 七、测试用例

### A 组：无画像降级测试 5 条

画像为空。

1. 好久没联系老客户了，帮我发几句话约他们来打球
2. 今天想发点朋友圈，不知道发啥
3. 团购客第一次来，问有没有助教可以约
4. 想搞个周赛，帮我写个通知
5. 助教拍了条短视频，帮我配文案

预期：

- Workbench 正常生成
- 不报错
- 不编门店画像
- 不编会员群 / 竞技群 / 桌型

---

### B 组：会员群测试 5 条

使用完整 MVP 画像。

1. 会员群里发个空台提醒
2. 会员群通知一下这周可以回来打球
3. 会员群发个周赛提醒
4. 会员群里喊老客户回来打两把
5. 会员群发个助教今天可约的通知

预期：

- 能识别会员群语境
- 语气自然
- 不乱编会员专属优惠
- 不乱编充值规则
- 不乱写会员权益或会员专属价格

---

### C 组：竞技群测试 5 条

使用完整 MVP 画像。

1. 竞技群发个今晚约局通知
2. 竞技群发周赛报名提醒
3. 竞技群里发个轻竞技活动通知
4. 竞技群赛后战报写一下
5. 竞技群里缺一位，怎么说自然点

预期：

- 能识别竞技群语境
- 可写约局 / 周赛 / 轻竞技 / 赛后战报
- 不写赌博
- 不写追分
- 不写大额输赢
- 不写搞钱局

---

### D 组：助教体系测试 5 条

使用完整 MVP 画像。

1. 今天新助教到了，帮我发朋友圈
2. 助教客户群发个今日助教可约通知
3. 有客户说想点助教，我怎么回
4. 客户说想找人陪玩，帮我回得专业一点
5. 技术型助教今天在，想发给想练球的人

预期：

- 服务体验型和技术陪练型不混淆
- “点助教 / 陪玩”能专业转译
- 不写免费助教
- 不写送助教课
- 不低俗擦边

---

### E 组：桌型分类测试 5 条

使用完整 MVP 画像。

1. 店里有乔氏台球桌，发给竞技客户的朋友圈
2. 今天想发个斯诺克邀约内容
3. 普通台球桌为主，写个适合老客户回来的朋友圈
4. 竞技群里发个乔氏约局通知
5. 帮我写个门店特色介绍，提一下桌型

预期：

- 可合理引用已填写桌型
- 不写“新到台球桌”
- 不写“设备升级”
- 不把普通台球桌乱写成乔氏 / 独牙 / 斯诺克
- 不扩展新桌型枚举

---

### F 组：混合画像真实大白话 5 条

使用完整 MVP 画像。

1. 今天店里人气一般，帮我弄点能发的
2. 群里有点冷，发什么比较好
3. 想让会员、竞技客户都活跃一点
4. 助教和周赛这块想一起推一下
5. 最近想让老客户回来，也想带一点竞技氛围

预期：

- 能结合画像，但不乱编具体数据
- 输出不过长
- 不乱写优惠
- 不乱写价格
- 能体现会员群 / 竞技群 / 助教 / 桌型等画像优势
- 不把所有画像信息硬塞进输出
