- 助教业务不能只理解为“专业教学陪练”

现在需要把这些规则同步到实际生成时使用的 YAML 中，否则产品大脑更新不会真正影响 Workbench 输出。

## 四、本次必须同步的核心规则

### 1. 助教服务双层分类

必须同步到 YAML：

#### A. 技术陪练型 / 高级助教

适用表达：

- 帮客户练球
- 陪客户找手感
- 纠正常见动作问题
- 做基础练球建议
- 更偏技术陪练 / 指导型陪练

但注意：

- 不承诺包教会
- 不承诺保证进步
- 不承诺一定赢球

#### B. 服务体验型 / 普通助教

适用表达：

- 助教服务体验
- 沟通自然
- 服务意识好
- 氛围轻松
- 陪打体验好
- 一个人来也不尴尬
- 想轻松打两把
- 想约助教提前说
- 到店可约
- 助教预约转化

底层理解可以包含：

- 形象吸引力
- 情绪价值
- 会聊天
- 摆球 / 记分 / 陪打
- 服务体验

但对外输出不要低俗化。

---

### 2. 行业口语识别 → 专业表达转译

必须同步：

用户输入中出现以下词，系统要能理解，不要简单拒绝：

- 美女助教
- 好看的助教
- 漂亮助教
- 点助教
- 新助教
- 助教照片
- 助教短视频
- 陪玩
- 大哥客户
- 情绪价值

这些词应理解为：

- 助教服务推广
- 助教预约转化
- 助教客户维护
- 助教到店通知
- 助教朋友圈内容
- 助教短视频配文
- 助教个人号运营
- 门店私域邀约

但输出时必须专业转译。

---

### 3. 输出层禁止直接低俗 / 擦边表达

默认输出不应直接写：

- 快来点她
- 陪玩
- 身材好
- 擦边引流
- 低俗暗示
- 颜值爆表
- 新来的妹妹
- 超好看
- 美女助教快来
- 大哥都喜欢
- 免费陪练
- 免费助教
- 送助教课
- 助教体验券

推荐转译为：

- 今日助教可约
- 新助教到店
- 助教服务体验
- 沟通自然
- 服务意识好
- 氛围轻松
- 适合一个人来打球
- 想约助教提前说
- 我帮你看时间
- 轻松打两把
- 陪打体验好
- 到店可约
- 助教服务按门店实际规则执行

---

### 4. “美女助教”不是绝对禁词，但不是默认外显词

规则必须明确：

- “美女助教”允许作为用户输入识别词
- 系统应理解为助教服务推广 / 助教预约转化
- 不建议作为前端默认卡片标题
- 不建议作为系统默认输出词
- 默认转译为专业助教服务表达

示例：

用户输入：

> 今天美女助教到了，帮我发朋友圈

系统理解：

> 用户想做助教到店通知 / 助教服务推广 / 助教客户预约转化

推荐输出：

> 今日助教到店，想约助教服务的朋友可以提前说。一个人来打球也不尴尬，我帮你看时间。

错误输出：

> 美女助教来了，快来点她。

---

### 5. “陪玩”边界必须特别写清楚

10F-0 审查发现，“陪玩”在行业术语文档中容易同时落入“可识别词”和“高风险词”。

请在 YAML 中明确：

- 用户输入里出现“陪玩”，可以被系统理解为“陪打体验 / 助教服务体验 / 轻松打两把”
- 系统输出时不要直接写“陪玩”
- 输出应转译为“陪打体验”“助教服务”“轻松打两把”“有人陪你打一会儿”

---

### 6. 新助教条件允许边界

必须保留并同步：

- 用户未提到新助教时，不得凭空编造“新助教到店”
- 用户明确说“新助教到店 / 新助教可约 / 今天来了个新助教”时，可以围绕新助教写
- 表达必须专业、合规、不低俗、不免费、不编造姓名价格照片档期

---

### 7. 老客户回访边界

继续强化：

用户只说：

- 好久没联系老客户了
- 老客户最近没来了
- 想喊老客户回来打球

系统不得自动补：

- 客户上次到店时间
- 客户上次打了几局
- 客户打什么玩法
- 客户消费记录
- 会员充值
- 充多少送多少
- 新助教
- 新球桌
- 新设备
- 门店新装修

除非用户明确给出。

正确默认方向：

- 好久没见你来打球了
- 有空回来打两把
- 来之前跟我说一声，我帮你看看有没有空台
- 一个人来也没事，我帮你看看有没有合适搭子
- 不像销售，不强推，不带优惠

---

### 8. 前厅 / 团购 / 新客转化边界

同步规则：

- 前厅遇到客户问助教，可以自然回应并转给助教管理 / 店长
- 团购客 / 新客如果表现出助教需求，可以引导“想约助教可以提前说”
- 不强推
- 不乱报价
- 不写免费助教
- 不写送助教课
- 不低俗引导
- 不把助教写成“美女噱头”

如果现有文件用 sections，就继续用 sections。

### 4. 不改变代码枚举
