## 三、问题复盘

10H-3 中 B9：

- 任务：助教招聘文案
- 问题：模拟对话里出现“美式台”
- 严重度：低 / BASIC_PASS
- 但属于重复出现的桌型边界问题

当前项目标准桌型只有：

1. 普通台球桌
2. 独牙台球桌
3. 乔氏台球桌
4. 斯诺克

重要规则：

> 除独牙、乔氏以外的中式八球台球桌，都归为普通台球桌。

禁止把以下词作为门店标准桌型或设备卖点输出：

- 美式台
- 英式台
- 中式八球台
- 比赛台
- 娱乐台

如果用户或模拟对话中提到“美式台”等非标准表达，应转译为：

- 普通台球桌
- 店里台子
- 常规台球桌
- 来店里打两把

## 四、修复目标

### 目标 1：强化“模拟对话 / 示例话术”场景中的桌型边界

此前规则可能覆盖正文文案，但 AI 在“模拟对话 / 面试话术 / 客户对话示例”中仍然绕出“美式台”。

需要补充边界：

```text
即使是在模拟对话、面试话术、客户问答示例、招聘文案示例中，也不得把“美式台/英式台/中式八球台/比赛台/娱乐台”等写成门店标准桌型或设备信息。
```

### 目标 2：反例库补充 B9 类型反例

新增或强化反例：

- 助教招聘文案 / 面试邀约 / 模拟对话中写“我们店里有美式台”
- 客户问答中把非标准桌型当成门店设备卖点

要求：

- `runtime_prompt_eligible: false`
- `regression_test: true`
- `priority: P0`
- 不注入错误全文
- 作为后续回归测试用例沉淀

### 目标 3：小回归验证

完成修复后做 8-12 条真实调用小回归，重点覆盖：

1. 助教招聘文案
2. 助教面试邀约
3. 前厅客户问“会不会打美式”
4. 客户问“有没有美式台”
5. 门店特色介绍
6. 桌型相关朋友圈
7. 助教客户私聊
8. 大白话“美式那个怎么说”

## 五、建议修改范围

### 1. `server/prompts/rules/baseline_rules.yaml`

在现有 Rule 17c 或桌型边界规则中补充“模拟对话同样适用”。

建议补充：

```text
桌型/设备边界同样适用于模拟对话、客户问答示例、招聘文案示例、面试邀约示例和员工话术示例。即使是示例对话，也不得编造门店有美式台、英式台、中式八球台、比赛台、娱乐台等非标准桌型。

```
