## 一、已可用后端接口

阶段 5A 已经提供以下接口：

### 1. 生成历史列表

`GET /api/v1/generations`

查询参数：

```text
page: int = 1
page_size: int = 20
type: copywriting | activity | 可选
sub_type: moments | group_notice | planning | 可选
```

响应示例：

```json
{
  "items": [
    {
      "id": "uuid",
      "type": "copywriting",
      "sub_type": "moments",
      "input_params": {},
      "content": "生成内容",
      "model_used": "deepseek-chat",
      "tokens_used": 718,
      "created_at": "2026-05-10T19:37:25.452343Z"
    }
  ],
  "total": 100,
  "page": 1,
  "page_size": 20
}
```

注意：

- 响应字段是 `content`
- 不返回 `result`
- 不返回 `prompt_used`
- 后端自动按当前门店过滤
- 前端不允许传 `store_id`

---

## 七、筛选设计

```text

朋友圈文案
群公告
活动方案
```

### 全部

不传 `type` 和 `sub_type`

### 朋友圈文案

```text
type=copywriting
sub_type=moments
```

### 群公告

```text
type=copywriting
sub_type=group_notice
```

### 活动方案

```text
type=activity
sub_type=planning
```

切换筛选时：

- page 重置为 1
- 清空当前详情或自动选择第一条
- 重新请求列表

## 十、API Client 要求

所有请求必须统一走：

```text
web/src/lib/api.ts
```

不要在页面中散落 `fetch`。

请新增类型，可以放在：

```text
web/src/types/generation-history.ts
```

或复用/扩展：

```text
web/src/types/generate.ts
```

建议新增类型：

```ts
export type GenerationType = "copywriting" | "activity"

export type GenerationSubType = "moments" | "group_notice" | "planning"

export interface GenerationHistoryItem {
  id: string
  type: GenerationType
  sub_type: GenerationSubType | null
  input_params: Record<string, unknown> | null
  content: string
  model_used: string | null
  tokens_used: number | null
  created_at: string
}

export interface GenerationHistoryListResponse {
  items: GenerationHistoryItem[]
  total: number
  page: number
  page_size: number
}

export interface ListGenerationsParams {
  page?: number
  page_size?: number
  type?: GenerationType
  sub_type?: GenerationSubType
}
```

API client 新增：

```ts
listGenerations(params?: ListGenerationsParams): Promise<GenerationHistoryListResponse>

getGenerationDetail(id: string): Promise<GenerationHistoryItem>
```

注意：

- 不要传 `store_id`
- 不要使用 `result`
- 统一使用 `content`
