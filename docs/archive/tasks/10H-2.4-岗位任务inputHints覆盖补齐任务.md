# 10H-2.4：岗位任务 inputHints 覆盖补齐任务

## 任务定位

你现在只负责【10H-2.4：岗位任务 inputHints 覆盖补齐】。

本任务是 10H-2.3 生成前补充引导优化后的覆盖补丁。

当前 10H-2.3 已完成：

- `RoleTaskCard` 新增 `inputHints?: string[]`
- AI 工作台从 `source=role_workbench` 跳转进入时，会显示“让结果更准”的提示卡
- 已覆盖 10 张岗位任务卡
- user_intent 自动填参已经在浏览器复验中正常生效

人工复验发现：店长岗位中还有 3 张已上线任务卡没有显示 inputHints：

1. 周赛活动通知
2. 每日简报
3. 员工群通知

这不是 P0 bug，但会造成同一岗位内有的任务有引导、有的任务没有引导，体验不一致。  
本轮只补齐这 3 张任务卡的 inputHints，不做其他功能。

## 三、本轮目标

给以下 3 张店长任务卡补齐 `inputHints`：

### 1. 周赛活动通知

建议 inputHints：

```ts
inputHints: [
  "周赛是今天、明天还是这周几？大概几点开始？",
  "想发朋友圈、群公告，还是私聊邀约？",
  "要不要提醒报名、赛制、到店时间或名额情况？",
]
```

### 2. 每日简报

建议 inputHints：

```ts
inputHints: [
  "今天想汇报哪些内容？人气、营收、助教、会员群还是竞技群？",
  "这份简报是发给老板看，还是发员工群？",
  "明天需要安排哪些重点工作？比如老客回访、助教预约、周赛报名。",
]
```

### 3. 员工群通知

建议 inputHints：

```ts
inputHints: [
  "这条通知是提醒卫生、接待、排班，还是服务标准？",
  "需要写成群公告，还是内部执行清单？",
  "要不要明确时间、负责人和注意事项？",
]
```

## 四、实现要求

1. 只在对应任务卡对象中补充 `inputHints`
2. 每张卡 3 条左右即可，不要写太长
3. 文案要面向球房真实管理场景
4. 不要出现低俗助教表达
5. 不要出现赌博、追分、大额输赢等风险表达
6. 不要把 inputHints 混入 userIntentTemplate
7. inputHints 只是前端提示，不进入生成正文
8. 不改变当前已通过的 user_intent 自动填参逻辑
