## 六、建议修复方式

根据实际代码选择一种稳定方式。

### 推荐方案 A：统一 URL 参数为 `intent`

在 `workbench/page.tsx` 中：

```ts
params.set("intent", task.userIntentTemplate)
params.set("source", "role_workbench")
```

在 `generate/page.tsx` 中：

```ts
const intentParam = searchParams.get("intent")
```

并确保设置到 textarea 绑定 state：

```ts
setWorkbenchIntent(intentParam || "")
```

### 推荐方案 B：如果 textarea 绑定的是表单对象

如果 textarea value 绑定的是：

```ts
workbenchForm.user_intent
```

则必须：

```ts
setWorkbenchForm(prev => ({
  ...prev,
  user_intent: intentParam || "",
}))
```

而不是只调用 `setWorkbenchIntent`。

### 推荐方案 C：避免后续覆盖

应用 URL 参数时使用单独分支：

```ts
if (source === "role_workbench" && !urlParamsAppliedRef.current) {
  urlParamsAppliedRef.current = true
  setTab("workbench")
  // 设置所有字段
  return
}
```

如果仍被覆盖，要找出覆盖逻辑并做保护。
