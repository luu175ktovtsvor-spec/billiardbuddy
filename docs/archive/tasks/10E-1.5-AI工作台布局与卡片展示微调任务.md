# 10E-1.5：AI 工作台布局与卡片展示微调任务

你现在只负责【10E-1.5：AI 工作台布局与卡片展示微调】。

本任务基于 10E-1 已完成的前端产品化改造继续做小范围 UI 微调。

本任务只改前端 UI，不改后端、不改 Prompt、不改数据库。

---

## 一、任务背景

10E-1 已完成：

1. Tab 改名为「AI 工作台」
2. 新增 `web/src/lib/workbench-config.ts`
3. 24 条示例按岗位分组
4. 30 张快捷场景卡片
5. output_package 三组分组展示
6. 推荐输出组合按钮
7. 默认勾选 `moments + execution_tips`
8. TypeScript / lint / build 通过

人工截图验收发现：

1. 常用场景卡片使用横向滚动，后面的卡片被截断，用户不容易发现可以横向拖动。
2. 左侧表单偏窄，电脑端看起来像移动端布局，内容较挤。
3. 「常用场景」和「试试这样说」层级不够清楚，用户可能不知道两者区别。
4. 推荐输出组合按钮缺少说明，用户不一定知道点击后会替换勾选项。
5. 右侧生成结果空状态太空，可以稍微优化文案。

## 五、具体修改要求

### 1. 常用场景卡片改为 2 列网格

当前问题：

- 卡片横向滚动，后面的内容被截断。
- 用户不一定知道可以横向拖动。

改造要求：

- 当前岗位对应的 5 张快捷场景卡片改为 2 列网格。
- 桌面端：2 列展示。
- 移动端：1 列或自适应，不要横向溢出。
- 卡片高度尽量统一。
- 文案不要被截断太严重。
- 不出现横向滚动条。

建议结构：

```text
常用场景 · 点击后自动填好参数

[老客户回访] [空台拉人]
[员工生日]   [下雨天邀约]
[卫生检查表]
```

### 2. 左侧表单区域适当加宽

当前问题：

- 左侧表单看起来偏窄。
- 快捷卡片和 output_package 区域比较挤。

改造要求：

- 仅在 AI 工作台页面调整整体左右布局。
- 不影响旧 4 个 Tab。
- 桌面端左侧表单建议宽度在 520px - 600px 之间。
- 右侧结果区占剩余空间。
- 移动端仍然单列展示，不能溢出。

如果当前布局是 grid，可调整为类似：

```text
desktop: 左 520-600px / 右 1fr
mobile: 1 column
```

### 3. 优化「常用场景」和「试试这样说」文案

当前问题：

- 两个区域都像示例，层级不清楚。

改造要求：

把文案区分清楚：

```text
常用场景 · 点击后自动填好参数
```

说明：点击后会自动填入需求、岗位、客户类型和输出类型。

```text
试试这样说 · 不知道怎么开口可以点一句
```

说明：这是短句输入参考。

如果现有「试试这样说」按钮已经会自动填入全部参数，也可以不改逻辑，只改文案。

### 4. 推荐输出组合增加说明

当前问题：

- 用户不一定知道“标准内容包 / 活动全案包 / 管理工具包”点击后会改变勾选项。

改造要求：

在推荐组合按钮附近增加一句简短说明：

```text
不知道选什么，可以先点一个组合，系统会自动勾选常用输出。
```

或：

```text
点击组合会替换当前勾选项。
```

注意：文案要短，不要让页面更挤。

### 5. 右侧空状态优化

当前问题：

- 右侧未生成时太空，只显示一句话。

改造要求：

空状态可以改为更有引导性的文案，例如：

```text
生成结果会显示在这里

你可以先选择一个常用场景，系统会自动填好岗位、客户和输出类型。
也可以直接用大白话输入你的需求。
```

或者更简洁：

```text
生成结果会显示在这里。
先选一个常用场景，或直接输入你想完成的运营动作。
```

不要做复杂插画，不要引入新组件库。
