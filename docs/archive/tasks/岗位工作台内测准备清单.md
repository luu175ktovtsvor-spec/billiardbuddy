## B. 内测前门店资料建议填写项

为了让 AI 生成内容更贴近本店，内测前建议完成以下资料：

### 必填基础

- [ ] 门店名称
- [ ] 城市/区域
- [ ] 门店定位（社区实惠型/商业品质型/年轻潮流型/赛事竞技型/助教特色型）
- [ ] 球桌数量

### 客户结构

- [ ] 主要客户类型（多选：团购客/新客户/老客户/助教客户/竞技客户/轻竞技客户/VIP大客户/单人练球客户）
- [ ] 当前最想提升目标（老客户回流/团购客转私域/助教预约转化/提升周赛人气等）

### 私域群矩阵

- [ ] 客户群
- [ ] 会员群 — 勾选后 AI 在生成会员群内容时不乱编优惠
- [ ] 竞技群 — 勾选后 AI 在生成竞技群内容时不写赌博/追分
- [ ] 搭子群
- [ ] 助教客户群
- [ ] 赛事群
- [ ] 员工群

### 助教体系

- [ ] 是否有助教
- [ ] 助教类型（服务体验型/技术陪练型）
- [ ] 是否允许写"新助教到店"
- [ ] 是否允许写"今日助教可约"

### 赛事活动

- [ ] 是否有固定周赛
- [ ] 是否做轻竞技/台费局

### 桌型设备

- [ ] 勾选门店实际桌型（普通台球桌/独牙台球桌/乔氏台球桌/斯诺克）
- [ ] 桌型补充说明（如：12 张普通台，2 张乔氏）

### 内容风格

- [ ] 朋友圈语气（熟人自然/轻松幽默/高端商务/年轻潮流/简短直接）
- [ ] 是否允许写优惠/折扣（建议关闭）
- [ ] 禁用表达（如：包教包会、全城最低）

### 团购/价格

- [ ] 是否做团购（美团/抖音）
- [ ] 是否有会员体系

## C. 内测建议测试路径

建议按以下顺序引导内测用户完成一次完整体验：

| # | 步骤 | 页面 | 预期结果 |
|---|------|------|---------|
| 1 | 填门店资料 | 门店资料页 | 完整度达到 70%+ |
| 2 | 看完整度提示 | 门店资料页 | 看到百分比 + 建议补充模块 |
| 3 | 进入岗位工作台 | /dashboard/workbench | 看到 6 个岗位 + 画像完整度提示 |
| 4 | 店长发朋友圈 | 店长→今日朋友圈→生成 | 产出 1 条自然朋友圈 |
| 5 | 会员群空台提醒 | 店长→会员群空台提醒→生成 | 不编优惠，语气自然 |
| 6 | 竞技群约局通知 | 店长→竞技群约局通知→生成 | 不写赌博/追分 |
| 7 | 今日助教可约 | 助教管理→今日助教可约通知→生成 | 专业表达，不低俗 |
| 8 | 前厅团购核销加微信 | 前厅→团购核销后加微信→生成 | 话术自然，不强推 |
| 9 | 老板经营简报 | 老板→今日经营简报→生成 | 结构清楚，不乱编数据 |
| 10 | 运营内容规划 | 运营→本周内容规划→生成 | 多渠道覆盖 |

## D. 内测记录表

内测时每条使用记录建议填写：

| 字段 | 说明 |
|------|------|
| 日期 | 使用的日期 |
| 使用岗位 | 店长/助教管理/前厅/老板/运营/教练 |
| 使用任务卡片 | 点击了哪张卡 |
| 用户原始需求 | 用户在 textarea 中补充了什么 |
| AI 输出是否可直接用 | 是/否/微调后可用 |
| 用户是否修改 | 改了哪里 |
| 不满意原因 | 太泛/太正式/信息不准/编了东西/不贴合门店/其他 |
| 是否有行业新信息 | 用户需求里包含了 AI 不知道的行业事实 |
| 是否有风险表达 | 是否出现低俗/赌博/乱编优惠/乱编价格等 |
| 是否需要进产品大脑 | 新发现的行业知识或运营模式 |
| 是否需要进 Prompt/样例/反例/测试 | Y/N |
| 备注 | 其他需要记录的 |

建议每个内测用户至少完成 10 次生成（覆盖 3+ 岗位），每次记录一条。
