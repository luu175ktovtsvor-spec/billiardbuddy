# 阶段 8C：门店资料首次填写引导任务文档

请先阅读项目根目录中的：

1. `CLAUDE.md`
2. `architecture-design.md`
3. `docs/tasks/阶段7D-MVP演示验收与功能清单.md`
4. `docs/tasks/阶段8A-今日工作台Dashboard规则引擎任务.md`

你现在只负责【阶段 8C：门店资料首次填写引导】。

当前项目状态：

- 当前 MVP 已经完成核心闭环：
  - 注册 / 登录
  - 门店资料
  - Logo / 二维码上传
  - AI 朋友圈文案 / 群公告 / 活动方案生成
  - 生成历史
  - 海报生成
  - 海报历史接入
  - 今日工作台
  - 5 个海报模板
- 当前 Dashboard 已经能根据门店完整度、Logo / 二维码、生成次数给出今日推荐。
- 当前问题：新用户第一次进入系统时，如果没有门店资料，虽然页面有提示，但引导还不够明确。

当前阶段目标：

优化新用户首次使用路径，让用户清楚知道：

1. 先填写门店资料
2. 上传 Logo 和二维码
3. 完善价格、会员卡、优势等信息
4. 再去生成文案、活动方案和海报

本阶段只做前端体验引导，不改后端接口，不改数据库。

---

## 一、本阶段核心目标

让新用户第一次登录后，不会迷路。

理想体验：

```text
注册 / 登录
→ 进入 Dashboard
→ 如果没有门店资料，看到明确引导
→ 点击“去完善门店资料”
→ 进入门店资料页
→ 按步骤填写核心信息
→ 保存成功
→ 返回 Dashboard 或继续生成内容
```

## 五、具体任务

### 任务 1：Dashboard 无门店状态增强

修改：

```text
web/src/app/dashboard/page.tsx
```

当前无门店状态已有引导，但需要更明确。

当 `GET /api/v1/stores/me` 返回 404 或 store 为空时，Dashboard 显示一张重点引导卡片：

标题：

```text
先完善门店资料，AI 才能帮你生成内容
```

说明：

```text
门店名称、价格、地址、Logo 和二维码会影响文案和海报效果。建议先花 3 分钟填写核心资料。
```

显示 3 个步骤：

```text
1. 填写门店名称、地址、电话
2. 填写价格、会员卡和门店优势
3. 上传 Logo 和微信二维码
```

按钮：

```text
去完善门店资料
```

跳转：

```text
/dashboard/store-settings
```

要求：

- 不要做复杂弹窗
- 不要阻止用户访问其他页面
- 只做明确引导
- 页面不能白屏
- 原有快捷入口可以继续保留在下方，但弱化展示

---

### 任务 2：门店资料页顶部增加“首次填写提示”

修改：

```text
web/src/app/dashboard/store-settings/page.tsx
```

当用户没有门店资料，或资料完整度低于 70 时，在页面顶部显示提示卡片。

标题：

```text
建议先完成这些核心资料
```

说明：

```text
这些资料会被 AI 用来生成朋友圈文案、群公告、活动方案和海报。
```

核心资料清单：

```text
门店名称
地址 / 电话
营业时间
价格体系
会员卡套餐
门店优势
Logo
微信二维码
```

要求：

- 可以用 checklist 样式
- 根据当前 store 字段判断哪些已完成、哪些未完成
- 已完成显示 ✅
- 未完成显示 ○
- 不需要做复杂进度条，已有 completeness 可以保留
- 不影响原有表单保存逻辑

---

### 任务 3：保存成功后的下一步提示

修改：

```text
web/src/app/dashboard/store-settings/page.tsx
```

门店资料保存成功后，除了原有成功提示，可以显示一个轻量提示：

```text
资料已保存。现在可以去生成 AI 文案或海报了。
```

提供两个按钮：

```text
去生成文案
去生成海报
```

跳转：

```text
/dashboard/generate
/dashboard/posters
```

要求：

- 不要自动跳转
- 让用户自己选择
- 不影响继续编辑资料
- 如果只是上传 Logo / 二维码成功，也可以显示类似提示

---

### 任务 4：资料完整度提示文案优化

如果页面已有资料完整度，请优化文案。

示例：

完整度低于 70：

```text
资料还不够完整，AI 可能无法准确写出你的价格、优势和活动信息。
```

完整度 70-89：

```text
资料已经基本可用，继续补充 Logo、二维码或会员卡信息，生成效果会更好。
```

完整度 90 以上：

```text
资料很完整，可以放心生成文案和海报。
```

要求：

- 只改前端展示
- 不改 completeness 计算逻辑
- 不改后端
