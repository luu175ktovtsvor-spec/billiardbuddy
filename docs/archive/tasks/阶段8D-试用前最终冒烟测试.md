## 五、安全与边界检查

请确认：

1. 前端没有 DeepSeek Key
2. 前端没有直接调用 DeepSeek
3. web/.env.local 没有密钥
4. 未登录不能访问受保护接口
5. 用户不能传 store_id 操作其他门店
6. 生成历史只返回当前门店数据
7. 海报只使用当前门店资料
8. 没有新增支付 / 配额 / OSS / SSE
9. 没有新增 AI 图片生成
10. 没有新增数据库迁移
11. 没有修改 server/models/

可以执行：

```bash
grep -r "DEEPSEEK\\|OPENAI\\|API_KEY\\|sk-" web/src/ || true
grep -r "store_id" web/src/app/dashboard || true
```

## 七、问题分级

请按等级记录问题。

### P0：阻断性问题

- 无法注册 / 登录
- 前端无法启动
- 后端无法启动
- 数据库无法连接
- Dashboard 白屏
- AI 生成不可用
- 海报生成不可用
- 历史记录不可用
- 权限 / 数据隔离错误

### P1：重要问题

- 某个模板生成异常
- 生成内容明显不可用
- 图片不能访问
- 上传体验异常
- 移动端严重错位
- 新用户引导不清楚
- Dashboard 推荐明显错误

### P2：优化问题

- 样式可以更好
- 文案可以更自然
- 海报视觉还可以优化
- loading 体验可以更好
- 页面信息层级可以更清楚
