## 3. 产品当前定位

当前产品定位已经明确为：

```text
面向台球房管理层和岗位人员的行业 AI 工作台
```

它不是普通聊天机器人，也不是简单文案模板工具。

它面向的真实用户包括：

- 老板
- 店长
- 助教管理
- 前厅
- 运营 / 内容负责人
- 教练 / 赛事负责人

核心价值是：

```text
让球房人员每天少花时间写文案、发通知、维护客户、推助教、做活动、写简报、做执行清单。
```

用大白话说：

```text
他们只要告诉系统想做什么，或者直接点岗位任务卡片，系统就能结合门店资料和台球行业逻辑，生成能直接发、能直接用、能执行的内容。
```

## 7. 当前已知边界和注意事项

### 7.1 非标准桌型表达

当前标准桌型只有：

- 普通台球桌
- 独牙台球桌
- 乔氏台球桌
- 斯诺克

规则：

```text
除独牙、乔氏以外的中式八球台球桌，都归为普通台球桌。
```

已知边界：

```text
用户大白话说“美式那个”时，AI 偶尔会引用“美式台”。
```

目前不认为是严重问题，因为它不是系统主动编造门店有美式台，而是跟随用户原话。但后续需要继续观察和优化成：

```text
用户说“美式” → AI 用“普通台球桌 / 店里台子 / 常规台子”承接。
```

## 10. 你去球房时怎么记录？

你计划用 Plaud 录音豆录音，并通过 App 转写，这个方案是合适的。

建议：

### 10.1 每段录音开头说一句说明

例如：

```text
这是 Day1，和店长聊日常运营。
这是 Day1，和助教管理聊助教预约和推广。
这是 Day1，和教练聊周赛和竞技群。
这是我自己的现场观察记录。
```

这样后面即使转写有点乱，也更容易判断角色和场景。

---

### 10.2 尽量按对象分段录音

最好分成：

```text
Day1-店长访谈转写
Day1-助教管理访谈转写
Day1-教练赛事访谈转写
Day1-前厅观察转写
Day1-我的现场观察
```

如果现场太乱，也可以粗一点：

```text
Day1-上午录音转写
Day1-下午录音转写
Day1-晚上录音转写
```

只要你在文件开头写一句：

```text
这里可能混着店长、助教管理和我自己的话，需要 ChatGPT 自己判断角色。
```

我后续会根据内容推断和拆分。
