# 子代理报告归档

> 📌 状态:✅现行 · 存放子代理产出的审计/代码审核/文档体检/前端设计等报告,随仓库跟踪、方便回查。

## 规矩(CLAUDE.md 文档维护规约 §7)

- 子代理的分析/审核/设计类报告一律落到这里,**不写进会话临时目录、不复制到桌面**(那些找不到、也会丢)。
- **按日期批次分文件夹**:每一批工作各建一个 `<日期>-<批次名>/` 文件夹,批次内再按类型分子目录(内核审计/代码审核/文档体检/前端设计…),这样能一眼分清哪份是哪天哪批产的。
- 派子代理时直接让它把报告落到 `docs/子代理报告/<当前批次文件夹>/<分类>/` 下。
