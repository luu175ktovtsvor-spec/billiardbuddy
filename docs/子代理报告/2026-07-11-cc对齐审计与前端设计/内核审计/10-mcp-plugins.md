## 本轮新增的两个真安全洞(未在原始待办清单里，务必看)

1. **#9 隐藏 Unicode 净化缺失**：cc 专门防御一个已披露真实漏洞(HackerOne#3086545)——恶意/被攻陷的 MCP server 能在 tool description 里塞入不可见的 Unicode Tag 字符向模型偷渡指令，用户在 UI 上完全看不见。我方目前对任何连接的 MCP server 零防御。
2. **#17 图像/音频内容块丢失**：MCP 工具调用结果里的 `image`/`audio` content block 在我方被硬编码成文字占位符（`[image mimeType=... bytes=N]`），从未真正把像素数据送进模型视觉输入——任何靠视觉交互的 MCP server（浏览器截图、图像生成、文档扫描类）在我方等于瞎的。好消息是 harness 已有 `ctx.imageResultSink`/`ctx.documentResultSink` 现成机制（`read_file` 已在用），MCP 侧只是没接线，属于"补一条线"级别的工作量而非推倒重来。
