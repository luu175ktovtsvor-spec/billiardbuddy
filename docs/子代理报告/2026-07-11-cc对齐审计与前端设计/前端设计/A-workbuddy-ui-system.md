# WorkBuddy UI 系统规格（供「球房管家」施工对齐）

> 来源：`docs/references/WorkBuddy逆向档案/`（README + 01~24）+ `docs/references/竞品拆解/02、03`。
> 口径：App 外壳/布局/导航/设置/右侧预览/输入区照抄 WorkBuddy；主对话消息渲染本体另照 cc-haha（见 `../cc-haha主对话框展示逆向.md`，本档不涉及）；颜色/品牌/文案换球房管家自己的。

## 1. 整体外壳布局

**一句话**：Electron 无边框窗口（`frame:false` + macOS `hiddenInset` + under-window 毛玻璃），VS Code 式可拖拽三栏 Grid：**左导航栏（展开 264px / 收起 48px）| 中聊天区（min 360px）| 右预览面板（min 318 / 默认 500 / max 无限）**，栏间 2px 可拖 sash。

### 1.1 尺寸常量（可直接抄数值）
```
SIDEBAR_SIZE      = { EXPANDED: 264, COLLAPSED: 48 }
CHAT_MIN_WIDTH    = 360
CONTEXT_VIEW_SIZE = { MIN: 318, DEFAULT: 500, MAX: Infinity }
RESIZE_HANDLE     = 2px
断点：窗口内宽 < 264+360+318=942 → 先收右栏；< 264+360=624 → 再收左栏（改左侧抽屉 placement:left, size:264, backdrop, 300ms）
```

### 1.2 窗口壳
- `frame:false` + mac `titleBarStyle:"hiddenInset"` + `vibrancy:"under-window"`；Win 用 Mica/Acrylic + `titleBarOverlay`。
- 默认窗口 1200×800，记忆到 `userData/window-state.json`（带跨屏可见性校验）。
- 交通灯（mac 红黄绿）定位：`MAC_TOPBAR_HEIGHT=52`，锚 x:21/y:20；侧栏折叠时避让 inset 68px（预览全屏 96px）。
- 拖拽区规则：所有顶部横条（detail-header 40px、顶栏 54px、侧栏各栏顶部）整条 `-webkit-app-region:drag`；条内 button/input/select/textarea/role=button/tab/nav 逐个标 `no-drag`。

### 1.3 各栏职责
| 栏 | 宽度 | 职责 |
|---|---|---|
| 左导航栏 | 264/48 | 品牌区→新建任务按钮→图标导航（助理/项目/专家技能连接器/自动化/更多）→搜索→会话列表（置顶/任务/空间三分区）→底部用户区 |
| 中聊天区 | min360，自适应 | 顶部拖拽条 54px + 消息流 + 底部 Composer（三层圆角盒）|
| 右预览面板 | 318/500/∞ | 概览/工作空间文件/浏览器/变更(文件版本管理)/MCP Apps/专家 —— 详见第 3 节 |

### 1.4 栏间收放
- 2px sash 可拖拽调宽；窄屏自动收右栏→收左栏（变抽屉）；右栏有「钉住/取消钉住」状态机（第 3 节 E）。

## 2. 导航模型（左栏）

**后端只控展示属性（显隐/文案/图标/排序），跳转行为由前端按 key 硬编码**——这条分层原则本身值得抄，方便做领域包按开关裁 Tab。

### 2.1 侧栏主 tab（order 升序，桌面本地版）
| key | 中文 | 给用户看什么 |
|---|---|---|
| `new_task` | 新建任务 | 点击清空当前会话→欢迎页（Logo+标题+三模式选择器 办公/代码/设计 + 快捷动作 + 工作空间选择）|
| `claw`（球房=助理） | 助理 | Dashboard：欢迎大卡+一句话派单 → 助理网格卡片 → 点卡进详情浮层(首页4指标+对话任务表) → 点"对话"进左rail+右对话大浮窗（编排/总控 @ 拉其他助理协作）|
| `project` | 项目 | 落地页(Hero+我的项目网格+5个内置模板) → 详情页(顶栏+4tab 动态/计划/任务/资产+右侧320px配置面板) |
| `experts` | 专家·技能·连接器 | 三Tab统一市场：技能(市场/我安装)、专家(精选场景+行业分类+召唤)、连接器(OAuth/扫码/设备码/Token四种授权) + 独立MCP面板 |
| `automation` | 自动化 | 两Tab：定时任务列表(RRULE调度)+运行记录；点行进整页编辑视图（非小弹窗）|
| `more`（hover下拉） | 更多 | 聚合"资料库(我的文件等)+灵感(discover案例库)"，副标签动态拼"资料库·灵感" |

- 「更多」是 **hover Dropdown**（不是点击），placement `right-start`，offset -12，副标签根据实际开启的子项动态拼接。
- 设置**不在**导航/更多里，在**左栏底部用户头像菜单**（账户管理/系统设置/个性化/外观/数据管理/帮助反馈/已归档任务/检查更新）。

### 2.2 球房管家的映射建议
`助理`→总控"店长助手" @ 拉"排班/营销/对账助手"；`专家`→运营角色模板；`技能`→门店运营小工具(排班/对账脚本)；`连接器`→POS只读集成；`自动化`→营业额播报/排班提醒/对账/赛事巡检定时任务；`更多/资料库`→门店文件/知识库。

## 3. 右侧详情/预览面板各态（★核心，重点抄）

**出现时机**：选中一个产物（文件/任务/变更记录）后从右侧滑出；窄屏收成抽屉；默认走 **next 壳**（`SidebarNext`，非 legacy pills tab）。

### 3.1 顶部 ViewSelector（切视图下拉胶囊，替代 legacy 的 pills tab）
| 视图 | 中文 | 隐藏条件 | 内容形态 |
|---|---|---|---|
| overview | 概览 | 不隐 | OverviewPanel 三 section：①任务进程(有任务才显，todolist步骤+连接线)②产物(始终显，列表+折叠阈值5)③团队信息(WorkBuddy自己也不显示，可不做) |
| fileTree | 工作空间文件 | 不隐 | 文件树；空="空目录"；加载="正在加载文件树..." |
| preview | 浏览器 | 不隐 | webview + 免登cookie 直接预览（HTML制品走这条） |
| changes | 变更／文件版本管理 | 无变更时隐 | commit时间线(左) + 文件明细+diff(右)，见3.4 |
| mcpApps | MCP Apps | 无MCP能力隐 | 利用ViewSelector天然隐藏机制 |
| expert | 专家 | 无专家隐 | 专家信息+"立即测试"按钮 |

- ViewSelector `.view-selector-pill`：icon+label+chevron，180ms 缓动。
- 兜底空态：未选产物时"请选择一个产物查看详情"。
- **死key别做**：`关注`/`审查`/`隐藏侧边栏`/`显示侧边栏`/`文件`（这几个 i18n 有但 0 引用）。

### 3.2 产物文件类型图标色（照抄）
pdf `#E57163` / code `#5A8AA4` / word `#528AE3` / ppt `#D24F31` / sheet `#51A776`。

### 3.3 钉住/收起左栏状态机（owner说的"隐藏/显示"真实现）
`effectiveLeftCollapsed = 钉住 ? false : 已选中产物`——选中文件/产物后，左侧列表自动让位给预览主区；钉住则左栏常驻；窄屏(<480)选中即收且取消钉住。折叠动画 180ms。

### 3.4 变更/文件版本管理（24号档案，价值最高的一态）
- 左栏：commit 时间线（短id+绝对时间+操作tag+"{n}个文件变更"+当前版本徽章）。
- 右主区：选中commit后展开文件明细，每文件变更类型徽章（A新建绿/M修改琥珀/D删除红/R重命名蓝）+ 点击展开 diff。
- **DiffViewer 不是Monaco**：自研 `diffLines`(diff库)+`highlight.js` 单栏inline diff，裁掉首尾未变化上下文，新增绿底/删除红底，无行号无并排。**这个直接抄，比接Monaco轻得多。**
- **回滚 vs 重置两种语义**（这个面板最有价值的交互）：回滚=保留后续提交、不弹确认直接执行；重置=丢弃后续+**必须二次确认**（"重置到此版本？将丢弃该commit之后的全部变更，且不可恢复"）。
- 兜底三态：二进制不支持diff / 文件过大不展示diff / 原始版本已回收无法查看。
- 后端建议：工作目录做成真git仓库，每次工具改文件后 `git add -A && git commit`，四方法契约：`listFileCommits/revertFileCommit/resetFileCommit/queryFileVersionCache`。

### 3.5 外层抽屉容器规格（球房管家实际会用的壳）
`width:{px}` inline style（非全屏用固定宽，全屏用父容器实测宽）+ CSS `transition width 240ms` 做放大动画；header：标题"产物预览" + 圆形28×28关闭按钮；`box-shadow:-8px 0 24px rgba(0,0,0,.06)`。裁剪建议：关掉"保存到资料库/上传网盘/调试工具"等我们不需要的动作。

## 4. 中央对话区

### 4.1 消息流布局
归 cc-haha 对标线（本档不深挖），只需知道：WorkBuddy 侧只提供外壳/composer/权限/@斜杠这层"契约"。

### 4.2 Composer 三层圆角盒（★核心，逐值可抄）
```
_content_（外壳）   flex column; gap 4px; 圆角 18px
  ├ _topArea_（顶行） 高28px; 顶部圆角7px  ← 上下文chips/上传
  ├ _mainArea_（打字区） 圆角16px; padding12px; gap12px; 1px border
  └ _inputOverlay_（禁用遮罩） 圆角18px; backdrop-filter blur(3px)
```
- 左侧控件（从左到右）：`+`更多动作 → `@`提及 → `/`命令 → 模式档(Craft/Plan/Ask) → 权限按钮(独立、不在+菜单里) → 增强提示词。
- 右侧控件：模型选择器 → 麦克风语音 → 发送按钮（圆形32px，流式态变停止）。
- 上下文用量条：`{percentage}% · {used}/{total} 上下文已使用`，分类=系统提示词/工具及子智能体/对话消息/连接器及MCP/技能。

### 4.3 「+」更多动作菜单（18号档案，最重要的一处交互细节）
- 24×24圆形按钮，**加号旋转45°变"×"**动画（0.42s cubic-bezier(0.25,.8,.3,1)）——标志性交互，务必抄。
- 一级菜单只留 **4项**（球房裁剪版）：添加文件(本地) / 引用对话中的文件 / 模式 / 技能。（专家/连接器/腾讯生态按"无注入即隐藏"机制整块砍）
- 二级hover展开：120ms关闭延迟防抖 + 安全三角（`::after`桥接区）防鼠标斜切误关。
- 模式子菜单(Craft/Plan/Ask)：顶部描述区(随模式换文案)+两个互斥开关行(Plan/Ask，都关=Craft默认)；tooltip延迟**1000ms**(非默认300ms，防选模式误触)。

### 4.4 权限按钮（★安全护栏，1:1保留）
- **独立于"+"菜单**，是输入框页脚一个独立按钮：盾牌图标+「默认权限/允许完全访问」+下箭头。
- 默认权限态灰字；完全访问态红字(`#B42C3F`)。
- 点"允许完全访问"（default→full）→ **必须弹二次确认弹窗**：标题"确认允许完全访问？"+红色危险盾牌+正文两段+**勾选框"我已了解风险，并愿意继续"门控**+确认按钮受勾选门控(未勾选浅红`#F5B9B9`禁用/勾选后红`#F64041`可点)。
- full→default 方向**直接切**，无需确认。
- 这套 = 后端沙箱/信任门的前端体现，别简化。

### 4.5 @提及/斜杠命令
- 两层结构：先选provider类型(file/image/skill/command...)→进该provider搜索；有返回按钮。
- 键盘导航↑↓+Enter，鼠标/键盘模式互斥；拼音输入法组合期间不触发选中。
- 空态输入框按Backspace→焦点跳到最后一个上下文标签。

### 4.6 消息操作条（助手消息底部）
复制(永远显示)→点赞/点踩(互斥，点踩弹反馈弹窗多选chip+其他textarea)→更多菜单(删除/复制请求ID)→积分/模型名→时间。仅对assistant类型且非同组中间消息显示。

## 5. 设置模块清单（11~16号档案，SettingsModal）

### 5.1 外壳
- 遮罩点空白关闭 + ESC关闭；`width:min(1040px,100vw-64px)`；`height:min(720px,100vh-64px)`；圆角12px；进场slideUp 0.2s。
- 左栏236px，14个导航项（球房建议精简到6-8项：账户/系统设置/快捷键/数据管理/系统授权[仅mac]/帮助反馈/[可选]记忆/个性化），32px行高+半透明选中态(`rgba(255,255,255,.1)`，无左边条无强调色)。

### 5.2 六页各管什么
| 页 | 管什么 | 关键机制 |
|---|---|---|
| 系统设置(通用) | 语言/字体大小(7档滑块)/技能自动更新/默认工作空间路径(原生目录选择器)/通知 | `CustomDropdown`自绘下拉、`FontSizeSlider`拖动即时存 |
| 快捷键 | 18条**扁平列表**(非分组)，命令/按键绑定/操作三列 | 录制状态机：点绑定区进入录制→按键跟随→**松手即存**（无独立确认按钮）；三层拦截(校验/系统保留键/命令冲突)；`=/+`、`-/_`视为等价键 |
| 记忆 | 生成对话记忆开关+可折叠记忆卡片(hover交叉淡入)+本地记忆开关+从其他AI导入 | 管理弹窗(编辑/重置双图标+FormattedMemoryText加粗)；导入弹窗两步引导+复制提示词模板；"记忆更新中"横幅+2.5s轮询状态机 |
| 个性化 | 语气风格(**下拉非卡片**，8项name+hint)+加载欢迎语开关(即时存)+自定义指令textarea(1500字分档变色) | 语气/指令走脏检查+底部"确认"按钮；欢迎语开关独立即时生效 |
| 安全中心 | 沙箱总开关+文件/命令/网络三入口详情页(说明卡+增删名单+内置项不可删+重置默认)+审计中心(预览5条+详情页搜索/三筛选/无限滚动/导出/清空) | 关闭沙箱**红色危险二次确认**；这套"铁律感"最值得抄 |
| 系统授权(仅mac) | 完全磁盘访问/辅助功能/自动化 3项(实际渲染只3项，非5项) | **懒检查**(只查用户点过"去授权"的项，避免首装弹osascript框)+`window focus`回刷+`/usr/bin/open`深链兜底 |

### 5.3 白标要点
- 弹窗尺寸/圆角/动画、SettingSection卡片(inline/stacked)、CustomDropdown、FontSizeSlider——机制照抄不变；品牌色/文案换球房管家。
- hash路由换本地state；cloud/local双模判断全砍成纯桌面单模式。

## 6. 配色与质感 Token（可直接落地的数值）

### 6.1 六件套配方（四家验证到的通用规律）
1. 不用纯白纯黑，背景分2-5层灰阶（深色是抬高的暖灰/冷灰）。
2. 文字用透明度分级适配任何背景（`text-primary/secondary/tertiary/disabled`同名语义两套数值互换切主题）。
3. **只留一个克制强调色，主按钮用中性黑/白，品牌色只点缀链接/角标/焦点**（最关键一条）。
4. 阴影柔和多层低透明度，非单层硬阴影。
5. 圆角集中4-8px，统一token量表。
6. 三层token架构：原始尺度(palette)→语义(text/border/bg)→组件别名。

### 6.2 我们已拍板并落地的走法B（owner 2026-07-05，`ts/desktop/renderer-react/src/theme/globals.css`）

## 7. 动效

| 场景 | 数值/曲线 | 体感 |
|---|---|---|
| 全局标准缓动 | `cubic-bezier(0.4,0,0.2,1)` | Material标准加减速 |
| 全局强调缓动 | `cubic-bezier(0.2,0,0,1)` | 更"干脆"收尾 |
| 时长梯度 | fast120/sm150/base200/slow320ms，细粒度过渡多在0.15~0.2s，**没有超过0.2s的过渡** | 快、不拖泥带水 |
| SidebarNext专用 | `180ms cubic-bezier(.05,.7,.1,1)` | 展开/收起 |
| 「+」按钮加号→× | `0.42s cubic-bezier(0.25,.8,.3,1)` | 旋转45°，标志性 |

## 8. 判断：该抄 vs 可砍

### 8.1 必做（★★★ 直接照抄，投入产出比最高）
1. **三栏Grid骨架 + 尺寸常量**（264/48 · 360 · 318/500 + 断点942/624）—— 整个空间结构的地基。
2. **右侧预览面板 next壳**（ViewSelector切视图 + 钉住/收起状态机 + OverviewPanel三section + 文件版本管理DiffViewer）—— owner明确点名要抄的核心。
3. **Composer三层圆角盒 + 权限按钮二次确认**（红色开关+勾选门+浅红禁用态）—— 安全护栏，不能简化。
4. **「+」菜单加号旋转动画 + 120ms关闭延迟 + 安全三角** —— 成本低、体感提升明显的标志性交互。
5. **配色六件套（灰阶分层+单一强调色+黑白主按钮+三层token）** —— 已拍板走法B并部分落地，需在新UI持续贯彻不要退回大面积绿/蓝。

### 8.2 可简化
- 设置弹窗14项导航裁到6-8项；快捷键拼音搜索降级为子串匹配；记忆"本地记忆"开关二选一别两处重复；语气风格下拉可选升级成卡片（数据结构不变）。
- 安全中心"内置运行时工具表"简化成一个总开关+一句说明；审计客户端5000条扫描可退化为后端keyword查询。
- 消息中心"全部/待处理"tab、系统通知推送分发器按需再做，先做面板即可。

### 8.3 可砍（它自己的业务，单用户本地Agent属过度）
1. **多租户/协作类**：项目详情页成员权限三态(所有者/管理员/成员)、邀请链接、AgentTeam侧栏子会话树(WorkBuddy自己都没发货)。
2. **发布/绑渠道/配额**：助理发布(未接线)、6渠道IM绑定矩阵(留1-2个真能用的即可)、配额上限弹窗(免登录单用户无套餐概念)。
3. **云同步类**：记忆云同步、快捷键云同步(`applyOverridesToLocal/scheduleUploadToCloud`)、会话数量上限（远端限制）。
4. **腾讯生态专属**：腾讯文档/ima知识库/乐享知识库/工蜂Git/CNB连接器、Ardot设计画布合成产物入口。
5. **企业/合规专属**：企业账号特判、内容审核查重、专家团/企业智能体Beta、Windows WSL系统级工具卡。
