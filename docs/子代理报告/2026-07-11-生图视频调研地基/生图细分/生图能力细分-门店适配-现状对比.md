# 生图能力细分 · 门店适配 · 现状对比

> 📌 状态:调研底稿 · 2026-07-11 · 子代理产出

---

## 一句话结论(大白话)

生图不是"打字出图"一件事,拆开是**十几种活**:文字出图、拿图改图、局部涂改、扩画面、放大清晰、锁人换场景、抠图换背景、重打光、修脸修老照片、把电话地址准确写进图、做 Logo…… 各家 2026 年的顶级模型(GPT Image 2 / Nano Banana 2 / Seedream 4 / Ideogram)分别擅长不同的活。

**对台球房店主来说,真正天天要用的就五样**:① 文字出图做海报、② 把电话/地址/活动词准确画进海报、③ 锁住同一个助教换场景换姿势出人物图、④ 出好的图再微调、⑤ 一张图导出朋友圈竖版/大众点评/抖音/易拉宝多种尺寸。这五样**我们现在的代码基本都有**(Seedream 4.5 + GPT-image-2 双引擎、参考图锁人、海报文字还带 OCR 复核、多比例、改图带遮罩局部重绘)。

**店主用得上、但我们现在缺的四个口子(建议按优先级补)**:
1. **高清放大 / 超分**(❌ 没有)—— 海报要拿去印易拉宝、喷绘、灯箱时,现在出图分辨率不够印。**最该补**。
2. **抠图→透明背景 PNG**(🟡 只能"换背景"、不能"抠成透明")—— 想把助教抠出来贴到任意背景、或把门店 Logo 抠干净时用得上。
3. **老照片/人像修复(修脸)**(❌ 没有)—— 助教自拍糊了、老门店照片翻新时用得上。
4. **扩图 / uncrop**(🟡 能改生成比例、但不能把"已有的一张图"往外扩)—— 把方图扩成横幅 banner 时用得上,改动量最小(现有 GPT 改图接口本就支持)。

**明确鸡肋、别做的**:虚拟试穿(不卖衣服)、电商白底商品图(不卖货)、Logo/矢量 SVG 生成(店本来就有 Logo,精确品牌 Logo 还得设计师)、ControlNet/pose/depth 姿势骨架控制(太技术,闭源模型早就用"参考图"隐式做了)。

## 第一部分:生图能力全谱系(2026-07 现状 · 联网查证)

> 每项说清「是什么 + 2026 谁家做得好 + 典型用途」。模型第一梯队(盲测投票排名,来源 llm-stats / Artificial Analysis Image Arena):**GPT Image 2(OpenAI,竞技场分 656 断层第一,文字渲染有"Thinking mode")**、**Nano Banana 2 = Gemini 3.1 Flash Image(综合最强、编辑最强、最多 14 张参考图)**、**Seedream 4(字节,4K、多参考图做品牌一致性)**、**Imagen 4 Ultra(Google,照片写实度最高)**、**Ideogram 3(图内文字准确率 ~95%,断层第一)**、**Recraft V3(唯一原生矢量 SVG 输出)**。

### 1. 文生图(text-to-image)
- **是什么**:一句话文字描述 → 出一张全新图。生图的地基。
- **谁家好**:GPT Image 2(综合第一)、Nano Banana 2(综合最强+快)、Seedream 4(4K)、Imagen 4 Ultra(最写实)。
- **门店用途**:所有营销图的起点 —— 活动海报、门店氛围图、节日图、朋友圈配图。

### 2. 图生图(image-to-image / 风格重绘)
- **是什么**:给一张底图 + 指令,在底图基础上重画/改风格,不是凭空生成。
- **谁家好**:GPT Image 2、Nano Banana 家族(编辑榜单它们领先)。
- **门店用途**:把一张现成海报改风格、参考某张图的调性再创作。

### 3. 局部重绘 / 涂抹编辑(inpainting)
- **是什么**:只改图里的某一块(圈出来或直接说),其余保持不动。2026 趋势是**免手工遮罩**:Nano Banana 2 自己推理该改哪块、保留其余,不用画蒙版;但指令含糊时仍不稳(如"把阴影调柔一点"可能被理解成"整体重打光")。GPT Image 2 也支持传 mask 精确框选。
- **谁家好**:GPT Image 2(mask 精确)、Nano Banana 2(免遮罩、指令驱动)。
- **门店用途**:海报只改一个错字、只换一个物件、只改一处颜色,不用整张重出。

### 4. 扩图 / 改比例(outpainting / uncrop)
- **是什么**:把已有图往外扩、填出画面外的新内容(不是拉伸,是 AI 按语境生成),或把方图扩成横/竖版。用扩散模型按光线/纹理/透视无缝续画。
- **谁家好**:Nano Banana Pro、Claid、Pixelcut、Picsart、Higgsfield(都有 uncrop 工具)。
- **门店用途**:把一张方形助教图扩成朋友圈封面横幅、把竖图补成海报比例。

### 5. 高清放大 / 超分(upscale)
- **是什么**:把小图/糊图放大到 4K、8K 甚至 16×,补出细节。分两派:**忠实放大**(Topaz Gigapixel、Real-ESRGAN、Upscayl)vs **创意增强放大**(Magnific、Topaz Bloom,用扩散模型"脑补"新细节)。
- **谁家好**:Topaz Gigapixel(桌面本地、金标准)、Magnific(云端创意放大、最高 16×)、**Upscayl(开源免费、本地跑、4.4 万 star)**、Crystal(Replicate API 最便宜 ~$0.025/张)。
- **门店用途**:海报要印刷(易拉宝/喷绘/灯箱/展架)时必须高分辨率,否则印出来糊。

### 6. 人物 / 主体一致性(character consistency)——⭐ owner 重点
- **是什么**:锁住同一个人的脸和特征,换场景、换姿势、换服装、换光线都还是"同一个她"。三条技术路线:
 - **参考图法(主流、免训练)**:传 1 张(Ideogram Character)到最多 20 张(getimg.ai)参考照,用 `@角色名` 在任意提示里复用。闭源大模型走这条。
 - **训练法(LoRA / DreamBooth)**:喂 15–30 张多角度照片微调一个小适配器,一致性更高但要训练。
 - **技术组件(IP-Adapter Face / InstantID)**:开源栈(ComfyUI)用的即插即用人脸锁定。
- **现状预期**:2026 年靠参考图工作流可达 **~85% 一致性**(不是 100%)。
- **谁家好**:Ideogram Character、getimg.ai、Freepik、Segmind(都带 API);Seedream 4 支持多张参考图做品牌/人物一致性;Nano Banana 2 最多 14 张参考图合成。
- **门店用途助教颜值人物图** —— 同一个助教换台球厅/换赛场/换写真风/换服装,始终是本人。这是 owner 明确点名的核心场景。

### 7. 抠图 + 换背景(background removal / replace)
- **是什么**:两件事。**抠图**=把主体从背景切出来、输出透明 PNG(alpha 通道);**换背景**=把背景替换成别的场景。
- **谁家好**:PhotoRoom(最懂电商、带阴影生成/打光/模板)、Clipdrop(抠图+去物+重打光一体,Stability 技术)、Claid(输出透明 PNG 或纯色背景,合规电商)、Pixelcut(免费、无水印透明 PNG)。
- **门店用途**:把助教抠出来贴到任意背景、把门店 Logo 抠干净放海报、做纯色底的规整形象图。

### 8. 商品图 / 电商图(白底图 / 场景图 / 模特上身)
- **是什么**:电商标准图 —— 白底商品图、场景化摆拍图、商品放到模特身上。
- **谁家好**:PhotoRoom、Claid、Pic Copilot、Segmind(AI Model Outfit Generator)。
- **门店用途**:台球房**基本不卖货**,顶多球杆/器材摆拍,弱需求。

### 9. 虚拟试穿(virtual try-on)
- **是什么**:把一件衣服"穿"到模特或顾客自拍上。2026 已成熟成产业:ASOS(2026-02 上线,~1 万商品)、Google(懂布料垂坠+身形)、FASHN v1.5、SegFit v1.3、PerfectCorp Clothes Changer API。
- **门店用途**:台球房**不卖服装**,鸡肋。

### 10. 重打光(relighting)
- **是什么**:改变一张图的光照方向/颜色/强度,不改内容。
- **谁家好**:Clipdrop、PhotoRoom(打光调整)、Nano Banana 2(产品重打光、像素级)。学术前沿 LightMover(可控光的移动/颜色/强度)。
- **门店用途**:门店实拍照太暗/光乱时补光,让环境图更亮堂高级。

### 11. 修脸 / 人像修复、老照片修复(face restoration / old photo)
- **是什么**:修复糊脸/划痕/褪色/黑白上色。开源 API 现成:**GFPGAN**(腾讯 ARC,修脸)、**CodeFormer**(身份保持更好)、**DDColor**(上色)、**Bringing-Old-Photos-Back-to-Life**(修划痕破损)、DeOldify(上色)—— 全在 Replicate 上可 API 调用。
- **谁家好**:VanceAI、LetsEnhance、HitPaw(打包多模型);开发者走 Replicate 上的 GFPGAN/CodeFormer/DDColor。
- **门店用途**:助教自拍糊了先修一版再做图;门店老照片翻新。中等需求。

### 12. 精确文字 / 海报文字(text-in-image)——⭐ 门店高频痛点
- **是什么**:把电话、地址、活动词、二维码旁的文案**准确无误**画进图里(AI 生图历来最容易画错字)。
- **谁家好Ideogram 3(~95% 文字准确率,断层第一)**;GPT Image 2 的 **Thinking mode** 文字渲染接近完美(多语言招牌、多行海报文案、密集数据标签,2025 年这些还得后期叠层)。多数其它模型仍画不准文字。
- **门店用途海报上的电话/地址/优惠价/活动时间必须一字不差** —— 这是店主投放前最怕出错的地方。

### 13. Logo / 图标
- **是什么**:生成品牌 Logo、图标。2026 市场分三层:概念探索(Midjourney、Nano Banana Pro)、文字专精(Ideogram 3,~95% 文字准)、**原生矢量(Recraft V3,唯一真出可编辑 SVG 路径,不是位图套壳)**、Adobe Firefly(唯一带商用 IP 赔付保障)。
- **门店用途**:店本来就有 Logo;真要做精确品牌 Logo 还得设计师定稿。**弱需求**。

### 14. 姿势 / 构图控制(ControlNet / pose / depth)
- **是什么**:用骨架图/深度图/边缘图精确控制人物姿势和构图。属 Stable Diffusion 开源栈(ComfyUI / Automatic1111)的专业玩法。
- **谁家好**:SD 生态 + ControlNet 插件。闭源大模型(GPT Image 2、Nano Banana)已用"参考图"隐式替代了大部分场景。
- **门店用途**:太技术、店主用不来,**鸡肋**。

### 15. 变体、表情 / 年龄编辑等
- **是什么**:一张图出多个相似变体;或改表情、改年龄、换发型等细粒度人脸编辑(学术如 ExpressEdit 在 Photoshop 里改表情)。
- **门店用途**:变体=一次出 2–4 张挑一张(实用);表情/年龄编辑对台球房弱需求。

## 第三部分:对比我们现状(代码已支持什么)

### 我们现在有什么(读码实证)

**工具层(`ts/src/media/mediaTools.ts`)三个 agent 工具**:
- `make_poster` / `generate_image` —— 文生图 + 参考图。
- `edit_image` —— 改图(改背景/换色/去除或替换某处/改画面文字/抠图重构),**带 `mask_path` 做局部重绘**,`edit_type` 分 `text_fix`(改错字)/`content`(改内容);硬闸:改图必须带原图,绝不凭文字重画。

**入参能力**:`ratio` 支持 `1:1 / 9:16 / 16:9 / 3:4 / 2:5 / 5:2`(六种,含易拉宝竖长条)、`count` 1–4、`reference_image_paths` + `reference_generation_ids`(**最多 14 张参考图 → 人物/品牌一致性**)、`poster_text`(结构化海报文案)、`print_mode`(印刷模式:ffmpeg 叠加 Logo + 二维码,二维码还会按内容重生成高纠错版)、`portrait` / `portrait_consent`(肖像授权闸)。

**双引擎 + 智能路由(`mediaJobs.ts`)**:内置 **Seedream 4.5(`doubao-seedream-4-5-251128`)+ GPT-image-2**,走网关藏 key/白标。路由逻辑:硬文字需求→Seedream;复杂写实人像/西文为主→GPT;改图文字修正→Seedream、改内容→GPT;失败自动互相兜底。GPT 生图走美国 relay 异步任务(治跨境 60s 掐断)。

**质检(`imageQC.ts`)**:输入图质检(人脸数/是否真人/单主体/模糊/遮挡/欠曝)、结果质检(手/脸/肢体/过度美化/塑料感/杂文字)、**海报硬文字 OCR 复核**(读出成图文字和要求文案逐条比对、标缺字)。

**肖像合规(`portraitGate.ts`)**:有真人照片输入且判为人像优化时,强制先确认肖像授权再出图。

### 能力 → 门店刚需度 → 我们支持没 → 怎么补

| 能力 | 门店刚需度 | 我们支持没 | 缺的话怎么补 |
|---|---|---|---|
| 文生图 | 刚需 | ✅ 有 | `generate_image`/`make_poster`,Seedream 4.5 + GPT-image-2。 |
| 精确海报文字 | 刚需 | ✅ 有 | 硬文字路由到 Seedream + 生成后 OCR 复核 + 印刷模式叠二维码/Logo。已是强项。 |
| 人物一致性(锁助教) | 刚需 | ✅ 有 | 参考图法(最多 14 张 ref),Seedream/GPT 双引擎都吃参考图。契合 2026 主流做法(~85% 一致性上限是模型天花板,非我们缺陷)。 |
| 图生图 / 改图 | 刚需 | ✅ 有 | `edit_image` 带原图硬闸。 |
| 改比例 / 多尺寸 | 刚需 | ✅ 有 | 六种 ratio,含 9:16 / 2:5。 |
| 局部重绘 inpainting | 有用 | 🟡 部分 | `mask_path` 已接 GPT `/images/edits` 的 mask;但 **Seedream 路径不吃 mask**,且**没有前端"涂抹画蒙版"UI**(得用户自备遮罩图)。补法:前端加一个圈选/涂抹生成 mask 的小工具;或多依赖 Nano Banana 式"免遮罩指令改图"(`edit_type=content` 已是这个思路)。 |
| **高清放大 / 超分** | **有用(印刷刚需)** | **❌ 无** | 现在只在生成时把 Seedream 尺寸抬到像素下限(≈1920²),**不是对已有图放大**。补法:加 `upscale_image` 工具 —— 首选**本地 Real-ESRGAN / Upscayl 引擎走 Node sidecar(免费、离线,契合"免费优先"铁律)**;或网关接 Crystal(Replicate,~$0.025/张)/Magnific API 做创意放大。**优先补**。 |
| **抠图 → 透明 PNG** | **有用** | **🟡 部分** | 现在能"换背景"(edit 提示词),但**不能抠成 alpha 透明 PNG**。补法:本地 **rembg / BiRefNet 走 Node sidecar(免费离线)**,或网关接 PhotoRoom / Claid API。产出透明 PNG 供后续叠层。 |
| **老照片 / 人像修复(修脸)** | **有用** | **❌ 无** | 补法:网关接 Replicate 上 **GFPGAN / CodeFormer(修脸)+ DDColor(上色)+ Bringing-Old-Photos(修破损)**;或打包开源权重走 sidecar(资产管理器后台下载,契合"瘦安装包"铁律)。 |
| 扩图 outpainting | 有用 | 🟡 部分 | 能设生成比例,但**不能把已有图往外扩**。补法:**改动最小** —— 现有 GPT `/images/edits` 接口本就支持:把原图放到更大画布 + 边缘 mask 即可 uncrop,给 `edit_image` 加一个 `expand`/`outpaint` 模式即可。 |
| 重打光 relighting | 有用 | 🟡 部分 | 只能靠 `edit_image` 提示词"改光线";无专用流程。Seedream/GPT 指令改光已可用,够用则不必单开工具。 |
| 变体 variations | 有用 | 🟡 部分 | `count>1` 可一次多出;`MediaJobKind` 里声明了 `'variations'`/`'compose'` 但**未接成工具**(死类型)。够用,低优先。 |
| 商品图 / 电商白底 | 鸡肋 | 🟡 部分 | 能生成/改图,无专用白底/模特流程。店不卖货,不补。 |
| 虚拟试穿 | 鸡肋 | ❌ 无 | 不卖服装,不补。 |
| Logo / 矢量 SVG | 鸡肋 | 🟡 部分 | 能出位图 Logo(提示词),无 SVG 矢量。已有 `print_mode` **叠加店主现成 Logo**(正确做法)。不补生成。 |
| ControlNet / pose / depth | 鸡肋 | ❌ 无 | 太技术;闭源模型用参考图隐式替代。不补。 |

### 缺口小结(店主刚需/有用 但我们没有,按补的优先级)

1. **高清放大 / 超分(❌)** —— 海报印刷刚需,现在出图印大幅会糊。建议本地 Real-ESRGAN sidecar(免费离线)优先。
2. **抠图→透明 PNG(🟡 只有换背景)** —— 本地 rembg/BiRefNet sidecar 补透明抠图。
3. **老照片/人像修复修脸(❌)** —— 网关接 GFPGAN/CodeFormer/DDColor,或 sidecar 打包。
4. **扩图 outpainting(🟡)** —— 改动最小,复用现有 GPT edits 接口加 `expand` 模式即可。

> 说明:一致性只有 ~85% 上限、mask 需自备、Seedream 不吃 mask 这些是**模型/接口天花板或交互缺件**,不是引擎选错。我们双引擎(Seedream 4.5 + GPT-image-2)选型在 2026 第一梯队内(GPT Image 2 综合第一);如未来要再强化"免遮罩改图 + 多图合成 + 编辑",Nano Banana 2 / Gemini 3 Flash Image 是当前编辑榜第一梯队的候选(owner 决定是否纳入,当前不改选型)。
