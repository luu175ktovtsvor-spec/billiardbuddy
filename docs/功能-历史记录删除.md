## 二、后端 API

**文件**：`server/api/v1/generations.py`

### 2.1 删除单条记录

```python
@router.delete("/{generation_id}")
async def delete_generation(
    generation_id: uuid.UUID,
    current_user: Annotated[User, Depends(get_current_user)],
    current_store: Annotated[Store, Depends(get_current_store)],
    db: Annotated[AsyncSession, Depends(get_db)],
    _perm: None = Depends(require_permission(Permission.GENERATION_LIST)),
):
    """软删除生成记录。"""
    generation = await get_generation_detail(
        db=db,
        store_id=current_store.id,
        generation_id=generation_id,
    )
    if generation is None:
        raise NotFoundException("生成记录不存在")

    generation.is_deleted = True
    await db.commit()
    return {"status": "ok"}
```

### 2.2 列表接口过滤已删除

现有的 `list_generation_history` 函数中，增加过滤条件：

# 在 list_generations 服务函数中增加
.where(Generation.is_deleted == False)

### 2.3 删除整个对话

```python
@router.delete("/conversations/{conversation_id}")
async def delete_conversation(
    conversation_id: str,
    current_user: Annotated[User, Depends(get_current_user)],
    current_store: Annotated[Store, Depends(get_current_store)],
    db: Annotated[AsyncSession, Depends(get_db)],
    _perm: None = Depends(require_permission(Permission.GENERATION_LIST)),
):
    """软删除整个对话的所有记录。"""
    from sqlalchemy import update

    await db.execute(
        update(Generation)
        .where(
            Generation.conversation_id == uuid.UUID(conversation_id),
            Generation.store_id == current_store.id,
        )
        .values(is_deleted=True)
    )
    await db.commit()
    return {"status": "ok"}
```

## 三、前端

### 3.1 历史页面

**文件**：`web/src/app/dashboard/history/page.tsx`

每条记录增加删除按钮：
```tsx
<button
  onClick={async () => {
    if (!confirm("确定删除这条记录？")) return;
    await api.deleteGeneration(item.id);
    // 从列表中移除
    setItems(prev => prev.filter(i => i.id !== item.id));
  }}
  className="text-xs text-slate-400 hover:text-red-600"
>
  删除
</button>
```

### 3.2 海报对话列表

**文件**：`web/src/app/dashboard/posters/page.tsx`

对话列表每项增加删除按钮：

<button
  onClick={async (e) => {

### 3.3 API 客户端

**文件**：`web/src/lib/api.ts`

```typescript
async deleteGeneration(id: string): Promise<void> {
  await this.request("DELETE", `/api/v1/generations/${id}`);
}

async deletePosterConversation(conversationId: string): Promise<void> {
  await this.request("DELETE", `/api/v1/generations/conversations/${conversationId}`);
}
```

## 四、不做的事

- 不删除磁盘图片文件（保留，防误删）
- 不恢复配额（删除 ≠ 没用过）
- 不做批量删除（初期不需要）
- 管理员后台暂不做已删除记录恢复（后续需要再加）
