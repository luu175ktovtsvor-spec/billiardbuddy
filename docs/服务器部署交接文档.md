### AI 图片生成架构

| Provider | API | 状态 | 原因 |
|----------|-----|------|------|
| `OpenAIImageProvider` | `images.generate` + `images.edit` | ✅ 在用 | 标准 Image API，无需组织验证 |
| `OpenAIResponseImageProvider` | Responses API（gpt-4o） | ❌ 未注册 | 需要 Organization Verification，无法通过 |

**为什么用标准 Image API：** OpenAI 的 Responses API 需要完成 Organization Verification 才能使用，我们的账号无法通过，所以选择了标准 Image API。

**"多轮对话"如何实现：** 标准 Image API 不支持 `previous_response_id`，我们通过 `images.edit` 接口把上一张图片作为 `refine_from` 传入，实现"基于此调整"的以图生图效果。

**Cloudflare Worker 代理：** `OPENAI_BASE_URL` 指向 Cloudflare Worker 代理，用于优化访问速度和稳定性，不是直连 OpenAI。

## 七、常见问题

### 后端启动失败
```bash
journalctl -u billiards-backend -n 50 --no-pager
# 常见原因：.env 配置错误、数据库连接失败、端口占用、语法错误
```

### 前端白屏
```bash
# 检查静态文件是否复制到 standalone 目录
ls /var/www/billiards-ai/web/.next/standalone/.next/static/
# 如果不存在，重新构建
cd /var/www/billiards-ai/web
npx next build --no-lint
cp -r .next/static .next/standalone/.next/static
systemctl restart billiards-frontend
```

### API 502
```bash
# 检查后端是否运行
systemctl status billiards-backend
# 检查 Nginx 配置
nginx -t
```

### 生图失败
- 检查 OpenAI Key 是否有效
- 检查 OPENAI_BASE_URL 是否指向 Cloudflare Worker 代理
- 美国服务器可通过代理访问 OpenAI

### SSL 证书过期
```bash
certbot renew
systemctl reload nginx
```
