## 二、部署流程

### 日常部署（代码更新后）

```bash
# 1. 本地提交并推送
cd ~/Desktop/球房 ai 运营助手
git add .
git commit -m "描述"
git push origin main

# 2. 服务器上部署
ssh root@39.106.214.21
bash /var/www/billiards-ai/deploy.sh
```

一键脚本自动执行：git pull → 重启后端 → 重新构建前端 → 重启前端 → 检查状态

### 首次部署（已完成）

1. 安装 PostgreSQL、Nginx、Python uv、Node.js
2. 克隆代码到 `/var/www/billiards-ai/`
3. 配置 `.env`（数据库密码、API Key、JWT Secret）
4. 执行数据库迁移：`uv run alembic upgrade head`
5. 构建前端：`NEXT_PUBLIC_API_URL=http://39.106.214.21 npm run build`
6. 配置 Nginx、systemd 服务
7. 开放安全组 80 端口

## 四、常用命令

```bash
# 查看服务状态
systemctl status billiards-backend billiards-frontend

# 查看后端日志
journalctl -u billiards-backend -n 50 --no-pager

# 查看前端日志
journalctl -u billiards-frontend -n 50 --no-pager

# 手动重启
systemctl restart billiards-backend
systemctl restart billiards-frontend

# 检查 API
curl http://localhost:8000/api/v1/health

# 检查 Nginx
nginx -t
systemctl status nginx
```

## 五、常见问题

### 后端启动失败
```bash
journalctl -u billiards-backend -n 50 --no-pager
# 常见原因：.env 配置错误、数据库连接失败、端口占用
```

### 前端白屏
```bash
# 检查静态文件是否复制到 standalone 目录
ls /var/www/billiards-ai/web/.next/standalone/.next/static/
# 如果不存在，重新构建
cd /var/www/billiards-ai/web
NEXT_PUBLIC_API_URL=http://39.106.214.21 npm run build
cp -r .next/static .next/standalone/.next/static
systemctl restart billiards-frontend
```

### API 502
```bash
# 检查后端是否运行
systemctl status billiards-backend
# 检查 Nginx 配置
nginx -t
```
