## 二、部署流程

### 日常部署（代码更新后）

```bash
# 1. 本地提交并推送
cd ~/Desktop/球房 ai 运营助手
git add .
git commit -m "描述"
git push origin main

# 2. 服务器上部署
ssh root@47.77.237.250
bash /var/www/billiards-ai/deploy_us.sh

# 3. 如有数据库迁移，执行迁移
cd /var/www/billiards-ai/server
uv run alembic upgrade head
```

一键脚本自动执行：git pull → 安装依赖 → 重启后端 → 构建前端 → 重启前端 → 检查状态

### 首次部署（已完成）

1. 阿里云创建 ECS（美国硅谷，2核2G，Ubuntu 26.04）
2. 安装 Node.js、Python、PostgreSQL、Nginx
3. 克隆代码到 `/var/www/billiards-ai/`
4. 配置 `.env`（数据库密码、API Key）
5. 执行数据库迁移：`uv run alembic upgrade head`
6. 构建前端：`NEXT_PUBLIC_API_URL=http://47.77.237.250 npm run build`
7. 配置 Nginx、systemd 服务
8. 开放安全组端口：22、80、443

## 五、常见问题

### 后端启动失败
```bash
journalctl -u billiards-backend -n 50 --no-pager
# 常见原因：.env 配置错误、数据库连接失败、端口占用
```

### 前端白屏
```bash
# 检查静态文件是否复制到 standalone 目录
ls /var/www/billiards-ai/web/.next/standalone/.next/static/
# 如果不存在，重新构建
cd /var/www/billiards-ai/web
NEXT_PUBLIC_API_URL=http://47.77.237.250 npm run build
cp -r .next/static .next/standalone/.next/static
systemctl restart billiards-frontend
```

### API 502
```bash
# 检查后端是否运行
systemctl status billiards-backend
# 检查 Nginx 配置
nginx -t
```

### 生图失败
- 检查 OpenAI Key 是否有效：`curl https://api.openai.com/v1/models -H "Authorization: Bearer <key>"`
- 检查 OPENAI_BASE_URL 是否指向 `https://api.openai.com/v1`
- 美国服务器可直连 OpenAI
