## M1 · 流式 / 渲染链路（SSE）　【最高优先 · 阻断核心功能】
> ✅ **已修复并合并 main（提交 `f6ea265`，2026-06-26）**：采用「方向②后端长工具静默期发 SSE keepalive 心跳保活」。E2E S3 已复验穿代理真出图。**遗留与注意事项见 `模块修复-遗留与注意事项.md`**(M1-2 错误路径未 E2E、需重打 dmg、M1-4/M1-5 低优先级未修)。

**这是什么**：用户发一句话后，后端把"思考/工具/成品/最终答复"通过 SSE 流式推给前端渲染的整条管线。**做海报/做视频"卡死"就出在这。**
**对应代码**：`web/src/lib/api.ts`(streamAgent SSE 消费) · `web/src/hooks/use-agent-chat.ts`(状态/回调) · `server/api/v1/agent.py:896-980`(event_generator) · **`desktop/scripts/build_frontend.js`(API_PROXY_URL) + Next standalone server 的 /api 反代** · `server/services/agent/loop.py`(事件产出)

- 🟢 **高 ★ 做海报/做视频后 UI 永不渲染、无限转圈 —— 根因：Next 代理(:3100→:8077)在长工具"静默期"憋死 SSE**（可一键复现：`node desktop/e2e-pw/run.js` 的 S3 场景，自动归因=前端/传输）
  - 实测铁证（同一请求两条路径对比）：**直连 :8077** 全程 41s 正常（token@1.1s→tool_call@3.2s→**tool_result@38.9s**→token→**final/done@41.1s**）；**走 :3100 代理**（前端实际路径）token@1.6s→tool_call@4.1s→**之后 300s 一个事件都没有→timeout，无 tool_result/final/done**。后端图照常生成、照常往下发，但**代理在生图那段 30~150s 无字节的静默期把流憋死**，后续事件全被吞。
  - 为何文字对话不卡：token 连续不断、代理一直 flush；做海报/视频中间有超长静默 → 代理 stall。Esc 中断后成品彻底丢失（见 M1 下条 + §15.1）。
  - **修复方向（三选一/组合）**：① 前端 SSE **直连 :8077**（壳已有 `backendUrl()`，绕开 Next 反代）；② **后端长工具执行期发 SSE 心跳保活**（每 5~10s 一个 `: keepalive` 注释/no-op 事件，最稳）；③ Next standalone 反代显式关闭 SSE 缓冲。
- 🟡 中 出错/取消中途**不发 done、已产出成品(deliverables)不落库不渲染** → 该轮从历史消失 — `agent.py:953-970`（except 分支只 yield error，不落库不补 done）。
- 🟡 中 SSE `json.dumps(event, ensure_ascii=False)` **无 `default=`**，一个漏转 .text 的对象进 event 即崩整流 — `agent.py:962`。修：加 `default=str` 安全网。
- 🟡 低 流式取消靠隐式 async 取消、无 `is_disconnected()` 早退，点停后当前步跑完才停 — `agent.py` event_generator。
- 🟢 低 后台学习器在出错轮照样跑（失败对话也喂学习器） — `agent.py:980`。
