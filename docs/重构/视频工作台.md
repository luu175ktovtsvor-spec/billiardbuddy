# 视频工作台

视频是 BilliardBuddy 自研领域，和 Codex Agent、图片画布分别拥有独立状态。

## 后端边界

视频领域拥有素材指纹、探测元数据、转写/视觉证据、编辑方案、时间线版本、预览、渲染、导出和恢复记录。正式服务在 `ts/src/server`；FFmpeg/FFprobe 或同类本机工具执行媒体处理。

```text
导入素材
  -> 探测与证据
  -> 可编辑时间线版本
  -> 预览或渲染操作
  -> 校验后的导出文件
```

模型可以提供带来源的理解或建议，但不能替代真实素材、时间线版本、预览和导出文件。进程退出也不等于成功：输出必须存在并通过媒体元数据与 hash 校验。

## 当前前端状态

旧视频前端与旧 Agent 前端已删除。后续视频界面只能显示视频领域 API 的真实项目、时间线、操作和恢复状态，不得复用 Agent Thread 或图片候选状态。

## 迁移

旧泛媒体数据仅保留为支持期内的读取/导入来源。新视频写入只归视频工作台；验证用户数据连续后再移除旧 reader。
