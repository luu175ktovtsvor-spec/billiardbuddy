# 视频工作台

## 用户结果

用户创建视频作品项目，导入真实素材，看到可追溯的文件信息、视觉证据和转写；据此选择并调整方案，在可操作时间线编辑片段，生成可取消、可恢复的预览与最终渲染，保存版本并导出经过校验的视频。

交互研究 OpenShot 等成熟桌面剪辑工具的素材库、时间线、播放头、裁切、预览、渲染和导出，不复制其代码或品牌。BilliardBuddy 的优势是把素材理解和门店创作目标接入上述确定性媒体链路。

## 领域边界

视频项目拥有：原始素材及指纹、探测元数据、转写和视觉证据、创作方案、场景选择、时间线、预览、渲染任务、时间线版本和导出验证。FFmpeg/ffprobe 或等价本机媒体工具拥有真实媒体处理；模型只提供带来源的理解和建议。

视频项目不共享图片的画布/候选状态，也不把 Agent 对话、模型文字或脚本当作视频输出。Renderer 不拥有时间线真相，服务器的版本记录才是可恢复编辑基础。

## 正式链路

```text
导入素材 -> 指纹、时长、轨道和元数据探测
  -> 转写/视觉证据/方案（均保留来源）
  -> 场景选择与可编辑时间线版本
  -> 本机预览或渲染持久任务
  -> 文件、媒体元数据和 hash 校验后的导出
```

预览和渲染使用独立任务记录、进度事件、取消语义和恢复判定。执行进程退出不等于成功；任务须以存在且通过验证的输出文件或明确失败/需要恢复终态结束。

## 完成范围

1. 素材导入、来源记录、指纹、时长、轨道与损坏文件错误；
2. 视觉证据和语音转写，且每个结论可追溯到对应素材；
3. 场景方案、锁定、替换和来源明确的调整；
4. 拖动、裁切、排列、播放头、预览和可编辑时间线；
5. 时间线版本的保存、比较、回滚和恢复；
6. 持久预览、渲染、进度、取消和重启后恢复；
7. 导出文件、媒体元数据和 hash 的验证。

## 重构要求

视频领域从泛媒体服务中拆出独立服务、持久仓库、媒体执行器和 API；它可复用共享资产、操作生命周期和诊断，不得与图片共用项目状态机。先保持用户现有素材可迁移，确认正式消费者已切换后删除旧路径。

## 完成验收

导入真实素材，完成证据与转写，编辑和保存多个时间线版本，创建预览和最终渲染，验证导出文件；覆盖取消、进程中断和重启。仅有文本分镜、静态时间线、脚本命令或模型声称“视频已完成”均不算完成。
