# 共享运行时与桌面壳

## 职责划分

| 层 | 拥有的事实 | 不拥有的事实 |
| --- | --- | --- |
| Renderer | 临时视图状态和用户意图 | Agent/媒体持久状态、密钥、权限终态 |
| Electron Main | 窗口归属、系统安全存储、子进程生命周期、IPC | Agent Loop、工具结果、媒体项目 |
| Codex Rust App Server | Agent Thread/Turn/Item、上下文、工具、审批、恢复 | 图片画布、视频时间线、平台账户额度 |
| 本地 Sidecar | 图片、视频、设置、视频所需转写及既有语音兼容数据的恢复 | Agent Thread/Turn、个人模型 Key、新建独立语音 Agent |
| Gateway / Relay | 托管模型运营、图片/视频远程结果交接 | 本地 Agent 会话和工具执行 |

Electron Main 到 App Server 的 stdio JSON-RPC 是必要的进程边界，不是多余的 Agent 转发层。Main 转发请求和通知，不能把流事件再解释为一套自己的任务状态机。

## 安全边界

- Renderer 不能读取系统密钥、直接批准系统操作或直接启动子进程。
- 个人 Key 使用 Electron 安全存储；模型请求经短生命周期本机代理完成，原始 Key 不进入 Rust 持久配置、Sidecar、Gateway、日志或 Renderer。
- App Server 的原生审批和追问必须由前端明确作答；未实现对应界面时拒绝，不默认放行。
- Sidecar 只监听本机地址，启动时不继承模型凭据或 Gateway capability。

## 前端重建规则

新的前端从空入口开始。它只能调用 Electron 暴露的原生协议和媒体 API，展示真实通知、审批和领域状态。它不得保存第二份 Thread、自动推断 Turn 成功、重放工具或复活已删除的 ProductTask/Agent Worker。
