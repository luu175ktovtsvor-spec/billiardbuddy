# 生图工作台

生图是 BilliardBuddy 自研领域，不属于 Codex Agent 内核，也不使用 Codex 原生 image-generation 工具。

## 后端边界

图片领域拥有自己的项目、参考资产、Brief、操作、候选、画布、版本、导出和事件记录。正式本地服务位于 `ts/src/server` 的图片工作台服务与 API；远端 Relay 只承接异步任务结果，不拥有图片项目事实。

```text
图片项目 / 资产 / Brief
  -> 可恢复 ImageOperation
  -> Gateway / Relay 异步请求
  -> 候选组
  -> 用户采纳
  -> 画布版本与校验导出
```

候选生成成功不等于用户作品完成；只有明确采纳、版本保存和导出文件校验后才形成领域结果。Agent 的文本、Thread 或工具结果不能替代图片候选、画布或版本。

## 当前前端状态

旧前端已经删除，因此不存在可交付的图片页面。后续界面应仅消费图片领域 API，展示项目、候选、画布、操作和恢复状态；它不能把图片操作塞进 Codex Thread 或重新引入泛化 ProductTask。

## 迁移

旧泛媒体目录只可作为受控的历史数据读取/导入来源。新图片写入只归图片工作台；待支持期结束并验证迁移后，再删除旧 reader，而不是让两套 writer 长期并行。
