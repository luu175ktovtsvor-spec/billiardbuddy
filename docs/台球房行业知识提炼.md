## 一、行业核心认知

### 1.1 行业现状
- **市场规模**：中国台球行业市场潜力巨大、处于高速增长期
- **消费群体**：以青年为主力，男性占比高、女性占比持续增长（女性更看重环境与服务）
- **行业阶段**：爆发期，野蛮生长背后是乱象丛生，精细化运营是生存之道
- **核心观点**：专业化才是生存之道

### 1.2 营销本质
- **营销 ≠ 推广**：不是抖音、美团、地推
- **营销 = 识别→创造→传播→交付**
- 核心：清晰客户画像 → 了解客户真正需求 → 围绕需求打造产品 → 对外传播吸引优质客户
- **没有优质客户，企业将无法生存**

### 1.3 球房卖的是什么？
- **氛围 + 人情世故**
- 不是台球桌，是社交场景和体验

## 二、球房运营体系（核心框架）

### 2.1 客户运营五步法
```
引流 → 服务 → 转化 → 复购 → 裂变
```

### 2.2 引流四大渠道
1. **助教引流**：抖音短视频+直播 → 交友软件 → 公域引流→私域导流→社群维护
2. **管理层/教练引流**：进同行店消费、结交打球搭子 → 客户身份→熟悉客户→引导到店
3. **团购引流**：美团金牌店铺（评分4.6及格/4.8良好/4.9优秀）、抖音团购
4. **线上曝光**：全员抖音矩阵推广

### 2.3 客户转化逻辑
- **三种客户**：散客、助教客户、竞技客户
- **转化流程**：管理层接待 → 引导到台 → 二次邀约 → 客户反馈
- **转化要点**：
  - 助教客户：免费体验、人情世故、撒娇、上钟技巧
  - 竞技客户：小游戏、球技指导、组局、会员比赛/活动
  - 散客：帮助谈门、控制赌博金额

### 2.4 客户分类与标签
- **四类客户**：娱乐型、仅限朋友、刚上瘾、竞技型
- **打标签方法**：备注（名字+初次进店时间+客户类型+球技档位）+ 描述（距离+消费频次+分区）

## 三、岗位体系与工作流程

### 3.1 核心岗位
| 岗位 | 核心职责 | 关键能力 |
|------|---------|---------|
| **店长** | 营销、团队搭建、数据分析、成本控制 | 投资回报思维、策划能力、培养能力 |
| **助教管理** | 招聘/面试/培训/筛选助教、提升助教赚钱能力 | 营销意识、带人能力 |
| **助教** | 引流、服务、转化、维客 | 个人形象 > 沟通能力 > 台球技术 |
| **教练** | 竞技氛围打造、散客转化、组局 | 让客户对台球上瘾的能力 |
| **前厅主管** | 统筹管理、供应管理、设备管控 | 八项工作任务、小推车促销 |

### 3.2 店长四大数据管理
1. **助教数据**：平均陪打时长、人事指标
2. **教练数据**：活动数据、器材销售
3. **前厅数据**：商品费、电费
4. **总营业额数据**：台费（团购占比）、助教费、商品费、充值

- 早上：检查形象、准备上钟

## 四、定价与促销策略

### 4.1 定价原则
- **定价定生死**：定价过高/过低都有严重后果
- **盈利点**：台费 + 商品费 + 器材费 + 助教管理费
- **一卡通模式**：充值1000送99、3000送399、5000送799、10000送1999
- **取消大额赠送**：分步骤执行（培训→下架→提示→最后机会）

### 4.2 团购产品设计
- 抖音/美团团购品类优化，设置爆款产品
- 引流区：新人9.9元/h、19.9/h、25.8/2h
- 团购产品减少至4-5个（品类太多不利于爆款积累）
- 管理层每天每单主动向客户要好评

### 4.3 促销目的
- **促销 = 我想让谁干什么**
- 助教免费体验 → 培养顾客消费习惯

## 五、数据分析框架

### 5.1 核心经营指标
| 指标 | 说明 |
|------|------|
| 日营业额 | 台费 + 助教费 + 商品费 |
| 台费占比 | 团购台费 vs 充值台费 |
| 助教上钟率 | 到岗人数 vs 上钟人数 |
| 平均陪打时长 | 助教服务质量指标 |
| 好评率 | 抖音/美团/大众点评 |
| 充值转化率 | 散客 → 充值会员 |

### 5.2 数据分析应用
- **日经营趋势图**：看出月内每天营业额变化
- **促销效果对比**：促销期间 vs 促销前的数据
- **阶段性目标跟踪**：投资回报周期经营表

## 六、人才管理

### 6.1 人才吸引力法则
- 顶尖人才吸引一流人才
- 选人不对，劣币驱逐良币
- 管理最大浪费 = 招来不合适的人

### 6.2 助教管理要点
- **招聘**：个人形象 > 沟通能力 > 台球技术
- **面试**：不要废话，主导聊天，花最少精力筛更多人
- **培训**：七天筛选制，打开思维+提升能力
- **管理**：禁止集体开管理会、多开分享会、针对性PK

### 6.3 PK 机制
- 管理层PK机制 → 日均台费增长6600+
- 助教PK机制 + 助教奖励机制

## 七、产品设计启示

### 7.1 产品应该解决的核心问题
1. **店长**：每日经营数据汇总、日报生成、问题发现
2. **助教管理**：助教排班、业绩跟踪、培训话术
3. **助教**：约客话术、客户维护、朋友圈文案
4. **教练**：组局话术、活动策划、客户转化
5. **前厅**：促销话术、好评引导、服务标准

### 7.2 AI 可以深度介入的场景
1. **日报生成**：基于经营数据自动生成店长日报
2. **话术生成**：针对不同客户类型的约客/维客话术
3. **活动策划**：基于门店数据的促销方案
4. **好评引导**：美团/抖音好评文案
5. **客户分析**：客户标签、消费频次、转化路径
6. **PK 方案**：管理层/助教 PK 机制设计

### 7.3 交互设计启示
- 管理层最关心的是**数据**和**结果**
- 助教最关心的是**话术**和**约客**
- 教练最关心的是**组局**和**活动**
- 产品应该**按角色**提供差异化的入口和内容
