### 1.2 窗口体系（desktop/src/main.js）

- 所有窗口出自同一工厂 `createWindow()`（main.js:66-136）；主聊天窗 `/dashboard/chat`、新工作台 `?workbench=<id>`、工作室 `/dashboard/studio`、视频区 `/dashboard/video`。
- ⚠️ **openStudio / openVideoStudio / newWindow 都不是单例**（main.js:342-358）：重复点无限开新窗口，没有"已开则聚焦"。
- 跨窗通信只有一条：工作室出图 → `notifyStudioArtifact` → 主窗**只刷新"最近作品"**（chat-shell.tsx:298）。主窗对话生图完成 → `onGeneratedImage` 自动开右侧画布（chat-shell.tsx:141）。

### 1.3 后端能力重叠（探查结论）

- **生图/改图/生视频（模型）**：agent 工具与 `/studio/*` 调**同一个 service 函数**（`poster_service.generate_images` / `video_service.generate_video`），只差外壳（对话内 inline 同步 vs media-jobs 异步）和参数面（studio 多 image_model/mask/refine_from 血缘）。乱在入口，不在底层。
- **剪视频（素材）**：两边共享 `timeline.json` 真相源和 assemble/operations 函数，但 **V2 能力（带包装渲染 render_v2、对话改任何东西 edit_feedback）只有 /dashboard/video 页能用**；agent 的剪辑工具（video_edit_tools.py）停在 V1，存在能力代差。
- **改 Excel**：`local_tools.edit_excel` 与 `/canvas/excel-edit` 是**两套平行 openpyxl 实现**（唯一真正的重复轮子）。
- 血缘链（generationId/refine_from）后端已通，跨界面接力有数据基础、**缺 UI 通路**。

## 2. 目标模型：两级三区，一句话可背

> **对话指挥，画布轻改，工作台重做。**

- **主窗** = 对话（指挥台）+ 右侧画布（看 + 轻改）。
- **创作工作台** = **一个**独立窗口（单例），内部两个面板：**图片 | 视频**。同时满足两条已有拍板——"分面板不分 app"（一个窗口装两个面板）和"独立整页"（视频面板就是现在的整页，原样搬进来）。
- **划分判据**（回答"预览的调用划分"）：能一眼看完、顺手小改的（改一段文案、改一格表、看 diff、看大图）→ **画布**；要调参数、出多版、反复迭代、花钱生成的 → **工作台**。
- **命名收敛**：对外只有「工作台」一个词。"生成工作室 / AI 剪辑台 / 视频创作工作区"三个名字全部退场。

## 3. 规则（写死，防再漂）

- **R1 画布自动打开只有一种情况**：本次任务的主交付物完成（对话里生图/生视频/长文案成品/文件 diff）。其余一律手动（点替身卡/附件/最近作品）。
- **R2 对话流只放替身卡**：缩略图 + 标题 + 一行规格 + 「打开」。全文/大图只活在画布——解决成品双重渲染、对话越滚越长。
- **R3 一个动作只在一处**：编辑动作全在画布/工作台；气泡下只留 复制/好评/重做（与《前端文案与交互规范-改造清单》C3 是同一件事）。触发按钮统一叫「打开」，废除"右侧打开/在右侧看大图/展开预览"三种叫法。
- **R4 跨面通路两条**：① 画布里的图/视频成品 → 常驻「去工作台改」（带 generationId/路径，打开工作台对应面板）；② 工作台图片面板「做成视频」→ 切到视频面板、把图带过去当首帧/素材（**6-30 i2v handoff 的落点就定在这**）。
- **R5 窗口单例**：工作台已开 → 聚焦 + 切面板，不新开（main.js 加 focus-if-exists）。「新工作台」多开聊天窗功能保留，与此无关。
- **R6 入口收敛**：侧栏一个「工作台」按钮（替换现 Wand2 图标）+ agent 对话里可建议跳转；`/video-studio`、`/video-workspace` 两条命令合并为一条或删除。
