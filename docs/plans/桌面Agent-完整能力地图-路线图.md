# 桌面台球运营 Agent · 完整能力地图与路线图

> **核心校准（2026-06-18）**：AI Agent = 壳(Electron) + 脑(大模型/BYOK) + 工具。但目标不是"能操作电脑上任何东西"(通用 Computer Use=成功率低/危险/对台球无用)，而是"**包办台球运营要干的一切**"——深、专、可靠的台球工具箱 + 智能编排。这比通用 bot 值钱得多。
> 灵魂 = **ReAct 编排**：一句话 → 脑子自己决定调哪些工具、按序执行、结果回灌再决策，直到干完整件事，只在花钱/对外处停下走审批闸。

| 1 | 脑子 | 大模型，可换、BYOK 门店自带 key | ✅ | — |

## 三个最值钱的缺口（用户未提、但该补）

### ① 回评论/私信/好评（对外互动）— P0
平台响应速度 = 排名 + 客户体验，天天要干、最烦、最该自动化。复用发布的 patchright RPA：
读评论/私信/新评价 → AI 拟回复(注入店脑+行规) → **人点确认 → 发出**。覆盖抖音/美团评价、私信、群消息草拟。

### ② 读 POS 导出做真诊断 — P0
现状诊断靠老板手敲营业额。桌面上 AI 直接读老板**从收银系统导出的 Excel/CSV** → 真数据进诊断("台费周中下午掉 18%")。
⚠️ **POS 只读边界不破**：只读导出的文件，不连收银系统、不写回。

### ③ 主动 + 一条龙 — P1（"Agent 替我运营"的终极感）
- **主动**：早上自动备好今日该发内容、催未写日报、盯新差评提醒。
- **一条龙编排**：一句"搞个周末活动" → 自己依次 plan_activity→写文案→出海报→剪短视频→发 4 平台，**只在花钱/对外闸口停下问人**。

## 已建（桌面这轮）
全本地架构(Electron+本地FastAPI+SQLite) / 知识加密(prompts.enc) / 4平台发布 RPA / 视频剪辑 ffmpeg / 发布·剪辑 UI。打包 .dmg/.exe 进行中。

## 边界（不变）
POS 只读、不帮经营/组织级犯罪、个人微信不自动群发、第三方机构名脱敏、对外/花钱走审批闸。

## 建议落地顺序
打包收尾 → P0(本地动手 edit_report 旗舰 + 看数读POS + 对外互动回评论) → P1(主动+一条龙编排) → P2(RAG 本地内容库)。每加一类工具配决策 eval(选对工具/越权拒绝/审批触发)。
