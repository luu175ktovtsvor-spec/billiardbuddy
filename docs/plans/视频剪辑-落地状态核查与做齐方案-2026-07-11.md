# 视频剪辑 · 落地状态核查 + 做齐方案(调研地基)

> 📌 状态:🚧调研地基 · 2026-07-11 · owner 让先把地基搭好再讨论怎么做。本文 = 视频侧"到底实现了没、怎么接上、工作台怎么搭、Agent 对话怎么接入"的核查与方案。生图侧另见 `docs/子代理报告/2026-07-11-生图视频调研地基/`。

## 一、大白话结论(先看这段)

1. **门店拍的大多是 B-roll 环境片(不是口播),这条路才是主路** —— 旧调研早就定了(门店视频三类:①口播+B-roll穿插 ②纯氛围燃剪 ③纯口播少),owner 今天再确认一次。whisper 转写只对"口播"有料,对纯环境片没料、硬套会鸡肋。
2. **真正的 B-roll 五步剪辑,我们已经写好了、还测了,但没接进跑起来的功能里** —— 这是最大的一个"有实现、没接线"的洞。用户现在点出片,拿到的是**占位初剪**(把素材按顺序排一排 + 占位字幕),不是真五步剪辑。
3. **视觉理解(让 AI 真看懂画面,旧调研说的头号关键缺口)其实已经接上了** —— 走网关那颗多模态模型(mimo-v2.5 能识图),缺模型时优雅退启发式。不是没做。
4. **新前端(renderer-react)里视频工作台是零** —— 一行没接。工作台"怎么搭"是全新命题,得照创作引擎 v2 定的"模板/面板/预览为默认、对话为加速层"来。
5. **对话里还完全不能剪视频** —— 一个视频 agent 工具都没有(只有生图/改图工具)。"Agent 对话接入"要新建粗粒度工具接到引擎。

**一句话**:引擎的活儿八成干完了(两条管线、五步、VLM、渲染都在),**卡在"接线"和"工作台/对话入口"** —— 不是重造,是把已建好的接起来 + 搭壳。

## 二、门店视频三类 + 两条管线(确认旧调研仍成立)

| 类型 | 占比 | 走哪条管线 | 靠什么 |
|---|---|---|---|
| ① 口播 + 环境 B-roll 穿插 | 最常见门店宣传 | 混合(口播为骨 + 环境镜穿插) | 转写挑话 + 视觉判"哪段是环境/往哪插" |
| ② 纯氛围 / 燃剪 | 一大片、非小众 | **scene/beat-first(视觉+卡点)** | 切镜头→美学挑镜→VLM看懂→音乐卡点→叠字 |
| ③ 纯口播 | 少 | **audio-first(转写驱动)** | whisper 逐字 → 按话切 → 烧字幕 |

**两条管线必须干净分裂**(owner 旧口径,别揉一团):
- **audio-first(口播路)**:whisper 转写 → phrase 切 → 字幕。**甜区,已通。**
- **scene/beat-first(B-roll/氛围路)**:五步。**已建未接。**
- 模式**用户可选**(口播/氛围),不只自动判;**输出比例可选**(竖9:16/方1:1/横16:9/保持原片)。

## 五、Agent 对话接入设计(owner:视频怎么进对话,你考虑)

**照两条线铁律 + video-use 的 confirm-first 手艺:B 线引擎干帧级活,A 线 agent 只做粗粒度意图编排。**

- **新建两个粗粒度 agent 工具**(照 `edit_image` 那样薄封装 `startVideoJob`):
 - `plan_video`:入参 = 高层意图(素材路径[] + 目标时长/比例/风格/口播 or 氛围)。触发 `video_auto_plan`(→ planEdit 真五步)。返回 job id,agent 轮询拿到方案 → **用大白话向用户复述"我打算这么剪"→ 等确认**(video-use Hard Rule 11 / 创作引擎 v2 短链人确认)。
 - `render_video`:入参 = project。用户确认后触发 `video_render` 出片。返回成片路径。
- **为什么不做一步到位的 `edit_video` 全自动**:违反 confirm-first + 复利衰减(5步0.9⁵≈59%)。分两步、中间人确认。
- **出片不弹审批**(去钱味:出片=本地文件不算对外),但**方案要人确认**(质量决策,不是安全审批)。
- **资产门**:缺 ffmpeg/whisper 时工具返回"正在准备组件 x%"(已有 `gateMediaAssets`),绝不点了没反应。

## 六、工作台怎么搭(owner:工作台到底怎么搭)

**照创作引擎 v2 定稿(已被四路验证,别走回头路):默认=结构化面板+模板+预览,对话=可切换加速层;质量=确定性检查+用户一眼挑,不是 AI 自评。**

视频工作台建议形态(renderer-react 新建):
1. **选素材** → 导入本机视频(多选)。
2. **选剪法**(显式,不只自动判):口播 / 氛围 / 混合;**比例**(9:16 / 1:1 / 16:9 / 原片);目标时长。
3. **一键出方案**(调 planEdit)→ **预览时间轴 + 大白话方案说明**(切了几镜/用没用 VLM/卡点/字幕)。
4. **一眼挑 + 圈点微调**(确定性控制,非 AI 自评):挑段/删段/换字幕/换 BGM;对话框当加速层("把开头空镜去掉""配点节奏感")。
5. **出片预览** → 满意再导出 MP4。
- **对话/Agent 是叠加的加速层**,不是主入口;工作台面板保下限。

## 七、视觉理解(VLM)现状 —— 够不够用

- **已接**:`buildVlmModel` → `providerConfigFromEnv`(复用 agent 主模型 = mimo-v2.5,能识图),网关出口;`tagShots` 缺模型/含清晰人脸/解析失败 → 退启发式,不崩、不外传人脸。
- **和旧调研的差异**:旧调研建议专用 `Qwen2.5-VL-7B(Apache)`;现走 mimo-v2.5(一颗模型省事)。**待验**:mimo-v2.5 对"门店镜头判好看/够燃/是不是环境镜"够不够准 —— 真机拿门店片测一版再定要不要上专用 VLM。
- **人脸护栏**:关键帧含清晰人脸自动走离线启发式(不把人脸外传),对齐红线。
