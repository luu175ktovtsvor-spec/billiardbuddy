## 二、四个关键决策(开工前拍板 · 对应总文档 §10)

### H1 · 安全红线不能被 `/studio` 直连绕过 〔已定〕
- **核查确认**:`_SAFETY_REDLINE` 只注入 LLM 系统提示(`server/api/v1/agent.py:153-164` 定义、`:409` 注入),**服务层无任何红线过滤**。`poster_service` 仅有防注入检查(`check_input_injection`,`security_guard.py:92`);`video_service` **连防注入都没有**、零内容检查直送 Ark。`filter_compliance`(广告法绝对化词,`security_guard.py:109`)只被 `content_service` 用,没接生图/视频。
- **决定**:把红线判据抽成**共享模块**(`server/core/safety.py` 或扩 `security_guard.py`),让 ① LLM 系统提示 和 ② `/studio/*` 服务层预检 **同源**。`/studio` 每个入口(generate/edit/variations/i2v/compose)在调 service 前过一道**确定性红线预检**(性交易/赌博坐庄/未成年/绝对化广告词),命中就拒、回人话理由。**别让直连成红线后门。**
- **落点**:阶段2 建 `/studio` 时同步落地(不是事后补)。视频路径(`video_service`)顺带补上防注入 + 红线预检。

### H2 · 改图也慢(gpt-image-2 单张 5-10 分)→ 交互式编辑实为长任务 〔已定〕
- **核查确认**:`config.py:42` 注释「单张可能 5-10 分钟」、`openai_image_timeout=900`(`config.py:43`,`openai_image.py:125` 消费)。edit 与 generate 共用此超时。
- **决定**:工作室里**每个生图/改图/变体动作都走 media_jobs 异步**(提交即返 job_id + 进度 + 预计时间),**UI 不假装秒回**。这正是「先打地基(阶段1)」的理由——没有异步任务系统,工作室体验是假的。

### H3 · `/studio` 直连绕过「每轮≤4张」额度护栏 〔已定〕
- **核查确认**:≤4 张护栏只在 ReAct 工具层(`tools.py:565-570`/`:676-681` 的 `_images_generated_this_run`),**不在 service**;`poster_service.py:28-36` 是**并发信号量**不是 ≤4 cap(总文档此处归因有误,见 §3)。DB 配额 `check_poster_quota`(`poster_service.py:261`)仍在但粒度不同。
- **决定**:`/studio` 自带护栏——**变体张数上限 n≤4**、**改图限频**、**视频仍走人确认**;服务层复用 `check_poster_quota`。否则变体+反复改+视频会烧 paid API(gpt-image-2 / Seedance 都贵)。

### ffmpeg 许可(多镜合成)〔已定:先用、发版前换〕
- **核查确认**:`desktop/node_modules/ffmpeg-static` = **GPL-3.0-or-later**(`ffmpeg-static/package.json:37` 确证),不是 LGPL。它是**老 web 既有依赖**(`desktop/package.json` `ffmpeg-static ^5.2.0`,`asarUnpack`)。
- **决定**:阶段5 用现有 ffmpeg-static 把多镜合成跑通;**商用分发前(发版前)换成 LGPL build 或确认合规**——owner 选型铁规要「免费·商用友好 license」,GPL 有 copyleft 传染性。**列为发版前必办项(§6)**,不阻塞开发。

## 五、地基接口契约(开发前定好,M3/M5/M2/M1/M6 落实)

### 5.1 media_jobs 表(SQLite,经 `_reconcile_columns` 建)
建议列:`id`(PK)、`kind`(generate/edit/variations/i2v/compose)、`status`(queued/running/done/error)、`progress`(0-100 或阶段串)、`result`(JSON:产物 URL/generation_id 列表)、`error`、`conversation_id`、`store_id`、`params`(JSON)、`created_at`/`updated_at`。进度走 SSE 端点或轮询;完成推送复用通知机制。**单用户本地、in-process**,不引分布式。

### 5.2 /studio/* 接口契约(M3 · 绕 LLM 直连)
- `POST /studio/generate`:文生图。入参 prompt/style/ratio/materials → 出 job_id。
- `POST /studio/edit`:基于底图改(整张 or +mask 局部)。入参 base_image/mask?/prompt/n → job_id。
- `POST /studio/variations`:出 N 版(n≤4)。
- `POST /studio/i2v`:图生视频。入参 images[]/audio/ratio/duration/首尾帧 → job_id(视频仍走人确认)。
- `POST /studio/compose`:多镜合成(调 video.js)。
- **全部入口先过 H1 红线预检 + H3 额度护栏**;产物落 generations(带 `parent_generation_id`);中间产物按 §5.3 策略。

### 5.3 中间产物落库策略(M5)
变体/mask/多次改会刷爆 generations → **最终版落库 + 中间版临时**(不落库或标记临时、定期清),别撑爆表。

### 5.4 跨窗口成品同步(M2)
子窗(工作室)出成品 → 新 IPC 报主进程 → 主进程推 `mainWindow.webContents`(或 `BroadcastChannel`/storage 事件)→ 主窗「最近作品」刷新。

### 5.5 mask 格式(M1)
gpt-image-2 要「透明(alpha=0)=要改」;konva `toDataURL` 导出是「笔触不透明/背景透明」→ 加合成步骤**反相**:涂的区域→透明、其余→不透明,与原图同尺寸,再喂 `images.edit`。别直接拿笔触图当 mask。
