# A. 生图工作台设计

## A.1 布局(左控制 / 右预览)

在 task#17 的右侧 440px 面板 🎨 海报 tab 基础上,进入"专业编辑"态时把面板体分成 **左窄控制条 + 右大预览**(或面板"展开成整页 Tab" = cc `WorkbenchTab` 机制,给更大画布)。

```
┌ 生图工作台(海报 tab / 展开整页) ──────────────────────────┐
│ [控制条 · 左 ~200px]        │ [预览板 · 右 flex]              │
│  ● 能力档下拉(代称)         │   Quick Look 灰底取景          │
│  ● 比例 9:16/1:1/16:9       │   ┌──────────────┐            │
│  ● 张数 1/2/4               │   │              │  ← 框选高亮  │
│  ● 清晰度档                 │   │   当前海报    │    浮层     │
│  ● 风格档                   │   │   实际比例    │            │
│  ● prompt 输入框            │   └──────────────┘            │
│  ● [框选重绘] [叠加文案]     │   尺寸标:9:16 · 1152×2048     │
│                            │   版本条:v1 v2 [v3当前] ↺回滚  │
│  底部工具条:⤓保存到本机 · ✎基于此调整(refine)· ↻重新生成 │
└────────────────────────────────────────────────────────┘
```

- 预览 = 直接 `<img src="/uploads/posters/xxx.png">`(同源可读,`html2canvas` 不污染 canvas);灰底 `#ececf0` / 暗色 token 取景,底部尺寸标。配色全用 `--wb-*`。
- 框选浮层 = 复用 cc `preview-agent` 的 Shadow DOM picker,但目标是**坐标矩形**不是 DOM 元素(task#17 §2.4 第 4 条已定这条"位图 refine"落法)。
- 版本条 = 前端状态栈(每次 generate/edit 产出一个 `generation_id` + `poster_url`),缩略图横排、点选切换、回滚。

## A.2 图片调整交互分类表(每类:操作方式 → 发什么给后端 → 期望结果)

| # | 调整类 | 用户怎么操作 | 前端发什么给后端 | 期望结果 | 后端状态 |
|---|---|---|---|---|---|
| **1** | **整图 refine 重生** | 底部 `✎ 基于此调整` / 改 prompt 后 `↻ 重新生成`;滑块/下拉调比例·张数·风格档后触发 | `POST /api/v1/studio/edit`,body `{ source_generation_id, image_prompt(新指令), ratio, count, edit_type, input_fidelity }`(纯新图则 `POST /studio/generate`)→ 拿 `job_id` → 轮询 `GET /api/v1/agent/media-jobs/{job_id}` | 以当前图为底,按新指令整体重生一张,进版本栈成为新版本 | ✅**已有可用** |
| **2** | **局部框选重绘(inpaint)** | 在预览图上**拖出一个矩形框** + 写人话("这里字太小""换个背景")→ 点"重绘选区" | 前端把框选区域**画成一张黑白 mask PNG**(选区=白/透明可编辑,其余=黑)存到本机可读路径 → `POST /api/v1/studio/edit`,body `{ source_generation_id, mask_path, image_prompt, edit_type }` | 只重绘框选区、其余保持,进版本栈 | ✅**后端已有可用**(mask 同步/异步路径均支持:`mediaJobs.ts` L984-987 同步、L1088-1089 异步 GPT relay);⚠️**前端需自己生成 mask PNG**(canvas 画框→导出→存本机),这是前端活不是后端缺口 |
| **3** | **文案叠加编辑** | 在预览图上加/拖/改文字层(字号·颜色·位置·字体),所见即所得 | 见下"落法二选一" | 图上叠一层可编辑文字,导出时合成 | ⚠️**需补 或 纯前端**(现只有 print_mode 的 logo/二维码 ffmpeg 叠层,无任意文字叠加端点) |
| **4** | **关键参数调节** | 下拉/滑块:比例(9:16·1:1·16:9)、张数(1/2/4)、清晰度档、风格档、"改字"vs"改画面"档 | 复用 #1 的 `/studio/generate`\|`/edit` body 参数:`ratio` / `count` / `input_fidelity`(清晰度)/ `edit_type`(`text_fix`\|`content`)/ 能力档→内部 `image_model`·`image_provider`(**前端不显示模型名**) | 换参重生,即时反映 | ✅**已有可用**(路由逻辑 `routeImageModel` L844 已按 edit_type/比例/文字需求自动选档) |
| **5** | **版本对比与回滚** | 版本条缩略图横排,点选切换 A/B 对比,点旧版"设为当前" | `GET /api/v1/studio/generation/{generation_id}`(取某历史版本元信息/URL);回滚 = 前端切回旧 `poster_url` 作为下一次 edit 的 `source_generation_id` | 无损来回切、以任意旧版为底继续调 | ✅**已有可用**(`localGeneration` L744;每次生成回传 `generation_ids` L1212;回滚是前端状态,无需写后端) |
| **6** | **导出 / 保存到素材库** | 底部 `⤓ 保存到本机`;或"存进素材库" | 下载 = 直接取同源 `/uploads/posters/xxx.png`;存库 = 见下 | 图片落到本机 / 进素材库供复用 | 🟡**下载✅已有**;**存进素材库需补**(`/canvas/save-to-library` L2599 只吃**文本** `renderDeliverableBytes`,不复制图片二进制) |

### #3 文案叠加 落法(二选一,推荐 a)
- **(a) 纯前端 canvas 叠字(推荐,不动后端)**:文字层用 DOM/canvas 所见即所得排版,导出时 `html2canvas`/canvas 合成 PNG 再走 #6 下载/存库。理由:文字排版要实时预览、字体/换行/描边全在前端最顺,不必往返服务器。
- **(b) 新增 `POST /api/v1/studio/overlay-text` ffmpeg drawtext 端点**:后端合成、可批量。仅当要"服务器侧统一水印/批量套版"才值得,起步不必。

# B. 入口 + 对话联动 + 白标代称

## B.1 在 app 里怎么进入

生图工作台嵌进正在迁的 cc 式 React 前端(= 前端架构 §5 **Block H 我们特有**;右侧预览 = Block E 归口 task#17)。

- **生图工作台**:寄生在**右侧预览面板 🎨 海报 tab**。
  - 自动开:Agent 生图出结果 → task#17 已定 `renderEvent` 的 `tool_result` 识别 `poster_url`/`generation_id` → 自动 `openPreview('poster', {...})`。
  - 手动开:底部 `✎ 基于此调整` 进入"专业编辑"态(左控制条 + 右预览);或斜杠 `/生图工作台` 开空态;或原生菜单。

## B.2 与对话窗口怎么联动(双向)

- **对话产物 → 工作台**(发送到工作台):端口 cc `assistantOutputTargets`(正文认产物→卡片),生图认 `generation_id`/`poster_url` 作为联动锚点;卡片上"打开/发送到工作台"→ 载进生图工作台。
- **工作台直控**(主路径,不经大模型):可视化操作直接调 `/studio/edit`,**这就是 owner 要的"不必完全依赖大模型"** —— 用户拖一下、框一块、点一下就改。
- **工作台 → 对话**(可选,想让 Agent 迭代时):端口 cc `selectionComposer`,把"框选截图 + 备注"塞回对话让 Agent 循环生成(refine)。**运行中就 steer 插话、空闲就 run**,复用现有 WS 通道,不新开连接。
- **真相源同一份**:对话和工作台改的是同一份产物(海报文件+generation_id),两边看到的始终一致。

## B.3 白标代称(工作台绝不出现真实模型名)

生图能力档代称(前端下拉只显中文档名,前端映射到内部 `image_model`/`edit_type`/`input_fidelity`,真 key 网关藏):

| 档名(用户可见) | 内部映射(不暴露) | 用途 |
|---|---|---|
| 清晰写实档 / 硬字海报档 | seedream 系(硬字/写实/中文强) | 要清楚文字、写实场景 |
| 创意海报档 | openai 系(复杂创意) | 复杂创意构图 |
| 精修画面档 | edit `content` | 局部/整图改画面 |
| 改字档 | edit `text_fix` | 只改图上文字 |

注入脚本/文案不得带 Claude/Anthropic/cc-haha 字样;全局名可用中性名(如 `__QF_PREVIEW__`)。口径同 task#17 §2.5。
