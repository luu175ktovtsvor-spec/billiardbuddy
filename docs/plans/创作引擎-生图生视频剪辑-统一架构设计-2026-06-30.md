# 创作引擎统一架构设计（生图 / 生视频 / 剪辑）

> 📌 状态:🚧设计稿 · 2026-06-30 · 待 owner 评审 → 转 writing-plans 出实现计划 → 新分支开发
> **给执行窗口**:这是架构设计(WHAT/WHY),不是逐步实现计划。评审通过后用 writing-plans 把"阶段1(共享地基+生图)"拆成可执行任务。本文统一三件事:生图/生视频/剪辑不是三个 app,是一条流水线上 AI 编排的三个能力。

## 一句话
**一个"创作大脑" + 「物料→加工→成品」流水线 + 三层控制皮 + 一台所有层共享的质量引擎。** 保成品质量靠底下的质量引擎(强模型+铁律+AI自检重生),三层皮只是上面让用户介入的控制层。

---

## 0. 它在产品里的位置(别孤立看)
产品本体 = **强模型 + Claude Code 壳**(能读写本机文件、上网抓取、操作浏览器、写脚本、定时任务、派子代理…)。"创作"(图/视频/剪)是这个通用 Agent 的一个**重点领域**。
- 通用 Agent 默认"对话编排、可控性低"(owner 原话)——通用任务这样没问题。
- 但"创作"这块**要成品质量**,所以给它**单独加一层可视化控制(三层皮)**,把可控性和质量提上来;Agent 在别的领域照旧通用。
- 一句话:**我们不是把 Agent 改成画布,而是给"创作"这个领域配一套"可看见、可干预、能自检"的引擎+控制皮。**

---

## 1. 核心形态:物料 → 加工 → 成品 流水线

```
进料口(前置物料)                加工(AI编排·可串)              成品
┌─ 拖拽/选本机 图&视频 ─┐
│                       ├─→ [★物料质量门] ─→ 生图 ─→ 图生视频 ─→ 剪辑 ─→ 竖屏成片
└─ 没物料: AI文生图/文生视频造 ─┘        │           (文/图生图)  (让图动)   (片段剪成成品)
                                        └ 不够好→先过一道生图/图生图美化,再喂下一步
```

**1.1 进料口(owner 核心关切:前置物料怎么喂)**
- a. **拖拽/选择本机图片、视频**(最常用)——走本地路径,不走 2MB 上传老路。
- b. **没有物料** → AI 文生图 / 文生视频 凭空造。
- c. **★物料质量门(保质量的关键一环)**:AI 判断拖进来的图/素材够不够好。不够 → **自动先过一道生图/图生图模型美化**(如 Qwen-Image-Edit/Seedream 重绘),再把美化结果喂给视频模型/剪辑。这一步直接顶住成品质量,是整套设计最聪明的地方。

**1.2 加工 = 三个能力,前一个的产出 = 后一个的原料**
```
生图(文生图 / 图生图美化)  ──喂──>  图生视频(让图动起来)  ──喂──>  剪辑(片段→成品)
```
所以"合并"不是 UI 省事,是它们本就是一条流水线。

## 2. 三层控制皮(渐进暴露 · 默认 Tier1 · 业界验证过的 progressive disclosure)

| 层 | 形态 | 给谁 | 干啥 |
|---|---|---|---|
| **Tier1 初始(默认)** | 对话 | 95% 店主 | 说大白话 → AI 自主跑完 物料→加工→成品 + **自检重生** → 出成品。啥都不用调 |
| **Tier2 进阶(点开)** | 右侧可编辑面板 | 想微调的人 | 改关键项。**面板按能力分**(见下),共享一个壳、不同控件。这就是 owner 说的"可编辑控制台" |
| **Tier3 专业(藏二楼·后做)** | 节点画布 | 高级用户/代运营/owner | AI 搭好节点图、专家重连。物料/生图/生视频/剪辑都是可串节点。**非技术店主不碰** |

**Tier2 面板按能力分(回答"要不要给生图生视频分别做界面")**:
- 生图面板:提示词 · 尺寸 · **参考图(图生图)** · 模型选择 · 重绘强度
- 生视频面板:提示词 · 时长 · **首帧/参考图** · 运镜 · 模型选择
- 剪辑面板:片段时间线 · 字体(多款) · 配乐 · 字幕开关 · 重选片段
→ **分面板、不分 app**:对话入口一个,Tier2 面板各一套(因为可调的参数本就不同)。

**Tier3 节点画布(为什么这么定·有调研支撑)**:业界 2025-26 已收敛——完整节点画布(ComfyUI)对普通人"出了名劝退",**新范式是"AI 自动搭节点图 + 用户微调/审批"**(Krea/Dify/n8n 都这么做),外加"专家搭图+普通人只看简化表单"(ComfyUI App Mode)。所以 Tier3 = AI 搭、专家微调,藏在"高级"入口,**靠后做,绝不抢质量引擎的资源**。

## 3. 质量引擎(底座 · 三层共享 · ★保成品质量的真正所在)

> 关键认知:**三层界面保证的是"控制力",不是"质量"。质量由底下这台引擎保证,三层皮再漂亮、底子差就一起出垃圾。** 所以保质量的劲,80% 砸这里。

三样,缺一不可:
1. **用对模型**(质量大头,见 §4)。
2. **正确性铁律**:剪辑 16 条(字幕最后烧/不爆音/卡词边界/HDR转SDR…);生图的尺寸/参考图约束;生视频的真人合规等。破了=静默废片。
3. **★AI 自检重生循环**(最像"保证质量"的机关):
   ```
   生成 → AI 自己看成品(视觉判断:糊?跑题?变形?破绽?) → 不够好 → 自动重来(可多生几条挑最好) → 过关才给用户
   ```
   这条让 **Tier1(用户啥都不调)也能稳定出好货**;对生视频/生图这种失败率高的,"多生+自检挑/重生"就是质量杠杆。

---

## 4. 模型接入(百炼一把 key 兜底 + 直连高质量 + 中转顶配 · 前端可选)

**统一原则**:能收进**阿里云百炼一把 key**的尽量收;高质量档加直连的第二/第三家;前端 Tier2 让用户**自选模型**(默认 AI 选最优)。共用 key、走网关藏 key + 配额。owner 拍板体积/成本非约束,只求好用。

| 能力 | 默认/兜底(百炼一key·直连便宜) | 高质量档(直连·免中转) | 顶配(可选·不当主力) |
|---|---|---|---|
| **生图/图生图** | Qwen-Image-Edit / 万相(百炼·最便宜·中文文字最稳) | **Seedream 4.5(火山方舟·大陆直连·近第一梯队)** | gpt-image-2(美国中转·贵慢脆) |
| **生视频** | 万相/Vidu/可灵/PixVerse(百炼一key) | Seedance(火山) | — |
| 真人视频 | 万相数字人/Vidu参考生/可灵(允许真人·见记忆) | — | — |
| 本地转录(剪辑) | faster-whisper medium/large-v3(本地·已落地) | — | — |

> 关键更新:**"必须靠 gpt-image 美国中转才高质量"这个旧假设作废**——Seedream 4.5 大陆直连就能近第一梯队。gpt-image 降级成顶配可选,主流程不吊在中转上。

## 5. 落地顺序(先立标杆,再复制 · 别一份大文档糊)

1. **共享地基**:进料口(拖拽+本地路径) + 三层皮(先 Tier1/2 壳) + 质量引擎(自检重生框架) + 模型路由(百炼一key + 网关) + 物料质量门。
2. **生图引擎先插上**(最成熟、用得最多、owner 点3要它先落) → 把"三层皮+质量引擎"整套模式**跑通立标杆**(含图生图/拖图美化)。
3. **生视频、剪辑照同一套模式套上**(剪辑引擎已建一半:`server/services/video_edit/`)。
4. **Tier3 节点画布最后**(三者串成流水线)。

每一步交付即可独立验收(出真成品)。writing-plans 阶段先只拆"步骤1+2"。

---

## 6. 不操心 / 硬约束(owner 拍板)
- **不操心**:打包体积(全内置打进 DMG/EXE)、成本、依赖大小、Tier3 早晚。
- **唯一硬约束**:**运行得好 + 成品质量**。一切设计为这两条让路。
- **前端 UI**:owner 说到时叫改就改,不是质量瓶颈,不在此过度纠结。

---

## 7. 关键决策记录(避免反复)
- 三层皮=控制力非质量;质量靠底座引擎。**劲砸引擎。**
- 生图/生视频/剪辑=一脑三能力一流水线;对话合并、引擎各管质量、画布串流水线。
- Tier2 分面板不分 app。
- 节点画布=AI搭+人微调,藏二楼靠后,别抢资源。
- 物料质量门(图不够好先美化再喂视频)=保质量关键环,一等公民。
- gpt-image 中转降级为顶配可选,主力走 Seedream 直连 + 百炼兜底。
- 体积/成本非约束。
