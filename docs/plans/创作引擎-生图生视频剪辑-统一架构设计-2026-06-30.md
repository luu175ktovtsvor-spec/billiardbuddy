# 创作引擎统一架构设计 v2（生图 / 生视频 / 剪辑）

> 📌 状态:🚧设计稿 v2 · 2026-06-30 · **经四路验证(真实产品对照/质量机制核实/反方挑刺/模型)后大改**。v1 的"对话自主当默认 + AI 自评保质量"两条被论文+真实产品双重证伪,已倒过来。
> **给执行窗口**:这是架构设计(WHAT/WHY)。评审通过后用 writing-plans 把"阶段1(模板+面板+确定性质量+用户挑)"拆成可执行任务。

## 一句话
**默认走"场景模板+参数面板+预览"(保下限) + 对话/Agent 当可切换加速层 + 质量靠"确定性检查+用户一眼挑"(不靠AI自评)。** 节点画布是专家层放 V2。生图/生视频/剪辑是一条流水线上的三个能力(分面板不分 app)。

---

## 0. 验证结论(为什么 v1 大改 · 别再走回头路)

四路验证一致指出 v1 两处**致命错**:
1. ❌ **把"对话自主"当默认** —— 真实产品(Runway/Krea/Higgsfield/即梦/可灵/通义万相…)**默认全是结构化面板/模板**,对话/Agent 是 2026 才叠上去的可切换层、多在 beta,只有 Luma 拿对话当主入口。纯对话默认是被 NN/g、创作者复盘点名最多的失败形态(83% 用户因反复改 prompt 受挫)。
2. ❌ **靠 AI 自评保质量** —— LLM 无外部反馈**不能自纠**(LLMs Cannot Self-Correct, ICLR 2024)、自评有自夸偏差(arXiv 2410.21819)、VLM 对"手指畸形/文字糊/色漂"这类细节最不准。唯一全自动量产案例 OpusClip 爆款分被独立测评批"~40% 不可用"。

**站得住、保留的**:分面板不分 app(全产品验证)✅;节点画布给专家(放 V2·AI搭你调)✅;参数面板(其实该当默认)✅;编排脑是对的方向(2026 大厂抢着上)但**当叠加层不是地基**✅;审批闸(HITL)是关键资产✅。

---

## 1. 两条脊椎铁律(v2 的地基)

1. **默认 = 结构化模板/面板 + 预览,不是对话。** 学 Canva——用模板/约束**牺牲上限换下限有保障**,这是非技术用户稳定出好货的唯一可靠路。对话/Agent 是叠在上面的**加速层**,不是地基。
2. **质量 = 确定性检查 + 用户一眼挑,不是 AI 自评。** 把现成的审批闸(人确认)从"对外动作"**扩到"质量决策"**——人挑,不是 AI 自判。一招同补"自评不准 + 控制感缺失 + 复利衰减"三洞。

---

## 2. 架构

### 2.1 默认形态:场景模板 + 参数面板 + 预览
- 店主进来**不是空白对话框**,是"你想做啥?"→ 选一个**台球房场景模板**(十来个:开业海报/促销活动/助教招募/赛事预告/探店短视频/会员卡/节日祝福…)。
- 模板把约束做满(尺寸/风格/版式/**精确元素占位**),店主只填几个空(店名/日期/电话/上传图)→ 预览 → 出。
- **下限有保障**(Canva 验证:约束+默认值替代设计能力)。范围先锁这十来个场景,自由创作留专家层。

### 2.2 对话/Agent = 叠加加速层(可切换,非地基)
- 模板没覆盖/想偷懒 → 切到对话,AI 帮串流水线(生图→图生视频→剪辑)。
- **但短链 + 人在交接口**(防复利衰减:每步 90%,5 步 0.9⁵≈59%):Agent 出"计划"(像 Krea Node Agent)→ 审批闸确认 → **每步之间用户一眼选/确认** → 继续。**不一口气跑到底、人不插手**(创作者要在每个交接口接管=优点不是缺点)。

### 2.3 质量机制(★不靠 AI 自评)
1. **确定性检查**(机器能判的硬指标):分辨率够不够、人脸畸形检测、OCR 比对烧的文字有没有串字、色差阈值、精确元素齐不齐。
2. **生成多条→用户一眼挑**:图片生 2-4 条让店主选一条(把审批闸用在这);**视频因成本/时长高 → 只 1 条 + 失败重试 1 次**(best-of-N 不套视频)。
3. **精确元素不让模型画**:电话/地址/二维码/价格 → 确定性叠层/模板占位(项目已有此教训,见记忆)。
4. **AI 自检设硬上限**:若用 VLM 做粗筛,只用**两两对比挑**(不用绝对打分)、最多 1-2 轮、且必须有外部信号(用户选择/规则分),不无限自我重生烧 token。

### 2.4 物料入口 + 物料质量门
- 入口:**拖拽/选本机图&视频**(走本地路径) + 模板里上传 + AI 文生图造。
- **质量门只做"非生成式增强"**(超分/降噪/修复·保内容,安全);**生成式重绘**(改内容、可能换脸)**绝不静默做**——对真人助教/门店照=改身份+撞真人脸红线;要做必须 before/after 给用户确认。

### 2.5 可视化干预 = 两层(不是三层)
- **消费层**(默认):场景模板 → 参数面板(每能力一套:生图调提示词/参考图/尺寸/模型;生视频调时长/首帧/运镜/模型;剪辑调片段/字体/配乐) → 对话加速。**分面板不分 app。**
- **专家层**(V2·靠后):节点画布,**AI 搭好图、专家重连**(Krea/Flora 范式),给代运营/owner/极少数。非技术店主不碰。

## 4. 落地顺序(先把"保下限"那套做扎实)
1. **模板引擎 + 参数面板 + 确定性质量检查 + 用户挑**(消费层默认,下限保障) —— **先做这块,这是产品立得住的根**。
2. **生图能力**插进去(最成熟、用得多),含图生图/拖图、确定性精确元素叠层。
3. **生视频、剪辑**照同一套模式套上(剪辑引擎已建一半:`server/services/video_edit/`)。
4. **对话/Agent 编排层**叠上去(可切换,短链+交接确认)。
5. **节点画布专家层**放 **V2**。

## 5. 关键决策记录(避免反复 · v2)
- **默认是模板/面板不是对话**(对话当加速层)。← 推翻 v1
- **质量靠确定性检查+用户一眼挑**,审批闸扩到质量决策。**不靠 AI 自评。** ← 推翻 v1
- 短链+每步人确认(防复利衰减),不一口气自动跑到底。
- 范围先锁十来个台球房模板场景(Canva式约束保下限),自由创作留专家层。
- 两层(消费↔专家),节点画布放 V2。
- 分面板不分 app(验证最稳)。
- 精确元素不让模型画(确定性叠层);生成式重绘真人照必须确认。
- 模型:百炼一key兜底+Seedream直连+gpt中转顶配可选。
- 体积/成本非约束(owner 拍板),只求好用。
