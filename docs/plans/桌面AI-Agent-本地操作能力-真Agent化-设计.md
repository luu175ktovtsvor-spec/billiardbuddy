# 桌面 AI Agent · 本地操作能力（真 Agent 化）— 设计

> **质变定位（2026-06-18 用户拍板方向）**：从「内容生成器」(AI 写好、你复制/下载) → 「本地操作者」(AI 直接在你电脑上动手：改它生成的报表、管你的素材、跑本地流程)。这是**桌面+本地形态唯一能给、云端给不了**的能力——云端碰不到你的文件。"它真替我把事办了"的感觉，才是 AI Agent 的质变。

## 1. 已具备的地基（不重造）
- **ReAct 循环 + 工具调用**：`server/services/agent/loop.py`（think→调工具→结果回灌→再推理）+ `tools.py`（工具注册）。加新工具即可扩能力。
- **知识库（已加密）**：`prompt_pack.py` 注入台球行规，让"改报表/写内容"懂行不瞎改。
- **审批闸**：对外/花钱动作已走"备好→人点确认→才执行"。本地写/删文件复用这套。
- **Electron IPC 桥**：`desktop/src/preload.js` 的 `window.electron.*` 白名单。本地文件操作经此暴露给前端、由主进程执行。
- **BYOK**：店主自带 key，本地直调大模型。

## 2. 新增：本地操作工具集（desktop-only，经 IPC）
仅桌面端可用（检测 `window.electron`）；每个写/删类工具标 `requires_approval=True`，走审批闸。

| 工具 | 作用 | 审批 |
|------|------|------|
| `read_local_file` | 读取用户当场选定的文件（Excel/文本/图片元数据） | 否（只读） |
| `list_content` | 列/搜 app 管的内容库（生成过的文案/报表/海报/视频） | 否 |
| `write_file` | 把生成的内容/报表写到本地文件夹 | 是 |
| `edit_report` | **旗舰**：直接在已生成的 .xlsx 报表里按指令改（openpyxl 读改写） | 是（给 diff） |
| `organize_files` | 整理/重命名/归档素材文件夹 | 是 |
| `run_publish` / `run_edit` | 发布(RPA)/剪辑(ffmpeg)——**已建** | 是 |

## 3. 旗舰场景：报表直改（先做这个，把"智能操作"感觉立住）
日报已生成 Excel(openpyxl)。桌面升级：
1. AI 把报表**直接生成到本地文件夹**（不只给下载）；
2. 店主一句「把今天营业额改成 8600、加一列各助教提成」→ AI 调 `edit_report` **直接改那个 .xlsx**；
3. 改完**呈现 diff（改了哪几个单元格/加了哪列）→ 人点确认才落盘**；
4. 改前自动备份原件（可回滚）。

## 4. RAG 用在对的地方
- **不用**在 171 条策展模板上（小、关键词 `_select_knowledge_keys` 够准）。
- **用在店主自己越攒越多的本地数据**：生成历史、报表、效果好(feedback)的内容、店脑记忆。本地向量库（如 sqlite-vec / 本地嵌入或 BYOK 嵌入 API）→ 语义检索「找我上次那条周末效果最好的文案」「上月助教提成怎么算的」。本地数据越厚，RAG 越有用——这才是它的战场。

## 5. 安全架构（能操作电脑 ≠ 放任乱翻）
- **审批闸**：写/删/改文件先给 diff、人点确认才动手。
- **范围锁死**：只动 ① app 管的内容库文件夹 ② 用户当场选定的文件。**绝不漫游全盘、不碰系统文件**。每个路径过 `_validate_path`（必须在白名单根下，拒绝 `..`/绝对越界）。
- **可回滚**：改文件前留原件备份到 `.billiards-desktop/backups/`。
- **只读默认**：读类工具无需审批；一切有副作用的都过闸。

## 6. 实现路径
1. `server/services/agent/local_tools.py`（新文件）：本地操作工具定义 + 路径校验 + 审批标记。
2. 注册进 `tools.py` 的工具表（仅当后端运行在桌面本地模式 `DESKTOP_LOCAL=1` 时启用）。
3. `desktop/src/localfs.js`（新）：主进程侧文件读写/openpyxl 调用（或经后端 sidecar 直接做，因后端就在本地）。
4. 前端：审批卡片渲染 diff（复用现有 approval_request 卡片）。
5. eval：给本地操作工具加决策 eval（选对工具/越权拒绝/审批触发）。

> ⚠️ **边界不变**：POS 只读、不帮经营/组织级犯罪、个人微信不自动群发。本地操作只服务台球运营内容/文件，不做通用电脑代操。
