**顺序**:①飞书骨架(1-2 天,官方 SDK 依赖 + 移植 adapter 接我们循环)→ ②微信 ClawBot(2-4 天,移植 protocol.ts;注意灰度放量/仅私聊/一号一实例)→ ③企微(备选,不急)。固有属性要向用户说清:电脑关机 = IM 里管家离线。

## 任务3 剪视频优化(架构已对路,补体验)

**结论**:「plan JSON 真相源→渲染」判定完全对路(OTIO/Shotstack/剪映草稿全这模式)。文字稿驱动(Descript 模式)只适用口播;氛围模式最优形态 = 候选片段宫格+勾选重排;病毒分不可信、人挑保底(与既有「确定性检查+用户一眼挑」互证)。
