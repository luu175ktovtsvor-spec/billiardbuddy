## 1. 架构决策(已定)

> **⚠️ 架构定调(2026-06-18 用户拍板)：做成「全本地·装了就用」——后端也打包进安装包、跑在用户自己电脑上,不依赖我们的云服务器。** 理由:① 用户要"自己拥有的软件"体验(装完整个在本地、我们服务器挂了也能用、数据是他自己的);② BYOK 天然吻合(每店自带 key,key+数据留本机、不经云中转、我们零服务器成本、无单点故障);③ 发布 RPA 本就在本地跑,全本地最干净。代价=多做"后端 PyInstaller sidecar + DB 换 SQLite",但这是对的地基,先连云后搬本地=返工。

| 决策点 | 选型 | 理由 |
|--------|------|------|
| 桌面壳 | **Electron** + 打包本地 standalone Next.js 前端 | 调研黄金参考 every-pdf(1229★);spa5k 证 App Router 用 `output:'standalone'` 整进 Electron(我们部署已是 standalone,复用产物) |
| 前端 | **本地 standalone Next.js(打包进 app)** | 本地起 node 跑 standalone server,Electron loadURL 本地端口;断网 UI 不白屏 |
| 后端 | **本地 FastAPI sidecar(PyInstaller --onedir 打进安装包)** | 全本地:内容/Agent/店脑全在用户本机跑;抄 every-pdf 的 build_backend.js + 动态 PORT + crash 自重启;server/main.py 业务零改,只改"部署形态" |
| **数据库** | **本地 SQLite(aiosqlite)** | 桌面 sidecar 不连任何远端库。PG 专属差异已按方言兜底:JSONB→JSON(SQLAlchemy 跨库类型)、UUID→跨库类型、pg_advisory_xact_lock→SQLite 单写无需(no-op)、用 create_all/`db/init_local.py` 建库。单店单用户、并发极简 |
| **知识库(护城河)** | **加密打包(Fernet),只下发 `prompts.enc`、不下发明文 YAML** | 知识库是产品命根子(本轮做成 PPT 真实运营逻辑)。明文塞包=同行解包抄走。打包时全部模板加密成一个二进制块(乱码),运行时内存解密(`prompt_pack.py` build_pack/load_pack;PromptEngine 优先解密加载;dev 不设 key 走明文不变)。抬高门槛、非绝对不可破(客户端加密 key 在包里);将来要更狠可改"激活时从云端拉加密包",load_pack 接口不变。**安装包体积:知识库才几 MB,体积是运行时(Python/Electron/Chromium/ffmpeg)撑的 ≈ 几百 MB,此类软件正常** |
| 发布(RPA) | **fork/借鉴 dreammis/social-auto-upload(12.7k★)** 作本地发布内核 | "小豆芽式一键多平台",每平台一 uploader(抖音/快手/视频号/小红书),headless+CLI+agent 友好;Electron child_process 驱动,不重造 |
| 发布反检测 | **patchright(非无头)+ 真人化延迟 + 单店自有号 + 扫码登录 + 人确认** | 官方 create_video API 资质门槛太高走不通;RPA 半自动+人确认正好规避"代发布"红线;符合既有审批闸原则 |
| 剪辑 | **ffmpeg-static + child_process.spawn**(不用已归档 fluent-ffmpeg) | short-video-factory 实证;asar 要 asarUnpack 二进制 |

**一句话架构**：一个安装包 = Electron 壳 + 打包的 Next.js 前端 + 打包的 FastAPI 后端(本地 SQLite) + 本地原生层(发布 RPA worker + ffmpeg 剪辑)。全跑在用户电脑上,用户纯 BYOK 自带 API key 直接调大模型(没配 key 即空 key、绝不回退平台、空 key → 友好 503);RAG 用 bge-zh 本地语义(fastembed/onnxruntime,非 pgvector);AI Agent 本地出内容 → 本地发布(扫码登录+人点确认)。我们不为门店维护服务器。

## 2. 关键技术要点(调研验证,落地照抄)

- **进程隔离**：浏览器自动化(patchright)放 Electron **主进程的独立 worker 子进程**,绝不放渲染进程(multi-publisher/oba-live-tool 都这么隔离)。
- **抖音网页发布流程**(creator.douyin.com 现状,已验证)：打开→抓二维码 img 给用户扫→轮询跳转 creator-micro/home 判登录→`storage_state` 存 cookie JSON→上传页 `content/upload`→file input 投喂视频→填标题/话题/封面→发布。⚠️ publish 页有 v1/v2 两套 URL 要双兼容;选择器集中管理+失效告警(平台改版会失效)。
- **IPC**：preload `contextBridge.exposeInMainWorld` 暴露白名单 `window.electron.publish.*` / `window.electron.video.*` / `window.electron.api.*`;双向用 `ipcRenderer.invoke`↔`ipcMain.handle`;进度(扫码就绪/发布进度/ffmpeg 进度)用 `webContents.send`→`ipcRenderer.on`。安全默认全保持(contextIsolation 开/sandbox 开/nodeIntegration 关,远程内容绝不开 nodeIntegration)。
- **ffmpeg 打包**：`ffmpeg-static` + 运行时路径 `app.asar`→`app.asar.unpacked`;electron-builder asarUnpack 含二进制。
- **签名**(分发前):mac Apple Developer $99/年+notarytool 公证;win EV 证书或 Azure Trusted Signing。**内测可暂不签**(用户手动放行)。

## 3. 分阶段开发计划

### P1 · 全本地地基 + 抖音发布 MVP（"装一个包 → 本地出内容 → 本地发抖音"）
> 全本地后,后端是地基,先让它本地+SQLite 跑起来,再壳、再发布。
1. **后端本地化 · DB 换 SQLite**(最大坑,优先)：models 的 JSONB→跨库 JSON、UUID→跨库类型、advisory_lock→SQLite no-op;config 加 `DATABASE_URL=sqlite+aiosqlite`;建库走 create_all 或 SQLite 迁移。本地起 `uvicorn` 验证全 API 通(pytest 绿)。**可拆子代理。**
2. **后端打包 sidecar**：`desktop/scripts/build_backend.js` 调 PyInstaller `--onedir`(hidden-import 列齐 uvicorn/starlette/Pillow…);main.py 启动打动态 `PORT=`。
3. **前端打包**：`web/` `output:'standalone'` 产物 + Electron 内起 node server;`NEXT_PUBLIC_API_URL` 指向本地 sidecar 端口。
4. **Electron 编排**(`desktop/`,骨架已搭)：main 起后端 sidecar(解析 PORT)+ 前端 server → loadURL 本地;crash 自重启。preload 白名单 IPC 已定。
5. **发布 worker**：fork/嵌入 social-auto-upload 抖音 uploader(Python+patchright),`desktop/publisher/`,Electron child_process 调(协议已在 publish.js 定)。
6. **扫码登录 + 发布 UI**：worker 抓二维码→IPC 推前端展示→扫码→cookie 加密持久化;web 前端加"发到抖音"面板(检测 `window.electron` 才启用),AI 生成视频/标题/话题 → **人点确认才发**(审批闸)。
7. **Agent 接入**：`make_platform_content` 出抖音脚本 → "发布"handoff → 本地发布。

### P2 · 多平台 + 本地壳优化
- 复用 social-auto-upload 的 快手/视频号/小红书 uploader,一条内容多平台发。
- 本地 standalone Next.js(断网不白屏)。定时调度/多账号管理。

### P3 · 视频剪辑
- ffmpeg 基础(裁剪/拼接/竖屏转码/烧字幕/Logo水印/变速)。
- 后续 AI 辅助(whisper.cpp 自动字幕/自动卡点/AI 混剪)。
