> 📌 状态:✅现行 · 最后核对 2026-07-12 · 施工地图:做完一块勾一块,整体落地后本文档退场。

## 一眼结论

1. **方法**:解包 `/Applications/ChatGPT.app` asar,提取 `zh-CN` 语言包全部 **9697 条文案 key**,按前缀聚类 = Codex 前端全功能地图(每个 UI 元素都有文案,key 数 ≈ 功能复杂度)。这比看截图/CSS 完整一个量级——**截图只能看到打开过的界面,i18n 能看到全部界面**。
2. **我们的对齐度**:外壳/对话流/斜杠浮层/权限/diff 红绿/终端等主干已对齐;但 Codex 前端的"长尾体验"(消息排队、工具活动人话摘要体系、线程头动作、通知收件箱、首启引导、线程内浏览器、附件体系、语音、子代理面板…)**大面积缺失**,详见差距矩阵。
3. **资产沉淀现状**:档案是「按需摘录」不是全量镜像——已沉淀 8 份规格文档 + 1834 条 token + 6 份 CSS + 9 截图;asar 里**还有 24 个 CSS 文件、全部组件 JS(可反混淆读,06 篇已验证方法)、48 语言 i18n** 未搬。结论:**不必全量搬**,沉淀"解包方法 + 资产索引"(已补进档案 README),施工哪块挖哪块。

## 方法与数据源(可复现)

```bash
npx @electron/asar extract /Applications/ChatGPT.app/Contents/Resources/app.asar <目标目录>
# 功能地图:webview/assets/zh-CN-*.js 提取 "key":`值` 对,按前缀聚类
# 组件规格:grep key 找到组件 bundle(排除 locale 文件)→ 定位函数 → 反混淆阅读(06 篇全程示范)
```

主 bundle:`webview/assets/app-initial~app-main~new-thread-panel-page~…js`(~8.8MB,composer/对话流/斜杠/审批都在);数字 = 该模块 i18n key 条数。
