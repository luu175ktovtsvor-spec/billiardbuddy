# 生图 · 能力细分 + 工作台 · 做齐方案(调研地基)

> 📌 状态:🚧调研地基 · 2026-07-11 · owner 要先把地基搭好再讨论怎么做。本文 = 生图侧"能力细分/门店刚需/我们缺什么/竞品工作台怎么做/我们该怎么搭"的合成结论。原始底稿:`docs/子代理报告/2026-07-11-生图视频调研地基/`(①生图细分 ②竞品工作台,来源逐条标注)。视频侧另见 `docs/plans/视频剪辑-落地状态核查与做齐方案-2026-07-11.md`。

## 一、大白话结论(先看这段)

1. **店主真正的生图刚需就 6 样,我们已经有 5 样的"能力",但缺"工作台"这个壳** —— 能力谱系里花哨的一大堆(试穿/电商白底/Logo/训模型/节点画布…)对台球房都是鸡肋,别做。
2. **业界生图工作台早就不是"一个输入框"了,统一收敛成三段式**:提示词+少量参数 → **一次出几张挑一张** → **就地圈选改图/扩图/放大/换背景**。参考图(锁风格锁人物)、局部重绘、扩图、放大是标配。
3. **我们现在正卡在"纯对话生图"这一档**(=ChatGPT/Gemini 把生图当聊天里一个能力)—— 只有对话入口、**没有结构化工作台**。竞品验证:**默认都是结构化面板/画布,对话是 2026 叠上的可切换加速层,没一家用纯聊天取代默认**(Krea 官方:agent 叠在画布之上、不取代它)。
4. **补能力上,该补 4 样(都在"有用"档,非刚需但印刷/交付会用到)**:超分放大(印刷会糊,最该补)> 抠透明PNG > 修脸/人像修复 > 扩图。**都能照现有 whisper/ffmpeg 那套"资产后台下载 + 原生 sidecar"模式挂,不引 Python。**
5. **和视频侧同一个结论**:该搭的是 **B 线确定性工作台(默认)+ A 线对话入口(加速层)**,两条线用"给工具/塞 prompt/后端直调"相接。生图、视频、剪辑三个工作台同构。

**一句话**:生图的"能力"我们不缺主力,缺的是**工作台这个壳**(把生图从"聊天里蹦一张"变成"面板起步→挑图→就地改")+ 4 个印刷/交付级增强。

## 三、竞品工作台三段式范式(底稿②·15 款产品)

覆盖国内 7(即梦/可灵/通义万相/LiblibAI/美图设计室/稿定/Canva中国)+ 国际 8(Midjourney/Krea/Leonardo/Playground/Firefly/Ideogram/Recraft/Canva Magic Media),每款 ×5 维度、逐条标来源。收敛出的通用范式:

```
① 起步:提示词框 + 少量参数(比例/风格/数量/模型)+【模板/预设填空】(小白友好)
② 出图:一次出 2-4 张 → 网格 → 用户【一眼挑一张】
③ 就地改:选中一张 → 圈选局部重绘 / 扩图 / 放大 / 换背景 / 出变体 /「基于这张再改」
   ↑ 参考图(锁风格锁人物)贯穿全程
```

- **默认 = 结构化面板/画布**;**对话/Agent = 2026 叠上去的可切换加速层**(2026-07 仍成立,没一家反过来)。
- 另有 **ChatGPT/Gemini 纯对话阵营** = 通用助手把生图当聊天一能力 —— **正是我们现状**;竞品共识是"工作台与对话并存,不是二选一"。

## 四、纯对话 vs 结构化工作台(2026-07 结论确认)

| | 纯对话生图(我们现状) | 结构化工作台(竞品默认) |
|---|---|---|
| 起步 | 打字描述 | 模板填空 / 面板,小白也能起 |
| 挑图 | 蹦一张、要改再说 | 出几张一眼挑 |
| 就地改 | 说"再改改"、来回打字 | 圈选/放大/扩图/换背景,所见即所得 |
| 适合 | 顺手来一张、Agent 编排 | 非技术用户稳定出好货(创作引擎 v2 铁律) |

**结论**:两者并存最优。我们**有对话(A 线)、缺工作台(B 线)** —— 该补的正是工作台。

## 五、我们该怎么搭(结论 · 与视频侧同构)

**搭 B 线确定性生图工作台(默认)+ 保留 A 线对话入口(加速层),两条线用三种廉价方式相接(给工具/塞预定义prompt/后端直调),中间绝无"把产品逻辑织进循环"的层。**

生图工作台建议形态(renderer-react 新建,对齐创作引擎 v2 + 三段式):
1. **起步**:提示词框 + 参数面板(比例/风格/数量/模型内部选,前端不显模型名·白标)+ **台球房模板填空**(海报/活动/助教人设/朋友圈九宫格,先锁十来个场景保下限)。
2. **出图**:一次出 2-4 张(视频贵→1张+重试)→ 网格 → **用户一眼挑**(确定性质量把关,非 AI 自评)。
3. **就地改**(选中一张):
   - **局部重绘**:前端**涂抹/圈选生成蒙版**(补上缺的 UI)→ 走 edit_image mask。
   - **放大**(超分)/**扩图**(outpainting)/**换背景**(抠图)/**出变体**(接死类型 variations)/**基于这张再改**。
   - 参考图(锁风格/锁人物)贯穿。
4. **对话框当加速层**叠在工作台上("把背景换成球房""字再大点"),不是主入口。

> ⚠️ "基于这张再改"的可视化台(圈点/涂抹)owner 之前说暂挂等 Codex 逆向文档;本节先把**后端契约 + 工作台骨架**定清,可视化交互细节等文档到位再落。

## 七、和视频侧合并看:一个统一架构

生图 / 视频 / 剪辑三个工作台**同构**,都是:
- **B 线确定性工作台(默认)**:面板 + 模板 + 出多个挑一个 + 就地改/预览。
- **A 线对话入口(加速层)**:粗粒度工具(生图 generate/edit_image;视频 plan_video/render_video),模型编排,人握方向盘确认。
- **质量 = 确定性检查 + 用户一眼挑**,不是 AI 自评。

**下一步该讨论的"怎么做"**:先补能独立推进的后端能力(视频接线 planEdit + 生图 4 增强 + 死类型),再进前端阶段搭三个同构工作台。owner 拍板顺序。
