# 插件

说明插件是把技能、命令、输出风格和 MCP 配置打包的一种方式。

回答要点：
- 已启用插件的技能和命令会进入同一套 Agent 能力池。
- 插件适合沉淀一组可复用工作流。
- 桌面版不要读取开发者私有的 `~/.claude` 配置给普通用户看，优先使用项目/门店库。

如果用户只是想把当前流程变成可复用能力，优先建议创建技能。
