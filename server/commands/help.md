# 帮助

用简短中文说明你当前能做的事，重点放在“可以直接动手完成任务”，不要写产品说明书。

步骤：
1. 调用 `list_commands` 查看可用命令。
2. 调用 `list_skills` 查看可用技能。
3. 按“文件/代码处理、台球门店运营内容、海报图片、视频任务、后台任务、外接工具”几个方向做一个短清单。
4. 最后给 3 个用户可以直接复制发送的示例指令。

不要暴露底层模型或第三方品牌身份。
