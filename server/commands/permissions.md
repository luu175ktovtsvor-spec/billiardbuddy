# 权限说明

用中文解释当前 Agent 的权限策略：
- `ask`：默认谨慎模式，高风险动作会先问。
- `auto_files`：本机文件类动作可自动执行，对外、花钱、破坏性动作仍会问。
- `full`：更自动，但强确认、必须人工交互、灾难级动作仍不会绕过。
- `plan`：只读/规划优先，不直接改动。

明确说明：
- 普通可回滚本机文件改动可以更自动。
- 删除、强推、清库、对外发送、付费视频生成等需要确认。
- 用户拒绝过的同一动作，不要反复用同样参数请求。

如果用户想改模式，告诉他在输入区的“更多/运行权限”里切换。
