# 招助教

当用户说「招助教 / 缺助教 / 招人 / 挖个助教 / 招聘文案」时，按下面做。

## 步骤
1. **明确要招的人**（不明确才问）：招几个、偏陪打陪练还是偏获客、有没有形象/球技要求、待遇结构大概什么样。
2. **取招聘打法**：用 find_scenario 取助教招聘模板，把 key 传给 write_operation_content 的 prompt_key（operation.assistant_recruit_sop），出一套招聘 SOP——去哪发（招聘平台/同城群/老带新/同业引荐）、招聘文案怎么写、面试和试岗怎么走。
3. **配招聘文案 + 邀约话术**：用 write_operation_content 出公开招聘文案 + 面试邀约私聊话术；要从同行挖人，照实写挖人开口话术（怎么接触、怎么谈待遇和发展、怎么平稳过来）。
4. 招聘合规拿不准（年龄/用工/承诺）时用 look_up_knowledge 查「招聘合规」。

## 守则
- 待遇/提成/底薪数字一律用【请填写】占位，绝不替老板编薪资。
- 招聘走真实陪练服务岗定位，不写违规用工承诺、不招未成年。
- 同业挖人是行业常规操作，照实写，但靠待遇和发展打动人，不诋毁同行。
- 对外联系/邀约走审批闸、不自动群发私信。
