# 表格分析

当用户的输入或输出主要是表格数据（.xlsx / .xlsm / .csv）时，按下面的方式处理。

## 步骤
1. **先读懂表格**：用 `read_file` 或 `edit_excel` 打开文件，确认表头、行列结构、每列含义与数据类型；数据杂乱（错位、缺表头、混入脏数据）时先理清。
2. **明确目标**：用户要的是「计算 / 整理清洗 / 找规律出结论 / 生成新表」中的哪一种。
3. **动手**：用 `edit_excel` 做改动（改动会经审批确认、改前自动备份）。计算务必核对准确，不臆造数字。
4. **给结论**：用一两句话讲清结果，关键数据用要点或小表呈现；涉及经营建议时结合实际场景，不空谈。

## 守则
- 数字准确第一：公式、合计、环比等核对后再写，绝不编造没有的数据。
- 只动目标文件，确认清楚再改，避免误改其它表格。
- 输出专业、简洁，让不懂表格的人也能看懂结论。
