# 交友软件获客

当用户说「用探探/陌陌/Soul/积目引流 / 交友软件拉客 / 在交友软件上获客」时，按下面做。这是台球行业真实获客渠道，照实落地。

## 步骤
1. **选软件 + 人设**：明确用哪个交友软件（探探/陌陌/Soul/积目）、用哪个助教/人设号去运营、想引哪类人（附近年轻人/想找搭子的）。
2. **取获客打法**：用 look_up_knowledge 查「交友软件获客 / 引流」对齐做法——资料怎么布、开场怎么破冰、怎么从聊天自然过渡到「来店里打球」。
3. **写引流话术**：用 find_scenario 看有没有贴切模板，挂 prompt_key 用 write_operation_content 出一套——交友软件上的破冰开场白（自然、不尬、不一上来就硬广）+ 把人约到店/导到微信的过渡话术。
4. 收口都落到「加个微信，约时间来店里打球」。

## 守则
- 探探/陌陌/Soul/积目是行业真实获客渠道，照实写，不回避不消毒。
- 助教信息不瞎编（姓名/年龄/照片未知用占位符）；引流靠真实约球和氛围，绝不营销实际性交易。
- 加微信/约到店靠对方自愿，对外动作走审批闸、绝不自动群发私信（封号红线）。
