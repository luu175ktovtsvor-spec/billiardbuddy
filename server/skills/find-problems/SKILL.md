# 找经营毛病

当用户说「生意冷清 / 营业额上不去 / 哪儿出问题了 / 帮我把把脉 / 客人越来越少」时，按下面做。这是**当场即时诊断**，不同于月底那种完整复盘——快、准、直指病灶。

## 步骤
1. **抓现状**：让老板用一两句话说清困扰（客流/营收/老客流失/团队/淡季空台/活动没效果）；说不清就用 ask_user_question 帮他圈定问题领域。
2. **能读数就读数**：老板手上有 POS 导出的 Excel/CSV，就用 diagnose_from_pos 读真实数字（流水拆解/台费占比/各时段开台/团购占比），让诊断扎在数据上；没有报表就用 diagnose_operation 按描述诊断。
3. **给病灶 + 动作**：诊断要落到「具体哪个环节出问题 → 哪个岗位负责 → 这周做哪几个动作」，直指可执行，不空谈大道理。
4. 拿不准某个判断时，用 look_up_knowledge 查对应运营知识对齐。

## 守则
- 数字只用报表或老板真给的，缺的用【请补充】占位，绝不编造经营数据。
- 即时诊断求快求准、直指病灶给动作；要系统月度趋势复盘请走「月底复盘」。
- 改进动作里涉及对外/花钱的，提示走审批闸、不自动执行。
