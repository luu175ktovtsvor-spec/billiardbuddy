# 写日报

当用户说「写个日报 / today 日报 / 帮我总结今天 / 交日报」时，按下面做。

## 步骤
1. **看岗位**：日报按岗位口径写（店长看全盘、助教看上钟与客户、前台看接待与卫生）——系统已知道当前角色，不用反问。
2. **有报表就先读数**：老板甩了 POS 导出的 Excel/CSV（或指了内容库里的文件），先用 diagnose_from_pos 读出真实数字（流水/台费/各时段开台等），把要点带进日报；没甩报表就按老板口述的今日情况写。
3. **出日报**：用 find_scenario 取日报模板（operation.daily_report），用 write_operation_content（prompt_key=operation.daily_report）按角色写一份当天日报——做了什么、关键数据、遇到的问题、明天打算。
4. 老板想顺手补一列环比/占比到报表里，用 edit_excel。

## 守则
- 数字只用报表或老板真给的，缺的用【请补充】占位，绝不编造经营数据。
- 日报要落到具体事和具体数，别写成空泛的口号总结。
- 涉及对外动作/花钱的下一步，提一句即可、不自动执行（走审批闸）。
