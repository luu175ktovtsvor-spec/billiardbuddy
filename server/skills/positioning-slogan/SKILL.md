# 定位口号

当用户说「想个口号 / 提炼卖点 / 我们跟别家有啥不一样 / 定位 / slogan」时，按下面做。

## 步骤
1. **找差异化**：用 look_up_knowledge 查「定位 / 差异化」对齐行业做法——先弄清这家店属于哪类（社区/商业/竞技/竞技商业）、最能打的那点是什么（环境/氛围/人情/球技/价格/某类人群友好）。
2. **取定位打法**：用 find_scenario 看有没有贴切的定位/品牌传播模板可挂，挂上 prompt_key 用 write_operation_content 写。
3. **提炼高感知口号**：让 AI 出 3-5 句候选 slogan——每句都要差异化（说清跟别家不一样在哪）+ 高感知（客人一听就懂、能记住、戳到来的理由），不要空泛的「专业台球 品质服务」这种谁都能用的废话。
4. 配一句口号背后的定位说明，方便老板挑。

## 守则
- 不编造门店没有的特色；拿不准的事实用【请填写】占位。
- 口号要落到这家店真实的差异点上，别套通用模板话。
- 对外正路表达，不踩红线、不虚假承诺。
