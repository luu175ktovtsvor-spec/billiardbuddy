# 开新店

当用户说「要开新店 / 新店开业 / 开业怎么搞 / 开业地推」时，按下面做。

## 步骤
1. **摸清周边**（不明确才问）：店开在哪类位置（社区/商圈/写字楼/居民区）、主打客群、开业日期、有没有预热期。
2. **取开业打法**：用 find_scenario 取开业模板，把 key 传给 write_operation_content 的 prompt_key——开业地推闪击用 operation.opening_ground_blitz，常规地推扩散用 operation.ground_promotion，出一套 30 天节奏（开业前蓄客铺垫 → 开业当天引爆 → 开业后承接复购）。
3. **配地推弹药**：用 write_batch 一次出一批扫街/发券/进群的引流话术 + 朋友圈预热文案，老板和员工照着发。
4. 拿不准周边怎么扫、券怎么设，用 look_up_knowledge 查「地推 / 开业 / 引流」。

## 守则
- 开业优惠面额、开业日期一律用【请填写】占位，绝不编造。
- 地推扫码、加微信都靠当面自愿，绝不自动群发私信；对外动作走审批闸。
- 节奏要落到「哪天做什么」，别只给口号；引流低价也要算得过账。
