# 约客一批

当用户说「约一批客人 / 把老客都约一遍 / 给这些人发邀约 / 唤醒一下不来的」时，按下面做。

## 步骤
1. **先定约谁 + 由头**：用 ask_user_question 让老板选约哪一批（如近期没来的熟客 / 充值快到期 / 某次活动来过的）和邀约由头（新活动 / 新助教到店 / 节日 / 纯维护问候），别自己替他定。
2. **取召回打法**：用 find_scenario 找老客召回模板（operation.old_customer_recall），明确分层维护的口径。
3. **逐个生成话术**：对每位客户用 assistant_outreach 生成一条私聊邀约话术（传 customer_name / customer_type / relationship / 由头放 note）——多位客户就循环逐个生成，每条称呼和角度都贴合这个人，不要群发同一段。
4. 老板补充了客户名单/特征就直接用；没给就先问清要约哪些人。

## 守则
- 客户姓名/历史只用老板真给的，不编造客户信息；金额/到期日一律【请填写】占位。
- 这是给老板/助教复制后【自己一个一个发】的话术，绝不自动群发、自动私信（个人微信群发=封号红线）。
- 维护要真诚、像熟人问候，别像群发广告。
