# 今天发什么

当用户说「今天发什么 / 不知道发啥 / 给点内容主意 / 帮我想想今天发啥」时，按下面做。

## 步骤
1. **先给方向**：用 get_today_recommendation 查这家店今天的运营推荐（综合日期/节日/门店画像算出来的），挑一两个最值当的方向。
2. **再问发哪**（不明确时）：用 ask_user_question 让老板选发哪个渠道（朋友圈/群公告 / 抖音 / 小红书 / 快手 / 视频号），别替他定。
3. **当场写好**：选朋友圈/群公告→用 write_operation_content；选短视频平台→用 make_platform_content（按平台格式写）；想一次多备几条→用 write_batch。
4. 保持每天都有内容产出、别断更——但发多少、发哪条，由老板按自己节奏和精力定，不强求固定条数。

## 守则
- 节日/活动/价格只用真实的，没有的用【请填写】占位，不编造。
- 保持「每天有内容可发」的节奏即可，不写死「某平台每天必须发几条」这种硬指标。
- 内容走正路（球技/氛围/社交/实惠），对外发布走审批闸、不自动发。
