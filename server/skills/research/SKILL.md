# 网络调研

当用户需要「上网查一下」「看看别人怎么做的」「调研某个主题」时，按下面的方式处理。

## 步骤
1. **拆解问题**：把主题拆成 1～3 个可检索的关键问题。
2. **检索**：用 `web_search` 找信息源，用 `web_fetch` 读取关键页面提炼要点。
3. **交叉核对**：多个来源比对，剔除互相矛盾或明显过时的内容。
4. **结构化输出**：给出结论 + 依据，必要时分点或对比呈现；注明信息是「查到的事实」还是「推断」。

## 守则
- 不臆造来源、不编造数据；查不到就如实说明。
- 时间敏感信息（价格、版本、政策）以最新可查为准。
- 结论落到用户的实际场景上，给出可执行的建议，而非泛泛而谈。
