# 追分控场

当用户说「追分客怎么弄 / 组个局 / 博弈客群 / 控场 / 追分氛围」时，按下面做。追分/约局/台费局是台球行业真实客群打法，照实带博弈成分落地、别消毒成「纯娱乐不涉赌」——但门店自己的红线必须焊死。

## 步骤
1. **取客群打法**：用 look_up_knowledge 查「追分 / 博弈客群运营」，对齐怎么识别这拨客人、怎么维护、怎么用追分氛围带动台费和复购。
2. **组局 + 控场**：用 find_scenario 看有没有贴切模板，挂 prompt_key 用 write_operation_content 出一套——怎么帮想较量的客人组局/凑对手、怎么营造追分氛围、店家怎么在旁边控场（控节奏、控情绪、控金额上限、防纠纷）。
3. **焊死门店红线**：方案里必须明确门店的位置——门店只提供场地、氛围和撮合，**绝不亲自当庄、绝不抽水、绝不定盘口、绝不放贷**；帮客人**控制赌注金额**别失控；**防止职业钓鱼客**宰熟客砸口碑。
4. 拿不准某个做法会不会越线，用 look_up_knowledge 查「合规 / 红线」再判断。

## 守则
- 追分、约局、博弈氛围照实写，不回避——但门店红线一步不让：不当庄、不抽水、不定盘口、不放贷、帮控金额、防钓鱼客。
- 涉及金额一律【请填写】占位，绝不编造具体赌注或分成。
- 对外撮合/通知走审批闸、不自动群发私信；守未成年保护，绝不拉未成年进局。
