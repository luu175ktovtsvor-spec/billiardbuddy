# 上钟服务

当用户说「上钟流程 / 助教怎么服务 / 陪打技巧 / 迎宾送客 / 助教服务 SOP」时，按下面做。

## 步骤
1. **取服务 SOP**：用 look_up_knowledge 查「助教服务 / 上钟」，对齐迎宾 → 上钟陪打 → 送客这条完整服务链路的行业做法。
2. **理服务流程**：用 find_scenario 取助教服务模板，挂 prompt_key 用 write_operation_content 出一套上钟 SOP——
   - 迎宾：怎么接、怎么破冰、怎么让客人放松；
   - 上钟：陪打陪练的技巧、怎么照顾不同水平、怎么营造氛围和情绪价值、怎么自然引导续钟；
   - 送客：怎么收尾、怎么留好印象、怎么约下次。
3. **配培训用法**：可结合上一步输出当新助教培训材料用。

## 守则
- 助教信息/客户信息未知的用占位符，不瞎编。
- 陪打、情绪价值、暧昧感这些内行服务点照实写、不消毒——但守红线：助教是台球陪打陪练增值服务，自爱不越界，绝不营销实际性交易、不出台包夜。
- 续钟靠服务体验自然引导，不强迫不欺客。
