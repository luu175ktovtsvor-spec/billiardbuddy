# 上套餐

当用户说「上个套餐 / 做个团购 / 弄个引流低价 / 写团购套餐」时，按下面做。

## 步骤
1. **问清套餐方向**（不明确才问）：面向谁（情侣/朋友开黑/家庭/新人）、什么场景时段、走哪个平台（美团/抖音团购）、是引流低价还是正价划算。
2. **取团购打法**：拿不准定价结构/核销规则时，用 look_up_knowledge 查「团购套餐 / 引流低价」对齐行业做法。
3. **生成套餐文案**：用 make_groupbuy_content（传 need + platform）出一套可直接上架的套餐——标题（带数字+时段标签）、卖点（点名人群场景）、包含内容清单、使用规则（有效期/适用时段/是否预约/不可拆分/超时补差/到店核销）+ 一条引流钩子。
4. 写好后告诉老板去对应商家后台（美团开店宝 / 抖音来客）自己上架。

## 守则
- 价格只用门店真实价格，没有就留【请填写】占位让老板填，绝不自己编价。
- 我们只写文案、引导上架，不替老板上架、不碰核销、不接服务商 API。
- 引流低价也要算得过账，别写「免费畅打/终身免费」这类无底线让利。
