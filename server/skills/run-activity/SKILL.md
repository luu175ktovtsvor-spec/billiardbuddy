# 办活动

当用户说「办个活动 / 搞个主题局 / 做会员日 / 节日搞一波 / 搞场搭子局」时，按下面做。（要办**比赛**请走「办比赛」。）

## 步骤
1. **定活动目标**：用 ask_user_question 让老板选这场活动主要图啥——拉人气 / 卖会员卡 / 老客回流 / 搭子群活跃 / 会员日 / 节日营销，或者**「产品自拟」**（让 AI 按门店当下情况自己判断最合适的目标）。别替他硬定。
2. **取活动打法**：用 find_scenario 看有没有贴切的活动精修模板可挂。
3. **出整套方案**：用 plan_activity（把上一步选的目标传给 goal，自拟则按门店画像挑最合适的；need 放老板原话，可带 target/budget/duration），出一套成体系方案——玩法机制、优惠力度、时间安排、传播话术、落地步骤。
4. **配预热弹药**：用 write_batch 一次出一批活动预热朋友圈 + 一条群公告，老板照着发。

## 守则
- 优惠金额、奖品、日期一律用【请填写】占位，绝不编造。
- 对外预热/发布走审批闸、不自动群发私信；内容走正路。
- 活动要有巧思、能落地执行，别只给一句口号。
