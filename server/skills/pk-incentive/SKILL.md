# 配PK激励

当用户说「搞个 PK / 助教激励 / 让团队卷起来 / 配奖励机制 / 业绩比拼」时，按下面做。

## 步骤
1. **取激励机制**：用 look_up_knowledge 查「PK激励 / 助教奖励」，把行业里成熟的 PK 机制和奖励档位（**硬数字以知识库为准，别自己拍**）取出来作为依据。
2. **定 PK 方向**：明确给谁配（助教个人 / 班组 / 全店）、比什么（上钟数 / 拉新 / 复购 / 好评），周期多长。
3. **出激励方案**：用 find_scenario 取 PK 模板，挂 prompt_key 用 write_operation_content（如 operation.manager_pk_plan）出一套——PK 规则（比什么、怎么计分、排名怎么定）+ 奖励设置（档位引用知识库的硬数字）+ 怎么营造比拼氛围（榜单/喊话/仪式感）。
4. 配一条 PK 启动的内部动员话术。

## 守则
- PK 规则里的硬数字（计分/档位）引用知识库口径；门店要自定的奖金面额用【请填写】占位，不替老板编。
- 激励靠正向比拼和荣誉感，不搞恶性内耗、不克扣应得。
- 涉及对外/花钱的动作走审批闸、不自动执行。
