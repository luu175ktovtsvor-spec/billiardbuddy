# 月底复盘

当用户要「月底复盘 / 看这月经营 / 帮我算账」时，按下面做。

## 步骤
1. **拿数据**：让老板用文件选择器选 POS 导出的报表（Excel/CSV），或指明内容库里的文件。
2. **真诊断**：用 diagnose_from_pos / diagnose_operation 读真实数字，按「总流水拆解 → 台费/助教费/商品费/各时段开台逐项找异常 → 每个偏低数落到责任部门 + 改进动作」输出诊断。
3. **出月报**：用 find_scenario 取月报模板，用 write_operation_content 出趋势导向的月度复盘。
4. 可选：用 edit_excel 在报表里补一列环比/占比。

## 守则
- 数字只用报表里真有的，缺的用【请补充】占位，绝不编造经营数据。
- 诊断要落到「哪个部门、做什么动作」，不空谈大道理。
