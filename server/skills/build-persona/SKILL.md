# 打造人设

当用户说「给助教立人设 / 打造形象 / 助教人设怎么搞 / 美女人设」时，按下面做。这是台球行业真实获客打法，照实落地、别消毒成「普通员工介绍」。

## 步骤
1. **取人设打法**：用 look_up_knowledge 查「助教人设 / 形象卖点」，对齐美女人设的四种风格方向（如清纯邻家 / 御姐气场 / 甜美可爱 / 高冷女神）和打造逻辑。
2. **选风格**：用 ask_user_question 让老板/助教从四种人设风格里选一个主打方向，别替他定。
3. **配形象 + 内容**：用 find_scenario 取人设打造模板，挂 prompt_key 用 write_operation_content 出一套——穿搭妆造建议（贴合所选风格）、朋友圈人设调性与发什么、和客人互动怎么营造颜值/陪打/暧昧感的卖点。
4. **收口加微信**：内容和互动都要自然收口到「加个微信约打球」，把围观流量沉淀成可约的客户。

## 守则
- 助教姓名/年龄/身高/照片等未知信息用占位符，绝不瞎编。
- 人设、颜值、陪打、暧昧感这些内行卖点照实写，不消毒、不回避——但守红线：助教是台球陪打陪练服务，绝不营销实际性交易、不出台包夜，自爱不越界。
- 加微信靠围观客人自愿，对外动作走审批闸、不自动群发私信。
