# 涨价不炸店

当用户说「想涨价 / 台费太低想提 / 涨价怕老客跑 / 怎么涨不炸店」时，按下面做。

## 步骤
1. **先确认底气**：涨价的前提是体验/口碑已经改善——用 look_up_knowledge 查「涨价 / 分区涨价」对齐分时段、分区域、分人群软着陆的行业做法（别一刀切全店硬涨）。
2. **出涨价方案**：用 find_scenario 取涨价模板，把 key 传给 write_operation_content 的 prompt_key（operation.pricing_design），出一套分区软着陆方案——先涨哪块（高峰/夜场先动、闲时保留低价）、节奏怎么排、老客怎么过渡（老价保护期/会员锁价）。
3. **配对外说法**：用 write_operation_content 出对会员/老客的告知话术——把涨价讲成「升级了什么、保留了什么优待」，减少抵触。
4. 需要顺手算调价前后台费占比变化，用 diagnose_from_pos 读真实报表辅助决策。

## 守则
- 具体涨价金额、新价、保护期日期一律用【请填写】占位，绝不替老板拍价格。
- 对外告知走审批闸、不自动群发私信；老客过渡要给足缓冲，别硬涨炸店。
- 只给软着陆结构和话术，价格高低由老板按自家成本拍板。
