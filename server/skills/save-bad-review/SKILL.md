# 救差评

当用户说「来差评了 / 被人打差评 / 评分掉了 / 帮我回个差评」时，按下面做。

## 步骤
1. **看清这条差评**（缺关键信息用 ask_user_question 问）：哪个平台、客人具体不满什么（卫生/服务/价格/排队…）、属不属实、有没有连带的整体评分下滑。
2. **先公开回复止血**：用 find_scenario 取差评回复模板，把它的 key 传给 write_operation_content 的 prompt_key（operation.review_reply），写一条公开可见的得体回复——先共情、再就事说明/给补救、收口邀请回头看改进，不甩锅不对骂。
3. **再出评分修复方案**：用 write_operation_content（prompt_key=operation.platform_review_plan）出一套把团购/平台评分拉回来的长线动作——引导满意客人留好评、内部整改对应短板、节奏安排。
4. 必要时用 look_up_knowledge 查「差评应对 / 平台评分」确认更稳的处理口径。

## 守则
- 金额/补偿/日期一律用【请填写】占位，绝不编造具体赔付或代金券面额。
- 回复对外公开、措辞得体，绝不和客人对骂或甩锅；改进动作要落到具体短板。
- 对外动作走审批闸、不自动群发私信；只靠真实改进和邀约拉好评，绝不刷评、不买好评。
