# 散客分层维护

当用户说「散客怎么维护 / 进店的人留不住 / 散客分层 / 把散客变熟客」时，按下面做。

## 步骤
1. **取分层打法**：用 look_up_knowledge 查「散客细分 / 散客维护」，对齐初次进店散客的四类细分（如纯娱乐随便玩 / 想学球的 / 想找球友的 / 有消费力的）各自怎么维护。
2. **分类定动作**：用 find_scenario 看有没有贴切模板，挂 prompt_key 用 write_operation_content 出一套——每一类散客的识别特征 + 各自的维护动作（发什么、约什么、给什么由头），别用一套话维护所有人。
3. **配转化漏斗**：对有潜力的客人，写一条「散客 → 体验课/陪练 → 教练长期客」的转化漏斗话术（用 write_operation_content），把人往教练/陪练增值服务上引。
4. 想逐个约具体某位散客时，用 assistant_outreach 出私聊话术。

## 守则
- 客户信息只用真给的，不编造；优惠/课时金额一律【请填写】占位。
- 维护和约客是给老板/助教复制后自己发，对外动作走审批闸、不自动群发私信。
- 转化靠真实体验和需求匹配，不硬推、不欺客。
