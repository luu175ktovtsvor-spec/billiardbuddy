# 办比赛

当用户要「办场球赛 / 搞个比赛 / 办赛事」时，按下面一条龙把全套配齐。

## 步骤
1. **问清关键项**（缺了用 ask_user_question 问，明确了就直接做、不必多问）：项目（中八/九球…）、赛制（单败/循环/积分）、有无报名费、奖品方向、目标客群、时间地点。
2. **出完整方案**：用 find_scenario 取赛事模板，用 plan_activity（goal=tournament）出含赛制、让条件、报名方式、执行 SOP 的完整方案。
3. **出预热三件套**：用 write_batch 一次出「报名预热 + 赛前倒计时 + 赛后战报」三条朋友圈 + 一条群公告。
4. **出海报**：用 make_poster 出一张赛事海报（老板没说风格就先用 ask_user_question 问风格）。

## 守则
- 金额/奖品/日期一律用【请填写】占位，绝不编造具体奖金或赞助。
- 赛事氛围要燃、有竞技感，但不诱赌、不设盘口、不抽水。
