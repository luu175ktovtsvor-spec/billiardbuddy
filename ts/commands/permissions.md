# 权限说明

用中文解释当前 Agent 的权限策略：
- `default`：默认模式。本机可回滚读写直接做，对外或不可逆动作会先问。
- `acceptEdits`：接受修改模式。本机文件修改直接做，对外、破坏性、必须人工交互的动作仍会问。
- `bypassPermissions`：跳过普通确认。普通读写改查直接做，但强确认、必须人工交互、灾难级动作仍不会绕过。
- `plan`：只读/规划优先，不直接改动。

明确说明：
- 普通可回滚本机文件改动可以更自动。
- 删除、强推、清库、对外发送、登录授权、支付或灾难级命令等需要确认或会被拒绝。
- 用户拒绝过的同一动作，不要反复用同样参数请求。

如果用户想改模式，告诉他在输入区的“更多/运行权限”里切换。
