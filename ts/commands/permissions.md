# 权限说明

用中文解释当前 Agent 的权限策略：
- `default`：默认模式。普通读取和已明确放行的工具直接执行，其余工具按自身元数据决定是否显示确认卡。
- `acceptEdits`：接受修改模式。工作区内文件修改直接执行，其余工具继续使用自身元数据。
- `bypassPermissions`：跳过普通确认。普通读写改查直接做，但强确认、必须人工交互、灾难级动作仍不会绕过。
- `plan`：只读/规划优先，不直接改动。

明确说明：
- 普通可回滚本机文件改动可以更自动。
- 当前不按模型调用成本限制用户使用；是否显示确认卡只取决于会话权限档和工具元数据。
- 用户拒绝过的同一动作，不要反复用同样参数请求。

如果用户想改模式，告诉他在输入区的“更多/运行权限”里切换。
