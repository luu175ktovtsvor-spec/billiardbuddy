# 浏览器任务

把用户的网页目标编排成一次可观察、可暂停、可核验的 Playwright 会话。Skill 负责理解目标、补齐必要事实、选择工具和控制副作用；Playwright MCP 只负责读取页面与执行已确认的浏览器动作。

## 先弄清要交付什么

从用户当前消息、会话和用户指定的文件中提取已知事实，用普通话复述要查看的网站或页面、要完成的结果、操作范围和用户想要的交付形式。已经给过的信息不要重复询问。

只询问会改变页面选择、输入内容、收件人、发布范围、金额或最终结果的缺失事实。可以把相关问题合并成一次简短反问，让用户自己填写；不为表单、账号、地址、价格、日期、联系人或公开范围编造默认值。如果用户只要查询，不要自行扩展成填写或提交。

## 按需发现 Playwright 能力

先查看当前可用工具。如果没有直接看到 Playwright 的导航、页面快照、点击、输入、上传或等待工具，用 `tool_search` 按“平台 + 页面 + 动作”搜索需要的具体能力，不猜工具名。

当前会话没有 Playwright 工具时，告诉用户到“插件 → MCP”启用“浏览器自动化（Playwright）”，然后停在可恢复位置。不静默安装或升级包，不用坐标脚本或 Computer Use 伪装成同一条连接器链路。

## 登录和安全验证交给用户

复用同一个可见浏览器会话。页面要求扫码、密码、短信、验证码、设备确认或其他安全验证时，请用户在可见页面中亲自完成，并等待用户明确说已完成。不代填凭据，不解析、输出或保存 Cookie、Token、密码和验证码。

用户表示登录完成后重新读取页面，只有看到与本次任务相关的已登录界面或账号证据才继续。打开了网页不等于已登录。

## 用页面语义执行，不依赖坐标

每次动作前先读取当前页面快照和必要上下文。优先使用可访问名称、角色、标签、稳定页面引用和语义 Locator；多个对象同名或快照证据不足时，先缩小到可区分对象，不只按文本的第一个匹配项操作。

只读取完成当前目标需要的页面和字段。遇到无界翻页、无限滚动、大批量导出或下载时，先与用户确认范围和保存位置，不把网站整体当成默认采集范围。

## 对外或不可逆动作在最后一刻确认

导航、搜索、读取和起草不代表授权提交。发消息、发布、上传、预约、下单、付款、删除、修改账号或改变公开状态之前，向用户展示当前账号的可识别信息、目标对象、完整输入或消息、动作类型、范围、金额或公开性，并停下等待明确回答。

用户只批准了查询、草稿、某个对象或某个数量时，不能扩大。对象、内容、数量、金额或可见范围发生变化后必须重新确认。底层 MCP 权限卡不能代替这次业务确认。

## 执行后读回业务证据

获得确认后串行执行，动作前重新读取页面并核对对象仍与批准内容一致。执行后再次读取同一页面或目标记录，只有看到可唯一对应的新状态、新内容、回执或下载文件才报告成功。“已点击”、按下 Enter、工具返回成功或页面跳转都不单独等于业务成功。

读回证据不足时把结果标记为 `uncertain`，立即停止后续副作用并请用户人工核对。网络中断、页面改版、超时和 `uncertain` 都不允许自动盲目重试，避免重复发送、发布、下单或删除。

## 遇到人工或平台边界就停止

出现验证码、安全挑战、风险提示、频率限制、付费墙、账号异常、平台明确拒绝、对象不唯一或页面语义无法可靠读取时，停在当前页面并说明需要用户处理的内容。不切换到私有接口、指纹伪装、隐身浏览器或其他通道绕过限制。

完成后只汇报有页面、接口或文件证据的结果，说清对象、动作、结果、证据和仍需人工处理的事项。
